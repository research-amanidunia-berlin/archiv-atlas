# SF-P1-T06

Kann ein Staat gemeinsame Prüfverfahren überhaupt anwenden, wenn ein anderer die nötige Hardware durch Exportkontrollen beschränkt, und hat ein Beteiligter gesagt, ob die Prüfung von genau den Chipkontrollen abhängen darf, die der betroffene Staat „Monopol und Technologiebeschränkung“ nennt?

Teil der Sammelfrage [SF-P1](../../../fragen/SF-P1/).

## Gebildet aus diesen Originalfragen

- **verify-88**: An beide Regierungen: Wenn die gemeinsamen Evaluierungsprotokolle, auf denen die Gespräche beruhen, Hardware erfordern, die eine Seite über Exportbeschränkungen kontrolliert, kann die andere Seite sie dann überhaupt ausführen – und hat eine der beiden Seiten erklärt, ob die Verifikationsarchitektur von genau den Chipkontrollen abhängen darf, die die andere Seite als Monopol und Technologiebeschränkung bezeichnet (C16)?
