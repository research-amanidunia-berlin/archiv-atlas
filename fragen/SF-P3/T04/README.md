# SF-P3-T04

Who audits the AI models that check other models, for prompts, versions and failure cases, and what independent audit shows that the model under test cannot manipulate them, especially if they come from the same model family? And if shared tests, severity levels and the triage of incident reports are drafted, run and summarised by language models, will each state accept a verification mechanism whose core components come from foreign labs?

Part of the collected question [SF-P3](../../../fragen/SF-P3/).

## Formed from these original questions

- **verify-83**: When a model’s cyber evaluations are run by an AI-assisted grader (e.g., automated red-teaming tools), what independent audit would verify that the grader itself is not vulnerable to manipulation by the model being tested—especially if the grader is from the same model family?
- **verify-49**: If the shared tests, severity levels and hotline triage end up being drafted, run and summarised by language models, who audits these checking models themselves — prompts, versions, failure cases — and is each side willing to accept a verification mechanism whose core components come from the other side's labs?
