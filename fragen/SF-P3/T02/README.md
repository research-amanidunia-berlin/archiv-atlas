# SF-P3-T02

Which independently verifiable commitments could governments ask their AI labs to publish, and what does independent verification look like when the proof that a model follows its intended goals and values comes only from the lab that trains it, and auditors see neither the model weights (the learned parameters) nor the training data?

Part of the collected question [SF-P3](../../../fragen/SF-P3/).
