# SF-H1-T01

Nach welchen gemeinsamen Kriterien sollen Regierungen die legitime Forschungsnutzung öffentlich zugänglicher KI-Ausgaben von einer Destillation unterscheiden, die die Sicherheitsinvestitionen eines anderen Landes systematisch unterläuft? Werden sie eine gemeinsame, enge Definition veröffentlichen, welche Nutzungen von Modellausgaben jede von ihnen als Verstoß wertet, und ein gemeinsames, überprüfbares Register geprüfter unerlaubter Versuche oder lizenzierter Destillation führen? Wie zeigt jede Regierung sonst, dass sie die Vereinbarung durchsetzt und den Vorwurf nicht nur gezielt einsetzt?

Teil der Sammelfrage [SF-H1](../../../fragen/SF-H1/).

## Gebildet aus diesen Originalfragen

- **origin-01**: Auf welche Kriterien sollten sich beide Regierungen einigen, um die legitime Nutzung öffentlich verfügbarer KI-Ausgaben für die Forschung von einer Modell-Destillation zu unterscheiden, die die Sicherheitsinvestitionen eines anderen Landes systematisch untergräbt?
- **origin-02**: Die Destillation führender US-amerikanischer oder chinesischer Modelle durch Labore im jeweils anderen Land ist jetzt Teil der Gespräche: Werden die beiden Regierungen eine gemeinsame, enge Definition veröffentlichen, welche Nutzungen von Modellausgaben (z. B. synthetische Daten für das Feintuning, das Abgreifen von Fähigkeitsbewertungen) jede von ihnen als Verstoß betrachtet, oder bleibt der Begriff eine einseitige Anschuldigung?
- **origin-25**: Wenn sich beide Regierungen auf eine gemeinsame Definition von unbefugter Destillation einigen (wie in origin-02 gefragt), werden sie dann auch ein gemeinsames, prüfbares Protokoll oder Register bestätigter unbefugter Versuche — oder lizenzierter, legitimer Destillation — führen, und wenn nicht, wie beweist dann eine der beiden Seiten, dass sie das Abkommen durchsetzt, statt den Vorwurf selektiv zu benutzen?
