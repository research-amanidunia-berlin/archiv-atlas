# SF-P2-T02

Before a verification arrangement between states builds on embedded evaluations, that is, on independent evaluators with ongoing, employee-like access inside AI companies, will the labs each commit that no embedded evaluation paid for by the lab being evaluated serves as evidence in that context? And will the governments treat lab-funded evaluation as insufficient per se for testing models for acute risks before release, so that the first embedded reports cannot quietly set a precedent?

Part of the collected question [SF-P2](../../../fragen/SF-P2/).

## Formed from these original questions

- **verify-85**: Accenture's embedded-evaluator engagement was announced 18 September with Anthropic "funding Accenture's work directly" and with "no standards for what information embedded evaluators should have access to, or how they should report what they find" (both Anthropic, 18 Sept, quoted in verify-21 and verify-22 evidence). Anthropic's own essay calls the funding problem open and points to pooled or government money long-term. Before any bilateral verification arrangement builds on this practice: will Anthropic and OpenAI each commit that no embedded evaluation used as evidence in a US–China context comes from an engagement funded by the lab being evaluated — and will both governments treat lab-funded evaluation as per se insufficient for Level 2 testing (P46), so that the first embedded reports cannot quietly set the precedent?
