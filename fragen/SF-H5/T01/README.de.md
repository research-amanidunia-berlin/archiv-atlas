# SF-H5-T01

Werden Staaten für jede Beschränkung fortgeschrittener Chips oder Anlagen den Sicherheitsgrund, die Dauer und das Prüfverfahren veröffentlichen, nach dem sie aufgehoben werden kann?

Teil der Sammelfrage [SF-H5](../../../fragen/SF-H5/).

## Gebildet aus diesen Originalfragen

- **transparency-09**: Wenn eine Regierung fortschrittliche Chips oder Ausrüstung aus Gründen der nationalen Sicherheit einschränkt, liest die andere Seite darin Monopol und Technologiebeschränkung; werden beide Seiten für jede Maßnahme den Sicherheitsgrund, die Dauer und die Überprüfung veröffentlichen, unter der sie aufgehoben werden kann, damit sich eine Sicherheitsmaßnahme von einem dauerhaften Vorteil unterscheiden lässt?
