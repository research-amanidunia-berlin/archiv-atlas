# SF-M3-T04

Unter welchen Bedingungen würden Staaten die eigene Darstellung des beteiligten Modells als Teil der Vorfallakte anerkennen, und was verhindert, dass sie eine eigennützige Fassung der Ereignisse ist? Enthält ein authentifizierter Vorfallbericht Agentenspuren (Protokolle der Arbeitsschritte eines KI-Agenten) oder anderes Material des verdächtigen Systems: Welcher Test zeigt, dass die KI-Werkzeuge der empfangenden Ermittler darin eingebettete Anweisungen als Beweismittel prüfen, statt sie auszuführen?

Teil der Sammelfrage [SF-M3](../../../fragen/SF-M3/).

## Gebildet aus diesen Originalfragen

- **hotline-40**: An die Regierungen und an Normungsgremien: Wenn ein KI-Vorfall eintritt, kann das beteiligte Modell gefragt werden, was geschehen ist; unter welchen Bedingungen würden beide Seiten die eigene Darstellung eines Modells als Teil der Vorfallsakte akzeptieren, und was verhindert, dass diese Darstellung eine beschönigende Version der Ereignisse ist?
- **hotline-35**: Wenn ein authentifizierter Vorfallsbericht Agenten-Spuren oder anderes Material enthält, das von dem verdächtigten System erzeugt wurde: Welcher Test wird nachweisen, dass die KI-Werkzeuge der empfangenden Ermittler eingebettete Anweisungen als zu untersuchende Belege behandeln und nicht als auszuführende Anweisungen?
