# SF-F1-T04

Welcher gemeinsame, neutrale und offene Maßstab (Aufgaben, Erfolgsrate, abgeschirmte Testumgebung, Belege) zeigt, dass eine Cyber-Schwelle überschritten ist? Würden ein Ministerium und ein Labor in verschiedenen Staaten ihn annehmen, bevor das nächste Modell als Überschreitung eingestuft wird, damit Schwellen gemessen und nicht behauptet werden? Und dient derselbe Maßstab dann sowohl dazu, ein Modell einzustufen, als auch dazu, das Tempo seiner Entwicklung zu steuern?

Teil der Sammelfrage [SF-F1](../../../fragen/SF-F1/).

## Gebildet aus diesen Originalfragen

- **cyber-14**: Welcher Maßstab sollte für die Behauptung gelten, dass Mythos und GPT-5.5-Cyber eine überschrittene Schwelle der Cyber-Fähigkeit markieren (C14), und würden ein Ministerium und ein Labor auf entgegengesetzten Seiten ihn beide akzeptieren?
- **cyber-15**: Können sich die Aufsichtsbehörden beider Seiten auf einen neutralen Benchmark für Cyber-Bewertungen einigen, damit „KI gegen KI“ (C14) ein gemeinsames Testfeld wird und keine Frontlinie?
- **cyber-16**: Einigen Sie sich auf einen minimalen offenen Standard für Tests offensiver Cyber-Fähigkeit, damit Schwellen zu Messungen werden?
- **cyber-17**: Welche gemeinsame Definition einer Cyber-Fähigkeitsschwelle – Aufgaben, Erfolgsquote, Sandbox – sollten beide übernehmen, damit das Benennen eines Modells und das Festlegen seines Tempos dieselbe Skala nutzen?
- **cyber-18**: Könnten sich die Aufsichtsbehörden beider Seiten darauf einigen, welche Belege – welche Tests, welche Kennzahlen – beweisen, dass eine Cyber-Schwelle überschritten ist, bevor das nächste Modell benannt wird?
