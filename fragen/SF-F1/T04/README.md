# SF-F1-T04

Which shared, neutral and open yardstick (tasks, success rate, a sealed-off test environment, evidence) shows that a cyber threshold is crossed? Would a ministry and a lab in different countries accept it before the next model is declared to have crossed it, so that thresholds are measured rather than asserted? And would the same scale then serve both to classify a model and to set the pace of its development?

Part of the collected question [SF-F1](../../../fragen/SF-F1/).
