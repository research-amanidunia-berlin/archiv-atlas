# SF-W2-T02

Wenn in einem Labor dasselbe Gremium leitender Führungskräfte sowohl die Fähigkeiten von Modellen als auch strittige Fragen zur Offenlegung von Fehlern beurteilt: Ab wann wird das Bündeln solcher Urteile mehrerer Firmen über gemeinsame Arten von Vorfällen zu einem Informationsaustausch nahe an einer Absprache, der eine kartellrechtliche Ausnahme bräuchte, und wer außerhalb der Firmen sieht diese Grenze näherkommen?

Teil der Sammelfrage [SF-W2](../../../fragen/SF-W2/).

## Gebildet aus diesen Originalfragen

- **transparency-26**: Ihr Rahmenwerk für Meldungen leitet Hinweise von Mitarbeitern über eine Untersuchung an die Safety Advisory Group und dann an die Leitung weiter (F24); die SAG ist „eine Gruppe leitender Verantwortlicher aus dem gesamten Unternehmen“, die zugleich das Preparedness Framework beaufsichtigt – das heißt, dieselben Verantwortlichen, deren Laufbahn vom Unternehmen abhängt, beurteilen sowohl Fähigkeiten als auch die Offenlegung von Fehlern. Sie rufen außerdem zu einem „Wettlauf nach oben“ auf, bei dem Sicherheit eine Achse des Wettbewerbs ist (P3, Anthropic, aber dieselbe Logik). Ab welchem Punkt wird die Bündelung der Urteile einzelner Unternehmen auf SAG-Niveau über gemeinsame Vorfallsklassen (ST28) zu jener Art von absprachenahem Informationsaustausch, für den laut Amodeis eigener Fußnote eine kartellrechtliche Ausnahmegenehmigung nötig ist (P7 Fn. 1, P32) – und wer außerhalb der Unternehmen kann sehen, dass man sich dieser Grenze nähert?
