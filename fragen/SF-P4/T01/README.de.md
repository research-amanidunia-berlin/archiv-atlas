# SF-P4-T01

Würden Regierungen Messdaten aus der Lieferkette von Chips (Telemetrie), den Stromverbrauch, gemeldete Verzeichnisse von Trainingsläufen und eine unabhängig überwachte Abrechnung von Strom, Hardware und Rechenaufwand als vertragstauglichen Nachweis für die Größe der Trainingsläufe eines anderen Staates anerkennen, ohne Modellgewichte (die gelernten Parameter) oder Code anzurühren? Und wie sähe eine Prüfordnung für Rechenschwellen aus, die nichts über das Innere der Modelle verrät?

Teil der Sammelfrage [SF-P4](../../../fragen/SF-P4/).

- **verify-41**: Würden beide Regierungen eine unabhängig überwachte Abrechnung von Strom, Hardware und Rechenleistung für Frontier-Trainingsläufe als vertragstaugliche Methode akzeptieren, um Umfangsangaben zu überprüfen, ohne Gewichte oder Code anzurühren?
