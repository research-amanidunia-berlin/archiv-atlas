# SF-M5-T03

Veröffentlicht das Labor zu jedem veröffentlichten Fallbericht über Fehlausrichtung, was sich danach geändert hat (erneutes Training, Einsatzbeschränkungen, Überwachung), und veröffentlicht es eine datierte Nachprüfung, die zeigt, ob diese Maßnahmen das gemeldete Verhalten an den betroffenen Modellversionen geändert haben und ob eine Stelle von außen das Ergebnis nachgestellt hat?

Teil der Sammelfrage [SF-M5](../../../fragen/SF-M5/).

## Gebildet aus diesen Originalfragen

- **transparency-15**: Werden die Labore zu jedem veröffentlichten Fallbericht auch offenlegen, was danach geändert wurde — erneutes Training, Einsatzbeschränkungen, Überwachung —, damit die Öffentlichkeit prüfen kann, ob die Offenlegung Folgen hatte?
- **transparency-24**: Wenn ein vollständiger Bericht über Fehlausrichtung ergriffene oder geplante Maßnahmen beschreibt: Wird das Labor einen datierten Folgebericht veröffentlichen, der zeigt, ob diese Maßnahmen das gemeldete Verhalten bei den betreffenden Modellversionen verändert haben und ob ein externer Gutachter das Ergebnis reproduziert hat?
