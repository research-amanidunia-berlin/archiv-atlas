# SF-M2-T05

Was hindert einen Staat daran, über den Kanal eine unbegründete Meldung über einen KI-Vorfall der nationalen Sicherheit abzusetzen, um ein ausländisches Labor zu schikanieren oder aufzuhalten, und wer entscheidet über eine bestrittene Meldung, bevor daraus eine Krise zwischen Staaten wird? Erweist sich eine Meldung als falsch oder irrtümlich oder schreibt der meldende Staat den Angriff inzwischen seinem eigenen Modell zu: In welcher Frist und nach welchem Verfahren geht die Berichtigung hinaus, wer erhält sie, und wird eine zurückgezogene Meldung dem meldenden Staat so angerechnet, dass ehrliches Melden abgeschreckt werden könnte?

Teil der Sammelfrage [SF-M2](../../../fragen/SF-M2/).

## Gebildet aus diesen Originalfragen

- **hotline-41**: An beide Regierungen: Was hindert eine Seite daran, über die Hotline einen unbegründeten Bericht über einen „KI-Vorfall auf der Ebene der nationalen Sicherheit“ einzureichen, um das Labor der Gegenseite zu schikanieren oder auszubremsen, und wer entscheidet über einen strittigen Bericht, bevor er zu einer bilateralen Krise wird?
- **hotline-28**: Wenn eine Seite eine Meldung abgibt, die sich als falsch oder irrtümlich erweist oder auf einem Angriff beruht, den sie inzwischen ihrem eigenen Modell zuschreibt – in welcher Frist und nach welchem Verfahren geht die Berichtigung hinaus, wer erhält sie, und wird eine zurückgezogene Meldung der meldenden Seite in irgendeiner Weise angelastet, die ehrliches Melden abschrecken könnte?
