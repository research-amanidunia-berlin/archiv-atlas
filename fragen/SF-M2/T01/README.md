# SF-M2-T01

Who receives a report in each state, and is it only a notification, or does it place a government under a standing obligation to act? Will the states publish a joint communiqué that sets out the competent authority in each state, the incident classes and severity levels that require notification, an encrypted and authenticated channel with receipt acknowledgment, and the maximum time from detection to notification?
