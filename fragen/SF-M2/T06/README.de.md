# SF-M2-T06

Wie wird Melden günstiger als Schweigen, und verpflichtet sich jeder Staat zu melden, auch wenn eine Meldung offenlegt, was er erkennen kann? Verpflichtet sich jeder Staat zu einer Mindestfähigkeit zum Erkennen und Melden für seine Betreiber kritischer Infrastruktur, und wer legt diese fest, stattet sie aus und prüft sie, bevor der Kanal als betriebsbereit erklärt wird?

Teil der Sammelfrage [SF-M2](../../../fragen/SF-M2/).

## Gebildet aus diesen Originalfragen

- **hotline-19**: Ein Hotline-Bericht kann offenlegen, was die meldende Seite erkennen kann. Wenn das teuer ist, könnte eine Seite über einen Vorfall schweigen, den sie gesehen hat. Wie macht die Hotline das Melden zur günstigeren Wahl — und wird sich jede Seite verpflichten zu melden, selbst wenn der Bericht eine ihrer Erkennungsfähigkeiten offenlegt?
- **hotline-32**: Eine Hotline kann nur Vorfälle melden, die jemand entdeckt. Chinas Aufsichtsplattform (C22) und die sicheren Kanäle, die für Betreiber kritischer Infrastruktur und für Regierungen vorgeschlagen werden (ST29), setzen voraus, dass die Betreiber KI-gesteuerte Angriffe erkennen können. Wird sich jede Seite auf eine Mindestfähigkeit zum Erkennen und Melden bei ihren Betreibern kritischer Infrastruktur verpflichten – wer legt sie fest, stattet sie aus und prüft sie –, bevor der Mechanismus für einsatzbereit erklärt wird?
