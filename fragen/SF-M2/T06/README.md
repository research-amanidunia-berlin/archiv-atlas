# SF-M2-T06

How is reporting made cheaper than silence, and will each state commit to report even when a report reveals what it can detect? Will each state commit to a minimum detection-and-reporting capacity for its critical-infrastructure operators, and who sets, equips and audits it before the channel is declared operational?

Part of the collected question [SF-M2](../../../fragen/SF-M2/).

## Formed from these original questions

- **hotline-19**: A hotline report can reveal what the reporting side is able to detect. If that is costly, a side may stay silent about an incident it has seen. How will the hotline make reporting the cheaper choice — and will each side commit to report even when the report exposes one of its detection capabilities?
- **hotline-32**: A hotline can only report incidents that someone detects. China's supervision platform (C22) and the secure channels proposed for critical infrastructure operators and governments (ST29) presume operators can see AI-driven attacks. Will each side commit to a minimum detection-and-reporting capacity for its critical-infrastructure operators — who sets, equips and audits it — before the mechanism is declared operational?
