# SF-T2-T01

What public, checkable act would count as withholding further scaling, rather than a mere announcement? What would a lab have to publish so that a rival government can confirm that a pause actually happened, and what retrospective evidence would show that no capability gains were held in reserve, such as undisclosed changes in inference-time compute or tool access, or undisclosed model swaps?
