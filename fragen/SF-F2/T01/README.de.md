# SF-F2-T01

Wenn ein Ministerium ein Modell als Beleg nennt, dass eine Schwelle überschritten ist: Veröffentlicht das Ministerium die Tests, die Modellversion und was es gemessen hat, und veröffentlicht das Labor die Cyber-Prüfung dieser Version auch in der Sprache des Ministeriums? Und welches Ergebnis würde das Ministerium dazu bringen, seine Behauptung zurückzunehmen?

Teil der Sammelfrage [SF-F2](../../../fragen/SF-F2/).

## Gebildet aus diesen Originalfragen

- **cyber-11**: Wenn ein amtliches Dokument ein Modell als Beweis dafür nennt, dass eine Schwelle überschritten ist, veröffentlichen Sie dann die Tests und die Version dahinter, damit die Benennung überprüfbar wird?
- **cyber-12**: Wenn ein Ministerium ein Modell als Zeichen für eine überschrittene Schwelle nennt: Würde es veröffentlichen, was es gemessen hat und welches Ergebnis es zur Rücknahme der Behauptung bewegen würde?
- **cyber-13**: Wenn ein Ministerium Ihr Modell als Zeichen einer überschrittenen Schwelle nennt: Veröffentlichen Sie die Cyber-Bewertung dieser Version auf Chinesisch und Englisch, damit sie geprüft und nicht behauptet wird?
