# Request for feedback: our updated Distribution Standards

Report Q011882 · Source medium.com · Date 2023-02-21 · [Open original](https://medium.com/blog/request-for-feedback-our-updated-distribution-standards-36b39e1dc353)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Der vollständige Bericht präsentiert einen Entwurf für Mediums Verteilungsstandards: Für einen Boost sollen Geschichten konstruktiv, originell, glaubwürdig und gut ausgearbeitet sein. Bestimmte Inhalte, darunter nicht gekennzeichnete KI-Texte und potenziell schädliche, unbelegte Behauptungen, sollen von der Netzwerkverbreitung ausgeschlossen werden. Medium bittet um Feedback; der Bericht nennt keine Ergebnisse der Kommentierung und sagt, dass derzeit nur englischsprachige Geschichten geprüft werden können.
