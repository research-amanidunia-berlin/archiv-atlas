## Zusammenfassung (von Luna, ungeprüft)

Medium Staff berichtet, dass die neu gestaltete Folgen-Schaltfläche rund 30-mal so viele Abonnements für Autorenmeldungen erzeuge wie zuvor; Messdetails und absolute Zahlen nennt der Newsletter nicht. Daneben bewirbt er eine Schreibkonferenz, eine tägliche Schreibaufgabe, Themen-Tags, das Medium Handbook, die Arbeit von Publikationsredaktionen und wöchentliche Schreibstunden.
