## Zusammenfassung (von Luna, ungeprüft)

Der vollständige Bericht empfiehlt einen fünfstufigen KI-gestützten Planungsablauf: Projekt untersuchen, Rückfragen stellen, betroffene Dateien auflisten, Änderungen pro Datei erklären und Gründe sowie Tests nennen. Die behaupteten Vorteile wie höheres Tempo und weniger Fehlentscheidungen beruhen auf einer persönlichen Erfahrung; systematische Belege oder eine Erörterung möglicher Nachteile fehlen.

## Sammelfragen

Je Zelle: Anteil Stufe 4–7 / Stufe 3–7 (4 = enthält zitierbare Belege … 7 = beantwortet direkt; 3 = nützlicher Hintergrund).
