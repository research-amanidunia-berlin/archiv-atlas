## Zusammenfassung (von Luna, ungeprüft)

Der Beitrag erklärt Agent Skills als wiederverwendbare, automatisch passend geladene Wissenspakete für GitHub Copilot und grenzt sie von allgemeinen benutzerdefinierten Anweisungen ab. Ein Beispiel zeigt einen Skill für das Debuggen von GitHub Actions; die erwarteten Vorteile wie konsistenteres Arbeiten werden behauptet, aber nicht durch Messungen belegt.
