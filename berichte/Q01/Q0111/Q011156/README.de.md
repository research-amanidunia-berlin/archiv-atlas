## Zusammenfassung (von Luna, ungeprüft)

Die Überschrift verspricht zehnfach weniger Tokens, doch der Bericht nennt keine Messwerte; seine Empfehlungen stützen sich auf eine erwähnte Reddit-Diskussion.
