# Plumbing for the Metaverse with Universal Scene Description (USD)

Bericht Q011150 · Quelle medium.com · Datum 2021-09-29 · [Original öffnen](https://medium.com/@nvidiaomniverse/plumbing-for-the-metaverse-with-universal-scene-description-usd-856a863d9b12)

## Zusammenfassung (von Luna, ungeprüft)

NVIDIA argumentiert, USD könne dank seiner umfangreichen Szenenbeschreibung, erweiterbaren Struktur und nicht destruktiven Layer eine Grundlage für ein offenes Metaversum sein. Da Pixar-USD laut Beitrag keine Replikation mitbringt, ergänzt NVIDIA es um ein System zur Übertragung einzelner Änderungen; der Artikel präsentiert dies als Kern von Omniverse, belegt die Eignung für ein offenes Metaversum aber nicht unabhängig.
