# What is Animation Retargeting?

## Zusammenfassung (von Luna, ungeprüft)

Der Artikel beschreibt, warum Animationen wegen unterschiedlicher Skelette, Proportionen und Skinning-Effekte nicht ohne Weiteres zwischen 3D-Charakteren übertragbar sind. NVIDIA nennt eine einfache „One Click“-Übertragung als Ziel, liefert im Beitrag aber keine konkrete Umsetzung oder Evaluation und lässt offen, ob vereinfachte Bewegungsdarstellungen alle gewünschten Bewegungen abdecken.
