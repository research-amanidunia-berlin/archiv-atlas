# Scalable Active Learning for Autonomous Driving

Report Q011108 · Source medium.com · Date 2019-12-18 · [Open original](https://medium.com/nvidia-ai/scalable-active-learning-for-autonomous-driving-a-practical-implementation-and-a-b-test-4d315ed04b5f)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

NVIDIA berichtet, dass Active Learning in einem einzelnen Versuch nächtliche Trainingsbilder für Fußgänger- und Fahrraderkennung wirksamer auswählte als manuelle Kuratierung, bei ungefähr gleichen Labelkosten. Der Vorteil zeigte sich besonders bei Fahrrädern; getestet wurden jedoch nur eine Iteration und ein spezifischer Anwendungsfall.
