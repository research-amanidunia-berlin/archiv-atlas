# SwiftUI: Access Music Library with MediaPlayer Framework

## Zusammenfassung (von Luna, ungeprüft)

Der Beitrag zeigt eine SwiftUI-App, die mit MediaPlayer lokale Alben und Wiedergabelisten abfragt, Titel abspielt und Änderungen an der Mediathek erkennt. Dafür sind eine Nutzungsbeschreibung und Bibliotheksberechtigung nötig; laut Autor funktioniert der Zugriff korrekt nur auf echten Geräten und umfasst keine Apple-Music-Inhalte. Die Anleitung bietet Codebeispiele, aber keine systematischen Testergebnisse.
