## Summary (German, by Luna, unchecked)

Der Artikel erklärt, wie eine API-Gateway-REST-API über CloudFront gecacht werden kann: Nach der Einrichtung von Lambda und API wird in der Distribution eine Cache Policy aktiviert, da die Standardeinstellung laut Autor Caching deaktiviert. Der Autor beschreibt außerdem einen einfachen Test mit einer zeitabhängigen Antwort, das Weiterleiten eines `X-API-Key`-Headers und Cache-Invalidierungen über API oder Konsole.
