## Zusammenfassung (von Luna, ungeprüft)

Der Artikel vergleicht `WebView` für einfaches Laden von Webseiten mit `WebPage` für weitergehende Kontrolle über Navigation, Cookies, JavaScript, Dialoge und das Teilen von Inhalten. Er beschreibt dabei Einschränkungen und Fehler aus eigenen Beta-Erfahrungen. Der Autor warnt, dass der Code aus einer frühen Beta stammt und sich die API, besonders die Navigation, bis Beta 3 verändert hat.
