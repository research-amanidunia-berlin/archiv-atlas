# SwiftUI: Synchronize/Store Files (Documents) with iCloud

## Zusammenfassung (von Luna, ungeprüft)

Der Beitrag zeigt eine SwiftUI-App, die Textdateien in iCloud Drive verwaltet und mithilfe von `NSMetadataQuery` Metadaten sowie Änderungen beobachtet. Der Autor weist darauf hin, dass iOS-Dateiinhalte gegebenenfalls erst heruntergeladen werden müssen, Simulator-Tests der Synchronisierung unzuverlässig gewesen seien und das Beispiel keine vollständige Dokument-basierte App darstellt.
