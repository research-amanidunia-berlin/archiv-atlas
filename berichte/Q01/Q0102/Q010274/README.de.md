## Zusammenfassung (von Luna, ungeprüft)

Der Artikel ist eine Befehlsreferenz für Apples `container`-Werkzeug auf Apple-Silicon-Macs: Er behandelt Installation, Images, Containerbetrieb und ein PostgreSQL-Beispiel. Ein Versionshinweis aktualisiert die anfängliche Aussage zur fehlenden Portweiterleitung: Seit Version 0.4.1 werde sie mit `--publish` unterstützt; der Bericht enthält keinen systematischen Vergleich mit Docker.
