## Zusammenfassung (von Luna, ungeprüft)

Andrade meint, dass immer menschlicher wirkende KI und natürliche Sprache dazu beitragen könnten, Sprachassistenten und Chatbots als Begleiter zu behandeln. Er sieht mögliche Hilfe für einsame Menschen, warnt aber vor einer Verdrängung menschlicher Kontakte. Seine Überlegungen beruhen auf persönlichen Beobachtungen und Beispielen, nicht auf einer systematischen Untersuchung.
