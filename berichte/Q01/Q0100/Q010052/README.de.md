## Zusammenfassung (von Luna, ungeprüft)

Frank Andrade bewertet Googles damalige experimentelle KI-Suche nach einem persönlichen Test als brauchbar für allgemeine Antworten, aber wenig neuartig gegenüber Bing oder ChatGPT. „Code Tips“ könne fehlerhaften Code liefern und keine Rückfragen zur Fehlerbehebung annehmen; „Add to Sheets“ habe in seinem Test lediglich einen Link gespeichert. Seine Einschätzungen beruhen auf einem begrenzten Praxistest, und er hält Verbesserungen der noch experimentellen Funktion für möglich.
