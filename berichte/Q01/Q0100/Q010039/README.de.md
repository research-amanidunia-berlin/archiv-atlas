# Little SwiftUI Tip: Get Network Information & Monitor Changes

## Zusammenfassung (von Luna, ungeprüft)

Der vollständige Bericht zeigt anhand eines SwiftUI-Beispiels, wie `NWPathMonitor` Netzwerkstatus, Interfaces, Gateways und verschiedene Verbindungseigenschaften beobachtbar macht. Laut Autor liefert die API dabei weder die lokale IP-Adresse noch Upload- und Downloadgeschwindigkeiten; Wi-Fi-Aware-Daten erfordern den Import von `WiFiAware`.
