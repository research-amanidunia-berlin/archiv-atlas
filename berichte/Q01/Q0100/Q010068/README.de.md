# Little SwiftUI Tip: Convert Any (Common Format) Files to Image

Bericht Q010068 · Quelle medium.com · Datum 2025-10-28 · [Original öffnen](https://medium.com/gitconnected/little-swiftui-tip-convert-any-common-format-files-to-image-pdf-in-seconds-87bbd0efd7c3)

## Zusammenfassung (von Luna, ungeprüft)

Der Autor zeigt einen SwiftUI-Ansatz, der Dateien mit WebKit `WebPage` lädt und über `exported(as:)` als Bild oder PDF ausgibt; ein Beispiel teilt die Daten per `ShareLink`. Er berichtet von Problemen beim Speichern von Bildern ohne PNG-Endung und vermutet einen Beta-Fehler, prüft aber weder alle Formate systematisch noch belegt er eine allgemeine Unterstützung.

## Sammelfragen

Je Zelle: Anteil Stufe 4–7 / Stufe 3–7 (4 = enthält zitierbare Belege … 7 = beantwortet direkt; 3 = nützlicher Hintergrund). Aufgeführt: Sammelfragen, bei denen mindestens ein Modell den Stufen 3–7 mindestens 10 % gibt. „–“ = Modell hat diesen Bericht nicht bewertet. Volle Verteilungen: [bericht.json](bericht.json).

Keine Sammelfrage erreicht bei einem Modell 10 % in Stufe 3–7.
