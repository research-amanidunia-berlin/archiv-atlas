# Little SwiftUI Tip: Custom Keyboard Submit Button Label

Bericht Q010020 · Quelle medium.com · Datum 2025-11-23 · [Original öffnen](https://medium.com/@itsuki.enjoy/little-swiftui-tip-custom-keyboard-submit-button-label-298c48a86406)

[Alle Berichte](../../../README.de.md) · Daten: [bericht.json](bericht.json)

## Zusammenfassung (von Luna, ungeprüft)

Der Beitrag zeigt `submitLabel(_:)` als einfache Möglichkeit, die Beschriftung der Tastaturtaste zum Absenden in `TextField`, `SecureField` und `TextEditor` festzulegen. Er nennt neun verfügbare Labels und weist darauf hin, dass manche dasselbe Symbol haben; `onSubmit(of:_:)` wird erwähnt, aber nicht näher erklärt.

## Sammelfragen

Je Zelle: Anteil Stufe 4–7 / Stufe 3–7 (4 = enthält zitierbare Belege … 7 = beantwortet direkt; 3 = nützlicher Hintergrund). Aufgeführt: Sammelfragen, bei denen mindestens ein Modell den Stufen 3–7 mindestens 10 % gibt. „–“ = Modell hat diesen Bericht nicht bewertet. Volle Verteilungen: [bericht.json](bericht.json).

Keine Sammelfrage erreicht bei einem Modell 10 % in Stufe 3–7.
