# Scrolling pickers in SwiftUI

## Zusammenfassung (von Luna, ungeprüft)

Der vollständige Bericht beschreibt einen horizontalen SwiftUI-Zahlenpicker mit Linealmarkierungen, zentraler Auswahl, gedimmten Randbereichen und eigenem Einrastverhalten. Der ausgewählte ganzzahlige Wert wird gebunden und Änderungen können haptisches Feedback auslösen; andere Werttypen und weitere Darstellungsanpassungen nennt der Autor als mögliche Erweiterungen.

## Sammelfragen

Je Zelle: Anteil Stufe 4–7 / Stufe 3–7 (4 = enthält zitierbare Belege … 7 = beantwortet direkt; 3 = nützlicher Hintergrund). Aufgeführt: Sammelfragen, bei denen mindestens ein Modell den Stufen 3–7 mindestens 10 % gibt. „–“ = Modell hat diesen Bericht nicht bewertet. Volle Verteilungen: [bericht.json](bericht.json).

Keine Sammelfrage erreicht bei einem Modell 10 % in Stufe 3–7.
