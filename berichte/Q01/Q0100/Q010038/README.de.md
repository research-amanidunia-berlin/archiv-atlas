# Blooming fireworks with Metal and SwiftUI

Bericht Q010038 · Quelle uvolchyk.medium.com · Datum 2024-12-01 · [Original öffnen](https://uvolchyk.medium.com/blooming-fireworks-with-metal-and-swiftui-6550cef997e2)

## Zusammenfassung (von Luna, ungeprüft)

Der vollständige Bericht zeigt einen experimentellen Metal- und SwiftUI-Shader, der über Partikel, Leuchteffekte, Rauschen und Bézierkurven einen Feuerwerksschweif und anschließend strahlenförmige Explosionen erzeugt. Der Autor warnt vor ruckeliger Darstellung durch die einfache Pixelverarbeitung; außerdem verwendet der gezeigte Code für die Strahlen π statt des im Text beschriebenen 2π-Winkels.
