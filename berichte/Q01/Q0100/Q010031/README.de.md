Frank Andrade empfiehlt für den Einstieg in KI und maschinelles Lernen Python samt wichtigen Datenbibliotheken, praktische Projekte auf Kaggle, Mathematik auf Schulniveau und anschließend Andrew Ngs Coursera-Spezialisierung.
