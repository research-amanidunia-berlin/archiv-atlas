# Bursting fireworks with Metal

## Zusammenfassung (von Luna, ungeprüft)

Der Artikel erklärt, wie aus Béziergeometrie, Shadern für Auflösung und Leuchten, Unschärfe-Nachbearbeitung sowie Metal-Instancing eine Feuerwerksanimation mit drei versetzten Feuerwerken entsteht. Der Autor zeigt mehrere Entwicklungsstufen, nennt aber weder Leistungsbenchmarks noch einen systematischen Vergleich mit seinem früheren Ansatz und sieht selbst weitere Optimierungsmöglichkeiten.
