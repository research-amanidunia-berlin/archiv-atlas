## Summary (German, by Luna, unchecked)

Der Artikel beschreibt eine Swift-Beispielarchitektur, in der JSON-Schemas von MCP-Werkzeugen zur Laufzeit in dynamische Foundation-Models-Tools übersetzt und über einen MCP-Client aufgerufen werden. Die Demo konzentriert sich auf HTTP und weist auf Grenzen der Schema-Abbildung hin, darunter nicht unterstützte boolesche, Array- und Objektkonstanten; Authentifizierung wird als mögliche Erweiterung genannt.
