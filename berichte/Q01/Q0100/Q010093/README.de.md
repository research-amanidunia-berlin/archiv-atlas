# Swift Foundation Models: Dynamic Tools with Dynamic Argument Structure & Dynamic Calls

Bericht Q010093 · Quelle medium.com · Datum 2025-10-13 · [Original öffnen](https://medium.com/gitconnected/swift-foundation-models-dynamic-tools-with-dynamic-argument-structure-dynamic-calls-11e89ae96068)

## Zusammenfassung (von Luna, ungeprüft)

Der Autor beschreibt, wie `DynamicGenerationSchema` zur Laufzeit Argumentfelder für Foundation-Models-Werkzeuge festlegen kann, und veranschaulicht das mit einem Werkzeug, dessen optionale Pokémon-Details per Schalter in das Schema aufgenommen werden. MCP wird als Anwendungsfall genannt, aber nicht konkret implementiert; der Beitrag bietet ein Beispiel, keine unabhängige Prüfung der Lösung.
