## Zusammenfassung (von Luna, ungeprüft)

Der Artikel beschreibt eine SwiftUI-Umsetzung, die HTML-Apps aus MCP-Tool-Aufrufen in einer Webansicht zeigt und über ein injiziertes `window.openai`-Objekt mit Chat und Tools verbindet. Der Autor sieht darin ein plattformübergreifend nutzbares Muster und kritisiert OpenAIs eigene Schnittstellen; wegen behaupteter Lücken im offiziellen Swift-MCP-SDK verwendet er eine Fork.
