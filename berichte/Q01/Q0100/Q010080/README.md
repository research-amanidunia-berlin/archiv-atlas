## Summary (German, by Luna, unchecked)

Der Artikel beschreibt eine SwiftUI-Umsetzung, die HTML-Apps aus MCP-Tool-Aufrufen in einer Webansicht zeigt und über ein injiziertes `window.openai`-Objekt mit Chat und Tools verbindet.
