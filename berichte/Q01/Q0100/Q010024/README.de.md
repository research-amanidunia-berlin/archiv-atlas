## Zusammenfassung (von Luna, ungeprüft)

Der Bericht zeigt anhand einer AppSync-API mit drei DynamoDB-Tabellen, wie Pipeline Resolver Eingaben vor dem Anlegen einer Beziehung prüfen und feldgebundene Unit Resolver relationale Daten bei Bedarf nachladen können. Der Autor hält diesen Aufbau für wiederverwendbarer als das manuelle Zusammensetzen jeder Antwort und empfiehlt relationale Felder, die jeweils direkt aus einer Datenquelle auflösbar sind; systematische Leistungsvergleiche enthält der Artikel nicht.
