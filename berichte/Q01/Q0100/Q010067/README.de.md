# Hiding actions in buttons with UIKit

Bericht Q010067 · Quelle uvolchyk.medium.com · Datum 2024-05-12 · [Original öffnen](https://uvolchyk.medium.com/hiding-actions-in-buttons-with-uikit-f113b0661991)

## Zusammenfassung (von Luna, ungeprüft)

Der vollständige Bericht erklärt, wie UIKit mit `UIInteraction`, langem Drücken, Animationen und haptischem Feedback eine bewegliche Liste sekundärer Aktionen umsetzen kann. Beim Loslassen wird die hervorgehobene Aktion ausgelöst; Layoutwerte und bestehende Gesten können Anpassungen erfordern und Konflikte verursachen.
