## Zusammenfassung (von Luna, ungeprüft)

Andrade argumentiert anhand von Beispielen, dass GPT Builder und DALL·E 3 das Erstellen von Prompts erleichtern, die Ergebnisse aber oft noch angepasst werden müssen. Seine Einschätzung beruht auf qualitativen Beispielen, nicht auf systematischen Tests: Prompt Engineering werde weniger nötig, bleibe für gezielte Ergebnisse jedoch relevant.
