# SwiftUI: Extract Information From Documents With Document Recognition

Bericht Q010074 · Quelle medium.com · Datum 2025-10-25 · [Original öffnen](https://medium.com/gitconnected/swiftui-extract-information-from-documents-with-document-recognition-86d41ed68d6c)

## Zusammenfassung (von Luna, ungeprüft)

Der Beitrag erklärt Apples `RecognizeDocumentsRequest` und zeigt ein SwiftUI-Demo zur Erkennung von Text, Tabellen, Listen, Barcodes und strukturierten Daten. Im getesteten Screenshot waren die Resultate laut Autor begrenzt: Eine Tabelle erforderte eine niedrigere Mindesttexthöhe, Überschriften wurden nicht als Titel erkannt, Geldbeträge fehlten und der Konfidenzwert blieb stets 0,0.

## Sammelfragen

Je Zelle: Anteil Stufe 4–7 / Stufe 3–7 (4 = enthält zitierbare Belege … 7 = beantwortet direkt; 3 = nützlicher Hintergrund). Aufgeführt: Sammelfragen, bei denen mindestens ein Modell den Stufen 3–7 mindestens 10 % gibt. „–“ = Modell hat diesen Bericht nicht bewertet. Volle Verteilungen: [bericht.json](bericht.json).

Keine Sammelfrage erreicht bei einem Modell 10 % in Stufe 3–7.
