# SwiftUI: Synchronized MultiView Playback

Bericht Q010047 · Quelle medium.com · Datum 2025-11-08 · [Original öffnen](https://medium.com/gitconnected/swiftui-synchronized-multiview-playback-c8fc32ec9150)

[Alle Berichte](../../../README.de.md) · Daten: [bericht.json](bericht.json)

## Zusammenfassung (von Luna, ungeprüft)

Der Autor zeigt, wie lokale AVPlayer über ein gemeinsames AVPlaybackCoordinationMedium Wiedergabesteuerungen synchronisieren können, während die Lautstärke separat bleibt. Das Beispiel nutzt dieselbe Videodatei für alle Player und ergänzt eine gemeinsame Steuerung; entfernte Gruppensitzungen werden nur als mögliche Erweiterung erwähnt.
