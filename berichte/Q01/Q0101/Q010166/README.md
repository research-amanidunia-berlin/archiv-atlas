## Summary (German, by Luna, unchecked)

Der vollständige Artikel vergleicht drei Zustimmungsverfahren für Strands-Agenten: ein bereitgestelltes Übergabewerkzeug, ein eigenes Zustimmungswerkzeug und einen Hook, der mit einer Ausnahme die Agentenschleife unterbricht.
