# Changing UITableViewCell height with ease

## Zusammenfassung (von Luna, ungeprüft)

Der vollständige Artikel beschreibt eine UIKit-Zelle, deren Zusammenfassung per Button animiert ein- und ausgeblendet wird; die Tabellenaktualisierung erfolgt über `performBatchUpdates`. Während der Animation fixiert der Code kurz die Höhe des Titellabels, um laut Autor unerwünschte Höhenänderungen zu vermeiden; Tests und weitere Anwendungsfälle werden nicht behandelt.
