## Zusammenfassung (von Luna, ungeprüft)

Frank Andrade testet OpenAIs damaligen Textklassifikator an einem eigenen Text und zwei ChatGPT-Texten: Die KI-Texte erhalten unterschiedliche Einstufungen, einer wird sogar als sehr wahrscheinlich menschlich bewertet. Der Autor folgert, dass das Werkzeug unzuverlässig ist; seine wenigen Tests belegen jedoch keine allgemeine Genauigkeit.
