## Zusammenfassung (von Luna, ungeprüft)

Der vollständige Newsletter kündigt eine Profil-Aktivitätsübersicht, voreingestellte Bezahlschranken und eine strengere Opt-out-Option für KI-Training an. Medium zufolge bleibt die traditionelle Suchmaschinenauffindbarkeit davon unberührt; zugleich seien Fragen zur Vergütung noch offen und nicht alle Bedenken ausgeräumt. Dazu kommen Schreibanregungen, drei Schreibangebote und eine Comedy-Veranstaltung im April.

## Sammelfragen

Je Zelle: Anteil Stufe 4–7 / Stufe 3–7 (4 = enthält zitierbare Belege … 7 = beantwortet direkt; 3 = nützlicher Hintergrund).
