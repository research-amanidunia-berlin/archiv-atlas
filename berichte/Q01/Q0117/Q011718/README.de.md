# An Easy To Build First App Using SwiftUI

## Zusammenfassung (von Luna, ungeprüft)

Das Tutorial zeigt, wie mit SwiftUI eine einfache iOS-App namens „Bullseye“ entsteht: Ein Regler soll einer zufälligen Zahl möglichst nahekommen, und abhängig vom Abstand gibt es Punkte. Es erklärt den Aufbau der Oberfläche, die Verwendung von State sowie die Wertung und das Zurücksetzen für die nächste Runde; Tests und weitergehende Funktionen werden nicht behandelt.
