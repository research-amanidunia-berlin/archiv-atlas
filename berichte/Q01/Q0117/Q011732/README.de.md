## Zusammenfassung (von Luna, ungeprüft)

Der vollständige Bericht erklärt anhand eines öffentlichen Posts-Endpunkts, wie Swift API-Daten lädt, JSON in `Codable`-Modelle dekodiert und Beiträge über ein ViewModel in einer SwiftUI-Liste anzeigt. Die Beispiel-Fehlerbehandlung prüft URL, Antwort, Statuscode und Dekodierung, beschränkt sich aber auf einen unauthentifizierten Lernfall und protokolliert Fehler lediglich.
