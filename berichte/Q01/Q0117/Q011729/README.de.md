# How to build a custom progress ring in SwiftUI

Bericht Q011729 · Quelle medium.com · Datum 2023-02-12 · [Original öffnen](https://medium.com/@jpmtech/how-to-build-a-custom-progress-ring-in-swiftui-d57eefe98556)

[Alle Berichte](../../../README.de.md) · Daten: [bericht.json](bericht.json)

## Zusammenfassung (von Luna, ungeprüft)

Der Bericht erklärt, wie ein SwiftUI-Fortschrittsring aus einem Hintergrundkreis und einem per `trim` zugeschnittenen Fortschrittskreis aufgebaut wird; eine Drehung lässt den Bogen oben beginnen. Die einfache Variante zeigt laut Autor Werte von 0 bis 100 Prozent und könnte etwa durch konfigurierbare Linienenden, einen anderen Startwinkel oder einen Farbverlauf angepasst werden.

## Sammelfragen

Je Zelle: Anteil Stufe 4–7 / Stufe 3–7 (4 = enthält zitierbare Belege … 7 = beantwortet direkt; 3 = nützlicher Hintergrund). Aufgeführt: Sammelfragen, bei denen mindestens ein Modell den Stufen 3–7 mindestens 10 % gibt. „–“ = Modell hat diesen Bericht nicht bewertet. Volle Verteilungen: [bericht.json](bericht.json).

Keine Sammelfrage erreicht bei einem Modell 10 % in Stufe 3–7.
