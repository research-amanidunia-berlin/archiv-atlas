## Zusammenfassung (von Luna, ungeprüft)

Der vollständige Bericht beschreibt ein SwiftUI-Onboarding mit zwei Seiten, einer Weiter-/Abschlussschaltfläche und einem über `@AppStorage` gespeicherten Status. Laut Autor ermöglicht eine Versionskennung, bei einer späteren Änderung erneut einen Ablauf anzuzeigen; der Beispielcode enthält im Vorschauaufruf eine nicht erläuterte Namensabweichung zwischen `OnboardingCell` und `OnboardingScreen`.
