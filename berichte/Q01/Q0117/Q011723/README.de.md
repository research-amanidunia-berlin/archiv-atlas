## Zusammenfassung (von Luna, ungeprüft)

Der vollständige Bericht zeigt ein SwiftUI-Beispiel, das über StoreKit mit `requestReview()` eine Bewertungsanfrage auslöst. Laut Artikel sollte man Anfragen passend zum Nutzungsmoment und sparsam einsetzen; der Autor nennt eine Begrenzung von drei angezeigten Aufforderungen pro 365 Tage und berichtet von möglichen Problemen im Simulator.

## Sammelfragen

Je Zelle: Anteil Stufe 4–7 / Stufe 3–7 (4 = enthält zitierbare Belege … 7 = beantwortet direkt; 3 = nützlicher Hintergrund).
