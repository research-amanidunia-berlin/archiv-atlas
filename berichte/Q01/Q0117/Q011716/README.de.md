# An Easy To Build First App Using Jetpack Compose

## Zusammenfassung (von Luna, ungeprüft)

Das Tutorial führt anhand des Android-Spiels „Bullseye“ in Jetpack Compose ein: Es zeigt den Aufbau der Oberfläche sowie Zustandsverwaltung für Zielzahl, Schieberegler und Punktestand. Die Punkte richten sich nach der Abweichung; nach jedem Versuch werden Zielzahl und Regler für eine neue Runde zurückgesetzt. Der Bericht beschreibt ein einfaches Lernbeispiel und nennt keine formalen Tests.

## Sammelfragen

Je Zelle: Anteil Stufe 4–7 / Stufe 3–7 (4 = enthält zitierbare Belege … 7 = beantwortet direkt; 3 = nützlicher Hintergrund). Aufgeführt: Sammelfragen, bei denen mindestens ein Modell den Stufen 3–7 mindestens 10 % gibt. „–“ = Modell hat diesen Bericht nicht bewertet. Volle Verteilungen: [bericht.json](bericht.json).

Keine Sammelfrage erreicht bei einem Modell 10 % in Stufe 3–7.
