## Zusammenfassung (von Luna, ungeprüft)

Das Swift-Vapor-Tutorial zeigt einen DELETE-Endpunkt, der die ID aus dem Request-Inhalt liest, den Datensatz in der Datenbank sucht und ihn bei einem Treffer löscht. Fehlt der Eintrag, wird „Not Found“ ausgelöst; bei erfolgreichem Löschen folgt „OK“. Die Migration sowie Authentifizierung und Autorisierung werden nicht behandelt.
