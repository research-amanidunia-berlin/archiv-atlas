# Adding Pull To Refresh to SwiftUI Views

## Zusammenfassung (von Luna, ungeprüft)

Der Bericht zeigt `.refreshable` für unterstützte SwiftUI-Ansichten sowie eine eigene Pull-to-Refresh-Erkennung für eine `LazyVGrid` in einer `ScrollView`. Der Autor nennt iOS 15 als möglichen Rückwärtskompatibilitätsfall; der Code demonstriert den Ansatz, während die Aktualisierung selbst nur durch eine dreisekündige Wartezeit simuliert wird.
