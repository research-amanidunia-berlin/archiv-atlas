# How to enable accessible font sizes in iOS

Bericht Q011735 · Quelle medium.com · Datum 2023-02-08 · [Original öffnen](https://medium.com/@jpmtech/how-to-enable-accessible-font-sizes-in-ios-b3758e7aac61)

## Zusammenfassung (von Luna, ungeprüft)

Der Bericht beschreibt den Weg in den iOS-Einstellungen zu „Größerer Text“ und erklärt, dass nach Einschalten der Option für größere dynamische Textgrößen zusätzliche Schriftgrößen im Regler erscheinen. Laut Autor wirkt die Einstellung nur in Apps, die größere Texte unterstützen; für andere schlägt er eine Rückmeldung an deren Entwickler vor.
