# How to Create a Custom SF Symbol using Colors

Bericht Q011722 · Quelle medium.com · Datum 2023-06-05 · [Original öffnen](https://medium.com/@jpmtech/how-to-use-custom-colors-in-an-sf-symbol-18b72451b15f)

## Zusammenfassung (von Luna, ungeprüft)

Der Artikel vergleicht SwiftUI-Methoden zum Einfärben von SF Symbols und empfiehlt `.foregroundStyle`, um bis zu drei Farben auf verschiedene Symbolebenen anzuwenden. Das Ergebnis hängt vom Aufbau des Symbols ab; das Aufteilen eines Symbols in eigene Ebenen wird nur erwähnt, aber nicht erklärt.

## Sammelfragen

Je Zelle: Anteil Stufe 4–7 / Stufe 3–7 (4 = enthält zitierbare Belege … 7 = beantwortet direkt; 3 = nützlicher Hintergrund). Aufgeführt: Sammelfragen, bei denen mindestens ein Modell den Stufen 3–7 mindestens 10 % gibt. „–“ = Modell hat diesen Bericht nicht bewertet. Volle Verteilungen: [bericht.json](bericht.json).

Keine Sammelfrage erreicht bei einem Modell 10 % in Stufe 3–7.
