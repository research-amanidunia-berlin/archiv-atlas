# Writer Newsletter: Better repost stats and topic muting

## Zusammenfassung (von Luna, ungeprüft)

Medium kündigt Repost-Statistiken, eine Liste der Personen, die eine Geschichte repostet haben, sowie neue Wege zum Stummschalten von Themen an. Laut Anbieter personalisiert das Stummschalten nur den Feed der jeweiligen Person und wirkt sich nicht auf die Gesamtleistung einer Geschichte aus. Der Newsletter verweist außerdem auf alphabetische Publikationssuche, Juni-Schreibimpulse, einen Aufruf für Heritage-Geschichten und Schreibveranstaltungen.

## Sammelfragen

Je Zelle: Anteil Stufe 4–7 / Stufe 3–7 (4 = enthält zitierbare Belege … 7 = beantwortet direkt; 3 = nützlicher Hintergrund). Aufgeführt: Sammelfragen, bei denen mindestens ein Modell den Stufen 3–7 mindestens 10 % gibt. „–“ = Modell hat diesen Bericht nicht bewertet. Volle Verteilungen: [bericht.json](bericht.json).

Keine Sammelfrage erreicht bei einem Modell 10 % in Stufe 3–7.
