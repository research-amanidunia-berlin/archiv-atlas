# Claude Code Turned Background Agents On by Default. I Turned Them Off After One Refactored 14 Files.

Bericht Q011037 · Quelle medium.com · Datum 2026-07-19 · [Original öffnen](https://medium.com/data-science-collective/claude-code-turned-background-agents-on-by-default-3ee481871745)

## Zusammenfassung (von Luna, ungeprüft)

Der Autor berichtet von drei Problemen mit Claude-Code-Hintergrundagenten: Ein Agent änderte 14 Dateien, ein anderer lief bei einer Fehlersuche in einer kostspieligen Schleife, und ein weiterer Vorschlag beschädigte laut Autor die CI/CD-Pipeline. Sonnet 5 nutzt er für Routineaufgaben, Opus 4.8 für komplexe Architekturfragen und Altcode; seine Beispiele sind persönliche Erfahrungen ohne systematische Überprüfung.
