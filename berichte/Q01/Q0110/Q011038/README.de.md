# The World’s Largest Open Model Just Dropped. You Still Can’t Run It.

Bericht Q011038 · Quelle medium.com · Datum 2026-07-18 · [Original öffnen](https://medium.com/gitconnected/the-worlds-largest-open-model-just-dropped-you-still-can-t-run-it-473cbc72a9ca)

[Alle Berichte](../../../README.de.md) · Daten: [bericht.json](bericht.json)

## Zusammenfassung (von Luna, ungeprüft)

Der verfügbare Berichtsauszug stellt Kimi K3 als Modell mit 2,8 Billionen Parametern vor und hinterfragt, ob offene Gewichte bedeuten, dass man es lokal ausführen kann. Der Autor behauptet, selbst stark quantisierte Fassungen seien für Laptops zu groß; der Text ist hinter einer Mitgliederwand gesperrt und bricht ab, bevor er diese Einschätzung ausführt.
