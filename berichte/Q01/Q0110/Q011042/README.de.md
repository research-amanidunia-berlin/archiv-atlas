## Zusammenfassung (von Luna, ungeprüft)

Der Bericht ist nur als Auszug verfügbar: Ein Agent zur Sortierung von Belegen wiederholte nach einer fehlgeschlagenen Texterkennung seine Versuche und verursachte laut Autor über Nacht 180 US-Dollar API-Kosten. Als erkennbare Lehre empfiehlt der Autor, Fehler vor einem Retry zu klassifizieren und klare Stoppbedingungen festzulegen; der restliche Artikel ist hinter einer Medium-Mitglieder-Schranke verborgen.
