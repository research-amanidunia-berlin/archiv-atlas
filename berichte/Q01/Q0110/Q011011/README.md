# Stripe Paid $8 Billion for OpenRouter. The Routing Was Never the Product.

Report Q011011 · Source medium.com · Date 2026-08-24 · [Open original](https://medium.com/ai-advances/stripe-paid-8-billion-for-openrouter-the-routing-was-never-the-product-0f5565b38eff)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Der Autor meint, OpenRouter verdiene vor allem an Guthabengebühren, während das Routing selbst laut Preisdokumentation ohne Inferenzaufschlag angeboten werde. Er vermutet, der strategische Wert des Kaufs liege eher in Einblicken in Anbieterabrechnungen und die Modellauswahl der Entwickler; seine Umsatz- und Kaufpreisrechnungen sind eigene, unsichere Schätzungen, und Stripe nannte keinen Kaufpreis. Trotz möglicher Interessenkonflikte und gemeinsamer Ausfallrisiken bleibt der Autor beim Dienst, weil ein Wechsel mehr Aufwand als Ersparnis bedeute.
