## Summary (German, by Luna, unchecked)

Der Autor schildert, dass eine KI-generierte PostgreSQL-Migration ohne Index auf der Fremdschlüsselspalte bei Millionen Bestellungen zu einer sehr langsamen Abfrage führte, obwohl sie lokal und in Tests unauffällig war. Er empfiehlt, fehlende Fremdschlüsselindizes und Abfragepläne gezielt zu prüfen; die passende Indexgestaltung hängt vom tatsächlichen Zugriffsmuster ab.
