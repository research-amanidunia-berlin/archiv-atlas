## Zusammenfassung (von Luna, ungeprüft)

Der Autor empfiehlt für KI-Coding-Agenten ein „10–80–10“-Vorgehen: Anforderungen präzise festlegen, die Agenten arbeiten lassen und das Ergebnis anschließend gründlich prüfen. Er berichtet, dass weniger Zwischenüberwachung seine eigene Bearbeitungszeit mehr als halbiert habe, während eine Abschlussprüfung einen fehlenden Fremdschlüsselindex aufdeckte, den Tests mit kleinen Datenmengen nicht zeigten.
