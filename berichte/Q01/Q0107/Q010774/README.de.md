## Zusammenfassung (von Luna, ungeprüft)

Der Bericht zeigt, wie eine private API Gateway REST-API über einen `execute-api`-VPC-Endpunkt, eine Ressourcenrichtlinie und ein Deployment eingerichtet wird, sowohl in der AWS-Konsole als auch mit CDK. Der Autor berichtet von einem erfolgreichen Test innerhalb und einem DNS-Fehler außerhalb seiner VPC; der Beitrag bietet eine Anleitung, aber keine unabhängige Sicherheitsbewertung.
