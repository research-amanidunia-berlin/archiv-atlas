# SwiftUI: Intercepting Sheet Dismiss

Bericht Q010722 · Quelle medium.com · Datum 2024-04-24 · [Original öffnen](https://medium.com/stackademic/swiftui-intercepting-sheet-dismiss-1415c68a1f1e)

[Alle Berichte](../../../README.de.md) · Daten: [bericht.json](bericht.json)

## Zusammenfassung (von Luna, ungeprüft)

Der Beitrag zeigt, wie `.interactiveDismissDisabled` das Wegwischen eines SwiftUI-Sheets bis zum Erfüllen einer Bedingung sperrt, etwa bis eine „Save“-Schaltfläche den Speicherzustand setzt. Ein Wegwischversuch selbst wird dabei laut Darstellung nicht erkannt; stattdessen wird das interaktive Schließen bedingt freigegeben.
