Der Beitrag zeigt, wie `.interactiveDismissDisabled` das Wegwischen eines SwiftUI-Sheets bis zum Erfüllen einer Bedingung sperrt, etwa bis eine „Save“-Schaltfläche den Speicherzustand setzt.
