# AWS: Control API Gateway Access Using WAF

## Zusammenfassung (von Luna, ungeprüft)

Der vollständige Bericht beschreibt eine AWS-WAF-Konfiguration, die eine regionale API-Gateway-REST-API nur für IPv4-Quelladressen in einem IP-Set freigibt und übrige Anfragen standardmäßig blockiert. Der Autor berichtet von HTTP 200 für seine erlaubte IP und einer Sperre bei einem Test über EC2; die Darstellung und Tests beziehen sich auf diese konkrete Konfiguration.
