# Amazon QuickSight: Create Controls(Filters) Apply to all Sheets Using Parameter

Bericht Q010793 · Quelle medium.com · Datum 2024-01-11 · [Original öffnen](https://medium.com/aws-tip/amazon-quicksight-create-controls-filters-apply-to-all-sheets-using-parameter-e163d1894220)

## Zusammenfassung (von Luna, ungeprüft)

Der Beitrag zeigt, wie eine mit dem Parameter `region` verbundene QuickSight-Steuerung über mehrere Blätter synchronisiert wird. Damit sie auch Visualisierungen filtert, muss laut Autor auf jedem Blatt ein eigener, an den Parameter gebundener Filter eingerichtet werden; bei mehreren Datasets kann eine gemeinsame Werteliste in einem Metadaten-Dataset helfen.

## Sammelfragen

Je Zelle: Anteil Stufe 4–7 / Stufe 3–7 (4 = enthält zitierbare Belege … 7 = beantwortet direkt; 3 = nützlicher Hintergrund). Aufgeführt: Sammelfragen, bei denen mindestens ein Modell den Stufen 3–7 mindestens 10 % gibt. „–“ = Modell hat diesen Bericht nicht bewertet. Volle Verteilungen: [bericht.json](bericht.json).

Keine Sammelfrage erreicht bei einem Modell 10 % in Stufe 3–7.
