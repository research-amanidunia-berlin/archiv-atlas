## Zusammenfassung (von Luna, ungeprüft)

Itsuki beschreibt eine verschachtelte UIKit-Struktur, mit der eine horizontal scrollbare Tabelle entsteht: Eine Collection View stellt Spalten dar, deren Zellen jeweils eine Tabelle mit Zeilen enthalten. Textmaße bestimmen die Zeilenhöhen; ein beim Scrollen beobachteter Fehler durch Zellwiederverwendung soll durch erneutes Laden der inneren Tabelle bei Änderungen behoben werden.

## Sammelfragen

Je Zelle: Anteil Stufe 4–7 / Stufe 3–7 (4 = enthält zitierbare Belege … 7 = beantwortet direkt; 3 = nützlicher Hintergrund). Aufgeführt: Sammelfragen, bei denen mindestens ein Modell den Stufen 3–7 mindestens 10 % gibt. „–“ = Modell hat diesen Bericht nicht bewertet. Volle Verteilungen: [bericht.json](bericht.json).

Keine Sammelfrage erreicht bei einem Modell 10 % in Stufe 3–7.
