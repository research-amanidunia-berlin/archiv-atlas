# Swift/VisionOS: Handling Multiple Windows

## Zusammenfassung (von Luna, ungeprüft)

Der vollständige Bericht zeigt anhand von SwiftUI-Code, wie eine App die Unterstützung mehrerer Fenster prüft sowie Fenstergruppen mit `openWindow(id:)` öffnet und mit `dismissWindow(id:)` schließt. Laut Autor startet visionOS grundsätzlich mit der zuerst deklarierten Fenster- oder Dokumentszene; für einen immersiven Start müsse eine Einstellung in der `info.plist` gesetzt werden. Eine systematische Prüfung der Beispiele oder ausführliche Angaben zu Einschränkungen bietet der Beitrag nicht.
