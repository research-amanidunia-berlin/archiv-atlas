# Android/Kotlin/Jetpack Compose: Bottom Thing Bottom

Bericht Q010770 · Quelle medium.com · Datum 2024-02-19 · [Original öffnen](https://medium.com/@itsuki.enjoy/android-kotlin-jetpack-compose-bottom-thing-bottom-b050019f0948)

## Zusammenfassung (von Luna, ungeprüft)

Der vollständige Beitrag zeigt zwei Wege, Inhalte zwischen einer oberen und unteren Leiste in Jetpack Compose anzuordnen: `Arrangement.SpaceBetween` verteilt die Kinder gleichmäßig, während `weight` dem Inhalt den verbleibenden Platz zuweist. Gewichtete Geschwister können den Platz proportional aufteilen; der Artikel erläutert außerdem knapp die Wirkung des Parameters `fill` und bleibt bei einfachen Layoutbeispielen.
