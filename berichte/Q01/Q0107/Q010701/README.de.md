## Zusammenfassung (von Luna, ungeprüft)

Der vollständige Bericht zeigt eine SwiftUI-Beispiellösung für Ziehauswahl in einer scrollbaren `LazyVGrid`: Langdruck aktiviert die Auswahl, ein `ItemManager` verfolgt Elementrahmen und Auswahlzustände, und am Rand wird die Ansicht automatisch gescrollt. Der Beitrag demonstriert das Ergebnis, nennt aber keine systematischen Tests über Geräte oder iOS-Versionen hinweg und räumt ein, dass die beschriebenen Verhaltensregeln unvollständig sein könnten.
