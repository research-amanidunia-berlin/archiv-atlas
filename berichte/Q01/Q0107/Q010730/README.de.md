# SwiftUI: Paged Tab Bar

## Zusammenfassung (von Luna, ungeprüft)

Der Autor zeigt eine SwiftUI-Tab-Leiste für iOS 17+, bei der ganze Seiten statt einzelner Elemente die Scrollposition bestimmen. So sollen anfängliche Auswahl, Paging und das Ergänzen weiterer Seiten zusammenspielen; zentrale Layoutvorgaben sind null Abstand im äußeren `LazyHStack` und eine feste Bildschirmbreite je Seite.

## Sammelfragen

Je Zelle: Anteil Stufe 4–7 / Stufe 3–7 (4 = enthält zitierbare Belege … 7 = beantwortet direkt; 3 = nützlicher Hintergrund). Aufgeführt: Sammelfragen, bei denen mindestens ein Modell den Stufen 3–7 mindestens 10 % gibt. „–“ = Modell hat diesen Bericht nicht bewertet. Volle Verteilungen: [bericht.json](bericht.json).
