# SwiftUI: Custom FullScreenSheet Transition Animation

Bericht Q010708 · Quelle medium.com · Datum 2024-05-06 · [Original öffnen](https://medium.com/stackademic/swiftui-custom-fullscreensheet-transition-animation-bd307d272ebf)

## Zusammenfassung (von Luna, ungeprüft)

Der Autor zeigt zwei SwiftUI-Animationen für `fullScreenCover`: einen vereinfachten Fade-in und einen horizontalen 3D-Flip. Dafür deaktiviert er den Standardübergang und animiert den Inhalt der Vollbildansicht über einen eigenen Zustand; beim Schließen muss dessen Ausblendung abgeschlossen sein, bevor die Ansicht geschlossen wird.

## Sammelfragen

Je Zelle: Anteil Stufe 4–7 / Stufe 3–7 (4 = enthält zitierbare Belege … 7 = beantwortet direkt; 3 = nützlicher Hintergrund).
