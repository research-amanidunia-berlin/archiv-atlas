# Android/Kotlin/Jetpack Compose: Dropdown Selectable List/Menu

Bericht Q010779 · Quelle medium.com · Datum 2024-02-10 · [Original öffnen](https://medium.com/@itsuki.enjoy/android-kotlin-jetpack-compose-dropdown-selectable-list-menu-b7ad86ba6a5a)

[Alle Berichte](../../../README.de.md) · Daten: [bericht.json](bericht.json)

## Zusammenfassung (von Luna, ungeprüft)

Der vollständige Bericht beschreibt ein Compose-Dropdown mit scrollbarer Liste, Auswahlrückgabe an die übergeordnete Ansicht und Schließen bei Auswahl oder Tippen außerhalb. Er weist auf einen möglichen Umschaltkonflikt beim Tippen auf die Schaltfläche hin; außerdem widerspricht der Anfangswert `true` im Gesamtbeispiel dem zuvor beschriebenen Startzustand `false`.

## Sammelfragen

Je Zelle: Anteil Stufe 4–7 / Stufe 3–7 (4 = enthält zitierbare Belege … 7 = beantwortet direkt; 3 = nützlicher Hintergrund). Aufgeführt: Sammelfragen, bei denen mindestens ein Modell den Stufen 3–7 mindestens 10 % gibt. „–“ = Modell hat diesen Bericht nicht bewertet. Volle Verteilungen: [bericht.json](bericht.json).

Keine Sammelfrage erreicht bei einem Modell 10 % in Stufe 3–7.
