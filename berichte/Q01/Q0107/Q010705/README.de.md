## Zusammenfassung (von Luna, ungeprüft)

Der vollständige Bericht erklärt SwiftUI-Rotationen um die Ansichtsmitte, um einen inneren Ankerpunkt und auf einer Umlaufbahn, die durch einen gedrehten `ZStack` umgesetzt wird. Ein Mehrfachbeispiel zeigt gegenläufige Bahnen mit verschiedenen Geschwindigkeiten; der Artikel erläutert dafür Platzhalter, Abstände und getrennte Animationen, dokumentiert aber keine Tests oder Kompatibilitätsangaben.
