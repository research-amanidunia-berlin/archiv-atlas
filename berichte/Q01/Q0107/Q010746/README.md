# AWS API Gateway: Set Up Custom Domain Names

Report Q010746 · Source medium.com · Date 2024-03-25 · [Open original](https://medium.com/aws-tip/aws-api-gateway-set-up-custom-domain-names-e161bd51eaad)

## Summary (German, by Luna, unchecked)

Der Bericht beschreibt, wie man für eine API in AWS API Gateway einen eigenen Domainnamen einrichtet: ACM-Zertifikat beantragen und validieren, regionalen Domainnamen anlegen, Route-53-Alias setzen und API, Stage sowie Pfad zuordnen. Die Anleitung setzt eine registrierte Domain voraus, führt nur die Zertifikatsanforderung mit DNS-Validierung aus und nennt ungefähre Zeiten von bis zu 30 Minuten für die Ausstellung und meist 60 Sekunden für die Verbreitung der DNS-Änderung.
