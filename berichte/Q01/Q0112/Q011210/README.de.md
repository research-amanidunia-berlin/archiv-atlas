## Zusammenfassung (von Luna, ungeprüft)

Laut Bericht erreicht ein Entwickler mit einem quantisierten Qwen3.8-27B-Modell auf einer RTX 3090 bis zu rund 381 Tokens pro Sekunde, wenn die Antwort weitgehend aus einem langen Dokument im Kontext übernommen werden kann. Bei gewöhnlichen Chat-Anfragen nennt der Artikel etwa 133 Tokens pro Sekunde; die Werte beruhen auf den berichteten Messungen, unabhängige Prüfungen werden nicht erwähnt.
