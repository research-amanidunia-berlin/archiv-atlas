# Claude Code did this: 400B AI on a Laptop

Report Q011286 · Source medium.com · Date 2026-03-21 · [Open original](https://medium.com/coding-nexus/claude-code-did-this-400b-ai-on-a-laptop-087c38381b23)

## Summary (German, by Luna, unchecked)

Der Bericht behauptet, Claude Code habe in knapp zweieinhalb Stunden eine Methode entwickelt und erprobt, mit der das Modell Qwen3.5–397B auf einem MacBook lokal mit etwa sechs Tokens pro Sekunde läuft. Die frühe Umsetzung könnte laut Autor private Offline-Nutzung ermöglichen, hat aber Einschränkungen wie fehlendes Prefill-Caching und ungünstige SSD-Zugriffe bei MoE-Modellen; unabhängige Messbelege führt der Bericht nicht an.
