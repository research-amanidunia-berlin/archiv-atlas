# Reusable AI Chat Components for SwiftUI

## Summary (German, by Luna, unchecked)

Der Artikel beschreibt Stream-Bausteine für SwiftUI-KI-Chats, darunter Streaming-Nachrichten, Statusanzeigen, Eingaben mit Anhängen und Spracheingabe, und erklärt ihre Einbindung über Stream Chat und einen Node.js-Server. Für KI-Antworten ist dieser Server erforderlich; ohne ihn bleibt ein Chat-Client ohne KI-Generierung. Die Bibliothek enthält laut Beitrag bislang nur einige Kernkomponenten.
