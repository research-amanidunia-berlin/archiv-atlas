# How To Test Alert Notifications With an iOS Simulator

Bericht Q011580 · Quelle medium.com · Datum 2023-11-24 · [Original öffnen](https://medium.com/@amosgyamfi/how-to-test-alert-notifications-with-an-ios-simulator-39bf921a96c5)

## Zusammenfassung (von Luna, ungeprüft)

Der Bericht beschreibt, wie sich iOS-Push-Alerts im Simulator mit einer `.apns`-JSON-Payload und der Kommandozeile `xcrun simctl push` testen lassen. Laut Autor braucht dieser Simulator-Test keinen eigenen APNs-Server; für produktive Remote-Benachrichtigungen über echte Geräte sei APNs jedoch erforderlich.

## Sammelfragen

Je Zelle: Anteil Stufe 4–7 / Stufe 3–7 (4 = enthält zitierbare Belege … 7 = beantwortet direkt; 3 = nützlicher Hintergrund). Aufgeführt: Sammelfragen, bei denen mindestens ein Modell den Stufen 3–7 mindestens 10 % gibt. „–“ = Modell hat diesen Bericht nicht bewertet. Volle Verteilungen: [bericht.json](bericht.json).
