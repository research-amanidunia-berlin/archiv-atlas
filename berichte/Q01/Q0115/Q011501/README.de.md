# Prototyping with code

## Zusammenfassung (von Luna, ungeprüft)

Das Panels-Team entwickelte eine einhändige Zoomfunktion für Comics, indem es mehrere Code-Prototypen ausprobierte: von einer Lupe über eine kleine Steuerfläche bis zum Zoomen der ganzen Seite. Laut Autor erwies sich die letzte Variante als natürlicher und wurde nach der Veröffentlichung von Nutzerinnen und Nutzern gut aufgenommen; unabhängige Messwerte oder detaillierte Tests nennt der Bericht nicht.

## Sammelfragen

Je Zelle: Anteil Stufe 4–7 / Stufe 3–7 (4 = enthält zitierbare Belege … 7 = beantwortet direkt; 3 = nützlicher Hintergrund). Aufgeführt: Sammelfragen, bei denen mindestens ein Modell den Stufen 3–7 mindestens 10 % gibt. „–“ = Modell hat diesen Bericht nicht bewertet. Volle Verteilungen: [bericht.json](bericht.json).

Keine Sammelfrage erreicht bei einem Modell 10 % in Stufe 3–7.
