# Build Interactive In-App Polls With SwiftUI

Bericht Q011562 · Quelle medium.com · Datum 2024-07-23 · [Original öffnen](https://medium.com/@amosgyamfi/build-interactive-in-app-polls-with-swiftui-c53f5cbb7f03)

[Alle Berichte](../../../README.de.md) · Daten: [bericht.json](bericht.json)

## Zusammenfassung (von Luna, ungeprüft)

Der vollständige Bericht erklärt, wie die integrierte Umfragefunktion des Stream Chat SDK ab Version 4.57.0 in eine SwiftUI-Chat-App eingebunden und angepasst wird. Das Beispiel aktiviert Umfragen, ermöglicht Abstimmungen und blendet über `PollsConfig` das Kommentarfeld aus; die gezeigten Zugangsdaten sind laut Autor nur für Demos gedacht.

## Sammelfragen

Je Zelle: Anteil Stufe 4–7 / Stufe 3–7 (4 = enthält zitierbare Belege … 7 = beantwortet direkt; 3 = nützlicher Hintergrund).
