## Zusammenfassung (von Luna, ungeprüft)

Der Artikel erklärt die Einrichtung von React Native CLI auf macOS und zeigt, wie eine Videoanruf-App mit Stream SDK für iOS und Android vorbereitet wird. Er behandelt Entwicklungswerkzeuge, SDKs, Berechtigungen und den Start auf Simulatoren oder Geräten, liefert aber keine vollständige Beschreibung der App-Implementierung oder Kompatibilität mit allen Versionen.
