# Custom SwiftUI transitions with Metal

## Zusammenfassung (von Luna, ungeprüft)

Der Bericht beschreibt mehrere SwiftUI-Übergänge mit Metal-Verzerrungen: von einem per Kreis aufgedeckten Ripple bis zu einem Shader, der Pixel abhängig von ihrer Position oder Entfernung zum Zentrum freilegt und wellenartig verschiebt. Der Autor stellt den verbesserten Ansatz anhand von Code und visuellen Beispielen vor, liefert jedoch keine systematischen Leistungs- oder Gerätevergleiche.

## Sammelfragen

Je Zelle: Anteil Stufe 4–7 / Stufe 3–7 (4 = enthält zitierbare Belege … 7 = beantwortet direkt; 3 = nützlicher Hintergrund). Aufgeführt: Sammelfragen, bei denen mindestens ein Modell den Stufen 3–7 mindestens 10 % gibt. „–“ = Modell hat diesen Bericht nicht bewertet. Volle Verteilungen: [bericht.json](bericht.json).

Keine Sammelfrage erreicht bei einem Modell 10 % in Stufe 3–7.
