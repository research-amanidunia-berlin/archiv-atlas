## Zusammenfassung (von Luna, ungeprüft)

Der Beitrag zeigt einen Swift-Property-Wrapper namens `@Tracked`, der bei jeder Änderung den vorherigen Eigenschaftswert in einem Array speichert und den Verlauf über `$eigenschaft` zugänglich macht. Der Autor schlägt Debugging und Undo als mögliche Anwendungen vor; Tests oder eine vollständige Undo-Lösung enthält der Bericht nicht.
