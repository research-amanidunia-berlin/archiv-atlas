## Summary (German, by Luna, unchecked)

Der Bericht stellt DiffuCoder-7B als Apples Codegenerierungsmodell vor, das Code ausgehend von Rauschen schrittweise überarbeitet und dadurch ganze Sequenzen bearbeiten können soll. Apple zufolge verbessert es sich um 4,4 Prozent auf EvalPlus; laut Autor bleibt es jedoch ein langsamer, rechenintensiver Forschungsprototyp, dessen Vorteile für die Praxis noch nicht belegt werden.
