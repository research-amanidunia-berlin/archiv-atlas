## Zusammenfassung (von Luna, ungeprüft)

Der Bericht erklärt SDFs und zeigt, wie sich Formen in Metal über Minimum- und Maximumfunktionen vereinigen, schneiden oder voneinander abziehen lassen. Eine glatte Vereinigung rundet Übergänge zwischen nahen Formen ab; Beispiele sind eine Lava-Lampe, Lichtkugeln und ein tropfender Button. Die Einführung bietet Code und Illustrationen, aber keine Leistungswerte oder einen Nachweis, dass damit Apples GlasContainer konkret implementiert wird.
