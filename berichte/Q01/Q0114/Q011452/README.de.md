## Zusammenfassung (von Luna, ungeprüft)

Der Bericht beschreibt `@Networked`, einen Combine-basierten SwiftUI-Property-Wrapper, der URL-Anfragen und das Dekodieren von JSON kapseln soll; als Vorteile nennt der Autor sauberere, weniger wiederholungsreiche Ansichten. Im Beispiel werden Fehler zu `nil`, sodass die Oberfläche einen fehlgeschlagenen Abruf nicht vom noch laufenden unterscheidet.
