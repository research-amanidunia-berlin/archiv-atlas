## Zusammenfassung (von Luna, ungeprüft)

Der Bericht erklärt, wie eine `MTKView` mithilfe von `NSViewRepresentable` und einem Coordinator in SwiftUI eingebunden wird. Das Minimalbeispiel setzt eine aufgelöste SwiftUI-Farbe als Clear Color und stößt das Zeichnen an; eine Demo variiert die Farbe in einem fünfsekündigen Zyklus. Es behandelt keine eigentliche Metal-Grafik.
