## Zusammenfassung (von Luna, ungeprüft)

Der Bericht erklärt, wie Metal-Shader für vertikale Glasstreifen einen breiteren Bildbereich abtasten und auf einzelne Spalten abbilden, sodass eine Lupenverzerrung entsteht. Er zeigt außerdem eine vereinfachte Berechnung mit `fract` und eine gekrümmte Variante, deren genaue Umsetzung im Text nicht ausgeführt wird.
