# Mandelbrot Set in SwiftUI using a Metal Shader: Part 1

Bericht Q011489 · Quelle medium.com · Datum 2025-01-12 · [Original öffnen](https://medium.com/@giikwebdeveloper/metal-accelerated-mandelbrot-set-in-swiftui-4bb062af389d)

## Zusammenfassung (von Luna, ungeprüft)

Der Autor erklärt, wie er eine Mandelbrot-Menge mit SwiftUI-Canvas und einem Metal-Shader zeichnet: Er skaliert und transformiert einen Ausschnitt der komplexen Ebene und färbt Punkte anhand der Iterationen der Mandelbrot-Rekursion. Er berichtet von schneller Darstellung und geringer CPU-Last, nennt dafür aber keine Messwerte; Zoom und eine editierbare Palette bleiben späteren Teilen vorbehalten.
