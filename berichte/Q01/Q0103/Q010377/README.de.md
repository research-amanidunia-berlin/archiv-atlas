## Zusammenfassung (von Luna, ungeprüft)

Der vollständige Artikel erklärt OAuth-2.0-Endpunkte und zeigt einen beispielhaften Express-Server mit Authorization Code, Refresh Token, PKCE, Metadaten und Widerruf. Ein `openid-client`-Testclient durchläuft den Ablauf bis zum Zugriff auf eine geschützte Ressource. Die Implementierung ist ausdrücklich grundlegend: Sie verwendet flüchtige Beispieldaten, lässt dynamische Clientregistrierung offen und erhebt nur einen eingeschränkten Konformitätsanspruch.
