## Summary (German, by Luna, unchecked)

Der Artikel vergleicht ältere MCP-Kommunikation über HTTP-SSE mit Streamable HTTP und führt anhand verkürzter TypeScript-Beispiele durch Verbindung, Sessions, Werkzeugaufrufe und Benachrichtigungen.
