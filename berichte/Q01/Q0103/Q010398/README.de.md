## Zusammenfassung (von Luna, ungeprüft)

Der vollständige Leitfaden empfiehlt für ein Datenwissenschafts-Portfolio eine Projektübersicht, Informationen zur Person und eine Kontaktmöglichkeit; als Technik nennt er Flask für einfache Websites, Django für komplexere Anwendungen sowie Bootstrap für die Gestaltung. Zur Veröffentlichung beschreibt der Autor Heroku, weist aber auf mögliche Startverzögerungen beim kostenlosen Hosting hin; konkrete Bau- oder Testergebnisse enthält der Beitrag nicht.
