## Zusammenfassung (von Luna, ungeprüft)

Der Artikel beschreibt einen noch nicht offiziell veröffentlichten MCP-Autorisierungsentwurf, bei dem ein separater Authorization Server Token für den Resource Server ausstellt. Das Beispiel nutzt JWTs und einen eigenen SDK-Fork; fehlende Scope-Unterstützung, Einschränkungen im SDK und der vorläufige Status machen die gezeigte Implementierung zu einem unfertigen Ansatz.
