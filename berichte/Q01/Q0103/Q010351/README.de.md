## Zusammenfassung (von Luna, ungeprüft)

Der Artikel beschreibt einen eigenen SwiftUI-`Transferable`-Typ, mit dem `ShareLink` ein Bild erst beim Teilen und bei Bedarf asynchron erzeugen kann. Eine zusätzliche URL-Repräsentation kann weitere Teilen-Ziele verfügbar machen; der Beitrag zeigt dies anhand von Code und Bildschirmaufnahmen, liefert aber keinen systematischen Leistungstest oder Kompatibilitätsvergleich.
