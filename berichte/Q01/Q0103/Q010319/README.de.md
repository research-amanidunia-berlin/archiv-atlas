## Zusammenfassung (von Luna, ungeprüft)

Der vollständige Bericht erklärt anhand einer SwiftUI-Notiz-App, wie CloudKit-Datensätze in benutzerdefinierten Zonen geteilt, Einladungen angenommen und Änderungen per Subscription abgerufen werden. Der Autor berichtet, dass Remote Notifications in seinen Tests auf Simulatoren nicht funktionierten, auf echten Geräten aber schon; weitere Details und den vollständigen Code verweist er auf GitHub beziehungsweise einen Folgebeitrag.
