# loc vs iloc in Pandas. Here’s The Difference.

Bericht Q010332 · Quelle frank-andrade.medium.com · Datum 2022-02-02 · [Original öffnen](https://frank-andrade.medium.com/loc-vs-iloc-in-pandas-heres-the-difference-16cd4bcbecab)

## Zusammenfassung (von Luna, ungeprüft)

Der vollständige Bericht vergleicht `loc` für Bezeichnungen mit `iloc` für nullbasierte Positionen und zeigt damit einzelne Werte, Listen, Slices und bedingte Auswahlen in Pandas. Bei Slices schließt `loc` das Ende ein, `iloc` schließt es aus; in einem Beispiel nennt der Text über 180 cm, während der Code über 170 cm prüft.

Je Zelle: Anteil Stufe 4–7 / Stufe 3–7 (4 = enthält zitierbare Belege … 7 = beantwortet direkt; 3 = nützlicher Hintergrund).
