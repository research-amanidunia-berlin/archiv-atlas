# SwiftUI: Inline Editable Table

## Zusammenfassung (von Luna, ungeprüft)

Der vollständige Bericht beschreibt eine SwiftUI-Tabelle mit Finder-ähnlicher Inline-Bearbeitung: Der Autor ergänzt Fokus- und Auswahlzustände, um Escape-Rollback, anfängliche Textmarkierung und Zeilenwechsel während der Bearbeitung umzusetzen. Er berichtet außerdem von einer gelegentlichen Absturzgefahr bei gemeinsam genutzter Textauswahl und davon, dass `fixedSize()` allein das Textfeld zittern lässt; seine Lösung und Erklärung dazu beruhen auf eigenen Beobachtungen.

Je Zelle: Anteil Stufe 4–7 / Stufe 3–7 (4 = enthält zitierbare Belege … 7 = beantwortet direkt; 3 = nützlicher Hintergrund).
