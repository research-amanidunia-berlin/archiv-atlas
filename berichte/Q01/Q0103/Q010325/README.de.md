# Command Box: An NPM for ColdFusion

## Zusammenfassung (von Luna, ungeprüft)

Der Autor stellt CommandBox als npm-ähnliches Werkzeug für CFML vor, mit Paketverwaltung sowie dem Ausführen von Dateien, eingebauten Funktionen und Tasks. Er hebt besonders hervor, dass CFML-Dateien ohne Serverstart ausgeführt werden können, und beschreibt dafür beispielhafte Befehle. Die Installationshinweise gelten nur für macOS; eigene Funktionen erforderten in seinem Beispiel Task Runner mit `.cfc`-Dateien.
