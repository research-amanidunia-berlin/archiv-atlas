## Summary (German, by Luna, unchecked)

Der Artikel zeigt an einer Next.js-Bildergalerie, wie die View Transition API React-Ansichtswechsel mit Überblendung, Zoom und Wischen animieren kann; dabei steuern `view-transition-name`, React-Zustand und CSS den Übergang. Für seitenübergreifende Effekte berichtet der Autor von Problemen mit Next.js-`Link` und `router` und nutzt stattdessen direkte Navigation mit URL-Parametern. Er weist auf den jungen Stand der API und nicht selbst getestete experimentelle Next.js-Unterstützung hin.
