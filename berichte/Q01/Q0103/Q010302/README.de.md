## Zusammenfassung (von Luna, ungeprüft)

Der Beitrag beantwortet 15 Fragen zu Aufgaben, Gehalt und Einstieg in Data Science. Andrade empfiehlt als Grundlagen Python, SQL sowie Mathematik und Statistik; Gehalt, Jobchancen und konkrete Aufgaben seien jedoch abhängig von Ort und Arbeitsfeld. Python könne bei großen Datenmengen und Machine Learning Vorteile bieten, während die Rechtslage beim Web Scraping umstritten sei.
