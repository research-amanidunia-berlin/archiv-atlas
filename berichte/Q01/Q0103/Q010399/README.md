# Node.Js/Typescript: An Import Path Cannot End with ‘.ts’

## Summary (German, by Luna, unchecked)

Der vollständige Bericht nennt drei Lösungsansätze für TypeScript-Importe mit `.ts`-Endung: `allowImportingTsExtensions` mit `noEmit` oder `emitDeclarationOnly`, das Weglassen der Endung bei geänderter Modulauflösung oder die Verwendung von `.js` im Import. Die Beispiele beruhen auf der Konfiguration des Autors; insbesondere könne die `.js`-Variante mit `commonjs` möglicherweise scheitern.
