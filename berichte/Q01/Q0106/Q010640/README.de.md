# SwiftUI: Create Systemwide Custom Keyboard

## Zusammenfassung (von Luna, ungeprüft)

Der vollständige Bericht führt anhand einer Emoji-Tastatur vor, wie eine systemweite iOS-Tastatur-Erweiterung mit SwiftUI, `UIHostingController` und `textDocumentProxy` aufgebaut wird. Der Autor nennt Unterschiede zwischen Geräten mit und ohne Notch sowie Probleme, die er beim Auffinden der Tastatureinstellungen im iOS-18-Simulator und beim Einbetten in eine `UIInputView` beobachtete; umfassende Kompatibilitätstests beschreibt er nicht.
