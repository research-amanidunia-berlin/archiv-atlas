# SwiftUI:  Clip Views with ClipShape

## Zusammenfassung (von Luna, ungeprüft)

Der Bericht erklärt, dass `clipShape` eine Ansicht auf eine Form zuschneidet, während `background` nur eine Form dahinter zeichnet und `mask` auch Deckkraft übertragen kann. An zwei Animationen zeigt der Autor bewegte und wachsende Kreisausschnitte; seine Vermutung, `mask` sei rechenaufwendiger, ist ausdrücklich ungemessen und persönlich.
