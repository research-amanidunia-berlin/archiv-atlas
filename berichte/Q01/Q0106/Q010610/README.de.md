# HTML/CSS: Two Inline-Block Same Height

## Zusammenfassung (von Luna, ungeprüft)

Der Artikel zeigt einen CSS-Workaround, der Inline-Blöcke mithilfe großer Innenabstände, negativer Außenabstände und `overflow: hidden` auf gleiche Höhe bringen soll. Die Werte müssen angepasst werden; der Ansatz ist auf Fälle zugeschnitten, in denen `inline-block` beibehalten werden muss, und `overflow: hidden` kann Inhalte abschneiden.
