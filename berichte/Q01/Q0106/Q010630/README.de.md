# PostgreSQL: UPSERT

## Zusammenfassung (von Luna, ungeprüft)

Der Bericht erklärt, dass PostgreSQL UPSERT mit `INSERT ... ON CONFLICT` umsetzt: Je nach Konflikt wird ein Datensatz eingefügt, ignoriert oder aktualisiert. Für mehrere Eingabezeilen zeigt er `EXCLUDED`, um die jeweils versuchten Werte in das Update zu übernehmen; die Darstellung bleibt bei einfachen Grundlagenbeispielen.
