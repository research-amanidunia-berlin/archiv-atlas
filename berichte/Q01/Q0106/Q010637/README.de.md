# Android/Kotlin/Jetpack Compose: Custom Launch Screen (Splash Screen)

Bericht Q010637 · Quelle medium.com · Datum 2024-07-25 · [Original öffnen](https://medium.com/gitconnected/android-kotlin-jetpack-compose-custom-launch-screen-splash-screen-fd15942db92d)

## Zusammenfassung (von Luna, ungeprüft)

Der vollständige Beitrag beschreibt in vier Schritten, wie ein Android-Splash-Screen mit `core-splashscreen`, einem XML-Theme, der Manifest-Konfiguration und `installSplashScreen()` eingerichtet wird. Für längere Anzeige dient `setKeepOnScreenCondition`, das Beispiel koppelt sie an einen Ladezustand; Testergebnisse oder weitergehende Kompatibilitätsgrenzen werden nicht berichtet.
