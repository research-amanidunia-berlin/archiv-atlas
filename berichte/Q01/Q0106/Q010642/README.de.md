## Zusammenfassung (von Luna, ungeprüft)

Der vollständige Artikel zeigt anhand eines Swift-/iOS-Timers, wie man Mitteilungskategorien und Aktionsschaltflächen registriert, sie einer lokalen oder Remote-Mitteilung zuordnet und Nutzeraktionen verarbeitet. Eine ergänzende Variante plant Erinnerungen nach; der Autor weist darauf hin, dass der Beispielcode dabei alle ausstehenden Anfragen löscht und produktiver Code gezielt die einzelne Erinnerung entfernen sollte.
