## Zusammenfassung (von Luna, ungeprüft)

Der vollständige Bericht zeigt eine inoffizielle Rust-Bibliothek für drei Funktionen der Google Translation API v2: Übersetzen, Spracherkennung und Auflisten unterstützter Sprachen. Er erläutert Einrichtung per API-Schlüssel oder Service-Account und weist darauf hin, dass `isReliable` und `confidence` wegen ihrer Veraltung nicht ins Antwortmodell aufgenommen wurden.
