# SwiftUI: Horizontal ScrollView on Vertical Drag Gesture

## Zusammenfassung (von Luna, ungeprüft)

Der Artikel zeigt, wie eine vertikale DragGesture eine horizontale SwiftUI-ScrollView steuern kann, und begrenzt die Position anhand der ermittelten Inhaltsgröße, um Überscrollen abzufangen. Für iOS 18 wird ScrollPosition vorgestellt, für ältere Versionen ein empfindlicherer offset-Ansatz; einige technische Erklärungen bleiben laut Autorin unsicher oder offen.
