# SwiftUI: Use SwiftData outside a View (In a Manager Class/ViewModel)

## Zusammenfassung (von Luna, ungeprüft)

Der vollständige Bericht erläutert am Beispiel einer Todo-App, wie eine Manager-Klasse SwiftData über `ModelContainer`, `ModelContext` und `FetchDescriptor` außerhalb einer View verwenden kann. Der Autor betont, dass der Manager seine Listen nach Änderungen selbst neu abfragen muss; seine Hinweise zu einem scheinbar zufälligen SwiftData-Fehler und möglichen Abhilfen sind Erfahrungsberichte ohne geklärte Ursache.
