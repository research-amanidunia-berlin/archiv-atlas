## Zusammenfassung (von Luna, ungeprüft)

Der Bericht erklärt, wie man im iOS-Simulator eine `.apns`-Datei mit Bundle-ID und Benachrichtigungs-Payload erstellt und per Ziehen auf den Simulator eine Push-Mitteilung auslöst. Laut Autor kann das Tests der Benachrichtigungsverarbeitung beschleunigen; vorausgesetzt wird eine bereits eingerichtete App, und systematische Testergebnisse werden nicht genannt.
