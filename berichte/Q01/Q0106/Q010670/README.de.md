# SwiftUI: Add App Delegate/Scene Delegate and Pass Data to Views

Bericht Q010670 · Quelle medium.com · Datum 2024-06-20 · [Original öffnen](https://medium.com/stackademic/swiftui-add-app-delegate-scene-delegate-and-pass-data-to-views-135a159a8e49)

## Zusammenfassung (von Luna, ungeprüft)

Der Bericht erklärt, wie App- und Scene-Delegates in SwiftUI eingebunden werden und wie sie über `ObservableObject`, `@Published` und `@EnvironmentObject` Daten an Views weitergeben können. Ein Leser berichtet von einem Fehler mit einem leeren Szenennamen in der `Info.plist`; der Artikel klärt diesen Einwand nicht und nennt keine umfassenden Voraussetzungen für die Beispiele.
