# SwiftUI: Color Picker 2 Ways

## Zusammenfassung (von Luna, ungeprüft)

Der Artikel vergleicht den SwiftUI-`ColorPicker` mit `UIColorPickerViewController` in einer SwiftUI-Umhüllung. Laut Autor ist die SwiftUI-Lösung einfacher und bietet die Farbpipette, während UIKit mehr Kontrolle über Titel, Auslöser, Sichtbarkeit und Höhe ermöglicht, aber eigene Anpassungen wie einen Schließen-Knopf erfordert.
