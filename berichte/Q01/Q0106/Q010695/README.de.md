# New Relic: Send Alert Notification to Slack

Bericht Q010695 · Quelle medium.com · Datum 2024-05-20 · [Original öffnen](https://medium.com/stackademic/new-relic-send-alert-notification-to-slack-26ac704d2777)

## Zusammenfassung (von Luna, ungeprüft)

Der vollständige Bericht erklärt anhand von AWS-CloudWatch-Logs, wie New Relic über Slack-Webhooks individuell gestaltete Alarmnachrichten senden kann. Dazu werden Slack-App und Webhook sowie in New Relic Ziel, Alert Policy, Bedingung und Workflow eingerichtet; der Autor empfiehlt für unregelmäßige Daten einen passend bemessenen Event Timer. Die Übertragbarkeit auf andere Dienste wird behauptet, aber nicht systematisch belegt.
