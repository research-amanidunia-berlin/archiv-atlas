# Send Email via Gmail API: Http Request Without Using Client Library

Bericht Q010671 · Quelle medium.com · Datum 2024-06-17 · [Original öffnen](https://medium.com/towardsdev/send-email-via-gmail-api-http-request-without-using-client-library-5019a0e0b68d)

## Zusammenfassung (von Luna, ungeprüft)

Der vollständige Bericht erklärt anhand von Python und ColdFusion 2018, wie Text-E-Mails und Nachrichten mit Anhängen ohne Client-Bibliothek über die Gmail API gesendet werden: MIME-Nachricht erstellen, Base64URL-kodieren und als `raw` an den Sende-Endpunkt schicken. Er nennt Anforderungen an `sub`, Absender und `userId`, weist auf die genaue MIME-Formatierung hin und zeigt beispielhafte Erfolgantworten, dokumentiert aber keine systematischen Tests oder umfassende Fehlerbehandlung.
