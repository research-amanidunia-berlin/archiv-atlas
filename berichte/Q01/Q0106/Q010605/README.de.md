# Rust API Server: Send and Receive Bytes Data

## Zusammenfassung (von Luna, ungeprüft)

Der vollständige Beitrag zeigt Axum-Beispiele zum Empfangen binärer Daten per direktem Request-Body oder Multipart sowie zum Zurücksenden der Daten mit passenden Antwort-Headern. Die Beispiele setzen beim Dateinamen ein bestimmtes `Content-Disposition`-Format voraus; außerdem nennt der Beitrag ein standardmäßiges Body-Limit von 2 MB und weist auf knappe Fehlerbehandlung im Multipart-Code hin.

## Sammelfragen

Je Zelle: Anteil Stufe 4–7 / Stufe 3–7 (4 = enthält zitierbare Belege … 7 = beantwortet direkt; 3 = nützlicher Hintergrund). Aufgeführt: Sammelfragen, bei denen mindestens ein Modell den Stufen 3–7 mindestens 10 % gibt. „–“ = Modell hat diesen Bericht nicht bewertet. Volle Verteilungen: [bericht.json](bericht.json).

Keine Sammelfrage erreicht bei einem Modell 10 % in Stufe 3–7.
