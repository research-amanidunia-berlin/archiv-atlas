# SwiftUI: Working with Path: Get All Points and Tangents!

Bericht Q010628 · Quelle medium.com · Datum 2024-08-04 · [Original öffnen](https://medium.com/gitconnected/swiftui-working-with-path-get-all-points-and-tangents-2c7dbe9af6e2)

## Zusammenfassung (von Luna, ungeprüft)

Der vollständige Bericht zeigt zwei SwiftUI-Verfahren, um Punkte auf einem `Path` zu ermitteln: `trimmedPath` liefert laut Autor gleichmäßig entlang des Pfads verteilte Punkte, aber keine Tangenten; eine mathematische Auswertung der Linien und Bézierkurven kann zusätzlich Tangentenwinkel berechnen. Bei der zweiten Methode wird die Punktzahl je Pfadelement festgelegt, und auf Bézierkurven sind die Punkte nicht unbedingt gleichmäßig nach Wegstrecke verteilt.
