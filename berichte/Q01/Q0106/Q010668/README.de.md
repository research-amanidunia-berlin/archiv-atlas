# SwiftUI: NFC Tags Background Reading with Custom JSON Payload and Pass Data to Views

Bericht Q010668 · Quelle medium.com · Datum 2024-06-22 · [Original öffnen](https://medium.com/gitconnected/swiftui-nfc-tags-background-reading-with-custom-json-payload-and-pass-data-to-views-3b3696eb9622)

[Alle Berichte](../../../README.de.md) · Daten: [bericht.json](bericht.json)

## Zusammenfassung (von Luna, ungeprüft)

Der Beitrag erläutert, wie eine SwiftUI-App Hintergrund-NFC-Lesen mit einem Universal-Link-Datensatz und einem JSON-Datensatz verbindet und die empfangenen Daten bei beendeter oder inaktiver App verarbeitet. Laut Autor sind dafür je nach App-Zustand Scene Delegate oder `onContinueUserActivity` zuständig; das Beispiel zeigt das Ergebnis als Text und nennt Einschränkungen der Hintergrundlesefunktion.

## Sammelfragen

Je Zelle: Anteil Stufe 4–7 / Stufe 3–7 (4 = enthält zitierbare Belege … 7 = beantwortet direkt; 3 = nützlicher Hintergrund). Aufgeführt: Sammelfragen, bei denen mindestens ein Modell den Stufen 3–7 mindestens 10 % gibt. „–“ = Modell hat diesen Bericht nicht bewertet. Volle Verteilungen: [bericht.json](bericht.json).

Keine Sammelfrage erreicht bei einem Modell 10 % in Stufe 3–7.
