# SwiftUI: Read/Write NFC Tags with Custom JSON Payload

Bericht Q010678 · Quelle medium.com · Datum 2024-06-09 · [Original öffnen](https://medium.com/stackademic/swiftui-read-write-nfc-tags-with-custom-json-payload-a49eb721eb1e)

[Alle Berichte](../../../README.de.md) · Daten: [bericht.json](bericht.json)

## Zusammenfassung (von Luna, ungeprüft)

Der vollständige Artikel erklärt anhand einer SwiftUI-Beispiel-App, wie Core NFC NDEF-Tags scannt, JSON-Payloads dekodiert und eigene JSON-Daten auf beschreibbare Tags schreibt. Er beschreibt Einrichtung und grundlegende Fehlerbehandlung; laut Autor sind ein echtes Gerät und eine bezahlte Apple-Mitgliedschaft zum Signieren nötig. Die Umsetzung bleibt beim gezeigten NDEF-Beispiel und wird nicht systematisch auf Geräten oder Tag-Varianten geprüft.

## Sammelfragen
