# SwiftUI: Custom Color Dropper to Get Color at any View Location

Bericht Q010591 · Quelle medium.com · Datum 2024-09-15 · [Original öffnen](https://medium.com/gitconnected/swiftui-custom-color-dropper-to-get-color-at-any-view-location-7847b65e06d5)

## Zusammenfassung (von Luna, ungeprüft)

Itsuki beschreibt eine SwiftUI-Farbpipette, die eine Ansicht mit `ImageRenderer` in ein `CGImage` umwandelt und anhand von Tipp- oder Ziehkoordinaten Pixelwerte als RGBA und Hex ausliest. Das Beispiel setzt voraus, dass das gerenderte Bild im RGBA-Format vorliegt, und weist darauf hin, dass die Größe in der gerenderten Ansicht selbst festgelegt werden muss.

## Sammelfragen

Je Zelle: Anteil Stufe 4–7 / Stufe 3–7 (4 = enthält zitierbare Belege … 7 = beantwortet direkt; 3 = nützlicher Hintergrund). Aufgeführt: Sammelfragen, bei denen mindestens ein Modell den Stufen 3–7 mindestens 10 % gibt. „–“ = Modell hat diesen Bericht nicht bewertet. Volle Verteilungen: [bericht.json](bericht.json).

Keine Sammelfrage erreicht bei einem Modell 10 % in Stufe 3–7.
