## Zusammenfassung (von Luna, ungeprüft)

Der vollständige Bericht erklärt anhand eines Beispiels, wie Lambda-, Choice- und Pass-Zustände in AWS Step Functions eine While-Schleife bilden: Eine Zahl wird wiederholt mit zehn multipliziert, bis sie über 100 liegt. Für die Eingabe 0,15 nennt der Autor das Ergebnis 150 und drei Lambda-Aufrufe; für For-Schleifen bevorzugt er persönlich den Map-Zustand.
