## Zusammenfassung (von Luna, ungeprüft)

Der Bericht erklärt SwiftUIs `Table` anhand von Pokémon-Daten: Spalten, feste Zeilenreihenfolge sowie Einzel- und Mehrfachauswahl werden mit Codebeispielen gezeigt. Der Autor schildert dabei ein mögliches Problem beim Auslesen von `EditMode` über die Umgebung und zeigt, wie einzelne Zeilen von der Auswahl ausgeschlossen werden können.
