# SwiftUI: Add, Erase and Save Custom Drawing Annotations to PDF

Bericht Q010507 · Quelle medium.com · Datum 2025-01-13 · [Original öffnen](https://medium.com/gitconnected/swiftui-add-erase-and-save-custom-drawing-annotations-to-pdf-6f971e717bb3)

[Alle Berichte](../../../README.de.md) · Daten: [bericht.json](bericht.json)

## Zusammenfassung (von Luna, ungeprüft)

Der Bericht erläutert eine SwiftUI-/PDFKit-Methode, die Zeichnungen zunächst als Punkte in einer Overlay-Ansicht sammelt und erst beim Abschließen als benutzerdefinierte PDF-Annotation speichert. Zum Radieren werden eigene Annotationen in Punkte zurückverwandelt und Punkte innerhalb eines kreisförmigen Bereichs entfernt. Laut Autor ist die Bearbeitung auf diese eigene Annotationsart begrenzt; systematische Tests werden nicht berichtet.

## Sammelfragen

Je Zelle: Anteil Stufe 4–7 / Stufe 3–7 (4 = enthält zitierbare Belege … 7 = beantwortet direkt; 3 = nützlicher Hintergrund). Aufgeführt: Sammelfragen, bei denen mindestens ein Modell den Stufen 3–7 mindestens 10 % gibt. „–“ = Modell hat diesen Bericht nicht bewertet. Volle Verteilungen: [bericht.json](bericht.json).

Keine Sammelfrage erreicht bei einem Modell 10 % in Stufe 3–7.
