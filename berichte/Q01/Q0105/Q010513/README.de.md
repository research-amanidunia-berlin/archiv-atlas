# React/Typescript: Table Row Re-Ordering with Drag and Drop

Bericht Q010513 · Quelle medium.com · Datum 2025-01-08 · [Original öffnen](https://medium.com/gitconnected/react-table-row-re-ordering-with-drag-and-drop-fb7105baafb7)

[Alle Berichte](../../../README.de.md) · Daten: [bericht.json](bericht.json)

## Zusammenfassung (von Luna, ungeprüft)

Der vollständige Bericht zeigt anhand einer Pokémon-Tabelle, wie React und TypeScript Zeilen mit der nativen Drag-and-Drop-API während des Ziehens neu sortieren und nach einem Abbruch die vorherige Reihenfolge wiederherstellen können. Der Autor beschreibt außerdem Zieheffekte und eine visuelle Markierung der bewegten Zeile; bei `setDragImage` meldet er eigene Probleme mit Safari.

## Sammelfragen

Je Zelle: Anteil Stufe 4–7 / Stufe 3–7 (4 = enthält zitierbare Belege … 7 = beantwortet direkt; 3 = nützlicher Hintergrund). Aufgeführt: Sammelfragen, bei denen mindestens ein Modell den Stufen 3–7 mindestens 10 % gibt. „–“ = Modell hat diesen Bericht nicht bewertet. Volle Verteilungen: [bericht.json](bericht.json).

Keine Sammelfrage erreicht bei einem Modell 10 % in Stufe 3–7.
