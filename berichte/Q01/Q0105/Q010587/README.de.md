# Swift: Sharing Data Between Apps/Extensions With App Group

## Zusammenfassung (von Luna, ungeprüft)

Der Bericht beschreibt die Einrichtung einer App Group für mehrere Apps oder Erweiterungen und zeigt, wie diese über eine gemeinsame `UserDefaults`-Suite einen Zählerwert teilen können. Für `@AppStorage` wird die Suite als `store` angegeben; der gezeigte Code verwendet bei fehlender Gruppen-Suite `UserDefaults.standard`.
