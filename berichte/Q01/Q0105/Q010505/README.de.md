# SwiftUI: Add Interactive Form Elements to PDF

Bericht Q010505 · Quelle medium.com · Datum 2025-01-15 · [Original öffnen](https://medium.com/gitconnected/swiftui-add-interactive-form-elements-to-pdf-579b555d680f)

## Zusammenfassung (von Luna, ungeprüft)

Der vollständige Bericht zeigt anhand von SwiftUI und PDFKit, wie Textfelder, Optionsfelder, Kontrollkästchen, Drucktasten und Auswahlmenüs als interaktive PDF-Widgets angelegt und konfiguriert werden. Als wichtige Stolperfalle nennt der Autor die Reihenfolge beim Einrichten gruppierter Optionsfelder; digitale Signaturen konnte er nicht funktionsfähig umsetzen.

## Sammelfragen

Je Zelle: Anteil Stufe 4–7 / Stufe 3–7 (4 = enthält zitierbare Belege … 7 = beantwortet direkt; 3 = nützlicher Hintergrund). Aufgeführt: Sammelfragen, bei denen mindestens ein Modell den Stufen 3–7 mindestens 10 % gibt. „–“ = Modell hat diesen Bericht nicht bewertet. Volle Verteilungen: [bericht.json](bericht.json).

Keine Sammelfrage erreicht bei einem Modell 10 % in Stufe 3–7.
