# SwiftUI: Step 0 to Layout Protocol

## Zusammenfassung (von Luna, ungeprüft)

Der vollständige Bericht demonstriert ein einfaches SwiftUI-`Layout`, das Unteransichten vertikal stapelt: Es berechnet die Containergröße aus Kindergrößen und Abständen und platziert die Kinder anschließend von oben nach unten. Ein fester Abstand und horizontale Ausrichtung sind konfigurierbar; weiterführende Funktionen wie Caching und eigene `LayoutValues` bleiben außerhalb des Beitrags.
