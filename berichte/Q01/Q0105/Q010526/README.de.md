Der Beitrag beschreibt einen AWS-CDK-Aufbau mit VPC, isoliertem Aurora-PostgreSQL-Serverless-v2-Cluster, RDS Proxy, Secrets Manager, Rust-Lambda und optionalem API Gateway. Er liefert Konfigurationsbeispiele, aber keine dokumentierten Testergebnisse; der Datenbankzugriff soll durch Ausführen der Lambda geprüft werden.
