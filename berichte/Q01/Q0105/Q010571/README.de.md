# Swift Assets: Same Name, Different Contents

Bericht Q010571 · Quelle medium.com · Datum 2024-10-13 · [Original öffnen](https://medium.com/gitconnected/swift-assets-same-name-different-contents-aad108f754f5)

[Alle Berichte](../../../README.de.md) · Daten: [bericht.json](bericht.json)

## Zusammenfassung (von Luna, ungeprüft)

Der vollständige, kurze Artikel zeigt, wie gleichnamige Bilder in verschiedenen Asset-Ordnern laut Autor über „Provides Namespace“ unterscheidbar werden: `Image("front/25")` und `Image("back/25")`. Ohne diese Einstellung ignoriere `Image("25")` den Ordnernamen und lade im Beispiel das Bild aus `back`.

## Sammelfragen

Je Zelle: Anteil Stufe 4–7 / Stufe 3–7 (4 = enthält zitierbare Belege … 7 = beantwortet direkt; 3 = nützlicher Hintergrund). Aufgeführt: Sammelfragen, bei denen mindestens ein Modell den Stufen 3–7 mindestens 10 % gibt. „–“ = Modell hat diesen Bericht nicht bewertet. Volle Verteilungen: [bericht.json](bericht.json).

Keine Sammelfrage erreicht bei einem Modell 10 % in Stufe 3–7.
