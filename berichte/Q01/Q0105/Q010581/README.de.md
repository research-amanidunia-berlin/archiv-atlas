# SwiftUI ContainerValues: Key to Custom Containers

Bericht Q010581 · Quelle medium.com · Datum 2024-09-29 · [Original öffnen](https://medium.com/gitconnected/swiftui-containervalues-key-to-custom-containers-f6ab6842f0ed)

[Alle Berichte](../../../README.de.md) · Daten: [bericht.json](bericht.json)

## Zusammenfassung (von Luna, ungeprüft)

Der Bericht zeigt, wie SwiftUIs `ContainerValues` eigene Werte – etwa Kartenfarben oder Hintergrund-Views – von Unteransichten an deren direkten Container übermittelt. Der Autor demonstriert dafür `@Entry` und `Subview.containerValues`; für Hintergrund-Views nutzt er `AnyView`, weist aber darauf hin, dass er diese Lösung nicht als die beste oder als Erklärung für SwiftUIs interne `listRowBackground`-Implementierung bestätigen kann.
