# SwiftUI: Pass Data and Link to Specific View from Widgets

Bericht Q010585 · Quelle medium.com · Datum 2024-09-26 · [Original öffnen](https://medium.com/gitconnected/swiftui-pass-data-and-link-to-specific-view-from-widgets-b68b8cae5658)

## Zusammenfassung (von Luna, ungeprüft)

Der vollständige Bericht erklärt anhand von zwei SwiftUI-Beispielen, wie Widgets über `widgetURL` und einzelne `Link`-Elemente Daten per URL an eine App übergeben, damit diese eine Übersicht oder direkt eine Detailansicht öffnet. Der Autor empfiehlt URLs für einfache Daten und nennt `NSUserActivity` als Alternative für viele Parameter in konfigurierbaren Widgets; eine systematische Prüfung von Randfällen enthält der Bericht nicht.
