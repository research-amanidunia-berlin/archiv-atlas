# Upload/Download Large Files to S3 using PreSigned URL

## Zusammenfassung (von Luna, ungeprüft)

Der Bericht zeigt anhand von Rust-Beispielen, wie vorab signierte S3-URLs für Uploads per `PUT` und direkte Downloads erzeugt werden. Der Autor nennt größere mögliche Dateigrößen und zeitlich begrenzten Zugriff als Vorteile, weist aber darauf hin, dass diese URLs weniger Sicherheit und Kontrolle bieten.
