# SwiftUI: Add Static Annotations & Page Graphics to PDF

Bericht Q010516 · Quelle medium.com · Datum 2025-01-03 · [Original öffnen](https://medium.com/gitconnected/swiftui-add-static-annotations-page-graphics-to-pdf-905f37af6a30)

## Zusammenfassung (von Luna, ungeprüft)

Der vollständige Bericht zeigt, wie statische PDF-Anmerkungen mit `PDFAnnotation` und seitenweite Grafiken über angepasste `PDFPage`-Unterklassen in SwiftUI/PDFKit umgesetzt werden. Er behandelt Zeichnen, Koordinatensysteme und die Reihenfolge beim Einrichten des Delegaten; interaktive Bearbeitung bleibt außen vor.
