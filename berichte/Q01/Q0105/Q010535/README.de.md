# SwiftUI: Mastering Layout Values in Layout Protocol

## Zusammenfassung (von Luna, ungeprüft)

Der vollständige Bericht erläutert eingebaute und benutzerdefinierte Layoutwerte in SwiftUIs `Layout`-Protokoll und zeigt, wie ein Container Unteransichten danach sortiert oder über Bindings skaliert. Der Autor hält die bidirektionale Variante wegen möglicher Layoutschleifen und zusätzlichem Aufwand für nicht empfehlenswert und rät für Änderungen an Unteransichten zu einem eigenen Container-View.
