## Zusammenfassung (von Luna, ungeprüft)

Der vollständige Artikel vergleicht `LocalizedStringKey` und `AttributedString` zum Rendern von Markdown in SwiftUI und beschreibt ihre jeweiligen Einsatzmöglichkeiten und Grenzen. Für schlecht dargestellte Codeblöcke schlägt der Autor vor, jede Zeile in Inline-Code umzuwandeln; Sprachfärbung bietet dieser einfache Ansatz nicht.
