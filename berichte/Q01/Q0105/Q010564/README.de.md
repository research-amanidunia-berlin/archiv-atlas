## Zusammenfassung (von Luna, ungeprüft)

Der Beitrag zeigt anhand von CDK-Beispielen, wie QuickSight-Filtergruppen für einen Datumsbereich und eine Nutzerkategorie samt Steuerelementen in Analyse und Sheet eingetragen werden. Er erklärt außerdem die einmalige Zuordnung einer Filter-ID pro Control und skizziert die Anpassung für alle Sheets; eine erfolgreiche Ausführung oder Testergebnisse werden nicht berichtet.
