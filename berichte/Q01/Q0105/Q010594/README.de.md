## Zusammenfassung (von Luna, ungeprüft)

Der vollständige Bericht vergleicht SwiftUIs hierarchische `List` mit einem eigenen animierten Kartenstapel: Die eingebaute Lösung ist knapp, während die individuelle Variante mehr Code braucht, aber die verborgenen Einträge sichtbar andeutet. Laut Autor wird der Stapel bei sehr vielen Elementen oder tiefen Hierarchien unübersichtlich; dafür empfiehlt er eine Begrenzung der angezeigten Karten beziehungsweise getrennte Ansichten mit Navigation.

## Sammelfragen

Je Zelle: Anteil Stufe 4–7 / Stufe 3–7 (4 = enthält zitierbare Belege … 7 = beantwortet direkt; 3 = nützlicher Hintergrund). Aufgeführt: Sammelfragen, bei denen mindestens ein Modell den Stufen 3–7 mindestens 10 % gibt. „–“ = Modell hat diesen Bericht nicht bewertet. Volle Verteilungen: [bericht.json](bericht.json).

Keine Sammelfrage erreicht bei einem Modell 10 % in Stufe 3–7.
