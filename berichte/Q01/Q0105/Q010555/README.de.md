# SwiftUI: Add ContextMenu to Table

## Zusammenfassung (von Luna, ungeprüft)

Der vollständige Bericht zeigt am Beispiel einer SwiftUI-Tabelle, wie ein an `Table` angebrachtes Auswahl-Kontextmenü Aktionen für angeklickte beziehungsweise ausgewählte Zeilen anbieten kann. Ein zweiter Kontextmenü-Modifier ohne Auswahltyp soll Aktionen für freien Tabellenraum bereitstellen; systematische Versions- oder Plattformtests werden nicht berichtet.
