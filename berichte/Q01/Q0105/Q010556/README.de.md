# SwiftUI: Hierarchical Table 2 Ways

Bericht Q010556 · Quelle medium.com · Datum 2024-11-02 · [Original öffnen](https://medium.com/gitconnected/swiftui-hierarchical-table-2-ways-c5b734438e17)

[Alle Berichte](../../../README.de.md) · Daten: [bericht.json](bericht.json)

## Zusammenfassung (von Luna, ungeprüft)

Der vollständige Bericht erklärt zwei SwiftUI-Ansätze für hierarchische Tabellen: einen `Table`-Initialisierer mit `children` sowie `OutlineGroup` innerhalb eines `rows`-Blocks. Laut Autor verarbeitet `OutlineGroup` verschachtelte Daten automatisch und erlaubt zugleich, statische Zeilen einzufügen; `DisclosureTableRow` löse die Datenhierarchie hingegen nicht selbst auf.

## Sammelfragen

Je Zelle: Anteil Stufe 4–7 / Stufe 3–7 (4 = enthält zitierbare Belege … 7 = beantwortet direkt; 3 = nützlicher Hintergrund). Aufgeführt: Sammelfragen, bei denen mindestens ein Modell den Stufen 3–7 mindestens 10 % gibt. „–“ = Modell hat diesen Bericht nicht bewertet. Volle Verteilungen: [bericht.json](bericht.json).

Keine Sammelfrage erreicht bei einem Modell 10 % in Stufe 3–7.
