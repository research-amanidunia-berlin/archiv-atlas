# SwiftUI/MacOS: NSTrackingView For Mouse Enter and Mouse Exit

Bericht Q010511 · Quelle medium.com · Datum 2025-01-11 · [Original öffnen](https://medium.com/gitconnected/swiftui-macos-nstrackingview-for-mouse-enter-and-mouse-exit-91cb3d688e3b)

## Zusammenfassung (von Luna, ungeprüft)

Der Beitrag beschreibt, wie eine per `NSViewRepresentable` eingebundene `NSView` mit `NSTrackingArea` Maus-Eintritts- und Austrittsereignisse an SwiftUI weitergeben kann. Er erläutert Rechteck, Eigentümer und Aktivitätsoptionen und zeigt als Beispiel farbige Effekte an der Mausposition; für einfache Hover-Abfragen empfiehlt der Autor `onHover`.
