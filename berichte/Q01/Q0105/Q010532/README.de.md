# SwiftUI: Support Custom URL Scheme

## Zusammenfassung (von Luna, ungeprüft)

Der Beitrag erklärt die Registrierung benutzerdefinierter URL-Schemas in Xcode und ihre Verarbeitung in SwiftUI über `.onOpenURL`. Der Autor nennt fehlenden Backend-Bedarf als Vorteil, warnt vor Schema-Kollisionen und bevorzugt Universal Links, wenn Links eindeutig zur Website gehören oder eine Ersatzseite bei nicht installierter App benötigt wird.
