# SwiftUI: Enable Drag and Drop for Table Rows With Custom Transferable

Bericht Q010563 · Quelle medium.com · Datum 2024-10-20 · [Original öffnen](https://medium.com/gitconnected/swiftui-enable-drag-and-drop-for-table-rows-with-custom-transferable-aa0e6eb9f5ce)

[Alle Berichte](../../../README.de.md) · Daten: [bericht.json](bericht.json)

## Zusammenfassung (von Luna, ungeprüft)

Der Bericht erklärt anhand einer Pokémon-Tabelle, wie SwiftUI-Zeilendaten mit einem eigenen UTType und `Transferable` per Drag-and-drop verschoben werden: Ziehbare Daten hängen an `TableRow`, das Drop-Ziel an `ForEach`. Die Autorin beziehungsweise der Autor berichtet von Problemen mit Xcode 16 und davon, dass die Logik auf dem iPad nicht funktioniere; Ursachen oder Tests werden nicht beschrieben.

## Sammelfragen

Je Zelle: Anteil Stufe 4–7 / Stufe 3–7 (4 = enthält zitierbare Belege … 7 = beantwortet direkt; 3 = nützlicher Hintergrund). Aufgeführt: Sammelfragen, bei denen mindestens ein Modell den Stufen 3–7 mindestens 10 % gibt. „–“ = Modell hat diesen Bericht nicht bewertet. Volle Verteilungen: [bericht.json](bericht.json).

Keine Sammelfrage erreicht bei einem Modell 10 % in Stufe 3–7.
