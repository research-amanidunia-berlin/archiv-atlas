# SwiftUI: Custom Container View + Editable

## Zusammenfassung (von Luna, ungeprüft)

Der vollständige Bericht erläutert zwei Wege, eine eigene SwiftUI-Boardansicht um Verschieben per Drag-and-drop und Löschen per Wischgeste zu erweitern; der Autor bevorzugt eine direkt übergebene Aktion gegenüber einem Binding in der SectionView. Eigene Containerwerte ermöglichen unter anderem individuelle Aktionen und deaktivierte Elemente, während die Erklärung zu SwiftUIs interner `List`-Umsetzung ausdrücklich Vermutung bleibt.
