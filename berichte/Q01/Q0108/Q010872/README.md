## Summary (German, by Luna, unchecked)

Der Bericht schildert, wie die Community das verwaiste Claude-Code-Projekt GSD nach einer Krise um einen damit verbundenen Token in ein neues Repository übertrug. Laut Autor blieben Code und MIT-Lizenz erhalten; die Ursache und Verantwortlichkeit für den Token-Rug-Pull sowie der Zustand des ursprünglichen Entwicklers seien ungeklärt. Als neue Bezugsquelle nennt der Text „open-gsd/gsd-core“ und empfiehlt, Installationsquelle und Maintainer selbst zu überprüfen.
