## Zusammenfassung (von Luna, ungeprüft)

Der Autor schildert Claude Code Projects als Beta-Koordinator, der Aufgaben auf mehrere Cloud-Threads verteilt und ihre Ergebnisse etwa als Pull Requests zusammenführt. In seinem Beispiel liefen zwei von drei Änderungen prüfbereit ein, während ein Thread bei einem Problem nachfragte; als Vorteile nennt er außerdem gemeinsames Projektgedächtnis und klare Anweisungen. Er warnt vor schnellem Verbrauch durch die standardmäßige Einstellung Opus mit hohem Aufwand und beschreibt die Funktion zum damaligen Zeitpunkt als auf Pro und Max beschränkt; seine Einschätzung beruht auf einem kurzen persönlichen Test.
