# TableView with Dynamic Height in Swift

Bericht Q010830 · Quelle medium.com · Datum 2023-09-06 · [Original öffnen](https://medium.com/@itsuki.enjoy/tableview-with-dynamic-height-in-swift-ffd06e989463)

## Zusammenfassung (von Luna, ungeprüft)

Der vollständige Bericht beschreibt eine Storyboard-Lösung, bei der eine `UITableView`-Unterklasse ihre intrinsische Höhe aus `contentSize` ableitet und bei Layoutänderungen neu berechnet. Eine optionale Mindest- und Höchsthöhe begrenzt die Tabelle laut Autor auf 100 bis 300 Punkte; weitere Randbedingungen werden nicht behandelt.
