## Summary (German, by Luna, unchecked)

Der Autor beschreibt Behavioral Skills als Anweisungen, die KI-Agenten zu angemessenem Aufwand anhalten sollen, etwa damit sie Aufgaben nicht vorzeitig abbrechen oder typische KI-Schreibmuster erzeugen.
