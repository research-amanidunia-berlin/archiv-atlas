## Summary (German, by Luna, unchecked)

Der Artikel zeigt, wie sich auf- und zuklappbare Tabelleninhalte in Swift durch eigene `UITableView`-Abschnitte umsetzen lassen: Eine Hauptzelle bleibt sichtbar, Optionszellen werden je nach Zustand ergänzt oder ausgeblendet. Beim Tippen auf die Hauptzelle wird der Zustand umgeschaltet und die Tabelle neu geladen; eigene Aktionen für Optionszellen können laut Autor ergänzt werden.
