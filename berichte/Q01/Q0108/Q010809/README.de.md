# Chrome Extension: Get User’s Access Token and Perform Google API Requests

Bericht Q010809 · Quelle medium.com · Datum 2023-11-19 · [Original öffnen](https://medium.com/@itsuki.enjoy/chrome-extension-get-users-access-token-and-perform-google-api-requests-346ce8078294)

## Zusammenfassung (von Luna, ungeprüft)

Der Bericht erklärt am Beispiel von Google Calendar, wie eine Chrome-Erweiterung eine OAuth-Client-ID einrichtet, über die Chrome-Identity-API ein Zugriffstoken erhält und damit Kalenderereignisse abruft. Laut Autor muss die Zustimmung gegebenenfalls interaktiv eingeholt werden; außerdem soll der Aufruf in einer externen JavaScript-Datei stehen. Die Darstellung bleibt ein Tutorial für diesen Beispielablauf.
