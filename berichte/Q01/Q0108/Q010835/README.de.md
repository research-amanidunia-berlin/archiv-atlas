# POST file using multipart/form-data in Rust

Bericht Q010835 · Quelle medium.com · Datum 2023-08-16 · [Original öffnen](https://medium.com/@itsuki.enjoy/post-file-using-multipart-form-data-in-rust-5171ae57aeed)

## Zusammenfassung (von Luna, ungeprüft)

Der vollständige Bericht zeigt einen zweistufigen Datei-Upload mit Rust und `reqwest` für die Line Works API: erst eine Upload-URL anfordern, dann die Datei als Multipart-Formular mit passenden Feldnamen senden. Der Autor berichtet von Fehlern bei direktem Versand der Dateibytes und falsch benannten Formularfeldern; seine Hinweise beruhen auf eigenen Beispielen für diese API.
