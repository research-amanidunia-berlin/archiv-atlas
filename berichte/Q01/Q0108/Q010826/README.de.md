# Infinite/Endless Scrolling Background in Swift/SpriteKit

Bericht Q010826 · Quelle medium.com · Datum 2023-09-25 · [Original öffnen](https://medium.com/@itsuki.enjoy/infinite-endless-scrolling-background-in-swift-spritekit-140a723c7d1f)

## Zusammenfassung (von Luna, ungeprüft)

Der Bericht zeigt eine SpriteKit-Technik für endloses Scrollen: Vier Hintergrundabschnitte bewegen sich zeitbasiert, und ein Abschnitt, der oben aus dem Bild läuft, wird unter den letzten gesetzt. Eine einfache Touch-Variante für Ziehbewegungen wird ebenfalls skizziert; Messungen oder systematische Tests nennt der Bericht nicht.

## Sammelfragen

Je Zelle: Anteil Stufe 4–7 / Stufe 3–7 (4 = enthält zitierbare Belege … 7 = beantwortet direkt; 3 = nützlicher Hintergrund). Aufgeführt: Sammelfragen, bei denen mindestens ein Modell den Stufen 3–7 mindestens 10 % gibt. „–“ = Modell hat diesen Bericht nicht bewertet. Volle Verteilungen: [bericht.json](bericht.json).

Keine Sammelfrage erreicht bei einem Modell 10 % in Stufe 3–7.
