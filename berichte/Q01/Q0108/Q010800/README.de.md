# Horizontal scrollable buttons (tabs) with Indicators

Bericht Q010800 · Quelle medium.com · Datum 2023-12-24 · [Original öffnen](https://medium.com/@itsuki.enjoy/horizontal-scrollable-buttons-tabs-with-indicators-7aafafbbaae2)

## Zusammenfassung (von Luna, ungeprüft)

Der vollständige Bericht zeigt anhand von UIKit-Code, wie horizontal scrollbare Tabs mit UICollectionView, einer dynamisch breiten Zellklasse und links/rechts eingeblendeten Scroll-Hinweisen umgesetzt werden können. Die beschriebenen Vorteile und Probleme beruhen auf den Erfahrungen des Autors; dokumentierte Tests oder eine umfassende Behandlung von Randfällen enthält die Anleitung nicht.

## Sammelfragen

Je Zelle: Anteil Stufe 4–7 / Stufe 3–7 (4 = enthält zitierbare Belege … 7 = beantwortet direkt; 3 = nützlicher Hintergrund). Aufgeführt: Sammelfragen, bei denen mindestens ein Modell den Stufen 3–7 mindestens 10 % gibt. „–“ = Modell hat diesen Bericht nicht bewertet. Volle Verteilungen: [bericht.json](bericht.json).

Keine Sammelfrage erreicht bei einem Modell 10 % in Stufe 3–7.
