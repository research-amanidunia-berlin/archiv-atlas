## Zusammenfassung (von Luna, ungeprüft)

Der Autor schildert, wie ein Next.js-Docker-Build nach einer Neuinstallation von Docker Desktop auf seinem M2-Mac hängen blieb. Bei ihm löste das Deaktivieren von „Use Rosetta to run Intel code“ das Problem; weitere Vorschläge wie engere Tailwind-Pfade oder mehr Ressourcen werden nur als mögliche Ansätze genannt. Der Bericht dokumentiert einen einzelnen Fall.
