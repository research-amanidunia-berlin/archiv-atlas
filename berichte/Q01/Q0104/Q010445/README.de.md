## Zusammenfassung (von Luna, ungeprüft)

Der vollständige Artikel erläutert eine native SwiftUI-Anmeldung über Amazon Cognito User Pools und das AWS-SDK, einschließlich Registrierung, Sitzungsverwaltung, Passwortrücksetzung und Tokenabruf. Er zeigt die nötige SDK-Konfiguration und eine Async-Überbrückung für AWS-Callbacks; Geräteinformationen erfordern aktivierte Geräteverfolgung, und der Autor hält `AWSUserPoolsSignIn` im Beispiel wegen zusätzlicher Anforderungen für wenig zweckmäßig.
