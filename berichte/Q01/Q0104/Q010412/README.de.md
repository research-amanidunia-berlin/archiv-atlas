## Zusammenfassung (von Luna, ungeprüft)

Der Artikel zeigt anhand von Swift-Beispielen, wie `async let` und Task Groups mehrere asynchrone Funktionen gemeinsam ausführen und Ergebnisse sammeln. `async let` eignet sich für feste Aufrufe, Task Groups für dynamische Aufgaben und Abbruchfälle; die Beispiele machen zugleich deutlich, dass abgebrochene Kindaufgaben nicht zwangsläufig sofort enden.
