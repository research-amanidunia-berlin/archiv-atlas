# Fake SMTP Email Server for Testing

## Zusammenfassung (von Luna, ungeprüft)

Der Autor schildert die Einrichtung von smtp4dev als lokalen SMTP-Testserver: Server starten, ein Testpostfach anlegen und die Anwendung mit Port 25 sowie ausgeschaltetem SSL/TLS und ausgeschalteter Authentifizierung verbinden. Bei ihm funktionierte als Hostname die private IP-Adresse statt `localhost`; geprüft werden können gesendete Nachrichten im Terminal oder in der Weboberfläche. Die Anleitung basiert auf der Windows-x64-Version und persönlichen Erfahrungen.
