# Making Your Custom Font Support Dynamic Font Sizes

## Zusammenfassung (von Luna, ungeprüft)

Der Artikel zeigt, wie SwiftUIs `Font.custom` mit `relativeTo` eine eigene Schrift an die bevorzugte dynamische Schriftgröße koppelt. Eine statische Eigenschaft in einer `CustomFont`-Klasse macht den Aufruf laut Autor übersichtlicher und erweiterbar; Tests oder Beispiele über Roboto in Größe 18 hinaus enthält der Bericht nicht.
