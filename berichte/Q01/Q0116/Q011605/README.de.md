# Understanding the Anchor Point in Kite Compositor

Bericht Q011605 · Quelle medium.com · Datum 2017-04-26 · [Original öffnen](https://medium.com/nimbbble/understanding-the-anchor-point-in-kite-compositor-2a203e48c617)

## Zusammenfassung (von Luna, ungeprüft)

Der vollständige Bericht erläutert, dass Drehungen und Skalierungen in Kite um den Ankerpunkt einer Ebene erfolgen, der standardmäßig links oben liegt und verschoben oder animiert werden kann. Der Punkt lässt sich im Inspector einstellen, direkt ziehen oder per Werkzeugleistensymbol zentrieren; der Bericht nennt keine Tests oder Kite-Version.
