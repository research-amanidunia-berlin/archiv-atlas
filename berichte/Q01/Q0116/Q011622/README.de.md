## Zusammenfassung (von Luna, ungeprüft)

Der Bericht zeigt eine wiederverwendbare SwiftUI-Komponente für Mehrfachauswahlen: Sie fügt Optionen beim Antippen hinzu oder entfernt sie und überlässt Darstellung und Anordnung dem aufrufenden Code. Beispiele zeigen eine horizontale Schaltflächenreihe und Checkboxen; Tests und Barrierefreiheit werden nicht behandelt.
