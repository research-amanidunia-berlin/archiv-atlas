## Zusammenfassung (von Luna, ungeprüft)

Der vollständige Bericht zeigt anhand einfacher Werte und `User`-Objekte, wie `Array(collection.enumerated())` Index und Element für eine SwiftUI-`ForEach`-Ansicht bereitstellt. Als Kennung dient im ersten Beispiel der Index, im zweiten die Objekt-ID; weitere Ansätze oder Sonderfälle werden nicht behandelt.
