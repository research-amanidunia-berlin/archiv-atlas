## Zusammenfassung (von Luna, ungeprüft)

Der vollständige Bericht zeigt, wie SwiftUI-Sheets mit `presentationDetents` auf feste, relative oder mehrere Höhen eingestellt und per benutzerdefiniertem Detent an Dynamic Type angepasst werden können. Der Autor empfiehlt eine gut erreichbare Schließen-Schaltfläche und warnt, dass feste Höhen je nach Gerät ungeeignet sein können; die Beispiele sind keine systematische Geräteprüfung.
