# Using Swift Signpost to Measure Performance of a Specific Function

## Zusammenfassung (von Luna, ungeprüft)

Der vollständige Beitrag erläutert, wie ein mit `OSSignposter` markiertes Intervall die Aufrufzahl und Laufzeit einer Swift-Funktion in Instruments messbar macht. Für das Fibonacci-Beispiel berichtet der Autor 91 Aufrufe in insgesamt 58 Millisekunden; diese Werte stammen aus der gezeigten Messung und werden nicht durch eine systematische Vergleichsreihe ergänzt.

## Sammelfragen

Je Zelle: Anteil Stufe 4–7 / Stufe 3–7 (4 = enthält zitierbare Belege … 7 = beantwortet direkt; 3 = nützlicher Hintergrund). Aufgeführt: Sammelfragen, bei denen mindestens ein Modell den Stufen 3–7 mindestens 10 % gibt. „–“ = Modell hat diesen Bericht nicht bewertet. Volle Verteilungen: [bericht.json](bericht.json).

Keine Sammelfrage erreicht bei einem Modell 10 % in Stufe 3–7.
