# Programmatically Hide Navigation in SwiftUI

Bericht Q011659 · Quelle medium.com · Datum 2024-05-13 · [Original öffnen](https://medium.com/stackademic/programmatically-hide-navigation-in-swiftui-87f2dba8e3e1)

## Zusammenfassung (von Luna, ungeprüft)

Der SwiftUI-Beitrag demonstriert, wie `.toolbar` mit `.visible` und `.hidden` Navigationselemente steuert: In einer Beispiel-App werden in „Home“ Navigations- und Tab-Leiste, in „Settings“ nur die Navigationsleiste umgeschaltet. Laut Autor muss der Modifier innerhalb der Ansicht stehen, deren Navigationselemente betroffen sein sollen; weitere Voraussetzungen oder Konfigurationen werden nicht behandelt.
