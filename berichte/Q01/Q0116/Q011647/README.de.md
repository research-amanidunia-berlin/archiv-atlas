## Zusammenfassung (von Luna, ungeprüft)

Der Artikel beschreibt eine SwiftUI-Seitenleiste, die über dem Hauptinhalt liegt, von links animiert ein- und ausgeblendet wird und sich über eine abgedunkelte Fläche schließen lässt. Die Menüeinträge sind Beispiele, die konkrete Navigation bleibt anzupassen; die behauptete iOS-16-Kompatibilität und Leistung werden nicht durch Tests belegt.
