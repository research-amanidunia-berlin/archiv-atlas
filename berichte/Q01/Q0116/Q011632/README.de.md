## Zusammenfassung (von Luna, ungeprüft)

Der vollständige Bericht erläutert SwiftUIs eingebaute Haptik über `sensoryFeedback` und zeigt mit Core Haptics ein Beispiel für ein eigenes Muster aus drei stärker werdenden Impulsen. Laut Autor benötigt Haptik ein unterstütztes physisches Gerät; eingebaute Rückmeldungen sollten ihrer üblichen Bedeutung entsprechend verwendet werden, während weitergehende Implementierungsfragen nur knapp behandelt werden.
