# Using matchedGeometryEffect in SwiftUI

## Zusammenfassung (von Luna, ungeprüft)

Der Beitrag demonstriert mit einer SwiftUI-Bildergalerie, wie `matchedGeometryEffect` den animierten Wechsel von einer Vorschau zur Vollbildansicht ermöglicht, ergänzt um Zoom-, Zieh- und Schließgesten. Er weist auf ablaufende Airtable-Links und mögliche Ladeverzögerungen hin und empfiehlt, Bilder für flüssige Übergänge vorab lokal bereitzustellen.
