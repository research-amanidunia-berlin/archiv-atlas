# Should we use Apple Intelligence for Text and Inputs in SwiftUI using writingToolsBehavior

Bericht Q011638 · Quelle medium.com · Datum 2024-11-22 · [Original öffnen](https://medium.com/@jpmtech/should-we-use-apple-intelligence-for-text-and-inputs-in-swiftui-using-writingtoolsbehavior-49d662ce5ede)

[Alle Berichte](../../../README.de.md) · Daten: [bericht.json](bericht.json)

## Zusammenfassung (von Luna, ungeprüft)

Der Autor berichtet, dass `.writingToolsBehavior` seine SwiftUI-Textfelder unter iOS 18.1.1 nicht wie erwartet steuerte: Selbst `.disabled` habe die Writing Tools nicht verhindert. Seine Tests erforderten ein unterstütztes physisches Gerät mit aktivierter Apple Intelligence; dabei traten zudem Berechtigungsfehler auf.
