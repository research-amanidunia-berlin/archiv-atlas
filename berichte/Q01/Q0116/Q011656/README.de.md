## Zusammenfassung (von Luna, ungeprüft)

Das Tutorial zeigt eine Berechtigungsanfrage und das Setzen eines App-Icon-Badges per Zähler, mit unterschiedlichen Codewegen für iOS 16 und älter sowie iOS 17 und neuer. Die behauptete Unterdrückung von Werten bis einschließlich null ist im gezeigten Code nicht umgesetzt, und eine Leserfrage zur SwiftUI-Spezifik bleibt offen.
