## Zusammenfassung (von Luna, ungeprüft)

Der Beitrag zeigt anhand eines SwiftUI-Codebeispiels, wie `ShareLink` eine App-Store-URL über eine Teilen-Schaltfläche weitergibt. Laut Autor kann Apple dabei App-Name und Bilder automatisch im Teilen-Menü anzeigen; weitere Anwendungsfälle oder Einschränkungen werden kaum behandelt.
