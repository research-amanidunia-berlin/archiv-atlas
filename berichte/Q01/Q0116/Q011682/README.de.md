## Zusammenfassung (von Luna, ungeprüft)

Der vollständige Bericht zeigt die Grundlagen von Core Data in SwiftUI: Datenmodell und persistenten Container einrichten, Einträge speichern und mit `@FetchRequest` anzeigen sowie Abfragen sortieren und filtern. Eine Beschreibung des Filterbeispiels widerspricht dem Code beim Grenzwert 65; außerdem bleibt das Tutorial auf ein einfaches Beispiel beschränkt.
