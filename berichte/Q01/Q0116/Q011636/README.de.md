## Zusammenfassung (von Luna, ungeprüft)

Der Artikel beschreibt einen SwiftUI-ViewModifier, der eine Ansicht beim Herunterwischen um mehr als 100 Pixel schließt und sie bei kürzerem Ziehen zurücksetzt. Eine Erweiterungsmethode macht die Funktion im Beispiel mit einem einzelnen Aufruf wiederverwendbar; weitergehende Tests oder Einschränkungen werden nicht behandelt.
