## Zusammenfassung (von Luna, ungeprüft)

Der vollständige Bericht zeigt XCTest anhand von Tests für einen Trinkgeldrechner: geprüft werden ungültige Eingaben und ein korrekt berechnetes Ergebnis. Als Grenzen nennt der Autor wiederholten Testcode, lange Testnamen und die Prüfung von Fehlern über einen Textvergleich; XCTest könne außerdem keine Argumente an Testfunktionen übergeben.
