# Custom keyboard (SwiftUI) to fulfill your app needs

Bericht Q011609 · Quelle medium.com · Datum 2024-07-22 · [Original öffnen](https://medium.com/@darrenthiores/custom-keyboard-swiftui-to-fulfill-your-app-needs-62a53971f9af)

[Alle Berichte](../../../README.de.md) · Daten: [bericht.json](bericht.json)

## Zusammenfassung (von Luna, ungeprüft)

Der Bericht zeigt, wie eine SwiftUI-Tastatur über einen `UIHostingController` als Eingabeansicht eines per `UIViewRepresentable` eingebundenen `UITextField` verwendet werden kann. Der Autor weist auf ein Cursorproblem hin und empfiehlt als Workaround, die Cursorposition auf das Textende zu beschränken; außerdem solle eine eigene Tastatur nur bei konkretem Nutzen und unter Beachtung von Apples HIG eingesetzt werden.
