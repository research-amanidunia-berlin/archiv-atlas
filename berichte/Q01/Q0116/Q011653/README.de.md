# New Text Formatters in iOS 18

Bericht Q011653 · Quelle medium.com · Datum 2024-06-11 · [Original öffnen](https://medium.com/@jpmtech/new-text-formatters-in-ios-18-4c9037e1d980)

## Zusammenfassung (von Luna, ungeprüft)

Der vollständige Bericht zeigt anhand eines SwiftUI-Beispiels, wie `reference`, `offset` und `timer` in iOS 18 Zeitabstände und Timer formatieren. Der Autor nennt Konfigurationsmöglichkeiten und berichtet als Beobachtungen unter anderem von einer nötigen Datumsreihenfolge beim Timer, einer offenbar auf Millisekunden begrenzten Anzeige und einem Countdown, der nach Ablauf auf null bleibt.

## Sammelfragen

Je Zelle: Anteil Stufe 4–7 / Stufe 3–7 (4 = enthält zitierbare Belege … 7 = beantwortet direkt; 3 = nützlicher Hintergrund). Aufgeführt: Sammelfragen, bei denen mindestens ein Modell den Stufen 3–7 mindestens 10 % gibt. „–“ = Modell hat diesen Bericht nicht bewertet. Volle Verteilungen: [bericht.json](bericht.json).

Keine Sammelfrage erreicht bei einem Modell 10 % in Stufe 3–7.
