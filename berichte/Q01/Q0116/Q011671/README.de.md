## Zusammenfassung (von Luna, ungeprüft)

Der Bericht stellt Flugmodus, Network Link Conditioner und Xcode als Wege vor, iOS-Apps auf physischen Geräten ohne oder mit eingeschränkter Verbindung zu testen. Für Simulatoren verweist der Autor auf eine externe Anleitung und merkt an, dass deren Methode die Netzwerkverbindung des Computers verändert.
