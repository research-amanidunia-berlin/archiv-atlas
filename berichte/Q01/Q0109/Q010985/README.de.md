# Fable 5.2’s Benchmarks Ran at Xhigh. Claude Code Runs It at Medium.

Bericht Q010985 · Quelle medium.com · Datum 2026-11-12 · [Original öffnen](https://medium.com/@lenner9090/fable-5-2s-benchmarks-ran-at-xhigh-claude-code-runs-it-at-medium-edd83c0927d3)

[Alle Berichte](../../../README.de.md) · Daten: [bericht.json](bericht.json)

## Zusammenfassung (von Luna, ungeprüft)

Der Autor hält die Spitzenwerte von Fable 5.2 für wenig aussagekräftig für den Alltag, weil sie mit Xhigh oder Max ermittelt wurden, während Claude Code standardmäßig Medium nutzt; ein Medium-Wert für den zentralen FrontierCode-Benchmark fehle. Externe Vergleichsdaten deuten laut Bericht auf deutlich höhere Kosten bei Xhigh hin, doch welche Einstellung sich eignet und wie zuverlässig Benchmarks bei möglicher Evaluationserkennung sind, müsse durch eigene Tests geklärt werden.
