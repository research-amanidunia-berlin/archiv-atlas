# Claude Code Uses 5.5x Fewer Tokens Than Cursor. Or 2.9x More. Both Numbers Are Real.

Bericht Q010987 · Quelle medium.com · Datum 2026-11-08 · [Original öffnen](https://medium.com/@lenner9090/claude-code-uses-5-5x-fewer-tokens-than-cursor-or-2-9x-more-both-numbers-are-real-4968e941ac17)

[Alle Berichte](../../../README.de.md) · Daten: [bericht.json](bericht.json)

## Zusammenfassung (von Luna, ungeprüft)

Die Zahlen von 5,5-mal weniger und 2,9-mal mehr Tokens stammen laut Bericht aus unterschiedlichen Tests: Der erste verglich verschiedene Modelle in einem einzelnen Auftrag, der zweite hielt das Modell konstant und fand bei gleich guter Testleistung mehr Tokens für Claude Code als für Cursor. Die Kosten lagen im zweiten Test dennoch nahe beieinander, und Konfiguration sowie Prompt-Caching beeinflussten die Ergebnisse; keine der Zahlen belegt daher zuverlässig, was ein bestimmtes Team zahlen wird.
