# Your DeepSeek API Model Changed Twice Since August. You Didn’t Change a Line.

Report Q010994 · Source medium.com · Date 2026-10-22 · [Open original](https://medium.com/towards-artificial-intelligence/your-deepseek-api-model-changed-twice-since-august-you-didnt-change-a-line-b92eb494ad2c)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Der Auszug behauptet, dass DeepSeek seit August zweimal geändert habe, welches Modell API-Aufrufe unter älteren Modellnamen bedienen, ohne dass Nutzer ihre Konfiguration änderten. Bei der Vorstellung von V4.1-Flash-1017 sei laut Autor wenig beachtet worden, dass DeepSeek Anfragen an alte Namen nun an das neue Modell weiterleite und keine Anleitung zur Weiternutzung des alten Modells gebe. Der restliche Bericht ist hinter einer Medium-Mitgliedschaftsschranke verborgen.
