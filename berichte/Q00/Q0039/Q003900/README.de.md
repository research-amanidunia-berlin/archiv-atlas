# Emergent introspective awareness in LLMs

Bericht Q003900 · Quelle anthropic.com · Datum 2025-10-29 · [Original öffnen](https://www.anthropic.com/research/introspection)

[Alle Berichte](../../../README.de.md) · Daten: [bericht.json](bericht.json)

## Zusammenfassung (von Luna, ungeprüft)

Anthropic berichtet, dass Claude-Modelle in künstlichen Versuchen manchmal eigene interne Aktivitätsmuster erkannten und beeinflussen konnten; selbst Opus 4.1 gelang die Erkennung injizierter Konzepte jedoch nur selten. Die Ergebnisse gelten als begrenzte, unzuverlässige Hinweise auf funktionale Introspektion und belegen weder Bewusstsein noch verlässliche Selbstberichte.
