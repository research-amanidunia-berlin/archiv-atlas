# Beijing Municipal Implementation Plan for Promoting the Innovative Development of Future Industries

Report Q003967 · Source cset.georgetown.edu · Date 2023-11-20 · [Open original](https://cset.georgetown.edu/publication/beijing-future-industries-plan/)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Der Auszug beschreibt Pekings Plan, bis 2035 Zukunftsindustrien in 20 Branchen zu fördern und ein durchgängiges Ökosystem von Technologieentwicklung bis zur industriellen Skalierung aufzubauen. Er nennt sechs Bereiche, erläutert aber die angekündigten acht Initiativen nicht; die Ziele sind keine belegten Ergebnisse. Es liegt ausdrücklich nur ein Auszug vor, der für den restlichen Plan auf ein PDF verweist.
