# Designing Trustworthy Data Institutions

Report Q003934 · Source oecd.ai · Date 2025-05-17 · [Open original](https://oecd.ai/en/wonk/documents/designing-trustworthy-data-institutions)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Der Auszug beschreibt, wie Daten und KI nach seiner Darstellung Klimaschutz unterstützen könnten, etwa durch Vorhersagen zu Migration und Extremwetter. Da Gemeinschaften bei der Datennutzung oft wenig mitbestimmen könnten, sollen Datentreuhandmodelle ihre Beteiligung stärken; konkrete Ergebnisse der dazu beauftragten Untersuchung nennt der Auszug nicht.
