# Nubank elevates customer experiences with OpenAI

Report Q003969 · Source openai.com · Date – · [Open original](https://openai.com/index/nubank/)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Der Bericht beschreibt Nubanks KI-Einsatz für interne Wissenssuche, Unterstützung im Callcenter, automatisierte Kundenanfragen und eine Pilotlösung zur Betrugsprüfung. Die genannten Verbesserungen und Nutzungszahlen sind Angaben aus der OpenAI-Darstellung; Messmethoden und unabhängige Bestätigung fehlen, und für die automatische Bearbeitung von Erstanfragen nennt der Text unterschiedliche Werte (bis zu 50 beziehungsweise 55 Prozent).
