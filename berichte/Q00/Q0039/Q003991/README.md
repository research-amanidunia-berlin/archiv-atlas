# A Primer on Data and Social Justice

Report Q003991 · Source oecd.ai · Date 2025-05-15 · [Open original](https://oecd.ai/en/wonk/documents/a-primer-on-data-and-social-justice)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Der vorliegende Bericht ist ein Auszug, der ungleiche Auswirkungen von Datennutzung und KI sowie die begrenzte Vielfalt in bestehenden Regulierungsansätzen kritisiert. Er plädiert für eine Regulierung im Gemeinwohlinteresse und für den Aufbau von Kompetenzen und Infrastruktur, damit Staaten ihre Datensouveränität stärken können; konkrete Methoden oder Maßnahmen nennt der Auszug nicht.
