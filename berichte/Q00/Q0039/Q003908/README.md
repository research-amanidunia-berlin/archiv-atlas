# LegalOn halves Codex costs while maintaining development speed

Report Q003908 · Source openai.com · Date 2026-10-08 · [Open original](https://openai.com/index/legalon-halves-codex-costs/)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

LegalOn zufolge sanken die geschätzten täglichen Codex-Kosten durch passende Modellauswahl, Einschränkung des Fast-Modus und abgestufte Budgets um rund 65 Prozent, während die Entwicklungsgeschwindigkeit erhalten blieb. Eine geplante Kennzahl soll künftig KI-Kosten pro Funktionsveröffentlichung mit dem Kundennutzen verknüpfen; die Berechnung dafür ist noch nicht fertig.
