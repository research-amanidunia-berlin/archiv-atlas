# Signing the Code of Practice on Transparency of AI-generated Content

Bericht Q001382 · Quelle digital-strategy.ec.europa.eu · Datum – · [Original öffnen](http://digital-strategy.ec.europa.eu/en/faqs/signing-code-practice-transparency-ai-generated-content)

[Alle Berichte](../../../README.de.md) · Daten: [bericht.json](bericht.json)

## Zusammenfassung (von Luna, ungeprüft)

Die EU-Kommission erläutert einen freiwilligen, zweiteiligen Kodex, mit dem Anbieter und bestimmte Betreiber Transparenzpflichten für KI-Inhalte umsetzen und nachweisen können. Eine positive Angemessenheitsbewertung ist Voraussetzung für den beschriebenen Nachweiswert; wer nicht unterzeichnet, muss die Pflichten aus Artikel 50 dennoch anderweitig erfüllen. Der Text nennt den 2. August 2026 als Anwendungsbeginn und eine mögliche Übergangsfrist, die von der Annahme einer Regel im AI Omnibus abhängt.
