# OpenAI Red Teaming Network

Bericht Q001360 · Quelle openai.com · Datum 2023-12-01 · [Original öffnen](https://openai.com/index/red-teaming-network/)

[Alle Berichte](../../../README.de.md) · Daten: [bericht.json](bericht.json)

## Zusammenfassung (von Luna, ungeprüft)

OpenAI kündigt ein Netzwerk externer Fachleute an, die Modelle und Produkte je nach Expertise auf Risiken prüfen sollen; Beiträge zu Projekten würden vergütet, könnten aber Vertraulichkeitsvereinbarungen unterliegen. Der Bericht nennt keine konkreten Wirkungsergebnisse, und die Bewerbungsphase der Ausschreibung endete am 1. Dezember 2023.
