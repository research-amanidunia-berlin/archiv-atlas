# Scientists Call for Global AI Safety Preparedness to Avert Catastrophic Risks

Report Q001371 · Source far.ai · Date 2026-08-19 · [Open original](https://www.far.ai/blog/scientists-call-for-global-ai-safety-preparedness-to-avert-catastrophic-risks)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Bei einem internationalen Treffen zur KI-Sicherheit in Venedig erarbeiteten Wissenschaftler und Politikfachleute laut FAR.AI drei Vorschläge: internationale Notfallvorsorge, unabhängige Sicherheitsnachweise für leistungsfähige KI und globale Forschung zur Überprüfung von Sicherheitsbehauptungen. Der Artikel berichtet über diese Empfehlungen, weist aber keine Umsetzung oder Wirksamkeit nach; es ist ein vollständiger Artikel, kein Auszug oder eine Fehlerseite.
