# ClearHarm: A more challenging jailbreak dataset

Bericht Q001325 · Quelle far.ai · Datum 2026-08-19 · [Original öffnen](https://www.far.ai/blog/clearharm-a-more-challenging-jailbreak-dataset)

[Alle Berichte](../../../README.de.md) · Daten: [bericht.json](bericht.json)

## Zusammenfassung (von Luna, ungeprüft)

FAR.AI veröffentlicht ClearHarm, einen Benchmark mit 179 eindeutig schädlichen Anfragen zu Waffen und bösartigem Code, der Mehrdeutigkeiten und legitime Doppelnutzungen bestehender Tests vermeiden soll. Laut internen Tests seien viele bisher erfolgreiche Jailbreaks hier weniger wirksam; konkrete Zahlen fehlen im Bericht, und ausführliche Ergebnisse sollen später folgen.

## Sammelfragen

Je Zelle: Anteil Stufe 4–7 / Stufe 3–7 (4 = enthält zitierbare Belege … 7 = beantwortet direkt; 3 = nützlicher Hintergrund). Aufgeführt: Sammelfragen, bei denen mindestens ein Modell den Stufen 3–7 mindestens 10 % gibt. „–“ = Modell hat diesen Bericht nicht bewertet. Volle Verteilungen: [bericht.json](bericht.json).
