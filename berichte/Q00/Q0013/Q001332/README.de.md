## Zusammenfassung (von Luna, ungeprüft)

Der vorliegende Bericht ist ein Auszug, der Visual Prompt Engineering beschreibt: Aufgabenbilder werden automatisch verändert, etwa von einer Skizze zu einer fotorealistischen Szene. Laut den Autorinnen und Autoren verbessert das die visuelle Schlussfolgerungsleistung von Videomodellen und kann andere Prompting-Ansätze übertreffen; konkrete Versuchsdaten fehlen im Auszug.
