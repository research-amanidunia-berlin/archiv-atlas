## Summary (German, by Luna, unchecked)

Mistral kündigt Codestral 25.08 und einen Unternehmens-Stack an, der Codevervollständigung, semantische Codesuche und agentische Entwicklungsaufgaben in einer IDE-Erweiterung verbinden soll.
