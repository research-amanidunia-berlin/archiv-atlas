## Summary (German, by Luna, unchecked)

CAIS stellt ein Dashboard vor, das mögliche Lohnverluste durch KI zugeschriebene Stellenstreichungen nach US-Bundesstaat und pro Person schätzt. Es berücksichtigt laut Bericht weder neue KI-bedingte Jobs, Produktivitätsgewinne noch Wiederbeschäftigung; die Gesamtwirkung auf Beschäftigung bleibt daher offen.
