# A Decision-Theoretic Formalisation of Steganography With Applications to LLM Monitoring

Report Q001399 · Source aisi.gov.uk · Date 2026-04-29 · [Open original](https://www.aisi.gov.uk/research/a-decision-theoretic-formalisation-of-steganography-with-applications-to-llm-monitoring)

## Summary (German, by Luna, unchecked)

Der bereitgestellte Text ist nur der Abstract eines Berichts über einen entscheidungstheoretischen Ansatz, um verborgenes steganografisches Schlussfolgern in großen Sprachmodellen anhand unterschiedlicher Nutzbarkeit von Informationen zu erkennen und zu messen. Die Forschenden behaupten, ihr Verfahren sei empirisch geprüft und könne auch zur Minderung solcher Verhaltensweisen dienen; konkrete Versuchsdaten enthält der Auszug nicht.
