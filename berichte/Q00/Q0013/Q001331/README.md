# AI-Bio Workstream

Report Q001331 · Source frontiermodelforum.org · Date 2025-01-16 · [Open original](https://www.frontiermodelforum.org/workstreams/ai-bio-workstream/)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Das Frontier Model Forum beschreibt seinen AI-Bio-Arbeitsbereich als Initiative, die gemeinsame Ansätze zu biologischen KI-Risiken, Sicherheitsprüfungen und Schutzmaßnahmen entwickeln soll. Es nennt Fachbeiträge aus Industrie, Wissenschaft und Regierung als Grundlage und erklärt, Veröffentlichungen wegen möglicher Informationsrisiken vorab fachlich zu prüfen. Die Seite listet einschlägige Veröffentlichungen von 2024 bis 2026 auf, berichtet jedoch keine konkreten Wirkungsnachweise.
