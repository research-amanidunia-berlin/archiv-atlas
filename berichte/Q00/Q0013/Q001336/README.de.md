# Collective Constitutional AI

Bericht Q001336 · Quelle anthropic.com · Datum 2023-10-17 · [Original öffnen](https://www.anthropic.com/research/collective-constitutional-ai-aligning-a-language-model-with-public-input)

[Alle Berichte](../../../README.de.md) · Daten: [bericht.json](bericht.json)

## Zusammenfassung (von Luna, ungeprüft)

Anthropic berichtet, dass eine öffentliche Online-Beteiligung mit rund 1.000 US-Amerikanerinnen und -Amerikanern in eine Verfassung für ein Sprachmodell mündete; bei deren Erstellung waren Auswahl- und Umformulierungsentscheidungen nötig. Ein damit trainiertes Modell zeigte in den berichteten Tests ähnliche allgemeine Leistungen wie das Vergleichsmodell und niedrigere Verzerrungswerte, doch die Autoren betonen die begrenzte Stichprobe, subjektive Verarbeitungsschritte und unvollständige Evaluationen.
