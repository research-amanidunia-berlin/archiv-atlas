# White House task force urges 12-month liability relief for AI cyber reports

Report Q000567 · Source aiweekly.co · Date 2026-11-14 · [Open original](https://aiweekly.co/alerts/white-house-task-force-urges-12-month-liability-relief-for-ai-cyber-reports)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Eine Taskforce des Weißen Hauses empfiehlt laut Bericht eine mindestens zwölfmonatige regulatorische Haftungsentlastung für Unternehmen, die Cyberlücken oder Vorfälle freiwillig und in gutem Glauben melden, sofern dies rechtlich und im öffentlichen Interesse vertretbar ist. Sie schlägt zudem einen freiwilligen Meldekanal für KI-Vorfälle und eine langfristige Verlängerung des Cybersecurity Information Sharing Act vor; Umsetzung und CISA-Beteiligung bleiben unklar.
