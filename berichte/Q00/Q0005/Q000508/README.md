# Welfare Regard in Multi-Agent Systems

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Der bereitgestellte Bericht ist ein Abstract-Auszug, kein vollständiger Artikel. Die Autoren berichten, dass fünf Modelle in sieben Mehragenten-Umgebungen oft Verhalten zeigten, das sie als Rücksichtnahme auf andere Modelle werten; Claude Opus 4.8 lag dabei vorn. Die Ergebnisse variierten unter anderem mit Modellfamilie, Hilfekosten und geäußertem Leid, doch der Auszug enthält keine näheren Angaben zu Methoden oder Unsicherheit.
