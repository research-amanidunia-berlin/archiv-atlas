# GreyNoise AI Cyber Index: Benchmarking AI Models on Defensive Capabilities

Report Q000542 · Source greynoise.io · Date 2026-11-12 · [Open original](https://www.greynoise.io/blog/ai-cyber-index-benchmarking-defensive-capabilities)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

GreyNoise zufolge vergleicht der neue AI Cyber Index 46 Modelle bei drei defensiven Aufgaben: Netzwerk- und Dateierkennung sowie Angriffsermittlung. Sieben Modelle überschritten die festgelegte Leistungsschwelle, angeführt von Grok 4.5; die Resultate schwankten stark je nach Aufgabe. Der Bericht weist darauf hin, dass der Benchmark bislang nur diese begrenzte Auswahl an Sicherheitsarbeiten abdeckt.
