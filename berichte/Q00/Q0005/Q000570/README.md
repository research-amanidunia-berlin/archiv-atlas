## Summary (German, by Luna, unchecked)

Der vorliegende Text ist ein gekürzter Vortragsauszug: Shanahan warnt, KI könne nukleare Entscheidungen vor allem indirekt gefährden, indem sie Informationen und Wahrnehmungen prägt, Entscheidungen beschleunigt oder Krisen auslöst.
