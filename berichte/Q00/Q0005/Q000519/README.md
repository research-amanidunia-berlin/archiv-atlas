# Seoul tweaks margin loan rule to contain stock selloff

Report Q000519 · Source ajupress.com · Date 2026-11-06 · [Open original](https://www.ajupress.com/view/20261106122823452)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Südkorea lockert für drei Monate die Sicherheitenregel für Margin-Kredite, damit Broker Zwangsverkäufe bei fallenden Kursen eher aufschieben können. Der Bericht hält fest, dass dies weder Zwangsverkäufe vollständig verhindert noch höhere Kreditlimits schafft und bei weiteren Kursverlusten größere Verluste für Anleger und Broker möglich sind. Die Behörden führen den Ausverkauf auf KI-politische Unsicherheit und schwächere globale Stimmung zurück; die angeführten Daten zu Zwangsverkäufen bilden die jüngsten Verluste nur teilweise ab.
