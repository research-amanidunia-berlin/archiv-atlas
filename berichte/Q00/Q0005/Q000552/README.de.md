# Federal AI Testing Unit CAISSI: Staff Asked to Report Informally to White House, AP Says

Bericht Q000552 · Quelle techtimes.com · Datum 2026-11-09 · [Original öffnen](https://www.techtimes.com/articles/330292/20261109/federal-ai-testing-unit-caissi-staff-asked-report-informally-white-house-ap-says.htm)

[Alle Berichte](../../../README.de.md) · Daten: [bericht.json](bericht.json)

## Zusammenfassung (von Luna, ungeprüft)

Laut AP sollten CAISSI-Mitarbeitende informell an das Weiße Haus berichten; zugleich nennt die einschlägige Anordnung weder CAISSI noch eine Pflicht zur Veröffentlichung von Modellbewertungen. Der Bericht beschreibt eingeschränkte öffentliche Prüfberichte, eine unklare Leitung und offene Fragen zur Sicherheitstests von KI-Agenten, wobei Angaben zur Veröffentlichungslage aus verschiedenen Quellen teils unterschiedlich ausfallen.
