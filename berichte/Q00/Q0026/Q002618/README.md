# Signing the General-Purpose AI code of practice

Report Q002618 · Source digital-strategy.ec.europa.eu · Date – · [Open original](http://digital-strategy.ec.europa.eu/en/faqs/signing-general-purpose-ai-code-practice)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Die EU-FAQ erklärt, wie Anbieter allgemeiner KI-Modelle den Verhaltenskodex unterzeichnen und ihn nach einer Angemessenheitsbewertung als Nachweis für bestimmte Pflichten des AI Act nutzen können. Nichtteilnehmende müssen ihre Compliance anderweitig darlegen und könnten häufiger angefragt werden; sofortige vollständige Umsetzung wird laut FAQ nicht zwingend erwartet. Der Kodex soll mindestens alle zwei Jahre überprüft werden, und Unterschriften können jederzeit zurückgezogen werden.
