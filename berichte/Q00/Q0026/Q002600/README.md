# Adversarial machine learning: A taxonomy and terminology of attacks and mitigations

Report Q002600 · Source aisi.gov.uk · Date 2025-03-24 · [Open original](https://www.aisi.gov.uk/research/adversarial-machine-learning-a-taxonomy-and-terminology-of-attacks-and-mitigations)

## Summary (German, by Luna, unchecked)

Der bereitgestellte Text ist nur der Abstract-Auszug eines NIST-Berichts, der eine Taxonomie und gemeinsame Terminologie für Angriffe auf KI-Systeme sowie deren Minderung beschreibt. Er nennt als Ziel, künftige Standards und Praxisleitfäden zu unterstützen, enthält aber keine konkreten Ergebnisse oder Wirksamkeitsnachweise.
