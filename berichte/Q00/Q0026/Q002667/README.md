# AI models can be dangerous before public deployment

Report Q002667 · Source metr.org · Date 2025-01-17 · [Open original](https://metr.org/blog/2025-01-17-ai-models-dangerous-before-public-deployment/)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

METR hält Prüfungen vor der Veröffentlichung für notwendig, aber nicht ausreichend: Risiken wie Modell-Diebstahl, interner Missbrauch oder unerwünschtes Verhalten autonomer Systeme könnten schon während Entwicklung und interner Nutzung auftreten. Der Bericht empfiehlt frühere Fähigkeitsprüfungen, bessere Sicherheits- und Kontrollmaßnahmen sowie nachvollziehbare, verantwortungsvolle Offenlegung, wobei Transparenz gegen Sicherheitsinteressen abgewogen werden müsse.
