# Introducing 100K context windows

Bericht Q002658 · Quelle anthropic.com · Datum 2023-05-11 · [Original öffnen](https://www.anthropic.com/news/100k-context-windows)

[Alle Berichte](../../../README.de.md) · Daten: [bericht.json](bericht.json)

## Zusammenfassung (von Luna, ungeprüft)

Anthropic kündigte an, Claude könne 100.000 Tokens beziehungsweise etwa 75.000 Wörter auf einmal verarbeiten, und veranschaulichte dies mit einem Erkennungstest in „The Great Gatsby“. Als mögliche Anwendungen nennt das Unternehmen die Analyse langer Dokumente, mehrerer Quellen und ganzer Codebasen; die Funktion war laut Beitrag über die API verfügbar. Die Leistungsangaben stammen von Anthropic und werden nicht durch systematische Vergleichstests im Bericht belegt.
