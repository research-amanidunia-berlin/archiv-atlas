## Summary (German, by Luna, unchecked)

Anthropic kündigte an, Claude könne 100.000 Tokens beziehungsweise etwa 75.000 Wörter auf einmal verarbeiten, und veranschaulichte dies mit einem Erkennungstest in „The Great Gatsby“.
