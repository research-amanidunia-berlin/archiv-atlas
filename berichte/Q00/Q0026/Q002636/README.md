# Introducing the OECD AI Capability Indicators

Report Q002636 · Source oecd.ai · Date 2025-06-03 · [Open original](https://oecd.ai/en/ai-publications/introducing-the-oecd-ai-capability-indicators)

## Summary (German, by Luna, unchecked)

Der Einführungstext beschreibt OECD-Betaindikatoren, mit denen KI-Fähigkeiten anhand von neun menschlichen Fähigkeiten verglichen werden sollen. Laut Bericht entstanden sie über fünf Jahre mit mehr als 50 Fachleuten und sollen politische Einschätzungen zu Auswirkungen in mehreren Lebensbereichen unterstützen; methodische Einzelheiten oder konkrete Ergebnisse fehlen im Auszug.
