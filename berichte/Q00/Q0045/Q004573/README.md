# 生成式人工智能服务管理暂行办法_中央网络安全和信息化委员会办公室

Report Q004573 · Source cac.gov.cn · Date – · [Open original](https://www.cac.gov.cn/2023-07/13/c_1690898327029107.htm)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Der vollständige Bericht enthält chinesische Vorschriften für generative KI-Dienste, die der Öffentlichkeit im Inland Inhalte anbieten; sie gelten seit dem 15. August 2023. Sie regeln unter anderem zulässige Inhalte, Trainingsdaten, Datenschutz, Kennzeichnung, Beschwerden, behördliche Aufsicht und Sanktionen, belegen aber nicht, wie die Vorgaben praktisch umgesetzt werden.
