# From AGI to ASI

Report Q004509 · Source deepmind.google · Date 2026-06-12 · [Open original](https://deepmind.google/research/publications/239142/)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Der vorliegende Auszug ist das Abstract eines Berichts über vier mögliche Wege von AGI zu ASI und über mögliche Hindernisse auf diesen Wegen. Die Autoren betonen die Unsicherheit der Prognosen: KI könnte sich weiter beschleunigen und eher eine Reihe gesellschaftlicher Veränderungen als einen einzelnen Umbruch auslösen; die Vorbereitung darauf sei eine globale, interdisziplinäre Aufgabe.
