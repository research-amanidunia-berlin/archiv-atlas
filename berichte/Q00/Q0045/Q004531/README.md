# Solipsistic superintelligence is unlikely to be cooperative

Report Q004531 · Source deepmind.google · Date 2026-06-04 · [Open original](https://deepmind.google/research/publications/231466/)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Der vorliegende Bericht ist nur ein Abstract-Auszug. Die Verfassenden argumentieren, dass einseitig aufgabenoptimierte KI durch ihren Einsatz die Umweltbedingungen verändert und deshalb wahrscheinlich nicht kooperativ ist; sie fordern dynamische Tests, die Institutionen berücksichtigen und menschliche Handlungsfähigkeit strukturell erhalten.
