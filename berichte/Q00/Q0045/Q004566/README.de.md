## Zusammenfassung (von Luna, ungeprüft)

Anthropic zufolge unterstützen Claude-Modelle Alexa+, das über Amazon Bedrock auf Claude zugreift. Das Unternehmen nennt außerdem Sicherheitsfunktionen wie Schutz vor Jailbreak-Versuchen und kündigt einen zunächst für die USA geplanten, schrittweisen Start an; konkrete Startdaten oder Einzelheiten zur Umsetzung fehlen.
