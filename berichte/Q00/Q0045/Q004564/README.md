# Risk thresholds for frontier AI: Insights from the AI Action Summit

Report Q004564 · Source oecd.ai · Date 2025-03-05 · [Open original](https://oecd.ai/en/wonk/risk-thresholds-for-frontier-ai-insights-from-the-ai-action-summit)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Ein Fachgespräch von OECD und britischem AI Security Institute behandelte, wie Schwellenwerte Risiken fortgeschrittener KI erfassbar machen und Schutzmaßnahmen auslösen können. Die Teilnehmenden betonten Messprobleme, unterschiedliche Evidenzlagen und die nötige breite Beteiligung; verbindliche Definitionen und Reaktionen auf überschrittene Schwellen bleiben offen.
