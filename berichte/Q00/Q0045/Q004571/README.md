# Destructive Cyber Operations and Machine Learning

Report Q004571 · Source cset.georgetown.edu · Date 2020-11-02 · [Open original](https://cset.georgetown.edu/publication/destructive-cyber-operations-and-machine-learning/)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Der Bericht beschreibt drei Wege, wie maschinelles Lernen Angriffe auf industrielle Steuerungssysteme erleichtern könnte: durch bessere Prozessmodelle, manipulierte Sensordaten und die Umgehung oder Überlastung von Erkennungssystemen. Er empfiehlt besseren Schutz industrieller Datenarchive, ein staatliches ICS-Team zur proaktiven Suche nach Bedrohungen und mehr Abwehrforschung. Der vorliegende Text ist ein Auszug und enthält keine empirische Prüfung dieser Szenarien oder der Empfehlungen.
