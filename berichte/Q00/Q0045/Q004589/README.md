# Image Generators are Generalist Vision Learners

Report Q004589 · Source deepmind.google · Date 2026-04-22 · [Open original](https://deepmind.google/research/publications/240658/)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Der Auszug stellt Vision Banana vor, ein auf Nano Banana Pro aufgebautes, leichtgewichtig angepasstes Modell, das laut Autoren bei mehreren 2D- und 3D-Vision-Aufgaben spezialisierte Modelle erreicht oder übertrifft und zugleich seine Bilderzeugung behält. Die Autoren sehen darin einen Hinweis, dass generatives Bildtraining allgemeines visuelles Lernen ermöglichen könnte; konkrete Messwerte und Versuchsdetails enthält der bereitgestellte Abstract-Auszug nicht.
