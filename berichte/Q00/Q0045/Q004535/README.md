# AI is a common workplace tool: Half of employed AI users now use it for work

Report Q004535 · Source epoch.ai · Date 2026-04-09 · [Open original](https://epoch.ai/publications/half-of-employed-ai-users-now-use-it-for-work)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

In einer gewichteten Epoch-AI/Ipsos-Befragung nutzte etwa die Hälfte der erwerbstätigen US-KI-Nutzenden KI mindestens ebenso häufig beruflich wie privat. Unter den besonders arbeitsorientierten Nutzenden berichteten 27 Prozent von automatisierten bisherigen Aufgaben und 21 Prozent von neuen KI-gestützten Aufgaben; die berufliche Nutzung war bei bezahltem Zugang häufiger, wobei die Ursache dieses Zusammenhangs offenbleibt.
