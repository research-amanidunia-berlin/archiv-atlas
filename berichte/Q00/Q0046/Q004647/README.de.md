# The next phase of the Microsoft OpenAI partnership

Bericht Q004647 · Quelle openai.com · Datum 2026-04-27 · [Original öffnen](https://openai.com/index/next-phase-of-microsoft-partnership/)

[Alle Berichte](../../../README.de.md) · Daten: [bericht.json](bericht.json)

## Zusammenfassung (von Luna, ungeprüft)

OpenAI meldet ein geändertes Abkommen mit Microsoft: Microsoft bleibt wichtigster Cloud-Partner und erhält bis 2032 eine nicht exklusive Lizenz, während OpenAI seine Produkte auch über andere Cloud-Anbieter anbieten kann. Umsatzbeteiligungen und Zahlungen werden neu geregelt; OpenAIs Zahlungen an Microsoft laufen gedeckelt bis 2030 weiter, und Microsoft bleibt Anteilseigner.
