## Zusammenfassung (von Luna, ungeprüft)

Der vorliegende Text ist ein Auszug aus der Executive Summary, keine vollständige Berichtsfassung. Cary zufolge integrieren acht von elf chinesischen WCCS-Hochschulen KI/ML in Cybersicherheitsstudiengänge, während dies bei den 20 US-amerikanischen CAE-Programmen für Cyberoperationen nur an einer Hochschule als optionaler ML-Kurs angeboten werde. Daraus leitet der Bericht einen möglichen künftigen Vorteil Chinas ab, belegt aber keinen bereits bestehenden Vorsprung.
