# Indonesia’s AI Promise in Perspective

Report Q004690 · Source cset.georgetown.edu · Date 2021-08-18 · [Open original](https://cset.georgetown.edu/publication/indonesias-ai-promise-in-perspective/)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Der vorliegende Auszug beschreibt Indonesiens KI-Potenzial und nennt als zentrale Hindernisse schwache Internetinfrastruktur, Fachkräftemangel und Cyberangriffe. Laut Bericht investieren sowohl China als auch die USA, verfolgen dabei aber unterschiedliche Ansätze; Indonesien könne versuchen, beide Beziehungen außenpolitisch auszubalancieren. Der vollständige Bericht liegt nicht vor, daher sind Methoden und Belege hier nicht enthalten.
