# Opening up a physics simulator for robotics

Report Q004687 · Source deepmind.google · Date 2021-10-18 · [Open original](https://deepmind.google/blog/opening-up-a-physics-simulator-for-robotics/)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

DeepMind kündigt an, MuJoCo kostenlos bereitzustellen und gemeinsam mit der Community als Open-Source-Projekt weiterzuentwickeln; zunächst sei eine vorkompilierte Bibliothek verfügbar, während die vollständige Öffnung noch vorbereitet werde. Der Bericht beschreibt das Kontaktmodell, die Robotik- und Biomechanikfunktionen sowie Beispiele aus DeepMinds Forschung, wobei die Leistungsangaben von den Autoren stammen. Der bereitgestellte Bericht ist am Ende bei einer Bildbeschreibung abgeschnitten.
