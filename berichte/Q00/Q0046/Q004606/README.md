# Human-centred mechanism design with Democratic AI

Report Q004606 · Source deepmind.google · Date 2022-07-04 · [Open original](https://deepmind.google/blog/human-centred-mechanism-design-with-democratic-ai/)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Der Bericht schildert eine Studie, in der ein mit menschlichen Spieldaten trainierter RL-Agent eine Verteilungsregel entwickelte, die in einem einfachen Spiel mehr Stimmen erhielt als mehrere Vergleichsregeln. Die Regel berücksichtigte Beiträge relativ zu den verfügbaren Mitteln und belohnte großzügige Einzahlungen; ob sich das auf reale Gesellschaften übertragen lässt und wie Minderheiteninteressen geschützt werden, bleibt offen.
