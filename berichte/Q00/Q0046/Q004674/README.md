# Jay Kreps appointed to Anthropic's board

Report Q004674 · Source anthropic.com · Date 2024-05-29 · [Open original](https://www.anthropic.com/news/jay-kreps-appointed-to-board-of-directors)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Anthropic beruft Jay Kreps, Mitgründer und CEO von Confluent, in seinen Verwaltungsrat und verweist auf dessen Erfahrung mit technischen Unternehmen, Dateninfrastruktur und Open-Source-Software. Luke Muehlhauser scheidet aus, um sich auf Open Philanthropy zu konzentrieren; die Mitteilung enthält vor allem Einschätzungen der Beteiligten und keine unabhängige Bewertung der Personalentscheidung.
