# Using Unity to Help Solve Intelligence

Report Q004626 · Source deepmind.google · Date 2020-11-18 · [Open original](https://deepmind.google/blog/using-unity-to-help-solve-intelligence/)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Der Bericht erklärt, weshalb DeepMind Unity für vielfältige KI-Forschungsumgebungen verwendet: Die Engine bietet unter anderem Physik, Grafik und plattformübergreifende Ausführung, während dm_env_rpc die Datenübertragung zwischen Simulation und Agent regelt. DeepMind optimiert die Umgebungen laut den Autoren auf hohen Durchsatz und parallele Läufe; Container sollen unabhängige Überprüfung erleichtern, doch konkrete Vergleichsmessungen nennt der Bericht nicht.
