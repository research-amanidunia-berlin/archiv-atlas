# STARC: A General Framework For Quantifying Differences Between Reward Functions

## Zusammenfassung (von Luna, ungeprüft)

Der vorliegende Bericht ist nur ein Auszug aus dem Abstract einer Arbeit zu STARC, einer Klasse von Pseudometriken zum Vergleich von Reward-Funktionen im Reinforcement Learning. Die Autorinnen und Autoren behaupten, STARC begrenze den schlimmsten möglichen Regret von oben und unten und könne so Analysen des Reward-Lernens unterstützen; Einzelheiten zu Beweisen und Experimenten enthält der Auszug nicht.
