# From deepfake scams to biased AI: How incident reporting can help us keep ahead of AI’s harms

Report Q002044 · Source oecd.ai · Date 2025-03-04 · [Open original](https://oecd.ai/en/wonk/deepfake-scams-biased-ai-incidents-framework-reporting-can-keep-ahead-ai-harms)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Der OECD-Beitrag beschreibt einen gemeinsamen Rahmen zur Erfassung von KI-Vorfällen, damit Risiken besser verglichen, Hochrisikosysteme früher erkannt und Gegenmaßnahmen international abgestimmt werden können. Der Rahmen umfasst 29 Kriterien in acht Bereichen; der Text erläutert seine erwarteten Vorteile, liefert aber keine unabhängige Prüfung seiner Wirksamkeit.
