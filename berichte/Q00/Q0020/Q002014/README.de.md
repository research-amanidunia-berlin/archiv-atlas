# Planning behavior in a recurrent neural network that plays Sokoban

Bericht Q002014 · Quelle far.ai · Datum 2026-07-13 · [Original öffnen](https://www.far.ai/research/planning-behavior-in-a-recurrent-neural-network-that-plays-sokoban)

[Alle Berichte](../../../README.de.md) · Daten: [bericht.json](bericht.json)

## Zusammenfassung (von Luna, ungeprüft)

Es liegt nur der Abstract vor. Die Autoren berichten, dass zusätzliche Rechenschritte bei einem Sokoban-Netz frühe überflüssige Aktionen reduzieren und bei einfachen Leveln die Leistung verbessern können; der Effekt bilde sich früh im Training und schwäche später ab. Sie deuten dies als Hinweis auf erlerntes Planungsverhalten, doch der Auszug enthält keine detaillierten Methoden oder Messwerte.
