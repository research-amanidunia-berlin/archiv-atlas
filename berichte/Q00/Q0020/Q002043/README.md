# AI Safety in China #24

Report Q002043 · Source aisafetychina.substack.com · Date 2025-12-19 · [Open original](https://aisafetychina.substack.com/p/ai-safety-in-china-24)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Der Bericht beschreibt chinesische Vorschläge zu internationaler KI-Risikosteuerung, Ergebnisse von Sicherheitstests für Programmiermodelle und Forderungen nach umfassender KI-Gesetzgebung. Die Befunde reichen von nach Einschätzung der CAICT teils erheblichen Cybermissbrauchsrisiken bis zur Einschätzung der PACEbench-Autoren, heutige Modelle stellten noch keine erhebliche reale Cyberangriffsgefahr dar; bei einem KI-Gesetz und seiner Priorität bleiben die offiziellen Signale uneinheitlich.
