# A simpler AI timelines model predicts 99% AI R&D automation in ~2032

Report Q002019 · Source metr.org · Date 2026-02-10 · [Open original](https://metr.org/notes/2026-02-10-simpler-ai-timelines-model/)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

METRs vereinfachtes Modell setzt bei fortgesetztem Wachstum von Rechenleistung und algorithmischer Effizienz den Median für mehr als 99 Prozent Automatisierung der KI-Forschung auf etwa Mitte 2032; bis 2035 ergeben die Simulationen große Zuwächse bei Softwareeffizienz und Forschungsleistung. Diese Werte hängen von unsicheren Annahmen ab: Das Modell lässt vollständige Automatisierung und wirtschaftliche Rückkopplungen außen vor und sagt nichts über die anschließende Beschleunigung bis zur Superintelligenz aus.
