# Claude computes a nine-loop amplitude in N=4 super-Yang-Mills

Report Q002001 · Source anthropic.com · Date 2026-09-25 · [Open original](https://www.anthropic.com/research/yes-claude-can-do-nine-loops)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Laut Matt von Hippel berechnete Claude eine zuvor nicht erreichte Neunschleifen-Amplitude in einem theoretischen Teilchenphysikmodell und wurde von Lance Dixon überprüft. Der Bericht stellt den Erfolg als Anwendung bekannter Methoden mit erheblicher, aber erschwinglicher Rechenleistung dar; eine zweite Forschungsgruppe erzielte unabhängig ebenfalls wesentliche Ergebnisse mit KI-Unterstützung. Ob sich daraus Schlüsse auf andere Physikprobleme oder künftige KI-Fähigkeiten ziehen lassen, bleibt offen.
