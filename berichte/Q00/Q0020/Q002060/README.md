# Clarifying limitations of time horizon

Report Q002060 · Source metr.org · Date 2026-01-22 · [Open original](https://metr.org/notes/2026-01-22-time-horizon-limitations/)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Der METR-Mitautor beschreibt die Zeithorizont-Werte als ungenaue, auf bestimmte Aufgabenverteilungen begrenzte Schätzungen menschlicher Arbeitslänge bei 50 Prozent KI-Erfolg – nicht als Maß autonomer Arbeitsdauer oder sicherer Delegierbarkeit. Als wichtigste Aussage der Studie verteidigt er den langfristigen Trend einer Verdopplung etwa alle sechs bis sieben Monate und dessen lineare Projektion auf einen Arbeitsmonat im Jahr 2030, weist aber auf eine kleine und zunehmend begrenzte Datengrundlage hin.
