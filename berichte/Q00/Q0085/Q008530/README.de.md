# Discovering types for entity disambiguation

Bericht Q008530 · Quelle openai.com · Datum 2018-02-07 · [Original öffnen](https://openai.com/index/discovering-types-for-entity-disambiguation/)

[Alle Berichte](../../../README.de.md) · Daten: [bericht.json](bericht.json)

## Zusammenfassung (von Luna, ungeprüft)

Der Beitrag beschreibt ein Verfahren, das mehrdeutige Namen mithilfe von rund 100 aus Wikipedia- und Wikidata-Daten ausgewählten Typen im Kontext auflöst. Die Autoren berichten hohe Genauigkeitswerte auf CoNLL (YAGO) und TAC KBP 2010, weisen aber darauf hin, dass das Typensystem auf einer kleinen Wikipedia-Teilmenge entdeckt wurde und seine Skalierung noch offen ist.
