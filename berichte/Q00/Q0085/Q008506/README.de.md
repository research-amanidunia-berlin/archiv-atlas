## Zusammenfassung (von Luna, ungeprüft)

Der bereitgestellte Bericht ist nur der Abstract einer Forschungsarbeit. Darin wird behauptet, dass neugiergetriebenes Lernen ohne externe Belohnungen in 54 Benchmarks, darunter Atari, überraschend gut abschneidet; zufällige Merkmale genügen oft, während gelernte Merkmale besser auf neue Level verallgemeinern sollen. Als Grenze nennt der Abstract Probleme vorhersagebasierter Belohnungen in stochastischen Umgebungen.
