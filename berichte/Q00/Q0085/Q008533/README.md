## Summary (German, by Luna, unchecked)

OpenAI berichtet, dass simulierte Roboter mit einer erweiterten MAML-Methode ihre Taktik zwischen Wettkampfrunden an Gegner anpassen und besser abschneiden konnten als Agenten mit festen Richtlinien.
