# Donating Agent Skills to the Agentic AI Foundation

## Summary (German, by Luna, unchecked)

Anthropic kündigt an, Agent Skills samt Name, Logo, GitHub-Organisation und Domain an die AAIF zu übertragen; Nutzung und Mitarbeit sollen weiterhin ohne AAIF-Mitgliedschaft möglich sein. Als nächste Schritte schlägt das Unternehmen versionierte Veröffentlichungen, ein formelles Verfahren für Vorschläge und Sicherheitshinweise vor; Angaben zu den Nutzungszahlen und zur geplanten Governance stammen aus dem Bericht und werden dort nicht unabhängig geprüft.
