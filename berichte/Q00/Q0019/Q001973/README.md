# CAISI Issues Request for Information About Securing AI Agent Systems

Report Q001973 · Source nist.gov · Date 2026-01-12 · [Open original](https://www.nist.gov/news-events/news/2026/01/caisi-issues-request-information-about-securing-ai-agent-systems)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

CAISI hat eine Informationsanfrage zur Sicherheit von KI-Agenten gestartet, um Beiträge für künftige freiwillige Leitlinien und Forschung zu sammeln. Im Fokus stehen unter anderem Prompt-Injection, manipulierte Modelle, schädliche autonome Handlungen und die Begrenzung von Agentenzugriffen; Stellungnahmen waren bis zum 9. März 2026 einzureichen. Der Bericht enthält keine Studienergebnisse oder beschlossenen Sicherheitsanforderungen.
