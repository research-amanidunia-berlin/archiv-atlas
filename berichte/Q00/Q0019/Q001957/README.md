# Five lessons from having helped run an AI-Biology RCT

Report Q001957 · Source metr.org · Date 2026-02-19 · [Open original](https://metr.org/blog/2026-02-19-five-lessons-from-ai-biology-rct/)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Eine achtwöchige RCT mit 153 Anfängerinnen und Anfängern fand laut Beitrag zwar Hinweise, dass KI einzelne Laborarbeitsschritte erleichtert, aber keinen signifikanten Effekt auf den Gesamterfolg bei drei Aufgaben. Der Autor fordert regelmäßige, gut besetzte Studien zu realistischen KI-Risiken, warnt vor den Grenzen solcher Versuche und empfiehlt, Schutzmaßnahmen frühzeitig zu entwickeln.
