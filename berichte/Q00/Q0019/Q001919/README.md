# Announcing DeepMind Health research partnership with Moorfields Eye Hospital

Report Q001919 · Source deepmind.google · Date 2016-05-07 · [Open original](https://deepmind.google/blog/announcing-deepmind-health-research-partnership-with-moorfields-eye-hospital/)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

DeepMind kündigt mit Moorfields ein Forschungsprojekt an, das maschinelles Lernen zur Auswertung von Augenaufnahmen bei diabetischer Retinopathie und AMD untersuchen soll. Der Beitrag beschreibt eine Million anonymisierte historische Scans, betont den NHS-Datenschutz und nennt mögliche Vorteile für die künftige Versorgung, berichtet aber noch keine Ergebnisse.
