# Using Claude to reduce the attack surface of code

Bericht Q001958 · Quelle anthropic.com · Datum 2026-10-20 · [Original öffnen](https://www.anthropic.com/research/attack-surface-reduction)

[Alle Berichte](../../../README.de.md) · Daten: [bericht.json](bericht.json)

## Zusammenfassung (von Luna, ungeprüft)

Anthropic zufolge fand Claude bei der Analyse von 25 Open-Source-Projekten 493 Probleme mit unnötig erreichbarem Code oder unsicheren Konfigurationskombinationen. Eine OpenSSH-Fallstudie führte laut Bericht zu Änderungen, die den vor der Authentifizierung erreichbaren Code deutlich verringerten; die Methode erschwert den Zugriff auf mögliche Schwachstellen, beseitigt sie aber nicht.
