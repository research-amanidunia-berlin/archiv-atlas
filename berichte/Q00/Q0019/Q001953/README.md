# India Country Brief: Anthropic Economic Index

Report Q001953 · Source anthropic.com · Date 2026-02-16 · [Open original](https://www.anthropic.com/research/india-brief-economic-index)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Laut Bericht entfielen im November 2025 5,8 Prozent der beobachteten Claude.ai-Nutzung weltweit auf Indien, doch pro Kopf lag das Land nur auf Rang 101 von 116 erfassten Ländern. Die Nutzung konzentrierte sich auf vier wirtschaftsstarke Regionen und stark auf Softwareaufgaben; Anthropic berichtet zugleich von höherem Arbeitsbezug und einer geschätzten 15-fachen Zeitersparnis bei Aufgaben mit KI. Die Auswertung umfasst eine Woche Verbraucher-Gespräche und erlaubt keine direkten Schlüsse auf die gesamte Bevölkerung oder langfristige Wirkungen.
