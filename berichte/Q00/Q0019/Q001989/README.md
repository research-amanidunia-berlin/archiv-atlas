# Public AI: Policies for democratic and sustainable AI infrastructures

Report Q001989 · Source oecd.ai · Date 2025-12-05 · [Open original](https://oecd.ai/en/wonk/public-ai-policies-for-democratic-and-sustainable-ai-infrastructures)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Der Beitrag wirbt für eine demokratisch kontrollierte und gemeinwohlorientierte KI, die öffentliche Rechenleistung, hochwertige gemeinschaftlich verwaltete Daten und offene Modelle verbindet. Er empfiehlt, kommerzielle Abhängigkeiten schrittweise zu senken und internationale Zusammenarbeit zu stärken, räumt aber fortbestehende Engpässe bei Chips und Cloud ein; konkrete Wirkungsnachweise für die genannten Initiativen liefert der Text nicht.
