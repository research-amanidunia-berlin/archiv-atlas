# Competitive programming with AlphaCode

Bericht Q001983 · Quelle deepmind.google · Datum 2022-12-08 · [Original öffnen](https://deepmind.google/blog/competitive-programming-with-alphacode/)

[Alle Berichte](../../../README.de.md) · Daten: [bericht.json](bericht.json)

## Zusammenfassung (von Luna, ungeprüft)

DeepMind berichtet, dass AlphaCode in zehn simulierten Codeforces-Wettbewerben ungefähr das Niveau der mittleren Teilnehmenden erreichte und zu den besten 54 Prozent zählte. Das System erzeugt große Mengen von Programmvorschlägen und filtert daraus Kandidaten; laut Beitrag bleibt es weit davon entfernt, Wettbewerbe zu gewinnen, und die Evaluation ist auf zehn Wettbewerbe beschränkt.
