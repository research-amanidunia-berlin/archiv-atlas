# Safety case template for ‘inability’ arguments

Report Q001575 · Source aisi.gov.uk · Date 2024-11-14 · [Open original](https://www.aisi.gov.uk/blog/safety-case-template-for-inability-arguments)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Das AISI legt eine Vorlage vor, mit der sich anhand von Fähigkeitsprüfungen begründen lässt, dass ein KI-System nicht leistungsfähig genug sei, um unvertretbare Cyberrisiken zu verursachen. Der Ansatz gilt laut Bericht als Machbarkeitsnachweis und beispielhaft für wenig leistungsfähige Systeme; bei stärkeren Systemen werden zusätzliche Schutzargumente nötig. Die Vorlage deckt weder alle soziotechnischen Aspekte ab noch bestimmt sie konkrete Sicherheitsschwellen.
