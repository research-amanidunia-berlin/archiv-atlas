# Why Codex Security doesn’t start with a SAST report

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Der Beitrag argumentiert, Codex Security solle Schutzmaßnahmen im Kontext des gesamten Repositories prüfen und Befunde möglichst praktisch validieren, statt seine Suche an einer SAST-Fundstellenliste auszurichten. SAST bleibe für bekannte und einfache Fehler nützlich; der Text begründet seine Designentscheidung, liefert aber keine quantitativen Vergleichsergebnisse.
