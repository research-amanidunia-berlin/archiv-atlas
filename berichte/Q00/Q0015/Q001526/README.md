# AI alignment is a human problem

Report Q001526 · Source aisi.gov.uk · Date 2026-05-30 · [Open original](https://www.aisi.gov.uk/research/ai-alignment-is-a-human-problem)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Der bereitgestellte Text ist nur ein Auszug aus dem Abstract eines Papers. Die Autorinnen und Autoren argumentieren, dass KI-Alignment stark von menschlichen Urteilen abhängt und schlagen Forschung zu fünf Aufsichtsengpässen vor: Verzerrungen, umstrittene Werte, begrenzte Aufmerksamkeit, eingeschränktes kontrafaktisches Denken und fehlende Prüfexpertise. Konkrete Studien oder Lösungen beschreibt der Auszug nicht.
