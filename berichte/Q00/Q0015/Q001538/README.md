# Offering Zero Data Retention for frontier models

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Der bereitgestellte Berichtsauszug beschreibt OpenAIs Private Safety Processing, das laut Unternehmen Risiken über mehrere Interaktionen hinweg erkennen soll, ohne OpenAI-Mitarbeitenden Zugriff auf Kundeninhalte zu geben. Der Auszug berichtet von Tests mit frühen Kunden und einem schrittweisen API-Rollout, enthält aber keine unabhängigen Nachweise zur Wirksamkeit oder technischen Umsetzung.
