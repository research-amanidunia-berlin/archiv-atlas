# Updating our Model Spec with teen protections

Bericht Q001560 · Quelle openai.com · Datum 2025-12-18 · [Original öffnen](https://openai.com/index/updating-model-spec-with-teen-protections/)

[Alle Berichte](../../../README.de.md) · Daten: [bericht.json](bericht.json)

## Zusammenfassung (von Luna, ungeprüft)

OpenAI ergänzt seine Model Spec um Schutzprinzipien für Jugendliche von 13 bis 17 Jahren, darunter stärkere Leitplanken bei riskanten Themen und Hinweise auf Unterstützung außerhalb des Chats. Das Unternehmen kündigt außerdem eine schrittweise Altersschätzung an; der Bericht beschreibt beabsichtigtes Verhalten und laufende Maßnahmen, liefert aber keine unabhängigen Wirksamkeitsdaten.
