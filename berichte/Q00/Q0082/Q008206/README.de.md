# OpenAI Five defeats Dota 2 world champions

Bericht Q008206 · Quelle openai.com · Datum 2019-04-15 · [Original öffnen](https://openai.com/index/openai-five-defeats-dota-2-world-champions/)

[Alle Berichte](../../../README.de.md) · Daten: [bericht.json](bericht.json)

## Zusammenfassung (von Luna, ungeprüft)

OpenAI führt den Sieg von OpenAI Five vor allem auf deutlich mehr Trainingsrechenleistung und lange Simulationen zurück; die genannten Leistungswerte stammen aus dem Bericht. Überraschend habe das System auch ohne spezielles Training mit Menschen kooperieren können, während Tests mit einem größeren Heldenpool nicht rechtzeitig Profiniveau erreichten. Eine öffentliche Arena sollte die Robustheit prüfen, deren Ergebnisse und eine technische Auswertung lagen im Bericht noch nicht vor.
