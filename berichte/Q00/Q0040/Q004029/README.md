## Summary (German, by Luna, unchecked)

OpenAI kündigt ein Programm an, das ausgewählte externe Forschende bei empirischen Studien zu den wirtschaftlichen Folgen von KI unterstützen soll. Der Bericht beschreibt Auswahlkriterien und Datenschutzvorkehrungen, enthält aber noch keine Forschungsergebnisse; die genannten Bewerbungsfristen stehen neben einem späteren Update, dessen Verhältnis zum Zeitplan ungeklärt bleibt.
