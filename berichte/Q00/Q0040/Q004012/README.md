# Skating to Where the Puck Is Going

Report Q004012 · Source cset.georgetown.edu · Date 2023-10-24 · [Open original](https://cset.georgetown.edu/publication/skating-to-where-the-puck-is-going/)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Der Bericht fasst eine CSET- und DeepMind-Gesprächsrunde von 2023 über leistungsfähigere KI, neue Risiken und politische Steuerungsmöglichkeiten zusammen. Er empfiehlt laut Zusammenfassung frühzeitige Modellbewertungen, mehr eigene technische Aufsichtskompetenz der Regierungen und klare Anreize für Tests und Berichte; solche Bewertungen allein seien aber keine umfassende Risikosteuerung. Es liegt ein Auszug vor.
