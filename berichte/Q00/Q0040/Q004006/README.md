# A Primer on Data and Economic Justice

Report Q004006 · Source oecd.ai · Date 2025-05-15 · [Open original](https://oecd.ai/en/wonk/documents/a-primer-on-data-and-economic-justice)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Der Text schlägt vier Datenrechte als Grundlage wirtschaftlicher Gerechtigkeit vor und sieht Plattformen als zentrale Orte datenbezogener Ungleichheit. Dateninfrastrukturen könnten Datenmacht verteilen; bestehende Initiativen, besonders in der EU und Indien, seien laut Text jedoch lückenhaft und uneinheitlich.
