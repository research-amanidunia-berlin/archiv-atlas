# YouTube: Enhancing the user experience

Bericht Q004088 · Quelle deepmind.google · Datum 2023-06-16 · [Original öffnen](https://deepmind.google/blog/youtube-enhancing-the-user-experience/)

[Alle Berichte](../../../README.de.md) · Daten: [bericht.json](bericht.json)

## Zusammenfassung (von Luna, ungeprüft)

Der Bericht beschreibt vier gemeinsame DeepMind- und YouTube-Projekte: automatische Beschreibungen für Shorts, MuZero-gestützte Videokompression, präzisere Labels für werbefreundliche Inhalte und KI-generierte Videokapitel. DeepMind berichtet unter anderem von einer durchschnittlichen Bitrate-Senkung um vier Prozent und Kapiteln auf zig Millionen Videos; unabhängige Belege, Testdetails und Fehlerquoten fehlen.
