# Enabling Data Sharing  for Social Benefit  Through Data Trusts:  Data Trusts in Climate

Report Q004016 · Source oecd.ai · Date 2025-05-15 · [Open original](https://oecd.ai/en/wonk/documents/enabling-data-sharing-for-social-benefit-through-data-trusts-data-trusts-in-climate)

## Summary (German, by Luna, unchecked)

Der vorliegende Text ist nur ein Auszug: Er beschreibt Daten und KI als mögliche Werkzeuge für Klimaschutz und behauptet, gemeinschaftliche Daten-Treuhandmodelle könnten Menschen mehr Einfluss auf die Nutzung ihrer Daten geben. Das Projekt untersuchte das Thema 2021–2022 anhand einer Literaturauswertung, von Fachgesprächen und eines Gestaltungsprozesses mit mehr als 50 Organisationen; Ergebnisse sind im Auszug nicht enthalten.
