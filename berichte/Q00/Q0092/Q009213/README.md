# Upgrading the Moderation API with our new multimodal moderation model

Report Q009213 · Source openai.com · Date 2024-09-26 · [Open original](https://openai.com/index/upgrading-the-moderation-api-with-our-new-multimodal-moderation-model/)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

OpenAI zufolge soll das neue, auf GPT‑4o basierende Moderationsmodell Text und teilweise auch Bilder präziser prüfen; neu sind außerdem zwei textbasierte Kategorien für unerlaubte Handlungen. Das Unternehmen meldet Verbesserungen in einer internen Auswertung von 40 Sprachen, doch der Bericht nennt keine detaillierte Testmethodik und die Bildprüfung deckt derzeit nur bestimmte Kategorien ab.
