## Summary (German, by Luna, unchecked)

OpenAI kündigte beim DevDay 2023 GPT‑4 Turbo, eine Assistants API, multimodale Funktionen und niedrigere Preise an. Mehrere Angebote waren laut Bericht noch Vorschau oder geplant; zudem korrigierte OpenAI die Aussage, ältere GPT‑3.5-Anwendungen würden automatisch umgestellt.
