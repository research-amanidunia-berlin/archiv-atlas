# Introducing the SWE-Lancer benchmark

Bericht Q009216 · Quelle openai.com · Datum 2025-02-18 · [Original öffnen](https://openai.com/index/swe-lancer/)

[Alle Berichte](../../../README.de.md) · Daten: [bericht.json](bericht.json)

## Zusammenfassung (von Luna, ungeprüft)

Der vorliegende Textauszug stellt SWE-Lancer vor: einen Benchmark mit über 1.400 realen Softwareaufträgen und Managemententscheidungen, deren Gesamtwert laut OpenAI einer Million US-Dollar an Auszahlungen entspricht. OpenAI berichtet, dass führende Modelle noch nicht die Mehrheit der Aufgaben lösen; ein Update von 2025 entfernte die Internetverbindung als Ausführungsanforderung, die eine Quelle von Leistungsschwankungen gewesen sei.
