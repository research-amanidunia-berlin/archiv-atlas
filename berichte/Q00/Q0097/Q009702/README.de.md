# SwiftUI: App Intents Make Spotlight Integration Easy!

Bericht Q009702 · Quelle medium.com · Datum 2026-07-25 · [Original öffnen](https://medium.com/@itsuki.enjoy/swiftui-app-intents-make-spotlight-integration-easy-76aee5014ec1)

## Zusammenfassung (von Luna, ungeprüft)

Der Beitrag zeigt, wie Entwickler App-Intents-Entitäten mit `IndexedEntity` und `indexAppEntities` für Spotlight indexieren und optional Öffnen, Neuindexierung sowie Ausblenden konfigurieren können. Als wichtigen Stolperstein nennt der Autor, dass ein fehlender Titel im `attributeSet` dazu führen könne, dass ein Eintrag trotz Titel in der `displayRepresentation` nicht in Spotlight erscheint.
