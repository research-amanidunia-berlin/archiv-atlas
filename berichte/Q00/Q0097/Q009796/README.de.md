# Avoiding Massive View Controllers by refactoring.

Bericht Q009796 · Quelle jamesrochabrun.medium.com · Datum 2017-04-27 · [Original öffnen](https://jamesrochabrun.medium.com/avoiding-massive-view-controllers-by-refactoring-ffb6a55dfa42)

## Zusammenfassung (von Luna, ungeprüft)

Das Swift-Tutorial zeigt anhand einer Film-App, wie der Autor Aufgaben aus einem ViewController in ein ViewModel, eine wiederverwendbare Zellenerweiterung und eine eigene Tabellen-Datenquelle verlagert. Er berichtet von einem Rückgang des Controllers von etwa 70 auf 40 Zeilen und behauptet, der Code werde klarer und leichter testbar; wie eine Auswahlmethode auf das private Filmarray zugreifen soll, bleibt offen.
