## Zusammenfassung (von Luna, ungeprüft)

Der Autor stellt elf Claude Skills vor, die unter anderem Präsentationen, Markengestaltung, Recherche, Prozessvisualisierung und die Umsetzung von Figma-Entwürfen unterstützen sollen.
