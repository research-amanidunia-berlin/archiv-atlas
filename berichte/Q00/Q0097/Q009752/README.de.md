## Zusammenfassung (von Luna, ungeprüft)

Der vollständige Bericht erklärt, wie FoundationModels Bilder als Anhänge verarbeitet und eigene Werkzeuge ein neues Bild zurückgeben können. Der Autor berichtet von einer Endlosschleife bei strukturierten Werkzeugaufrufen, empfiehlt beschriftete Bildanhänge und zeigt ein Beispiel zum Skalieren von Bildern; seine Fehlerbeobachtungen beruhen auf eigenen Tests.
