# Little SwiftUI Tip: RGB/HSB Color to Hex String in One Line

Bericht Q009769 · Quelle medium.com · Datum 2026-05-24 · [Original öffnen](https://medium.com/@itsuki.enjoy/little-swiftui-tip-rgb-hsb-color-to-hex-string-in-one-line-001d7efc410a)

[Alle Berichte](../../../README.de.md) · Daten: [bericht.json](bericht.json)

## Zusammenfassung (von Luna, ungeprüft)

Der Beitrag zeigt, dass `Color.description` bei direkt per RGB oder HSB erzeugten SwiftUI-Farben eine Hex-Darstellung liefern kann. Für eingebaute oder aus `UIColor` stammende Farben gilt das laut den Beispielen nicht; der Autor empfiehlt dort, aufgelöste RGB-Werte direkt zu formatieren und bei Bedarf die Deckkraft einzubeziehen.

## Sammelfragen

Je Zelle: Anteil Stufe 4–7 / Stufe 3–7 (4 = enthält zitierbare Belege … 7 = beantwortet direkt; 3 = nützlicher Hintergrund). Aufgeführt: Sammelfragen, bei denen mindestens ein Modell den Stufen 3–7 mindestens 10 % gibt. „–“ = Modell hat diesen Bericht nicht bewertet. Volle Verteilungen: [bericht.json](bericht.json).

Keine Sammelfrage erreicht bei einem Modell 10 % in Stufe 3–7.
