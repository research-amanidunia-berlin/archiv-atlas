# SwiftUI: Provide/Use Systemwide Fonts

## Zusammenfassung (von Luna, ungeprüft)

Der vollständige Bericht zeigt anhand eines SwiftUI-Demos, wie Apps mit Core Text eigene Schriften systemweit installieren und Schriften anderer Apps anfordern können. Der Autor berichtet, dass fremde Schriften nicht zuverlässig über die registrierten Deskriptoren auffindbar sind und dass zusätzliche Deskriptor-Attribute Anfragen ohne sichtbaren Dialog scheitern lassen können.
