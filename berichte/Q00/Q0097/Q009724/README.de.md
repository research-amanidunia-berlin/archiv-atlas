## Zusammenfassung (von Luna, ungeprüft)

Der Beitrag empfiehlt für das Öffnen von Dateien und Ordnern `NSWorkspace` mit einer File-URL; `OpenURLAction` scheitere laut den Beispielen bei den gezeigten URL-Formen. Für die Auswahl einer Datei im Finder nennt er `selectFile`, das Pfade statt URL-Darstellungen erwartet und bei symbolischen Links den Link selbst auswählen kann.
