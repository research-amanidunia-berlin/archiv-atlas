# The Long-Term Benefit Trust

Report Q000800 · Source anthropic.com · Date 2023-09-19 · [Open original](https://www.anthropic.com/news/the-long-term-benefit-trust)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Anthropic beschreibt den Long-Term Benefit Trust als unabhängige, schrittweise gestärkte Aufsicht, die bei langfristigen KI-Risiken öffentliche Interessen neben den finanziellen Interessen der Anteilseigner einbringen soll. Das Unternehmen nennt das Modell ein Experiment; der Bericht erläutert seine Struktur, belegt aber nicht, wie wirksam sie in der Praxis ist.
