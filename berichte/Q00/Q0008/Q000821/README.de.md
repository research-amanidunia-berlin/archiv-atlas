## Zusammenfassung (von Luna, ungeprüft)

Mistral stellt OCR als API für die strukturierte Verarbeitung von PDFs und Bildern vor und behauptet anhand eigener Benchmarks hohe Genauigkeit, Mehrsprachigkeit und Verarbeitungsgeschwindigkeit. Die Benchmarkvergleiche beruhen laut Bericht auf einem internen Texttest mit Einschränkungen; zudem wird das Modell inzwischen nicht mehr gewartet und gilt als durch neuere Modelle ersetzt.
