# Not All Forests Are Equal: Mapping the World’s Forests

Report Q000875 · Source deepmind.google · Date 2026-10-22 · [Open original](https://deepmind.google/blog/beyond-tree-cover-mapping-the-worlds-forest-types/)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Der Bericht beschreibt ForTy, eine globale 10-Meter-Karte, die sechs Wald- und Landnutzungstypen unterscheidet, sowie eine vorläufige Zeitreihe für 2017 bis 2025. Laut den Autoren erkannte das Modell bei einer Prüfung an über 9.000 Standorten den Waldtyp zu 90 Prozent korrekt; die Zeitreihe soll auch Umwandlungen von Naturwald in Plantagen zeigen. Die vorliegenden Genauigkeitsangaben stammen aus dem Bericht, der keine regionalen Werte aufführt und die Zeitreihe als noch in Entwicklung beschreibt.
