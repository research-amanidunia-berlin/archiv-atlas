# Prompt engineering for business performance

Bericht Q003563 · Quelle anthropic.com · Datum 2024-02-29 · [Original öffnen](https://www.anthropic.com/news/prompt-engineering-for-business-performance)

[Alle Berichte](../../../README.de.md) · Daten: [bericht.json](bericht.json)

## Zusammenfassung (von Luna, ungeprüft)

Anthropic empfiehlt klare Anweisungen, iterative Tests sowie schrittweises Prompting, Beispiele für gewünschte Antworten und das Aufteilen komplexer Aufgaben in mehrere Prompts. Bei einem anonymisierten Fortune-500-Kunden habe eine Zusammenarbeit zwischen Anthropic-Prompt-Engineering und Fachleuten laut Beitrag die Genauigkeit eines Kunden-Chatbots um 20 Prozent erhöht; Messmethode und Testbedingungen werden nicht angegeben.
