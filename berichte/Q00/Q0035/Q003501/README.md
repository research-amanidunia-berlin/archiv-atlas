# How evolutionary selection can train more capable self-driving cars

Report Q003501 · Source deepmind.google · Date 2019-07-25 · [Open original](https://deepmind.google/blog/how-evolutionary-selection-can-train-more-capable-self-driving-cars/)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Waymo und DeepMind berichten, dass Population Based Training neuronale Netze durch regelmäßige Wettbewerbe und die Weitergabe erfolgreicher Trainingszustände effizienter abstimmen kann. In einem Experiment zur Erkennung von Fußgängern sank die Zahl falscher positiver Ergebnisse laut Bericht um 24 Prozent, bei hohem Recall und geringerem Trainingsaufwand. Die Angaben beziehen sich auf die beschriebenen Tests.
