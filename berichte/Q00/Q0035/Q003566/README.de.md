# Bibliometric Analysis of China’s Non-Therapeutic Brain-Computer Interface Research

Bericht Q003566 · Quelle cset.georgetown.edu · Datum 2024-03-28 · [Original öffnen](https://cset.georgetown.edu/publication/bibliometric-analysis-of-chinas-non-therapeutic-brain-computer-interface-research/)

[Alle Berichte](../../../README.de.md) · Daten: [bericht.json](bericht.json)

## Zusammenfassung (von Luna, ungeprüft)

Der vorliegende Auszug berichtet, eine Analyse chinesischer Veröffentlichungen und Patente lasse auf weit entwickelte Forschung zu nichttherapeutischen Gehirn-Computer-Schnittstellen schließen, mit Schwerpunkten bei Signalverarbeitung, Materialien und der Erkennung kognitiver oder emotionaler Zustände. Die Autoren empfehlen eine fortlaufende Beobachtung; konkrete Methoden und Daten der Analyse sind in diesem Auszug nicht enthalten.
