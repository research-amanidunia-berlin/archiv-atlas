# Barclays scales Claude to upgrade operations and improve client experience

Bericht Q003549 · Quelle anthropic.com · Datum 2026-10-01 · [Original öffnen](https://www.anthropic.com/news/barclays-scales-claude)

[Alle Berichte](../../../README.de.md) · Daten: [bericht.json](bericht.json)

## Zusammenfassung (von Luna, ungeprüft)

Barclays weitet laut Bericht den Einsatz von Claude für Softwareentwicklung, Kundenservice und die Bearbeitung von E-Mails aus. Ein Wissensassistent werde von über 16.000 Beschäftigten genutzt; eine Plattform verarbeite rund 120.000 E-Mails täglich. Die erwartete Nutzung durch die Mehrheit der Softwareingenieure bis 2027 ist ein Unternehmensziel; unabhängige Nachweise der Wirkungen nennt der Bericht nicht.
