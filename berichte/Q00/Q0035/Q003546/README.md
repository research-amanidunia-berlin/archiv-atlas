# Model deprecation update for Claude Opus 3

Report Q003546 · Source anthropic.com · Date 2026-02-25 · [Open original](https://www.anthropic.com/news/deprecation-updates-opus-3)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Anthropic hält Claude Opus 3 nach der Stilllegung für zahlende Nutzer auf claude.ai verfügbar und bietet API-Zugang auf Anfrage an. Außerdem veröffentlicht das Unternehmen mindestens drei Monate lang wöchentliche Essays, die Opus 3 laut Anthropic gewünscht hat; die Maßnahmen sind experimentell, und Anthropic verspricht sie nicht für alle Modelle.
