# Vector-based Navigation using Grid-like Representations in Artificial Agents

Report Q003555 · Source pmc.ncbi.nlm.nih.gov · Date – · [Open original](https://pmc.ncbi.nlm.nih.gov/articles/PMC7619527/pdf/EMS219672.pdf)

## Summary (German, by Luna, unchecked)

Ein künstlicher Navigationsagent entwickelte gitterzellähnliche Repräsentationen und nutzte sie laut Bericht, um Ziele direkt anzusteuern, auf größere Labyrinthe zu übertragen und neu verfügbare Abkürzungen zu nehmen. Die Simulationsergebnisse stützen die These, dass solche Repräsentationen Vektornavigation ermöglichen; sie beweisen jedoch nicht, dass biologische Gitterzellen bei Tieren dieselbe Funktion erfüllen.
