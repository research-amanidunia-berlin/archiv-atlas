# A learning agent that acquires social norms from public sanctions in decentralized multi-agent settings

Report Q003043 · Source journals.sagepub.com · Date – · [Open original](https://journals.sagepub.com/doi/pdf/10.1177/26339137231162025)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Das CNM lässt dezentrale Agenten aus öffentlichen Sanktionen ableiten, welches Verhalten eine Gruppe missbilligt, und fördert so in zwei Simulationen Koordination und höhere kollektive Erträge. Es kann jedoch auch ungünstige Normen stabilisieren; die Resultate hängen unter anderem von öffentlichen Sanktionen und einem eingefrorenen Klassifikator ab und belegen noch keine Wirkung in realen Systemen.
