# Gemini Robotics On-Device brings AI to local robotic devices

Bericht Q003088 · Quelle deepmind.google · Datum 2025-06-24 · [Original öffnen](https://deepmind.google/blog/gemini-robotics-on-device-brings-ai-to-local-robotic-devices/)

[Alle Berichte](../../../README.de.md) · Daten: [bericht.json](bericht.json)

## Zusammenfassung (von Luna, ungeprüft)

Google DeepMind beschreibt ein lokal auf Robotern ausführbares Modell für feinmotorische Aufgaben, das laut eigenen Tests besser abschneidet als die verglichene bisherige On-Device-Alternative und mit 50 bis 100 Demonstrationen angepasst werden kann. Die Angaben beruhen auf Googles eigenen Auswertungen; der Zugang ist zunächst auf ausgewählte Tester begrenzt, und der Beitrag bietet keine unabhängige Prüfung oder umfassende Sicherheitsbewertung.
