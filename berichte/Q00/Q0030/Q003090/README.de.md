# Stargate Advances with 4.5 GW Partnership with Oracle

Bericht Q003090 · Quelle openai.com · Datum 2025-07-22 · [Original öffnen](https://openai.com/index/stargate-advances-with-partnership-with-oracle/)

[Alle Berichte](../../../README.de.md) · Daten: [bericht.json](bericht.json)

## Zusammenfassung (von Luna, ungeprüft)

OpenAI zufolge soll eine Vereinbarung mit Oracle Stargate um 4,5 Gigawatt US-Rechenzentrumskapazität erweitern; zusammen mit Abilene seien damit über fünf Gigawatt und mehr als zwei Millionen Chips in Entwicklung. OpenAI schätzt, dass der Ausbau über 100.000 Arbeitsplätze schaffen und die bisherige Investitionszusage übertreffen könnte, legt aber weder die Berechnung der Jobzahl noch konkrete Kosten, Standorte oder Fertigstellungstermine dar. Der Text ist eine Unternehmensmitteilung ohne unabhängige Bestätigung der Angaben.
