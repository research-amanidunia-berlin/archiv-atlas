# Using the Veil of Ignorance to align AI systems with principles of justice

Report Q003031 · Source pmc.ncbi.nlm.nih.gov · Date – · [Open original](https://pmc.ncbi.nlm.nih.gov/articles/PMC10160973/pdf/pnas.202213709.pdf)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

In fünf Online-Experimenten entschieden Teilnehmende hinter dem „Schleier des Nichtwissens“ häufiger als Kontrollgruppen, dass eine KI die am schlechtesten Gestellten bevorzugen sollte; Fairnessüberlegungen spielten laut Bericht eine größere Rolle als Risiko- oder politische Einstellungen. Der Effekt fehlte jedoch, wenn die Prinzipien nur abstrakt bezeichnet wurden, und die Versuche belegen noch nicht, dass das Verfahren für reale KI-Anwendungen geeignet ist.
