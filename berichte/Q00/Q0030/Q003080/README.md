# Music AI Sandbox, now with new features and broader access

Report Q003080 · Source deepmind.google · Date 2025-04-24 · [Open original](https://deepmind.google/blog/music-ai-sandbox-now-with-new-features-and-broader-access/)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Google stellt neue Funktionen der experimentellen Music AI Sandbox vor: „Create“ erzeugt Musikideen, „Extend“ führt Audioclips weiter und „Edit“ verändert Klang oder einzelne Abschnitte. Mehr Musikschaffende in den USA sollen Zugang erhalten; die positiven Künstlerstimmen sind persönliche Erfahrungsberichte, und eine unabhängige Bewertung der Werkzeuge enthält der Beitrag nicht.
