# A joint statement from OpenAI and Microsoft

Report Q007098 · Source openai.com · Date 2025-09-11 · [Open original](https://openai.com/index/joint-statement-from-openai-and-microsoft/)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

OpenAI und Microsoft erklären, eine unverbindliche Absichtserklärung für die nächste Phase ihrer Partnerschaft unterzeichnet zu haben; die endgültigen Vertragsbedingungen seien noch in Arbeit. Sie nennen als gemeinsame Ziele KI-Werkzeuge für alle und ein Bekenntnis zu Sicherheit, machen dazu aber keine näheren Angaben.
