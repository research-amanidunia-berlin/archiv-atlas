## Summary (German, by Luna, unchecked)

Der Auszug beschreibt, dass das Kapitel KI-Kurse, universitäre Einschreibungen, Einstellungen und Vielfalt in der KI-Ausbildung anhand verschiedener Datenquellen untersuchen soll. Konkrete Ergebnisse fehlen; die drei mitgelieferten Bildunterschriften samt nicht vorliegenden Abbildungen liefern dazu keine zusätzlichen belegten Befunde.
