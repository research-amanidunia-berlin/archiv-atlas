# Dein Browser wird geprüft!

## Zusammenfassung (von Luna, ungeprüft)

Der bereitgestellte Auszug ist eine Anubis-Schutzseite, kein Fachbericht: Der Browser soll eine Proof-of-Work-Aufgabe lösen, bevor der Zugriff freigegeben wird. Die Seite weist darauf hin, dass JavaScript-blockierende Erweiterungen wie JShelter den Vorgang stören können; ob die Prüfung erfolgreich war, bleibt offen.
