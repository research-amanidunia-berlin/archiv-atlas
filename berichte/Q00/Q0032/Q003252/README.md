# Salesforce and Anthropic expand partnership

Report Q003252 · Source anthropic.com · Date 2025-10-14 · [Open original](https://www.anthropic.com/news/salesforce-anthropic-expanded-partnership)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Anthropic und Salesforce bauen ihre Zusammenarbeit aus: Claude kommt in Agentforce für regulierte Branchen, Salesforce will Claude Code intern einsetzen, und die Verbindung mit Slack wird vertieft. Einige Funktionen sind laut Bericht bereits verfügbar; branchenspezifische Finanzlösungen und die Agentforce-360-Integration in Claude werden noch entwickelt. Die genannten Vorteile beruhen auf Aussagen der Unternehmen und werden nicht unabhängig belegt.
