## Summary (German, by Luna, unchecked)

Die Autorinnen und Autoren berichten, dass ein rekurrentes KI-Netz in simulierten Aufgaben Regeln auf neue Beispiele übertragen konnte, ähnlich dem im Text beschriebenen Harlow-Experiment. Sie schlagen vor, dass Dopamin neben der Anpassung von Verbindungen auch abstrakte Informationen über Aufgabenregeln vermitteln könnte; dies ist eine Theorie, kein im Bericht abschließend belegter Mechanismus.
