# GraphCast: AI model for faster and more accurate global weather forecasting

Report Q003213 · Source deepmind.google · Date 2023-11-14 · [Open original](https://deepmind.google/blog/graphcast-ai-model-for-faster-and-more-accurate-global-weather-forecasting/)

## Summary (German, by Luna, unchecked)

Google DeepMind zufolge erstellt GraphCast globale Wetterprognosen für bis zu zehn Tage schneller und in vielen Tests genauer als das Vergleichssystem HRES. Das Team berichtet auch von früheren Hinweisen auf extreme Wetterereignisse; der Beitrag nennt Leistungswerte und Beispiele, legt das Prüfverfahren und die Grenzen hier aber nicht vollständig dar.
