# The AI Workforce: What LinkedIn data reveals about ‘AI Talent’ trends in OECD.AI’s live data

Report Q003226 · Source oecd.ai · Date 2025-05-22 · [Open original](https://oecd.ai/en/wonk/ai-workforce-what-linkedin-data-reveals-about-ai-talent-trends-in-oecd-ai-live-data)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Der Beitrag berichtet auf Grundlage von LinkedIn-Profilen über das Wachstum von KI-Fähigkeiten und -Berufen: 2024 hätten sieben von 1.000 Mitgliedern als KI-Engineering-Talente gegolten. Er hebt zugleich Geschlechterlücken und wachsende Kenntnisse zu generativer KI, Produktivität, KI-Agenten und verantwortungsvoller KI hervor. Die Angaben beziehen sich auf LinkedIn-Mitglieder und die dort angewandte Talentdefinition.
