# 2026 Usage Policy update

Report Q003299 · Source anthropic.com · Date 2026-10-08 · [Open original](https://www.anthropic.com/news/2026-usage-policy-update)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Anthropic kündigt für den 12. November 2026 eine aktualisierte Nutzungsrichtlinie an, die überwiegend bestehende Verbote und Anforderungen präzisieren soll. Sie konkretisiert Regeln zu Täuschung, Wahlen, Waffen, Überwachung, Hochrisikoanwendungen und autonomer Hardware; laut Anthropic bleiben unter anderem menschliche Kontrolle in Hochrisikofällen sowie Verbote täuschender und nicht einvernehmlicher Überwachung bestehen.
