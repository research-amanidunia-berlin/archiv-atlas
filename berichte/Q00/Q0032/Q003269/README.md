# Anthropic is endorsing SB 53

Report Q003269 · Source anthropic.com · Date 2025-09-08 · [Open original](https://www.anthropic.com/news/anthropic-is-endorsing-sb-53)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Anthropic befürwortet SB 53, einen kalifornischen Entwurf, der große Entwickler leistungsfähiger KI zu Sicherheitsrahmen, Risikoberichten, Vorfallmeldungen und Schutz für Hinweisgebende verpflichten würde. Das Unternehmen hält den Entwurf für eine sinnvolle Grundlage, fordert aber eine überprüfbare Erfassung möglicher Modelle, mehr Details zu Tests und Gegenmaßnahmen sowie Regeln, die mit der Technik Schritt halten; die Wirkungen beschreibt der Beitrag aus Anthropics eigener Perspektive.
