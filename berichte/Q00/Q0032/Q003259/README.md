# Deloitte brings Claude to 470,000 people

Report Q003259 · Source anthropic.com · Date 2025-10-06 · [Open original](https://www.anthropic.com/news/deloitte-anthropic-partnership)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Anthropic und Deloitte wollen Claude für mehr als 470.000 Deloitte-Beschäftigte bereitstellen, 15.000 Fachkräfte zertifizieren und ein Zentrum für Einführung und Support aufbauen. Geplant sind außerdem Compliance-orientierte KI-Lösungen für regulierte Branchen; die Mitteilung schildert Ziele, aber keine bereits belegten Ergebnisse.
