# Usage Policy update

Report Q003210 · Source anthropic.com · Date 2025-08-15 · [Open original](https://www.anthropic.com/news/usage-policy-update)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Anthropic kündigt für den 15. September 2025 klarere Nutzungsregeln an: Böswillige Cyberangriffe bleiben untersagt, während erlaubte defensive Sicherheitsarbeit unterstützt werden soll. Politische Beschränkungen werden gezielter auf manipulative oder störende Eingriffe ausgerichtet; Regeln zu Strafverfolgung und Hochrisikofällen werden präzisiert, wobei laut Anthropic bestehende Verbote und Schutzanforderungen im Wesentlichen fortgelten.
