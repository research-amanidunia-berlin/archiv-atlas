OpenAI berichtet von drei KI-Ergebnissen: neuen Beweisen zu Vermutungen der harmonischen Analysis, einer behaupteten Widerlegung der Exponentialzeithypothese und Existenzbeweisen für bestimmte Quantenfeldtheorien.
