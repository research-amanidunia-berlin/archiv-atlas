## Zusammenfassung (von Luna, ungeprüft)

Der Autor beschreibt Accessibility API und simuliertes ⌘+V als kombinierbare Wege, Text in andere macOS-Apps einzufügen. Seinen Versuchen zufolge ist Accessibility oft unzuverlässig; die Zwischenablage dient als Rückfall, erkennt aber kein aktives Eingabefeld und kann bei anderen Tastaturlayouts scheitern.
