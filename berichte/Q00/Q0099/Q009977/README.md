## Summary (German, by Luna, unchecked)

Der Autor findet Claude 3 Opus in seinen kleinen Tests zu Logik, Programmierung, Bildanalyse und Kreativität insgesamt mit GPT‑4 vergleichbar; Claude antwortet meist knapper, GPT‑4 oft ausführlicher. Die Benchmarkvorsprünge werden im Bericht als Angaben von Anthropic wiedergegeben, und die persönlichen Tests sind zu begrenzt für allgemeine Aussagen. Für GPT‑4 sprechen laut Autor außerdem Zusatzfunktionen wie Code Interpreter, DALL‑E 3 und GPTs.
