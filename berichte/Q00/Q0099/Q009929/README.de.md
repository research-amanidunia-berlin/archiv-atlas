## Zusammenfassung (von Luna, ungeprüft)

Der Bericht erläutert Apples SwiftUI-Übersetzung mit einer einfachen Systemansicht oder einer selbst gesteuerten `TranslationSession` samt Sprachwahl, Verfügbarkeitsprüfung und Einzel- oder Stapelübersetzung. Laut Autor funktioniert die Systemansicht im Simulator, die eigene Sitzung jedoch nur auf einem echten Gerät; außerdem wird derselbe `translationTask` durch erneutes Zuweisen derselben Konfiguration nicht nochmals ausgelöst.

## Sammelfragen

Je Zelle: Anteil Stufe 4–7 / Stufe 3–7 (4 = enthält zitierbare Belege … 7 = beantwortet direkt; 3 = nützlicher Hintergrund).
