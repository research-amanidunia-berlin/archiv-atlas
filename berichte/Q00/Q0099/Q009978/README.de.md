# LiveActivity: REMOTE Control With Push Notifications

Bericht Q009978 · Quelle medium.com · Datum 2025-12-20 · [Original öffnen](https://medium.com/gitconnected/swiftui-liveactivity-remote-control-with-push-notifications-005d4a6b7005)

## Zusammenfassung (von Luna, ungeprüft)

Der vollständige Bericht erläutert, wie ActivityKit-Pushs einzelne Live Activities aus der Ferne starten, aktualisieren und beenden, einschließlich Token-Arten, Payloads und Tests mit Apples Push Notification Console. Der Autor nennt Grenzen wie ein nicht genau beziffertes stündliches Push-Budget, mögliche unsichtbare Zustellungen und die iOS/iPadOS-Mindestversion 17.2 für Starts per Push; Updates und Beenden seien auch auf älteren Versionen möglich.
