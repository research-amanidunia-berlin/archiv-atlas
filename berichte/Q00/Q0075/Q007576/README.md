## Summary (German, by Luna, unchecked)

OpenAI kündigt einen Leitfaden zur ChatGPT-Nutzung für Familien und Tipps für Eltern im Gespräch mit Jugendlichen an. Die Materialien sollen unter anderem über Fehler von KI, kritisches Denken, Grenzen und Datenschutz informieren; laut Bericht wurden Fachleute einbezogen, doch eine unabhängige Prüfung oder Wirkungsmessung enthält der Text nicht.
