## Summary (German, by Luna, unchecked)

Der Bericht stellt ein Plugin vor, mit dem Administratoren von ChatGPT Work und Codex Nutzungsdaten einsehen, Berechtigungen und Mitglieder verwalten sowie bestimmte Abläufe automatisieren können. OpenAI zufolge bleibt das Plugin an vorhandene Rechte und Freigaben gebunden; die genannten internen Erfolge, darunter rund 45 Prozent gelöste IT-Tickets, sind Unternehmensangaben ohne im Bericht erläuterte unabhängige Prüfung.
