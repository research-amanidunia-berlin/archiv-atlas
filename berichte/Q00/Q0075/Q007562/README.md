# Introducing LifeSciBench

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

LifeSciBench umfasst laut Bericht 750 fachlich erstellte Forschungsaufgaben und bewertet neben Antworten auch Begründungen, Unsicherheit und den Umgang mit Datenartefakten. OpenAI berichtet Fortschritte von GPT‑Rosalind gegenüber GPT‑5.5, zugleich aber deutliche Schwierigkeiten bei artefaktreichen, analytischen und exakten Aufgaben. Der Benchmark prüft abgeschlossene Aufgaben; Auswirkungen auf reale Forschung müsse man in längerfristigen Studien untersuchen.
