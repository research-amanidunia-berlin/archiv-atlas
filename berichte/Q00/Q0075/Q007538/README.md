# How ChatGPT adoption has expanded

Report Q007538 · Source openai.com · Date 2026-06-30 · [Open original](https://openai.com/index/how-chatgpt-adoption-has-expanded/)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

OpenAI berichtet anhand aggregierter Nutzungsdaten, dass ChatGPT mit der Zeit häufiger und für mehr Aufgaben genutzt werde; global sei das relative Wachstum seit Juli 2023 besonders stark in Afrika, Asien und Ländern mit niedrigerem HDI gewesen. Nichtenglischsprachige Nutzung stelle inzwischen mehr als die Hälfte der aktiven Nutzerschaft. Die Angaben beruhen auf begrenzten Stichproben und Klassifikationen; insbesondere werden Geschlechter nur aus Vornamen abgeleitet.
