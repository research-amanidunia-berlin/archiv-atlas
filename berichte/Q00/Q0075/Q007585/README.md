# An update on our safety & security practices

Report Q007585 · Source openai.com · Date 2024-09-16 · [Open original](https://openai.com/index/update-on-safety-and-security-practices/)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

OpenAI beschreibt fünf Schwerpunkte für seine Sicherheitsarbeit: unabhängige Aufsicht, stärkere Cybersicherheit, mehr Transparenz, externe Zusammenarbeit und einen gemeinsamen Rahmen zur Bewertung und Überwachung von Modellen. Viele Schritte sind angekündigt oder werden geprüft; konkrete Fristen und ausführliche Ergebnisse der o1-Sicherheitsprüfung nennt die Mitteilung nicht. Der vorliegende Text ist keine erkennbare Auszugs- oder Fehlerseite.
