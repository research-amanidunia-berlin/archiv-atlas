# Introducing ChatGPT Go, now available worldwide

Report Q007564 · Source openai.com · Date 2026-01-16 · [Open original](https://openai.com/index/introducing-chatgpt-go/)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

OpenAI kündigt die weltweite Einführung von ChatGPT Go für 8 US-Dollar pro Monat in den USA an; der Tarif soll gegenüber der Gratisversion mehr Nachrichten, Uploads und Bilderstellung sowie längere Erinnerung bieten. Der Bericht beschreibt außerdem Plus und Pro und kündigt einen geplanten Werbetest in den USA für Gratisversion und Go an, belegt die Anbieterangaben aber nicht unabhängig und nennt keine genaueren Nutzungslimits.
