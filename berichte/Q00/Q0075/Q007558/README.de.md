# Introducing HealthBench

Bericht Q007558 · Quelle openai.com · Datum 2025-05-12 · [Original öffnen](https://openai.com/index/healthbench/)

[Alle Berichte](../../../README.de.md) · Daten: [bericht.json](bericht.json)

## Zusammenfassung (von Luna, ungeprüft)

OpenAI beschreibt HealthBench als Benchmark aus 5.000 realistischen Gesundheitsgesprächen, die anhand ärztlich verfasster Kriterien bewertet werden. Das Unternehmen berichtet über deutliche Modellfortschritte, betont aber weiteren Verbesserungsbedarf bei fehlendem Kontext und der Zuverlässigkeit schwacher Einzelantworten.
