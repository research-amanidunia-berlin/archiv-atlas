# Basis scales accounting by turning OpenAI model progress into trusted agents

Report Q007382 · Source openai.com · Date 2025-08-12 · [Open original](https://openai.com/index/basis/)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Basis entwickelt laut Bericht KI-Agenten, die Buchhaltungsaufgaben automatisieren und Mitarbeitenden nachvollziehbare Empfehlungen sowie Kontrolle über Abläufe bieten sollen. OpenAI und Basis geben an, dass Nutzerfirmen im Schnitt 30 Prozent Zeit sparen; ein interner GPT‑5-Test paralleler Werkzeugaufrufe habe 100 Prozent Erfolg erzielt. Der Bericht bietet dafür keine unabhängige Überprüfung.
