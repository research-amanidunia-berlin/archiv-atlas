## Summary (German, by Luna, unchecked)

OpenAI berichtet von einem gemeinsam mit dem Met entwickelten Chat, der Besuchern einen KI-gestützten Dialog mit einer historischen Darstellung von Natalie Potter und ihrem Leben rund um ein Hochzeitskleid von 1931 ermöglicht. Als Grundlage dienten historische Dokumente und die Mitarbeit von Museumshistorikern; der Bericht präsentiert das Projekt als Bereicherung des Ausstellungserlebnisses, liefert aber keine unabhängige Bewertung seiner Genauigkeit oder Wirkung.
