# Romance-baiting scam: AI-assisted pig butchering workflows

Bericht Q007374 · Quelle openai.com · Datum 2025-02-01 · [Original öffnen](https://openai.com/index/disrupting-malicious-uses-of-ai-romance-baiting-scam/)

[Alle Berichte](../../../README.de.md) · Daten: [bericht.json](bericht.json)

## Zusammenfassung (von Luna, ungeprüft)

OpenAI zufolge nutzte eine mutmaßlich aus Kambodscha operierende Gruppe ChatGPT zum Übersetzen und Verfassen von Nachrichten für Liebes- und Anlagebetrug; die Konten wurden gesperrt. Der Bericht skizziert einen Ablauf von öffentlicher Kontaktaufnahme über romantische Chats bis zu fingierten Investitionsangeboten, kann aber weder tatsächliche Überweisungen noch die Zahl der Geschädigten bestätigen.
