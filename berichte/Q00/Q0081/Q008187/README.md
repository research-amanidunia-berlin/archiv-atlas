# Evolved Policy Gradients

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

OpenAI stellt EPG als experimentelle Methode vor, die eine Verlustfunktion entwickelt, damit Agenten neue Aufgaben schneller lernen können. Laut den berichteten Tests generalisierte EPG bei Ant-Agenten auf Ziele auf der anderen Arenaseite und trainierte schneller als PPO. Der Ansatz ist bislang auf kleine Aufgabenfamilien beschränkt und laut Beitrag weniger allgemein einsetzbar als Standard-RL-Verlustfunktionen.
