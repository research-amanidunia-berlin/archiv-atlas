# OpenAI Scholars 2020: Applications open

## Zusammenfassung (von Luna, ungeprüft)

OpenAI schrieb 2019 den dritten Jahrgang eines viermonatigen Deep-Learning-Programms für acht Personen aus unterrepräsentierten Gruppen aus. Geboten werden sollten unter anderem Stipendium, Azure-Guthaben und Einzelmentoring; verlangt wurden Softwareerfahrung, Python-Kenntnisse sowie US-Arbeitserlaubnis und Aufenthalt in einer US-Zeitzone. Der Bericht enthält die damalige Planung, aber keine Angaben zum späteren Verlauf.
