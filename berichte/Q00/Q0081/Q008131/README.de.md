# Joint Statement from OpenAI and Microsoft

Bericht Q008131 · Quelle openai.com · Datum 2026-02-27 · [Original öffnen](https://openai.com/index/continuing-microsoft-partnership/)

[Alle Berichte](../../../README.de.md) · Daten: [bericht.json](bericht.json)

## Zusammenfassung (von Luna, ungeprüft)

OpenAI und Microsoft erklären, ihre Partnerschaft und die dazugehörigen Vereinbarungen blieben trotz neuer OpenAI-Finanzierungen und Kooperationen unverändert. Microsoft behalte laut Erklärung seine Rechte an OpenAIs geistigem Eigentum und Azure seine exklusive Rolle für zustandslose APIs; OpenAI könne zugleich zusätzliche Rechenkapazität anderweitig sichern. Die Vertragsangaben sind Aussagen der Unternehmen und werden im Bericht nicht unabhängig belegt.
