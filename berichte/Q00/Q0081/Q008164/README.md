# Elon Musk wanted an OpenAI for-profit

Report Q008164 · Source openai.com · Date 2024-12-13 · [Open original](https://openai.com/index/elon-musk-wanted-an-openai-for-profit/)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

OpenAI behauptet anhand ausgewählter Nachrichten und Unternehmensunterlagen, Musk habe 2017 selbst eine gewinnorientierte Struktur angestrebt, dabei aber weitreichende Kontrolle verlangt; an dieser Frage seien die Verhandlungen gescheitert. Der Bericht zeichnet anschließend OpenAIs Wechsel zu einer begrenzt gewinnorientierten, gemeinnützig kontrollierten Struktur sowie Musks Rückzug und Gründung von xAI nach. Es ist OpenAIs parteiliche Darstellung mit geschwärzten Auszügen, keine unabhängige Prüfung des Konflikts.
