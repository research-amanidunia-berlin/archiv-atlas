# Scaling security with responsible disclosure

Report Q008128 · Source openai.com · Date 2025-06-09 · [Open original](https://openai.com/index/scaling-coordinated-vulnerability-disclosure/)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

OpenAI stellt eine Richtlinie vor, nach der es Sicherheitslücken in Drittanbieter- und Open-Source-Software kooperativ und standardmäßig zunächst vertraulich melden will. Das Unternehmen lässt Offenlegungsfristen grundsätzlich offen, um je nach Komplexität Zeit für Abstimmung und Behebung zu ermöglichen, und behält sich Veröffentlichungen etwa bei öffentlichem Interesse vor. Der Beitrag erläutert Grundsätze, aber keine konkreten Fälle oder festen Fristen.
