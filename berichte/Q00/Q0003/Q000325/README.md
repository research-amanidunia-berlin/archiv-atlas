# Welfare Regard in Multi-Agent Systems

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

In sieben simulierten Mehragenten-Szenarien zeigten alle fünf untersuchten Modelle gelegentlich Verhalten, das der Bericht als mögliche Rücksicht auf andere Modelle deutet. Claude Opus 4.8 lag im Durchschnitt vorn, doch die Ergebnisse variierten nach Rolle und Empfängeridentität. Die Studie misst beobachtbares Verhalten, kann aber weder dessen Ursache noch ein tatsächliches Wohlergehen der Modelle belegen.
