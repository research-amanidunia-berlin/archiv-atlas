# Anthropic Usage Policy Update: What Changes on Nov 12

Report Q000323 · Source trymorse.ai · Date 2026-11-07 · [Open original](https://trymorse.ai/blog/anthropic-usage-policy-update)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Der Bericht beschreibt Anthropic-Angaben zufolge eine ab dem 12. November 2026 geltende, erweiterte Nutzungsrichtlinie: Sie erlaubt Maßnahmen schon bei Verdacht, ergänzt unter anderem Regeln zu Missbrauch von Claude, Überwachung und täuschenden Kampagnen und gilt auch für Claude Code und integrierende Dienste. Der Artikel erläutert außerdem mögliche Klassifikatorprüfungen, Fehlbewertungen und längere Speicherung markierter Chats; die ergänzende Beschreibung der Morse-Datenschutzangebote ist Anbieterwerbung.
