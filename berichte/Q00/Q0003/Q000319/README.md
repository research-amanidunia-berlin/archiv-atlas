# A Stanford-led benchmark found frontier models fold when a teammate pushes back.

Report Q000319 · Source sanctity.ai · Date – · [Open original](https://www.sanctity.ai/signal/collab-intelligence-bench-e071)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Ein Stanford-naher Benchmark mit 240 Aufgaben legt laut Bericht nahe, dass gute Einzelleistung keine verlässliche Teamfähigkeit garantiert: Unter Verhandlungsdruck erzielten die getesteten Modelle das beste Teamergebnis nur in 14 Prozent der Läufe. Die Befunde beruhen auf konstruierten Testszenarien; ob sie auf reale Arbeitsplätze übertragbar sind, ist nicht belegt.
