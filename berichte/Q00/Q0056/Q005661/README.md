# Kína külföldi technológiára irányuló kívánság listája

Report Q005661 · Source cset.georgetown.edu · Date 2023-04-06 · [Open original](https://cset.georgetown.edu/publication/kina-kulfoldi-technologiara-iranyulo-kivansag-listaja/)

## Summary (German, by Luna, unchecked)

Der Text ist ein Auszug aus der ungarischen Zusammenfassung eines CSET-Berichts von 2021. Er beschreibt chinesische Wissenschafts- und Technologiediplomaten als staatlich unterstützte Vermittler, die ausländische Technologie- und Investitionsmöglichkeiten für chinesische Unternehmen erkunden; von 642 erfassten Gelegenheiten betraf etwa die Hälfte Biotechnologie oder KI, und in einer Stichprobe von 30 Firmen kooperierte ungefähr die Hälfte später mit chinesischen Unternehmen oder legte geistiges Eigentum offen.
