# OpenAI announces new members to board of directors

Bericht Q005655 · Quelle openai.com · Datum 2024-03-08 · [Original öffnen](https://openai.com/index/openai-announces-new-members-to-board-of-directors/)

## Zusammenfassung (von Luna, ungeprüft)

OpenAI kündigt drei neue Mitglieder für seinen Verwaltungsrat an: Sue Desmond-Hellmann, Nicole Seligman und Fidji Simo; CEO Sam Altman soll ebenfalls zurückkehren. Das Unternehmen verweist auf deren Erfahrungen in Medizin, Recht, Unternehmensführung und Technologie. Die Ankündigung nennt keine Amtszeiten oder Einzelheiten zur Auswahl.
