## Summary (German, by Luna, unchecked)

Der vorliegende Bericht enthält nur das Abstract: Es stellt Self-AIXI vor, einen universellen RL-Agenten, der durch Vorhersage seiner eigenen Aktionsdaten lernen soll, statt hauptsächlich umfassende Suche einzusetzen.
