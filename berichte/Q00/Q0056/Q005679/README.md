# Andrew Lohn's Testimony before House of Representatives Science, Space and Technology Subcommittees

Report Q005679 · Source cset.georgetown.edu · Date 2022-05-11 · [Open original](https://cset.georgetown.edu/publication/andrew-lohns-testimony-before-house-of-representatives-science-space-and-technology-subcommittees/)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Andrew Lohn zufolge erleichtert das Teilen von Datensätzen, KI-Modellen und Code den Fortschritt, schafft aber Risiken durch manipulierte Daten und Modelle, unsichere Programmierressourcen und Abhängigkeit von Anbietern. Er empfiehlt vertrauenswürdige Ressourcen, finanzierte Sicherheitsprüfungen, Übersichten über staatlich genutzte Komponenten und mehr KI-Fachwissen in Regierungsteams; Häufigkeit und Abwehrwirkung der Risiken beziffert er nicht.
