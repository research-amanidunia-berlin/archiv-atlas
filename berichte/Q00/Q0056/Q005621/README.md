# Mapping Biosafety Level-3 Laboratories by Publications

Report Q005621 · Source cset.georgetown.edu · Date 2022-08-23 · [Open original](https://cset.georgetown.edu/publication/mapping-biosafety-level-3-laboratories-by-publications/)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Der Auszug beschreibt BSL-3-Labore als wichtige Infrastruktur für die Forschung an gefährlichen Erregern und verweist auf den möglichen Nutzen dieser Forschung sowie auf Unfall- und Missbrauchsrisiken. Die Autorinnen suchten in PubMed Central nach englischsprachigen Veröffentlichungen von Institutionen aus den Jahren 2006 bis 2021, um deren Standorte zu kartieren. Konkrete Ergebnisse oder Abbildungen enthält der Auszug nicht.
