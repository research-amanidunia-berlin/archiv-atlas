# Andrew Lohn's Testimony before the Senate Armed Services Subcommittee on Cybersecurity

Report Q005673 · Source cset.georgetown.edu · Date 2022-05-03 · [Open original](https://cset.georgetown.edu/publication/andrew-lohns-testimony-before-the-senate-armed-services-subcommittee-on-cybersecurity/)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Andrew Lohn beschreibt, wie KI Cyberabwehr unterstützen, Angriffe autonomer und Phishing überzeugender machen könnte. Zugleich warnt er vor manipulierbaren KI-Systemen und Trainingsdaten, betont aber, dass Cyberoperationen weiterhin stark von Menschen abhängen und die Risiken außerhalb von Laboren nur begrenzt belegt sind.
