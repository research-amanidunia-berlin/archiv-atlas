# Online RL in Linearly $q^\pi$-Realizable MDPs Is as Easy as in Linear MDPs If You Learn What to Ignore

Bericht Q005651 · Quelle deepmind.google · Datum 2023-12-12 · [Original öffnen](https://deepmind.google/research/publications/34921/)

## Zusammenfassung (von Luna, ungeprüft)

Der vorliegende Text ist nur der Abstract mit bibliografischen Angaben. Die Autoren behaupten, dass sich linear q^π-realisierbare MDPs durch das Überspringen von Zuständen mit annähernd gleichen Aktionswerten auf lineare MDPs zurückführen lassen und darauf ein Online-Lernalgorithmus mit polynomialer Stichprobenkomplexität aufbauen lässt. Das Verfahren sei rechnerisch ineffizient; bei Modellabweichungen verschlechtere sich die Stichprobenkomplexität laut Abstract graduell.
