# Will AI Make Cyber Swords or Shields?

Report Q005600 · Source cset.georgetown.edu · Date 2022-08-08 · [Open original](https://cset.georgetown.edu/publication/will-ai-make-cyber-swords-or-shields/)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Der Bericht modelliert mögliche Auswirkungen technologischer Fortschritte auf Phishing, Schwachstellensuche und Patch-Verteilung. Die Autoren sehen besonders bei der schnelleren Installation von Patches und beim Austausch von Bedrohungsinformationen mögliche Vorteile, betonen aber, dass die Modelle stark unsicher sind und eher Annahmen klären als eindeutige Empfehlungen liefern.
