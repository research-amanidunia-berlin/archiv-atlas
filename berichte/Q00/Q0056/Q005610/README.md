# Deepfakes: A Grounded Threat Assessment

Report Q005610 · Source cset.georgetown.edu · Date 2020-07-29 · [Open original](https://cset.georgetown.edu/publication/deepfakes-a-grounded-threat-assessment/)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Der bereitgestellte Text ist nur die Zusammenfassung eines Berichts über Deepfakes. Laut Bericht könnten einfache Fälschungen leichter verfügbar werden, während maßgeschneiderte Deepfakes eine größere Bedrohung darstellen, deren Einsatz durch Zeit, Datenlage und Zuordnungsrisiken begrenzt ist. Empfohlen werden Beispielsammlungen, bessere Forschungsstandards, zugängliche Erkennung samt Schulungen und markierte Trainingsdaten.
