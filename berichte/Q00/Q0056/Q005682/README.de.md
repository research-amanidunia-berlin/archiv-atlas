# Andrew Lohn's Testimony Before the House Homeland Security Subcommittee on Cybersecurity, Infrastructure Protection, and Innovation

Bericht Q005682 · Quelle cset.georgetown.edu · Datum 2022-06-22 · [Original öffnen](https://cset.georgetown.edu/publication/andrew-lohns-testimony-before-the-house-homeland-security-subcommittee-on-cybersecurity-infrastructure-protection-and-innovation/)

[Alle Berichte](../../../README.de.md) · Daten: [bericht.json](bericht.json)

## Zusammenfassung (von Luna, ungeprüft)

Lohn zufolge kann KI Cybersicherheit verbessern, ist aber selbst verwundbar und kann mit überzeugenden Texten zur Meinungsbeeinflussung eingesetzt werden. Eine von ihm angeführte kontrollierte Studie zeigte deutliche Meinungsverschiebungen nach dem Lesen KI-generierter Nachrichten; wie lange diese anhielten, sei jedoch unbekannt.
