# Layered AI Defenses Have Holes: Vulnerabilities and Key Recommendations

Bericht Q001601 · Quelle far.ai · Datum 2026-07-16 · [Original öffnen](https://www.far.ai/blog/defense-in-depth)

[Alle Berichte](../../../README.de.md) · Daten: [bericht.json](bericht.json)

## Zusammenfassung (von Luna, ungeprüft)

FAR.AI berichtet, dass der gestufte Angriff STACK eine selbst entwickelte mehrschichtige KI-Schutzpipeline auf ClearHarm mit 71 Prozent Erfolg umgehen konnte, sofern Angreifende erfuhren, welche Schutzschicht blockiert hatte; konventionelle Angriffe erreichten dort laut Bericht null Prozent. Für einen Übertragungsangriff auf ein anderes Blackbox-System lag der Erfolg bei 33 Prozent. Die Ergebnisse sind durch eine vereinfachte Testumgebung, eine hohe zugelassene Falsch-Positiv-Rate und den engen Fokus auf englische, waffenbezogene Anfragen begrenzt.
