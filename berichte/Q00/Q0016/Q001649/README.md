# Brief #27: China bans AI partners for minors and lays out AI agent threats

Report Q001649 · Source aisafetychina.substack.com · Date 2026-05-06 · [Open original](https://aisafetychina.substack.com/p/china-bans-ai-partners-for-minors)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Der Bericht schildert verschärften Kinderschutz bei Chinas Regeln für emotionale KI, neue TC260-Standards für Agentensicherheit und einen unverbindlichen Expertenentwurf für ein knappes KI-Grundgesetz. Ausgewählte Studien melden erhebliche Sicherheitsprobleme und wirksame Angriffe, doch die Zahlen sind Forschungsangaben, deren Übertragbarkeit der Bericht nicht umfassend prüft; die praktische Wirkung der Regeln hängt zudem von ihrer Umsetzung ab.
