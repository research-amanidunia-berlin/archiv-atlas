# What to know about a recent Mixpanel security incident

Report Q001682 · Source openai.com · Date 2025-11-26 · [Open original](https://openai.com/index/mixpanel-incident/)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

OpenAI berichtet von einem Sicherheitsvorfall bei Mixpanel, bei dem begrenzte Kontaktdaten und technische Analysedaten von Nutzern der API-Plattform sowie einigen ChatGPT-Nutzern betroffen gewesen sein könnten. Laut OpenAI blieben Chats, API-Nutzungsdaten und Zugangsdaten unberührt; Mixpanel wurde entfernt, während die Untersuchung weiterlief. Der Bericht warnt vor möglichem Phishing und empfiehlt erhöhte Vorsicht sowie Mehr-Faktor-Authentifizierung.
