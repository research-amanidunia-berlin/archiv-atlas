# Can we predict the jobs robots will do?

Report Q001639 · Source anthropic.com · Date 2026-09-30 · [Open original](https://www.anthropic.com/research/what-work-can-robots-do)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Der Bericht schätzt, dass heutige Roboter 74 Prozent der körperlichen US-Arbeitsaufgaben unter bestimmten Bedingungen bewältigen können; gemeinsam mit Sprachmodellen seien rund 81 Prozent aller Aufgaben exponiert. Besonders betroffen erscheinen Fahr- und Lagerberufe, während Kosten, Fähigkeiten, Regulierung und menschliche Präferenzen die Einführung bremsen. Die Expositionswerte und Zukunftsszenarien beruhen auf Schätzungen und sind keine sichere Vorhersage von Arbeitsplatzverlusten.
