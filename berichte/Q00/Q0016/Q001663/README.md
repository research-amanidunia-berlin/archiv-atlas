# Aeneas transforms how historians connect the past

Report Q001663 · Source deepmind.google · Date 2025-07-23 · [Open original](https://deepmind.google/blog/aeneas-transforms-how-historians-connect-the-past/)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Das Aeneas-Team beschreibt ein multimodales KI-Modell, das lateinische Inschriften ergänzt, datiert, geografisch zuordnet und vergleichbare Texte aus einem Datensatz mit über 176.000 Einträgen abruft. Laut einer Studie mit 23 Historikern verbesserten Parallelen und Vorhersagen die gemeinsame Bearbeitung; die veröffentlichten Genauigkeitswerte beziehen sich auf die im Beitrag beschriebenen Aufgaben und Datensätze.
