# How fast is autonomous AI cyber capability advancing?

Report Q001605 · Source aisi.gov.uk · Date 2026-05-13 · [Open original](https://www.aisi.gov.uk/blog/how-fast-is-autonomous-ai-cyber-capability-advancing)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

AISI schätzt, dass sich die Länge autonom lösbarer Cyberaufgaben seit Ende 2024 etwa alle 4,7 Monate verdoppelt hat; Claude Mythos Preview und GPT-5.5 übertrafen diesen Verlauf, doch ob das eine neue Entwicklung markiert, ist unklar. Die Tests sind begrenzt und bilden reale, verteidigte Systeme nicht verlässlich ab; AISI fordert robustere Sicherheitsmaßnahmen und entwickelt anspruchsvollere Evaluationen.
