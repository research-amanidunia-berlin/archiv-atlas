# Labor market impacts of AI: A new measure

Report Q001666 · Source anthropic.com · Date 2026-03-05 · [Open original](https://www.anthropic.com/research/labor-market-impacts)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Der Bericht entwickelt ein Maß für die KI-Exposition von Berufen, das theoretische Fähigkeiten von Sprachmodellen mit tatsächlichen Claude-Nutzungsdaten kombiniert. Er findet bislang keinen klaren Anstieg der Arbeitslosigkeit in stärker exponierten Berufen, aber einen knapp statistisch signifikanten Hinweis auf weniger Neueinstellungen von 22- bis 25-Jährigen in diese Berufe. Die Autoren betonen, dass die Ergebnisse vorläufig sind und alternative Erklärungen sowie Messgrenzen bestehen.
