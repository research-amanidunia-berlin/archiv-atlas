# What makes a good monitoring prompt?

Report Q001672 · Source apolloresearch.ai · Date – · [Open original](https://apolloresearch.ai/monitoring/what-makes-a-good-monitoring-prompt)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Der Bericht kommt zu dem Ergebnis, dass strukturierte Analysevorgaben, eine detaillierte Schweregradskala und ein Bewertungsbeispiel die Qualität von Monitoring-Prompts besonders stützen; bloßes Streichen ganzer Abschnitte ist laut den Tests meist schlechter als Verdichtung. Die Befunde beruhen auf drei Modellen, fünf Fehlermustergruppen und angenäherten Referenzbewertungen, deren Verwendung der Skala eine mögliche Zirkularität erzeugt.
