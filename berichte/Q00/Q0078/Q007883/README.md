## Summary (German, by Luna, unchecked)

OpenAI kündigt für ChatGPT neue Datenanalysefunktionen an: direkte Dateiimporte aus Google Drive und OneDrive, interaktive Tabellen sowie anpassbare und herunterladbare Diagramme. Laut Bericht kann ChatGPT Daten per Python auswerten; nicht unterstützte Diagrammarten werden statisch dargestellt, und die Datenschutzangaben stammen von OpenAI selbst.
