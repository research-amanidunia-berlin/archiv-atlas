# Introducing ChatGPT for Teens: Built for learning, backed by protections

Report Q007858 · Source openai.com · Date 2026-08-18 · [Open original](https://openai.com/index/chatgpt-for-teens/)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

OpenAI kündigt ChatGPT for Teens mit Lernhilfen wie Study Mode und Quizzen sowie standardmäßigen Schutzmaßnahmen für unter 18-Jährige an. Der Unternehmensbericht beschreibt auch Elternkontrollen, Regeln für gesunde Nutzung, eine KI-Bildungspartnerschaft und laufende Sicherheitsprüfungen, nennt aber nur begrenzte konkrete Ergebnisse zu deren Wirksamkeit.
