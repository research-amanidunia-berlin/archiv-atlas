# Point-E: A system for generating 3D point clouds from complex prompts

Bericht Q007769 · Quelle openai.com · Datum 2022-12-16 · [Original öffnen](https://openai.com/index/point-e/)

[Alle Berichte](../../../README.de.md) · Daten: [bericht.json](bericht.json)

## Zusammenfassung (von Luna, ungeprüft)

Der vorliegende Text enthält nur das Abstract: Point-E erzeugt laut den Autoren 3D-Punktwolken, indem ein Text-zu-Bild-Modell zunächst eine Ansicht und ein zweites Diffusionsmodell daraus eine Punktwolke erstellt. Die Autoren geben eine Laufzeit von ein bis zwei Minuten auf einer einzelnen GPU an, räumen aber eine geringere Qualität als beim damaligen Stand der Technik ein; nähere Versuchsdaten enthält der Auszug nicht.
