## Zusammenfassung (von Luna, ungeprüft)

Der Bericht beschreibt ein System, das 100 mögliche Lösungen für eine Grundschulaufgabe erzeugt und sie von einem trainierten Prüfer bewerten lässt. Laut den Autoren erzielte es auf GSM8K starke Vergleichsergebnisse, darunter 55 Prozent gegenüber 60 Prozent bei einer kleinen Gruppe von Kindern; die Befunde gelten für den beschriebenen Test, und eine Übertragung auf andere Bereiche wird nicht gezeigt.
