# Emergent tool use from multi-agent interaction

Bericht Q007797 · Quelle openai.com · Datum 2019-09-17 · [Original öffnen](https://openai.com/index/emergent-tool-use/)

[Alle Berichte](../../../README.de.md) · Daten: [bericht.json](bericht.json)

## Zusammenfassung (von Luna, ungeprüft)

Der Bericht beschreibt, wie Agenten in einem simulierten Versteckspiel laut OpenAI bis zu sechs Strategien und Gegenstrategien entwickelten, ohne eigens fürs Erkunden oder den Objektgebrauch belohnt zu werden. Der Transfer auf andere Aufgaben blieb begrenzt, und die Agenten nutzten gelegentlich unbeabsichtigte Eigenschaften der Physik aus.
