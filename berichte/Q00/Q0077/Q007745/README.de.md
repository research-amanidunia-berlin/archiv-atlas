# Our response to the Axios developer tool compromise

Bericht Q007745 · Quelle openai.com · Datum 2026-04-10 · [Original öffnen](https://openai.com/index/axios-developer-tool-compromise/)

[Alle Berichte](../../../README.de.md) · Daten: [bericht.json](bericht.json)

## Zusammenfassung (von Luna, ungeprüft)

OpenAI berichtet, dass eine kompromittierte Axios-Version in einem GitHub-Actions-Ablauf für macOS-App-Signaturen ausgeführt wurde. Das Unternehmen fand nach eigener Aussage keine Hinweise auf entwendete Nutzerdaten, veränderte Apps oder missbrauchtes Signaturmaterial, rotiert das Zertifikat aber vorsorglich. macOS-Nutzer sollen bis zum 8. Mai 2026 auf die genannten Versionen mit neuem Zertifikat aktualisieren und Apps nur über offizielle Wege beziehen.
