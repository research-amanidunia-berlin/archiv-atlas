# Healthcare organizations can now connect EHR and additional industry data to ChatGPT

Report Q007719 · Source openai.com · Date 2026-09-01 · [Open original](https://openai.com/index/chatgpt-connects-health-records-and-healthcare-sources/)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

OpenAI stellt eine Epic-Anbindung für autorisierte Patientenakten und ein Plugin für neun öffentliche Gesundheitsquellen vor, damit Teams Informationen in ChatGPT for Healthcare zusammenführen und prüfen können. Das Unternehmen nennt positive ärztliche Bewertungen, deren Umfang und Ergebnisse sich auf die beschriebenen Tests beschränken; die Funktionen sind je nach Kundengruppe und Einrichtung unterschiedlich verfügbar.
