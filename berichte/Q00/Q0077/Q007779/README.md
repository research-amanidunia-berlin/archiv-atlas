# GPT-2: 1.5B release

Report Q007779 · Source openai.com · Date 2019-11-05 · [Open original](https://openai.com/index/gpt-2-1-5b-release/)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

OpenAI begründet die Freigabe des GPT‑2-Modells mit 1,5 Milliarden Parametern mit seinem gestuften Veröffentlichungsplan und berichtet über Glaubwürdigkeit, mögliche propagandistische Nutzung sowie begrenzte Erkennungsleistung. Das Unternehmen sah nach eigener Aussage bislang keine starken Missbrauchsbelege, betont aber, dass Erkennung, Bias-Prüfung und die Einschätzung möglicher Risiken Grenzen haben.
