# The Alignment Project by AISI — The AI Security Institute

Report Q002784 · Source aisi.gov.uk · Date – · [Open original](https://www.aisi.gov.uk/blog/announcing-the-alignment-project)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Das 2025 gestartete Alignment Project fördert laut Bericht interdisziplinäre Forschung zur Sicherheit und Kontrollierbarkeit fortgeschrittener KI. In der ersten Runde gingen über 27 Millionen Pfund an mehr als 60 Projekte; Bewerbungen sind aktuell geschlossen, und ein ähnliches Programm ist 2026 unwahrscheinlich, während weitere akademische Förderungen erwartet werden.
