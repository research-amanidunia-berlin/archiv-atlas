# Security challenges in AI agent deployment: Insights from a large scale public competition

Bericht Q002731 · Quelle aisi.gov.uk · Datum 2025-07-27 · [Original öffnen](https://www.aisi.gov.uk/research/security-challenges-in-ai-agent-deployment-insights-from-a-large-scale-public-competition)

[Alle Berichte](../../../README.de.md) · Daten: [bericht.json](bericht.json)

## Zusammenfassung (von Luna, ungeprüft)

Der bereitgestellte Bericht enthält nur einen Abstract-Auszug. Laut dessen Autoren lösten in einem Wettbewerb mit 22 Agenten und 44 Szenarien mehr als 60.000 von 1,8 Millionen Prompt-Injection-Angriffen Richtlinienverletzungen aus; die Angriffe übertrugen sich oft zwischen Modellen und Aufgaben. Der Auszug nennt keine näheren methodischen Einzelheiten.
