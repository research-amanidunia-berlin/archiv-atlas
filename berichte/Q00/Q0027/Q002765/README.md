# Funding the AI Cloud — Amazon, Alphabet, and Microsoft's Cloud Computing Investments, Part 3

Report Q002765 · Source cset.georgetown.edu · Date 2024-11-20 · [Open original](https://cset.georgetown.edu/publication/funding-the-ai-cloud-amazon-alphabet-and-microsofts-cloud-computing-investments-part-3/)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Der Bericht analysiert PitchBook-Daten und kommt zu dem Ergebnis, dass Alphabet seit 2011 die meisten Investitionen tätigte, während die KI-Anteile der Portfolios aller drei Konzerne zunahmen. Die Autoren sehen in Beteiligungen, Förderprogrammen und Cloud-Guthaben mögliche Mittel, um Start-ups an die Cloud-Ökosysteme der Konzerne zu binden; die Daten belegen jedoch nicht, dass dies bei jeder Investition geschieht, und für manche Accelerator-Geschäfte fehlen Datumsangaben.
