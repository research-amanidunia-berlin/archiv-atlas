# Efficient Exploratory Synthesis of Quaternary Cesium Chlorides Guided by In Silico Predictions

Report Q002706 · Source pmc.ncbi.nlm.nih.gov · Date – · [Open original](https://pmc.ncbi.nlm.nih.gov/articles/PMC11528441/pdf/ja4c10294.pdf)

## Summary (German, by Luna, unchecked)

Der Bericht beschreibt eine Synthesestrategie, die DFT-Stabilitätsvorhersagen, verfügbare Ausgangsstoffe und In-situ-Röntgenbeugung verbindet. Laut den Autoren kamen vier von zehn Laborversuchen einer Zielphase nahe; berichtet werden Cs₂LiIrCl₆ als neue Verbindung sowie wenig untersuchte Strukturvarianten von Cs₂LiCrCl₆ und Cs₂LiRuCl₆. Die Vorhersagen ersetzen keine Syntheseprüfung und bilden Temperatureffekte nicht automatisch ab.
