# Issue Brief: Measuring Training Compute

Report Q002792 · Source frontiermodelforum.org · Date 2024-05-02 · [Open original](https://www.frontiermodelforum.org/updates/issue-brief-measuring-training-compute/)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Das Frontier Model Forum empfiehlt Standards, nach denen der Rechenaufwand beim KI-Training gemessen und gemeldet werden soll, weil er vorläufig als Näherungswert für Modellfähigkeiten dient. Zu den Vorschlägen gehören gleiche Zählung verschiedener Operationen, der Ausschluss von Neuberechnungen und verworfenen Zweigen sowie begrenzte Näherungen und eine reduzierte Berichtspflicht für Modellvarianten; der Text formuliert Empfehlungen und weist keine verbindliche Einführung oder empirische Wirkung nach.
