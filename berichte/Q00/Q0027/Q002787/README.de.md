# Introducing Claude 2.1

Bericht Q002787 · Quelle anthropic.com · Datum 2023-11-21 · [Original öffnen](https://www.anthropic.com/news/claude-2-1)

[Alle Berichte](../../../README.de.md) · Daten: [bericht.json](bericht.json)

## Zusammenfassung (von Luna, ungeprüft)

Anthropic beschreibt Claude 2.1 mit einem 200.000-Token-Kontextfenster, verbesserten Genauigkeitswerten laut unternehmenseigenen Tests und einer neuen Werkzeugnutzung in der Beta. Außerdem stellt das Unternehmen Entwicklerfunktionen wie Workbench und System-Prompts vor; das große Kontextfenster ist Pro-Konten vorbehalten und seine Verarbeitung kann einige Minuten dauern.
