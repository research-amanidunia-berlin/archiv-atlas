## Zusammenfassung (von Luna, ungeprüft)

DeepMind beschreibt Co-Scientist als ein System spezialisierter KI-Agenten, das wissenschaftliche Hypothesen erzeugt, diskutiert, prüft und weiterentwickelt. Der Bericht nennt Laborbeispiele aus mehreren Forschungsgebieten, weist aber keine unabhängige Gesamtbewertung aus; das System soll Fachleute unterstützen und nicht ersetzen.
