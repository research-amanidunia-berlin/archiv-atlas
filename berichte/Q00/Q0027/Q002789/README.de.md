# How does V1 population activity inform perceptual certainty?

Bericht Q002789 · Quelle pmc.ncbi.nlm.nih.gov · Datum – · [Original öffnen](https://pmc.ncbi.nlm.nih.gov/articles/PMC11185272/pdf/jovi-24-6-12.pdf)

[Alle Berichte](../../../README.de.md) · Daten: [bericht.json](bericht.json)

## Zusammenfassung (von Luna, ungeprüft)

Der Bericht legt nahe, dass mehrere Merkmale der V1-Aktivität die Unsicherheit einer geschätzten Reizorientierung anzeigen können; am engsten war sie mit der Variabilität der neuronalen Antwortverstärkung verbunden. Die Ergebnisse beruhen auf modellbasierter Decodierung bei zwei Makaken und belegen weder direkt deren berichtete Sicherheit noch die Übertragbarkeit auf andere Aufgaben oder Hirnareale.
