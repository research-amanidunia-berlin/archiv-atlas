# Funding the AI Cloud — Amazon, Alphabet, and Microsoft's Cloud Computing Investments, Part 2

Bericht Q002782 · Quelle cset.georgetown.edu · Datum 2024-11-13 · [Original öffnen](https://cset.georgetown.edu/publication/funding-the-ai-cloud-amazon-alphabet-and-microsofts-cloud-computing-investments-part-2/)

[Alle Berichte](../../../README.de.md) · Daten: [bericht.json](bericht.json)

## Zusammenfassung (von Luna, ungeprüft)

Die Autoren vergleichen die öffentlichen Open-Source-Repositories von AWS, GCP und Azure und finden unterschiedliche Aktivitätsmuster: Azure bot die meisten Pakete, während AWS bei mehreren Durchschnittswerten je Repository vorn lag. Sie halten es für möglich, dass kostenlose, cloudbezogene Werkzeuge Entwickler an Anbieter binden und später Geschäft fördern; die GitHub-Daten belegen diese Wirkung oder eine entsprechende Absicht aber nicht.
