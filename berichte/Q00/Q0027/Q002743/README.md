# Covert influence operation: Ghana election activity

Report Q002743 · Source openai.com · Date 2025-02-01 · [Open original](https://openai.com/index/disrupting-malicious-uses-of-ai-ghana-election/)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

OpenAI zufolge wurden vor der ghanaischen Wahl 2024 ChatGPT-Konten gesperrt, die Beiträge zugunsten Mahamudu Bawumias und gegen John Mahama für die Website „Empowering Ghana“ und deren Social-Media-Kanäle erzeugten. OpenAI hält einen Teil der Instagram-Kommentare und Follower für künstlich aufgebläht, kann das aber nicht sicher belegen, und stuft die Wirkung insgesamt als gering ein: Die Inhalte seien nicht nachweislich von echten Menschen breit verbreitet worden.
