# Preparing for global elections in 2024

Report Q002780 · Source anthropic.com · Date 2024-02-16 · [Open original](https://www.anthropic.com/news/preparing-for-global-elections-in-2024)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Anthropic berichtet über Regeln gegen politische Kampagnen mit seinen KI-Systemen, interne Tests auf Wahlrisiken und geplante beziehungsweise eingeführte Weiterleitungen zu verlässlichen Wahlinformationen. Der Bericht nennt keine messbaren Ergebnisse zur Wirksamkeit; ein Nachtrag beschreibt eine entsprechende Weiterleitung für EU-Nutzende und eine Präzisierung der Nutzungsrichtlinie.
