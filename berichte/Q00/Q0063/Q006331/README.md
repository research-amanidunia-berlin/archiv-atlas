# Performance per dollar improves around 30% each year

Report Q006331 · Source epoch.ai · Date 2024-10-23 · [Open original](https://epoch.ai/data-insights/price-performance-hardware)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Epoch AI behauptet, dass sich das Preis-Leistungs-Verhältnis von Hardware bei gleicher Leistung und Genauigkeit jährlich um etwa 30 Prozent verbessert. Die Tabelle zeigt für vier ausgewählte NVIDIA-RechenzentrumsgPUs einen Anstieg der inflationsbereinigten FLOP/s pro Dollar von 1,3 Milliarden beim P100 auf 22 Milliarden beim H100; sie bildet jedoch keine vollständige jährliche Zeitreihe ab.
