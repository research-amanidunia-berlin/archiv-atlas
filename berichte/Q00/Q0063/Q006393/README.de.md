# New Student Visa Rule Likely to Harm National Security More Than Help

Bericht Q006393 · Quelle cset.georgetown.edu · Datum 2020-10-26 · [Original öffnen](https://cset.georgetown.edu/publication/new-student-visa-rule-likely-to-harm-national-security-more-than-help/)

## Zusammenfassung (von Luna, ungeprüft)

Der vorliegende Auszug fasst die Einwände von zwei CSET-Autoren gegen eine geplante DHS-Regel zu Aufenthaltsfristen für internationale Studierende und andere Gruppen zusammen. Sie behaupten, die Regel könne Talente abschrecken und der US-Sicherheit wahrscheinlich mehr schaden als nützen; konkrete Belege oder die Antwort des DHS enthält der Auszug nicht.
