# The computational performance of machine learning hardware has doubled every 2.3 years

Report Q006321 · Source epoch.ai · Date 2024-10-23 · [Open original](https://epoch.ai/data-insights/peak-performance-hardware-on-different-precisions)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Epoch AI behauptet, dass sich die FP16-Spitzenleistung von ML-Hardware im Schnitt alle 2,3 Jahre verdoppelt; für FP32 gelte ein ähnlicher Trend. Der Bericht führt dies auf Fertigungsfortschritte und KI-spezialisierte Hardware zurück und enthält Leistungsdaten verschiedener Formate, erläutert aber weder die Berechnung des Trends noch die Vergleichbarkeit der Werte.
