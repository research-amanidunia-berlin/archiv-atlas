# AI developers accurately report GPQA Diamond scores for recent models

Report Q006346 · Source epoch.ai · Date 2025-09-19 · [Open original](https://epoch.ai/data-insights/self-reported-gpqa)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Epoch AI berichtet, dass die GPQA-Diamond-Angaben der untersuchten KI-Entwickler mit unabhängigen Messungen übereinstimmen: Alle aufgeführten Werte liegen innerhalb der 90-Prozent-Konfidenzintervalle. Die Aussage gilt für die dargestellten Modelle und diesen Benchmark; der Mistral-Eintrag ist in seiner Quellenanmerkung uneindeutig.
