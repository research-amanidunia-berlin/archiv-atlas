# Measures for Cybersecurity Reviews

Bericht Q006320 · Quelle cset.georgetown.edu · Datum 2021-02-03 · [Original öffnen](https://cset.georgetown.edu/publication/measures-for-cybersecurity-reviews/)

[Alle Berichte](../../../README.de.md) · Daten: [bericht.json](bericht.json)

## Zusammenfassung (von Luna, ungeprüft)

Der Bericht ist ein Auszug: Laut Einleitung verpflichtet eine 2020 erlassene chinesische Regelung bestimmte Betreiber kritischer Informationsinfrastruktur zu einer CAC-Prüfung vor dem Start sicherheitsrelevanter Produkte oder Dienste. Der sichtbare Regelungstext beginnt mit der gemeinsamen Bekanntmachung durch die CAC und weitere Behörden; konkrete Prüfregeln sind im Auszug nicht enthalten.
