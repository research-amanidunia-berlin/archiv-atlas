# Notice on the Publication of Management Methods for the Demonstration Project for Building World-Class Cybersecurity Colleges

Bericht Q006324 · Quelle cset.georgetown.edu · Datum 2021-02-03 · [Original öffnen](https://cset.georgetown.edu/publication/notice-on-the-publication-of-management-methods-for-the-demonstration-project-for-building-world-class-cybersecurity-colleges/)

[Alle Berichte](../../../README.de.md) · Daten: [bericht.json](bericht.json)

## Zusammenfassung (von Luna, ungeprüft)

Der vorliegende Auszug aus einer chinesischen Regelung von 2017 beschreibt ein Demonstrationsprojekt für weltklasse Cybersecurity-Hochschulen von 2017 bis 2027. Laut redaktioneller Einleitung sollen unter anderem eine Zulassung ohne die übliche Master-Aufnahmeprüfung und staatliche sowie private Finanzierung den Ausbau beschleunigen; der enthaltene Artikel 1 legt Ziele und Begründung dar, aber keine Umsetzungsergebnisse.
