## Summary (German, by Luna, unchecked)

Der vorliegende Auszug aus einer chinesischen Regelung von 2017 beschreibt ein Demonstrationsprojekt für weltklasse Cybersecurity-Hochschulen von 2017 bis 2027. Laut redaktioneller Einleitung sollen unter anderem eine Zulassung ohne die übliche Master-Aufnahmeprüfung und staatliche sowie private Finanzierung den Ausbau beschleunigen; der enthaltene Artikel 1 legt Ziele und Begründung dar, aber keine Umsetzungsergebnisse.
