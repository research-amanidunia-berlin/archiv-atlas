# The length of time spent training notable models is growing

Report Q006374 · Source epoch.ai · Date 2024-08-16 · [Open original](https://epoch.ai/data-insights/training-length-trend)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Epoch AI zufolge ist die Trainingsdauer bemerkenswerter Modelle seit 2010 im Schnitt jährlich um den Faktor 1,2 gewachsen; Fine-Tuning-Modelle sind ausgeschlossen. Eine Fortsetzung könnte Hardware entlasten, doch bei sehr langen Läufen kann das Warten auf bessere Algorithmen oder Chips günstiger sein. Die Methodik bleibt im Auszug offen, und die Tabelle enthält Einträge bis 2025 trotz eines Änderungsdatums von 2024.
