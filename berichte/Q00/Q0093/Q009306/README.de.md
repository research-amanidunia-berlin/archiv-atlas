# Usage policies

## Zusammenfassung (von Luna, ungeprüft)

OpenAIs Richtlinien untersagen zahlreiche Nutzungen, die Menschen gefährden, Privatsphäre verletzen, Minderjährige schädigen oder manipulieren könnten; für folgenreiche Entscheidungen verlangen sie menschliche Prüfung. Sie begrenzen außerdem das Training konkurrierender Modelle mit OpenAI-Ausgaben und sehen begrenzte, fallweise Genehmigungen sowie laufende Aktualisierungen vor.
