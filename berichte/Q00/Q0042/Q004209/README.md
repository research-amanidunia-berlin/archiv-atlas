# Using AI to predict retinal disease progression

Report Q004209 · Source deepmind.google · Date 2020-05-18 · [Open original](https://deepmind.google/blog/using-ai-to-predict-retinal-disease-progression/)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Der Bericht beschreibt eine KI, die anhand von Netzhaut-OCT-Aufnahmen das Fortschreiten trockener AMD zur exsudativen AMD innerhalb von sechs Monaten vorhersagen soll. Laut Autoren schnitt sie im Vergleich mit sechs Fachleuten ähnlich gut oder teilweise besser ab, ist aber noch nicht für den klinischen Alltag einsatzbereit und muss unter anderem auf andere Bevölkerungsgruppen sowie auf mögliche Folgen falsch positiver Warnungen geprüft werden.
