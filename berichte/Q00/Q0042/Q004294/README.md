# Boosting Innovation while Regulating AI: Overview of 2023 Activities and 2024 Outlook

Report Q004294 · Source oecd.ai · Date 2025-05-12 · [Open original](https://oecd.ai/en/wonk/documents/boosting-innovation-while-regulating-ai-overview-of-2023-activities-and-2024-outlook)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Der Bericht schildert, wie eine GPAI-Arbeitsgruppe ihre Pläne zur Untersuchung der Auswirkungen von KI-Regulierung auf Innovation wegen dynamischer Regeln und praktischer Herausforderungen für 2024 neu ausrichtete. Sie will Messansätze und Beispiele sammeln, aber weder Standards setzen noch eine „beste“ Regulierung empfehlen; konkrete Ergebnisse werden im Text nicht genannt.
