# Towards understanding glasses with graph neural networks

Bericht Q004236 · Quelle deepmind.google · Datum 2020-04-06 · [Original öffnen](https://deepmind.google/blog/towards-understanding-glasses-with-graph-neural-networks/)

[Alle Berichte](../../../README.de.md) · Daten: [bericht.json](bericht.json)

## Zusammenfassung (von Luna, ungeprüft)

Die Studie berichtet, dass ein Graph-Neuronales Netz die Teilchenbeweglichkeit in Glassimulationen besser vorhersagte als die verglichenen Modelle und auch langfristig brauchbare Ergebnisse lieferte. Seine Reaktion auf Veränderungen entfernter Teilchenschalen deutet laut Autoren auf wachsende räumliche Korrelationen nahe dem Glasübergang hin, ist aber keine direkt messbare Korrelationslänge und klärt den Übergang nicht abschließend.
