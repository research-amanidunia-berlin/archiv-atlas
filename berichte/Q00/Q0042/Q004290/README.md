# Hello GPT-4o

Report Q004290 · Source openai.com · Date 2024-05-13 · [Open original](https://openai.com/index/hello-gpt-4o/)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

OpenAI kündigte GPT‑4o 2024 als multimodales Modell an und behauptete Verbesserungen bei Reaktionszeit, Mehrsprachigkeit, Audio und Bildverständnis; die Leistungs- und Preisvergleiche stammen aus dem Bericht selbst. Die damalige Einführung sollte schrittweise erfolgen, und OpenAIs Risikobewertung stufte das Modell insgesamt als mittleres Risiko ein.
