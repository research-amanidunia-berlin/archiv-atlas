# A milestone in expanding access to AI

Report Q004272 · Source openai.com · Date 2026-08-31 · [Open original](https://openai.com/index/expanding-access-to-ai-with-chatgpt-ads/)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

OpenAI berichtet von einer annualisierten Umsatzrate von einer Milliarde US-Dollar für ChatGPT Ads und erweitert den Self-Service-Zugang auf weitere Regionen. Anzeigen sollen Gesprächskontext nutzen und laut Unternehmen gekennzeichnet, von Antworten getrennt und für Werbetreibende ohne Zugang zu privaten Gesprächen sein; konkrete Vertrauensmesswerte werden nicht genannt. Genannte Werbeergebnisse stammen aus einzelnen Beispielen, während weitere Märkte und Funktionen geplant sind.
