# Can AI learn from experience? EBR-Bench results

Bericht Q004263 · Quelle epoch.ai · Datum 2026-07-01 · [Original öffnen](https://epoch.ai/publications/earthborne-rangers-benchmark)

[Alle Berichte](../../../README.de.md) · Daten: [bericht.json](bericht.json)

## Zusammenfassung (von Luna, ungeprüft)

Epoch AI berichtet, dass KI-Modelle beim wiederholten Spielen von *Earthborne Rangers* kaum durch Erfahrung besser wurden. Sie machten taktische Fehler, erkundeten wenige Deckvarianten und blieben deutlich hinter der Expertenreferenz; die Ergebnisse gelten allerdings nur für den fünf Tage langen Spieleinstieg und beruhen auf einer vorläufigen menschlichen Vergleichsbasis.
