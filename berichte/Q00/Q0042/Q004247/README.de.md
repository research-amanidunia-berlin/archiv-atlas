# Using WaveNet technology to reunite speech-impaired users with their original voices

Bericht Q004247 · Quelle deepmind.google · Datum 2019-12-18 · [Original öffnen](https://deepmind.google/blog/using-wavenet-technology-to-reunite-speech-impaired-users-with-their-original-voices/)

[Alle Berichte](../../../README.de.md) · Daten: [bericht.json](bericht.json)

## Zusammenfassung (von Luna, ungeprüft)

DeepMind und Google rekonstruierten aus rund 30 Minuten alter Aufnahmen eine synthetische Version der Stimme von Tim Shaw, der wegen ALS kaum noch sprechen konnte. Die Stimme war laut Bericht noch nicht so ausdrucksvoll oder steuerbar wie eine echte; eine breitere Anwendung blieb ein Forschungsziel.
