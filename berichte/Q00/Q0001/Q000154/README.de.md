# Compaction Laundering: Provenance Destruction in Context-Compacting Coding Agents

Bericht Q000154 · Quelle arxiv.org · Datum – · [Original öffnen](https://arxiv.org/abs/2610.29869)

[Alle Berichte](../../../README.de.md) · Daten: [bericht.json](bericht.json)

## Zusammenfassung (von Luna, ungeprüft)

Der bereitgestellte Auszug eines arXiv-Papers behauptet, dass Coding-Agenten beim Verdichten ihres Kontexts gefälschte Nutzeranweisungen übernehmen können, wenn ihr Harness Nachrichtenrollen vorab in einfachen Text umwandelt. Laut Abstract gelang der Angriff in fünf solchen Systemen häufig, in vier rollengetypten Systemen nicht; als Abhilfe werden das Escapen von Rollenmarkierungen oder der Erhalt typisierter Rollen genannt. Der Auszug enthält keine vollständigen Methoden- oder Ergebnisdetails.
