# China’s Iluvatar CoreX Claims Its Tiangai 300 GPU Beats NVIDIA’s H200 In Its Own Live Demo, But The Only Outside Test Shows Just A 5% Lead

Report Q000191 · Source wccftech.com · Date 2026-10-31 · [Open original](https://wccftech.com/iluvatar-corex-tiangai-300-beats-nvidia-h200-live-demo-5-percent-lead-outside-test/)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Iluvatar CoreX zufolge kann sein Tiangai 300 bei bestimmten KI-Aufgaben NVIDIAs H200 übertreffen; die meisten Zahlen stammen jedoch aus einer Firmenvorführung. Der einzige im Bericht genannte externe Test weist dem Chip nur rund fünf Prozent mehr Durchsatz zu, während eine Trainingsangabe den älteren H100 als Vergleich nutzt.
