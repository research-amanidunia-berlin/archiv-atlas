# An updated Model Spec for more capable and beneficial AI

Report Q000196 · Source openai.com · Date 2026-10-29 · [Open original](https://openai.com/index/updated-model-spec/)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

OpenAI ordnet sein Model Spec neu um fünf Werte, darunter die Orientierung an menschlichen Absichten, Schadensminimierung, Transparenz, Handlungsfähigkeit und Fürsorge. Die Überarbeitung ergänzt Kontext- und Verhaltensregeln und reduziert detaillierte Stilvorgaben. OpenAI betont, dass die Werte nicht alle menschlichen Werte abdecken und die Modelle das angestrebte Verhalten noch nicht vollständig zeigen.
