## Summary (German, by Luna, unchecked)

Taiwan plant laut Wirtschaftsminister Kung Ming-hsin, fortgeschrittene KI-Chips und Server ausdrücklich zu kontrollieren und die Exportregeln an US-Beschränkungen anzunähern. Das soll Lücken schließen, die laut Bericht die Verfolgung mutmaßlich unerlaubter Lieferungen erschwerten. Ein Starttermin und genaue Umsetzungsdetails werden nicht genannt; die beschriebenen Schmuggelvorgänge sind Vorwürfe beziehungsweise Angaben von Behörden.
