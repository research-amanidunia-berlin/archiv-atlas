# Institute for Progress calls for remote-access restrictions, antitrust exemption to hold off China’s frontier AI advances

Report Q000101 · Source insideaipolicy.com · Date 2026-10-28 · [Open original](https://insideaipolicy.com/ai-daily-news/institute-progress-calls-remote-access-restrictions-antitrust-exemption-hold-china-s)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Der vorliegende Auszug berichtet, das Institute for Progress behaupte, die USA könnten ihren KI-Vorsprung gegenüber China durch Fernzugriffsbeschränkungen, eine kartellrechtliche Ausnahme und strengere Chip-Exportkontrollen verdoppeln. Der Auszug bricht bei einer Aussage zum Modellabstand ab; nähere Belege und Einschränkungen sind daher nicht enthalten.
