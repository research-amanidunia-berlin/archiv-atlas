# Treasury Issues Proposed Rule to Implement Comprehensive Outbound Investment National Security Act

Report Q000139 · Source home.treasury.gov · Date 2026-06-23 · [Open original](https://home.treasury.gov/news/press-releases/sb0667/)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Das US-Finanzministerium schlägt vor, Regeln für bestimmte Auslandsinvestitionen von US-Personen auszuweiten: Einige Geschäfte sollen meldepflichtig, andere in festgelegten Technologiebereichen verboten sein. Der Entwurf ergänzt die gesetzlich genannten Bereiche um Biotechnologie und ist noch offen für Stellungnahmen; endgültige Regeln und ein Inkrafttretensdatum stehen laut Bericht noch aus.
