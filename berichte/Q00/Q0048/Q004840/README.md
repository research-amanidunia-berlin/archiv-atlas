# Maryland partners with Anthropic to serve residents

Report Q004840 · Source anthropic.com · Date 2025-11-13 · [Open original](https://www.anthropic.com/news/maryland-partnership)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Anthropic zufolge plant Maryland, Claude für Sozialleistungsinformationen, die Prüfung von Leistungsanträgen und weitere Verwaltungsaufgaben einzusetzen; zusätzliche Vorhaben sollen Beschäftigte qualifizieren und lokale Versorgungslücken sichtbar machen. Als bestehendes Beispiel nennt das Unternehmen einen zweisprachigen SUN-Bucks-Chatbot, doch der Bericht liefert keine Zeitpläne oder unabhängigen Nachweise zur Wirkung der neuen Partnerschaft.
