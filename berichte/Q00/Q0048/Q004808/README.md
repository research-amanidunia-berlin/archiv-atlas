# An AI policy tool for today: Invest in NIST

Report Q004808 · Source anthropic.com · Date 2023-04-20 · [Open original](https://www.anthropic.com/news/an-ai-policy-tool-for-today-ambitiously-invest-in-nist)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Anthropic fordert für NIST im US-Haushaltsjahr 2024 eine Erhöhung der Mittel um 15 Millionen US-Dollar gegenüber 2023, um KI-Fähigkeiten und -Risiken besser messen und Standards entwickeln zu können. Das Unternehmen sieht unabhängige Tests als wichtigen, aber nicht ausreichenden Baustein einer umfassenderen KI-Governance; konkrete Wirkungen der vorgeschlagenen Finanzierung werden nicht berichtet.
