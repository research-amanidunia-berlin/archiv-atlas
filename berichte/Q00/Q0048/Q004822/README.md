# From assistance to execution: How enterprises put AI to work

Report Q004822 · Source openai.com · Date 2026-08-12 · [Open original](https://openai.com/index/how-enterprises-put-ai-to-work/)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Der Bericht behauptet, dass Unternehmen KI zunehmend für mehrstufige Aufgaben einsetzen und dass besonders intensive Nutzergruppen agentische Funktionen wie Codex, Plugins und Skills häufiger verwenden. Er empfiehlt passende Datenzugriffe, klare Governance und menschliche Prüfung; Token- und Nachrichtenzahlen zeigen Nutzung, belegen aber für sich genommen weder Qualität noch Geschäftswirkung.
