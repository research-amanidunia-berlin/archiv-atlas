# Australia and Anthropic sign AI safety MOU

Report Q004830 · Source anthropic.com · Date 2026-03-31 · [Open original](https://www.anthropic.com/news/australia-MOU)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Anthropic kündigt ein MOU mit Australien zur KI-Sicherheitsforschung sowie Forschungsförderung von 3 Millionen australischen Dollar für vier Einrichtungen an. Die Mitteilung nennt weitere Pläne für Wirtschaftsanalysen, Infrastruktur und Start-up-Förderung, berichtet aber keine unabhängigen Bewertungen oder bereits erzielten Forschungsergebnisse.
