# Chris Olah's remarks on Pope Leo XIV's encyclical

Report Q004837 · Source anthropic.com · Date 2026-05-25 · [Open original](https://www.anthropic.com/news/chris-olah-pope-leo-encyclical)

## Summary (German, by Luna, unchecked)

Chris Olah fordert in seiner Rede zur KI-Enzyklika von Papst Leo XIV. unabhängige Kritik und gesellschaftliche Mitwirkung, weil KI-Labore eigenen wirtschaftlichen und geopolitischen Anreizen unterliegen. Er hebt mögliche Arbeitsplatzverluste, die globale Verteilung der KI-Gewinne, menschliches Wohlergehen und die schwer durchschaubare Natur der Modelle als zentrale Fragen hervor. Von seinem Team berichtete Hinweise auf gefühlsähnliche interne Zustände ordnet er ausdrücklich als rätselhaft und deutungsbedürftig ein.
