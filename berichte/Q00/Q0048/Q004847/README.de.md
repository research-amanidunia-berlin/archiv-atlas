# Latency scaling differences for GPT and Claude models

Bericht Q004847 · Quelle epoch.ai · Datum 2026-09-08 · [Original öffnen](https://epoch.ai/publications/long-context-latency-scaling-gpt-vs-claude)

[Alle Berichte](../../../README.de.md) · Daten: [bericht.json](bericht.json)

## Zusammenfassung (von Luna, ungeprüft)

Bei Messungen bis ungefähr einer Million Tokens stieg die TTFT der getesteten GPT-5.6-Modelle zunehmend stark, während Claude Sonnet 5 und, trotz größerer Messstreuung, Opus 5 nahezu linear skalierten. Der Autor sieht darin einen Hinweis auf unterschiedliche Ansätze bei langen Kontexten, doch die Messungen belegen keine konkrete Architektur; Hochrechnungen bis zehn Millionen Tokens sind ausdrücklich keine Prognosen.
