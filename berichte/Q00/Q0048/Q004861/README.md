# Anthropic and Amazon expand compute collaboration

Report Q004861 · Source anthropic.com · Date 2026-04-20 · [Open original](https://www.anthropic.com/news/anthropic-amazon-compute)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Anthropic zufolge soll eine neue Vereinbarung mit Amazon bis zu fünf Gigawatt Rechenkapazität für Claude sichern; sie umfasst langfristige AWS-Ausgaben, eine geplante Claude-Plattform in AWS und weitere Amazon-Investitionen. Das Unternehmen begründet den Ausbau mit starkem Wachstum und zeitweisen Leistungsproblemen, doch die genannten Kennzahlen und zukünftigen Kapazitäten werden in der Mitteilung nicht unabhängig belegt.
