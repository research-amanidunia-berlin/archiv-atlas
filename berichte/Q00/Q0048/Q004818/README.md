# Charting a path to AI accountability

Report Q004818 · Source anthropic.com · Date 2023-06-13 · [Open original](https://www.anthropic.com/news/charting-a-path-to-ai-accountability)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Anthropic empfiehlt ein gestuftes System zur KI-Rechenschaft: mehr geförderte und standardisierte Evaluationen, risikobasierte Prüfungen, vertrauliche Vorabmeldungen großer Trainingsläufe und unabhängige externe Tests vor der Freigabe fortgeschrittener Modelle. Das Unternehmen betont zugleich, dass dafür Prüfkapazitäten und Forschung erst ausgebaut werden müssen und eine Pflicht zu interpretierbaren Modellen derzeit nicht praktikabel sei.
