## Summary (German, by Luna, unchecked)

Nimble-v4-max v4.1 ist laut Hugging-Face-Seite ein Entscheidungsmodell von Bespoke Labs und erreicht im angegebenen öffentlichen Decision Index 0.3 einen höheren Wert als v4.0. Die Benchmark-Verbesserungen variieren; zur Nutzung werden spezieller Inferenzcode und eine GPU mit mindestens 80 GB genannt, und die Lizenz schließt kommerzielle Verwendung aus.
