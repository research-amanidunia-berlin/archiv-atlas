# Machine learning model sizes and the parameter gap

Report Q004872 · Source epoch.ai · Date 2022-07-05 · [Open original](https://epoch.ai/publications/machine-learning-model-sizes-and-the-parameter-gap)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Epoch AI analysiert 237 Meilensteinsysteme und berichtet, dass Modellgrößen seit 2018, besonders bei Sprachmodellen, deutlich schneller zugenommen haben. Zugleich gab es ab 2020 auffällig wenige Modelle zwischen 20 und 70 Milliarden Parametern; mögliche Kosten- und Wettbewerbsursachen dafür bleiben Hypothesen.
