# How AI is expanding what people do at work

Report Q004896 · Source openai.com · Date 2026-07-27 · [Open original](https://openai.com/index/how-ai-is-expanding-what-people-do-at-work/)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Eine Analyse von mehr als 800.000 arbeitsbezogenen ChatGPT-Nachrichten aus den USA legt laut OpenAI nahe, dass Nutzer häufig Aufgaben aus anderen Berufen übernehmen: 43,5 Prozent der spezifischen, nicht allgemein verbreiteten Aufgaben fallen außerhalb des eigenen Berufs. Besonders weit verbreitet sind unter anderem technische und finanzielle Tätigkeiten sowie Marketingaufgaben. Die Daten zeigen Nutzungsmuster als möglichen frühen Hinweis auf veränderte Arbeitsteilung, belegen aber nicht deren tatsächliche Folgen für Arbeitsplätze.
