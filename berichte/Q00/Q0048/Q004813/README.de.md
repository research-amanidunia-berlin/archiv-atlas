# Anthropic raises $450 million in Series C

Bericht Q004813 · Quelle anthropic.com · Datum 2023-05-23 · [Original öffnen](https://www.anthropic.com/news/anthropic-series-c)

[Alle Berichte](../../../README.de.md) · Daten: [bericht.json](bericht.json)

## Zusammenfassung (von Luna, ungeprüft)

Anthropic berichtet von einer Series-C-Finanzierung über 450 Millionen US-Dollar, angeführt von Spark Capital, und will damit Claude, Produktentwicklung, Sicherheitsforschung und das Team ausbauen. Die Mitteilung nennt technische Ziele und eine Weiterentwicklung der Governance, liefert dazu jedoch überwiegend Unternehmensangaben und keine unabhängige Prüfung der Wirkungen.
