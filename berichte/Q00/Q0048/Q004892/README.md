# AlphaFold Reveals a Key Protein Behind Heart Disease

Report Q004892 · Source deepmind.google · Date 2025-11-25 · [Open original](https://deepmind.google/blog/revealing-a-key-protein-behind-heart-disease/)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Forschende der University of Missouri kombinierten AlphaFold-Vorhersagen mit Kryo-EM-Daten, um ein detailliertes Strukturmodell von ApoB100 zu erstellen, dem Gerüstprotein des LDL. Die Struktur könnte künftig gezieltere Ansätze gegen hohe Cholesterinwerte und Herz-Kreislauf-Erkrankungen ermöglichen, doch der Bericht beschreibt diese Anwendungen als Zukunftspotenzial, das noch Zeit braucht.
