## Summary (German, by Luna, unchecked)

DeepMind beschreibt eigene KI-Projekte für Wettervorhersage, Biodiversitätsbeobachtung, effizientere Infrastruktur, Windenergie und die Steuerung von Fusionsplasma. Der Bericht schildert Fortschritte und laufende Erprobungen aus Unternehmenssicht, nennt aber keine konkreten Emissionsminderungen oder unabhängige Bewertung.
