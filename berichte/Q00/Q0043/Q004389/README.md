# Using JAX to accelerate our research

Report Q004389 · Source deepmind.google · Date 2020-12-04 · [Open original](https://deepmind.google/blog/using-jax-to-accelerate-our-research/)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Der Bericht beschreibt JAX als flexible Python-Bibliothek, die laut den Autoren von DeepMind Experimente im maschinellen Lernen beschleunigt und durch automatische Differenzierung, Vektorisierung sowie JIT-Kompilierung skaliert. Vorgestellt werden fünf ergänzende Bibliotheken für neuronale Netze, Optimierung, Reinforcement Learning, Tests und Graph-Netze. Die Aussagen beruhen auf den Erfahrungen der Autoren; quantitative Vergleiche fehlen, und RLax ist kein vollständiges Agenten-Framework.
