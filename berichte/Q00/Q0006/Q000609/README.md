# Claude now watermarks text from older models, with no opt-out

Report Q000609 · Source notebookcheck.net · Date 2026-11-07 · [Open original](https://www.notebookcheck.net/Claude-now-watermarks-text-from-older-models-with-no-opt-out.1444769.0.html)

## Summary (German, by Luna, unchecked)

Anthropic weitet laut Bericht unsichtbare Wasserzeichen auf weitere Claude-Modelle und Produkte aus; Kunden können sie nicht deaktivieren. Die Markierung kann bei kurzen, übersetzten oder stark bearbeiteten Texten fehlen, und veränderte API-Parameter könnten ihre Erkennung laut The Decoder beeinträchtigen. Ein erkannter Wasserzeichenfund beweise laut Anthropic nicht, wer den Text verfasst hat.
