# Cloud and AI Development Act

Report Q000676 · Source digital-strategy.ec.europa.eu · Date – · [Open original](https://digital-strategy.ec.europa.eu/en/policies/cloud-and-ai-development-act)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Der Bericht beschreibt den CADA als EU-Vorhaben, das Forschung und Innovation, den Ausbau von Rechenkapazität sowie die digitale Autonomie Europas stärken soll. Dazu gehören das Ziel, die Rechenzentrumskapazität binnen fünf bis sieben Jahren mindestens zu verdreifachen, und ein vierstufiger Rahmen zur Bewertung von Cloud- und KI-Souveränität. Der Text erläutert geplante Maßnahmen, nennt aber keine Ergebnisse ihrer Umsetzung.
