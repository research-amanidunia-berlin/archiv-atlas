# Changing how we measure AI chip inference performance

Report Q000666 · Source epoch.ai · Date 2026-11-09 · [Open original](https://epoch.ai/publications/inference-performance-index)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Der Bericht beschreibt den IPI als Vergleichsmaß für die modellierte Inferenzkapazität von KI-Chips, das neben Rechenleistung auch Speicher, Chip-Verbindungen und den Zielkonflikt zwischen Parallelität und Ausgabegeschwindigkeit berücksichtigt. Die Schätzungen beruhen auf vier agentischen Modellarbeitslasten und Hardwareprojektionen; Software-Reife, Modellwahl und weitere Annahmen begrenzen ihre Aussagekraft.
