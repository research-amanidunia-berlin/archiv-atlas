# Anthropic's text watermark is easy to bypass on several older Claude models

Bericht Q000604 · Quelle the-decoder.com · Datum 2026-11-04 · [Original öffnen](https://the-decoder.com/anthropics-text-watermark-is-easy-to-bypass-on-several-older-claude-models/)

[Alle Berichte](../../../README.de.md) · Daten: [bericht.json](bericht.json)

## Zusammenfassung (von Luna, ungeprüft)

Anthropic führt laut Bericht Textmarkierungen in mehreren älteren Claude-Modellen ein und begründet die Nachrüstung mit der EU-AI-Act-Frist. Bei Opus 4.6 und Sonnet 4.6 lässt sich die Markierung demnach durch Änderung eines Sampling-Parameters umgehen; ob sie die Textqualität unverändert lässt, ist umstritten.
