# Disrupting deceptive uses of AI by covert influence operations

Report Q000679 · Source openai.com · Date 2024-05-30 · [Open original](https://openai.com/index/disrupting-deceptive-uses-of-ai-by-covert-influence-operations)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

OpenAI zufolge störte das Unternehmen fünf verdeckte Einflussoperationen, die seine Modelle für Inhalte, Übersetzungen, Recherche oder Codeaufgaben nutzten. Keine habe dadurch merklich an Reichweite oder echtem Engagement gewonnen; Sicherheitsfilter und KI-gestützte Ermittlungswerkzeuge hätten laut OpenAI zur Abwehr beigetragen. Die Wirkungseinschätzung bezieht sich auf die untersuchten Fälle, und OpenAI weist auf die Schwierigkeit hin, die Verbreitung über Plattformen hinweg vollständig nachzuverfolgen.
