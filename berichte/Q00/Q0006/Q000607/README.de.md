# xAI Watermarks Grok by Default, 23 Days Before EU Deadline

Bericht Q000607 · Quelle santageai.com · Datum 2026-11-09 · [Original öffnen](https://santageai.com/news/2026/11/09/ai-text-watermark-defaults-eu-deadline)

[Alle Berichte](../../../README.de.md) · Daten: [bericht.json](bericht.json)

## Zusammenfassung (von Luna, ungeprüft)

Der Bericht stellt die unterschiedlichen Wasserzeichen-Standards von xAI, Anthropic und OpenAI vor: xAI markiere Grok-API-Ausgaben weltweit standardmäßig mit einem bestätigungspflichtigen Opt-out, Anthropic markiere Claude weltweit ohne Opt-out, und OpenAI beschränke die Kennzeichnung auf EU-Ausgaben seiner Apps; die API bleibe standardmäßig unmarkiert. Laut Artikel ist die Erkennung nur begrenzt zugänglich, sodass Wasserzeichen zwar angewendet, aber nicht allgemein geprüft werden können; zudem belegten sie nicht zwingend die Urheberschaft.
