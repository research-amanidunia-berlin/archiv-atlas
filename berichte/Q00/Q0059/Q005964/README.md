# Training compute has scaled up faster for language than vision

Report Q005964 · Source epoch.ai · Date 2024-06-19 · [Open original](https://epoch.ai/data-insights/compute-trend-language-vs-vision)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Epoch AI zufolge lagen der Trainingsrechenaufwand großer Sprach- und Bildmodelle vor 2020 ähnlich, während Sprachmodelle danach schneller skalierten; der Bericht führt dies auf den Erfolg von Transformer-Architekturen zurück. Die aufgeführte Modelldatenbank reicht bis 2025, doch Methode und Unsicherheit der Werte werden nicht ausführlich erläutert, und das Metadatum zum Änderungsdatum widerspricht diesem Datenumfang.
