## Summary (German, by Luna, unchecked)

Der bereitgestellte Auszug stellt SEAHORSE vor: einen Datensatz mit 96.000 menschlich bewerteten Zusammenfassungen aus sechs Sprachen, die anhand von sechs Qualitätsdimensionen beurteilt werden. Laut Abstract erzielen damit trainierte Metriken starke Ergebnisse auf TRUE und mFACE; Details zur Methode und zu konkreten Leistungswerten fehlen im Auszug.
