# SEAHORSE: A Multilingual, Multifaceted Dataset for Summarization Evaluation

Bericht Q005944 · Quelle deepmind.google · Datum 2023-12-06 · [Original öffnen](https://deepmind.google/research/publications/82492/)

[Alle Berichte](../../../README.de.md) · Daten: [bericht.json](bericht.json)

## Zusammenfassung (von Luna, ungeprüft)

Der bereitgestellte Auszug stellt SEAHORSE vor: einen Datensatz mit 96.000 menschlich bewerteten Zusammenfassungen aus sechs Sprachen, die anhand von sechs Qualitätsdimensionen beurteilt werden. Laut Abstract erzielen damit trainierte Metriken starke Ergebnisse auf TRUE und mFACE; Details zur Methode und zu konkreten Leistungswerten fehlen im Auszug.

## Sammelfragen

Je Zelle: Anteil Stufe 4–7 / Stufe 3–7 (4 = enthält zitierbare Belege … 7 = beantwortet direkt; 3 = nützlicher Hintergrund).
