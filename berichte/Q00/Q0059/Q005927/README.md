# “Startup” Companies in PARAT

Report Q005927 · Source cset.georgetown.edu · Date 2022-05-11 · [Open original](https://cset.georgetown.edu/publication/startup-companies-in-parat/)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Von 55 in PARAT als „Startup“ eingestuften Unternehmen weisen laut CSET 26 mindestens eine erfasste KI-Veröffentlichung oder ein KI-Patent auf; die Kategorien überschneiden sich, sechs Unternehmen haben beides. Die meisten dieser Unternehmen sitzen in den USA, und die Beispiele reichen von Bildverarbeitung und Deep Learning bis zu Bildungstechnologie; die Ergebnisse hängen von den beschriebenen Zuordnungs- und Klassifikationsverfahren ab.
