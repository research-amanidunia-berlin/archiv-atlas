# Previewing PARAT 2.0

Bericht Q005952 · Quelle cset.georgetown.edu · Datum 2022-06-22 · [Original öffnen](https://cset.georgetown.edu/publication/previewing-parat-2-0/)

[Alle Berichte](../../../README.de.md) · Daten: [bericht.json](bericht.json)

## Zusammenfassung (von Luna, ungeprüft)

CSET kündigt für PARAT 2.0 eine Aufschlüsselung von KI-Publikationen und Patenten nach Teilgebieten, Zitationskennzahlen sowie Daten zu KI-bezogenen Arbeitsplätzen an. Der Beitrag beschreibt geplante Funktionen, nennt aber weder Datenumfang und Messmethoden noch konkrete Ergebnisse oder einen Veröffentlichungstermin.
