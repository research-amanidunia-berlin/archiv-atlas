# Frontier AI capabilities can be run at home within a year or less

Bericht Q005997 · Quelle epoch.ai · Datum 2025-08-15 · [Original öffnen](https://epoch.ai/data-insights/consumer-gpu-model-gap)

[Alle Berichte](../../../README.de.md) · Daten: [bericht.json](bericht.json)

## Zusammenfassung (von Luna, ungeprüft)

Epoch AI schätzt anhand mehrerer Benchmarks, dass offene Modelle für eine einzelne Verbraucher-GPU führenden Frontier-Modellen im Durchschnitt sechs bis zwölf Monate hinterherliegen; eine RTX 5090 unter 2.500 US-Dollar könne daher Modelle auf dem Leistungsstand des Frontier-Jahres zuvor lokal ausführen. Der Bericht nennt Modellskalierung, Destillation und GPU-Fortschritte als Faktoren, warnt aber, dass Benchmarkoptimierung besonders kleiner Modelle den Rückstand in der Praxis größer erscheinen lassen kann.
