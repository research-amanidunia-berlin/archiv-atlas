## Summary (German, by Luna, unchecked)

OpenAI kündigt für die Codex-Desktop-App Computerbedienung, einen integrierten Browser, Bildgenerierung, zusätzliche Plugins und erweiterte Entwicklerwerkzeuge an. Automatisierungen, Erinnerungen in Vorschau und kontextbezogene Vorschläge sollen länger laufende Arbeit unterstützen; einige Funktionen starten eingeschränkt, etwa SSH in Alpha und Computerbedienung zunächst auf macOS.
