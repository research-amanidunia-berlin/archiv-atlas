# GitHub Data: Capturing Open Source Software and Implementation

Bericht Q005979 · Quelle cset.georgetown.edu · Datum 2022-09-28 · [Original öffnen](https://cset.georgetown.edu/publication/github-data-capturing-open-source-software-and-implementation/)

[Alle Berichte](../../../README.de.md) · Daten: [bericht.json](bericht.json)

## Zusammenfassung (von Luna, ungeprüft)

CSET beschreibt einen monatlich aktualisierten Datensatz mit 291.264 öffentlichen GitHub-Repositorys, ausgewählt anhand von Literaturverweisen oder KI-relevanten Tags. Die wachsende Zahl KI-/ML-markierter Projekte bei sinkenden durchschnittlichen Forks und Commits deutet laut Bericht auf eine Verteilung der Entwicklung auf mehr Repositorys hin; wegen der Auswahlkriterien und des Ausschlusses privater Projekte ist die Abdeckung begrenzt.
