# Swim till you sink: Computing the limit of a game

[Alle Berichte](../../../README.de.md) · Daten: [bericht.json](bericht.json)

## Zusammenfassung (von Luna, ungeprüft)

Der bereitgestellte Bericht ist nur ein Abstract-Auszug: Er beschreibt die Berechnung der langfristigen Verteilung der Noisy-Replicator-Dynamik über Sink-Gleichgewichte. Für Anfangsverteilungen über reine Strategien wird nahezu lineare Laufzeit zur Größe des Best-Response-Graphen behauptet; Experimente sollen bei stichprobenfähigen Verteilungen eine recht genaue Schätzung ermöglichen. Details zu Beweisen und Messwerten fehlen im Auszug.
