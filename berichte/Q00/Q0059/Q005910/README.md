# Prompting Considered Harmful

Report Q005910 · Source deepmind.google · Date 2024-10-17 · [Open original](https://deepmind.google/research/publications/90773/)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Der Auszug aus Meredith Ringel Morris’ Abstract vertritt die Einschätzung, Prompting sei eine schlechte Benutzeroberfläche für generative KI und solle möglichst bald ersetzt werden. Als Gründe nennt sie Schwierigkeiten für Endnutzer und das Risiko, Anwendungen und Forschung auf Prompt Engineering aufzubauen; nähere Belege oder Ergebnisse enthält der Auszug nicht.
