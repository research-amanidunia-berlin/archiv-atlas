# Popularity != Public Implementation: How Organizations Leverage Open Source Code

Bericht Q005988 · Quelle cset.georgetown.edu · Datum 2022-10-12 · [Original öffnen](https://cset.georgetown.edu/publication/popularity-public-implementation-how-organizations-leverage-open-source-code/)

[Alle Berichte](../../../README.de.md) · Daten: [bericht.json](bericht.json)

## Zusammenfassung (von Luna, ungeprüft)

Der Bericht argumentiert, dass Unternehmen öffentliche GitHub-Software unter anderem durch Nutzerfeedback und als Einstieg zu kostenpflichtigen Angeboten nutzen können. Microsoft führt bei Sternen und Codebeiträgen zu KI/ML-Repositories, während Explosion bei den im Bericht erfassten öffentlichen Implementierungen zehnmal vor Microsoft liegt. Private Nutzungen können in den Daten fehlen, sodass der Vergleich nicht alle Implementierungen abbildet.
