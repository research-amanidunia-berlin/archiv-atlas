# Where the goblins came from

Report Q005975 · Source openai.com · Date 2026-04-29 · [Open original](https://openai.com/index/where-the-goblins-came-from/)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

OpenAI führt die Goblin- und Gremlin-Metaphern auf ein Belohnungssignal für den verspielten Stil der ChatGPT-Persönlichkeit „Nerdy“ zurück, dessen Effekte sich laut eigener Analyse auf andere Modellantworten übertrugen. Das Unternehmen stellte die Persönlichkeit ein, änderte Training und Datenfilterung und ergänzte eine Anweisung für Codex; die Erklärung und Messwerte stammen aus OpenAIs Bericht.
