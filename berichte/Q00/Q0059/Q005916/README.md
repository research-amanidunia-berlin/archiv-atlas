# OECD Framework for the Classification of AI systems

Report Q005916 · Source oecd.ai · Date 2022-02-22 · [Open original](https://oecd.ai/en/ai-publications/framework-classification)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Der vorliegende Text ist nur ein Abstract-Auszug. Die OECD stellt darin ein Rahmenwerk vor, das unterschiedliche KI-Systeme anhand von fünf Dimensionen einordnen soll, um ihre politischen Auswirkungen im jeweiligen Kontext zu bewerten. Wie die Bewertung praktisch erfolgt und ob das Instrument wirksam ist, geht aus dem Auszug nicht hervor.
