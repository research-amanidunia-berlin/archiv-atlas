## Summary (German, by Luna, unchecked)

Der vorliegende Bericht ist ein Auszug aus dem Abstract zu Genie, einem laut Autorenteam mit unbeschrifteten Internetvideos trainierten Modell zur Erzeugung interaktiver, steuerbarer virtueller Welten.
