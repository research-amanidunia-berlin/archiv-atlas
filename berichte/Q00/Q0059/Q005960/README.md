# Views of AI PhD Recipients on Resources to Build the Domestic Talent Pool

Report Q005960 · Source cset.georgetown.edu · Date 2022-08-17 · [Open original](https://cset.georgetown.edu/publication/views-of-ai-phd-recipients-on-resources-to-build-the-domestic-talent-pool/)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

In einer CSET-Umfrage unter 127 KI-Promovierten galt ein starkes Hochschul- und Forschungsökosystem als wichtigste Ressource für den Aufbau eines inländischen KI-Talentpools; bei staatlicher Förderung und dem privaten Ökosystem unterschieden sich die Bewertungen je nach Beschäftigungssektor. Die Ergebnisse spiegeln die Einschätzungen einer begrenzten Gruppe von Promovierten wider und belegen nicht die tatsächliche Wirksamkeit der genannten Maßnahmen.
