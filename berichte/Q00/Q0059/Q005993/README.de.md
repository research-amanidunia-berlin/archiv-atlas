# Tech Proliferation: How GitHub Facilitates Academic Breakout

Bericht Q005993 · Quelle cset.georgetown.edu · Datum 2022-10-26 · [Original öffnen](https://cset.georgetown.edu/publication/tech-proliferation-how-github-facilitates-academic-breakout/)

[Alle Berichte](../../../README.de.md) · Daten: [bericht.json](bericht.json)

## Zusammenfassung (von Luna, ungeprüft)

Der Bericht vergleicht GitHub-Repositorien, die in wissenschaftlichen Publikationen zitiert werden, und untersucht, wie sich die Zahl ihrer Mitwirkenden nach Veröffentlichung verändert. Laut Auswertung lassen die Zahl der Publikationen und Repositorien nicht unmittelbar auf die Entwicklung der Zusammenarbeit schließen; die Aussagen gelten für die ausgewerteten Datensätze, und manche Felder sind auf GitHub wenig vertreten.
