# IDSISA: Influence-Distilled Sharded Training for Efficient Machine Unlearning

Bericht Q000424 · Quelle arxiv.org · Datum – · [Original öffnen](https://arxiv.org/abs/2611.06519)

[Alle Berichte](../../../README.de.md) · Daten: [bericht.json](bericht.json)

## Zusammenfassung (von Luna, ungeprüft)

Der bereitgestellte Bericht enthält nur den Abstract-Auszug zu IDSISA. Das Verfahren soll Löschanfragen in wenigen Trainings-Shards bündeln und Modellgüte durch Destillation zurückgewinnen; die Autoren behaupten eine exakte Löschgarantie sowie empirische Qualitätsgewinne, doch die Angaben zur Entlernzeit sind unvollständig.
