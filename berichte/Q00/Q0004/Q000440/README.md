# Developers have been hacking around MCP’s file-upload problem for two years. A fix is taking shape.

Report Q000440 · Source thenewstack.io · Date 2026-11-11 · [Open original](https://thenewstack.io/mcp-file-upload-extension/)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

MCP soll eine experimentelle Erweiterung für Datei-Uploads und -Downloads erhalten, weil Entwickler bislang eigene Umwege nutzen müssen. Der Entwurf überträgt Dateien direkt zwischen Client und Ziel, wirft aber noch offene Sicherheitsfragen zu unbekannten Upload-Zielen auf; eine Referenzimplementierung fehlt, und die Erweiterung soll optional bleiben.
