# US keeps AI model testing rules under wraps

Report Q000439 · Source heise.de · Date 2026-11-02 · [Open original](https://www.heise.de/en/news/US-keeps-AI-model-testing-rules-under-wraps-11508225.html)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Die US-Regierung hat nach einer FOIA-Klage einige Unterlagen zu ihrem freiwilligen Prüfrahmen für leistungsstarke KI-Modelle veröffentlicht, hält aber die vollständigen Regeln und eine vollständige Liste früher zugelassener Partner zurück. Protect Democracy kritisiert, dass die Geheimhaltung unabhängige Prüfungen erschwere und ausgewählten Unternehmen Vorteile verschaffen könne; welche Modelle und Tests genau betroffen sind, bleibt laut Bericht unklar.
