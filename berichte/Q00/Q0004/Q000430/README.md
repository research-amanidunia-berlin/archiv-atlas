# Paris Call on AI Safety and Security Explained

Report Q000430 · Source casrai.org · Date 2026-11-13 · [Open original](https://casrai.org/news/paris-call-ai-safety-security-joint-declaration-2026)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Der Bericht fasst eine unverbindliche Erklärung von sechs Staaten, zehn KI-Unternehmen und zivilgesellschaftlichen Organisationen zusammen, die gemeinsame Risikobewertung, Verantwortlichkeit und Vorfallmeldungen fördern soll. Kritiker bemängeln fehlende Fristen, Risikoschwellen und garantierte Prüfzugänge; konkrete Standards und ein gemeinsames Testverfahren stehen noch aus.
