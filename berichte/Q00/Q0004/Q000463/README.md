# A Macroprudential Layer for Frontier AI Governance – Simon Institute for Longterm Governance

Report Q000463 · Source simoninstitute.ch · Date – · [Open original](https://simoninstitute.ch/blog/post/a-macroprudential-layer-for-frontier-ai-governance/)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Der Bericht argumentiert, dass einzelne KI-Modelle und Entwickler zwar weiterhin geprüft werden müssen, aber eine zusätzliche Aufsicht über systemweite Risiken nötig sei. Agenten könnten Risiken gemeinsam erzeugen oder Schwachstellen über geteilte Modelle und Infrastruktur verbreiten; die dafür nötigen Zuständigkeiten und wirksamen Instrumente bleiben laut Beitrag jedoch ungeklärt.
