# 国家发改委：AI全生命周期安全标准将建立

Report Q000466 · Source aiproducthub.cn · Date 2026-11-03 · [Open original](https://aiproducthub.cn/newsflash/china-ndrc-ai-full-lifecycle-safety-standards/)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

China plant nach den bei einer NDRC-Pressekonferenz vorgestellten Zielen einen umfassenden KI-Regelrahmen mit Sicherheitsstandards über den gesamten Lebenszyklus, anpassungsfähiger Aufsicht, klarer Verantwortung und Maßnahmen zu Beschäftigung und gesellschaftlichen Risiken. Der Bericht betont, dass bislang weder konkrete Vorschriften noch ein Zeitplan veröffentlicht wurden.
