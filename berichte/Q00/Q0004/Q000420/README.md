# Paris Call for AI Safety: CeSIA signs, urges safeguards

Report Q000420 · Source cesia.org · Date 2026-11-10 · [Open original](https://cesia.org/en/publications/paris-call-ai-safety-cesia/)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

CeSIA begrüßt den Pariser Aufruf, der große KI-Entwickler auf einen gemeinsamen Rahmen für Risikobewertung und -management verpflichten soll. Die Organisation fordert verbindliche Risikoschwellen, garantierten Zugang für unabhängige Prüfende und Behörden sowie die Befugnis öffentlicher Stellen, Entwicklung oder Einsatz bei unannehmbaren Risiken auszusetzen.
