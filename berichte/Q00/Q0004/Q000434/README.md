## Summary (German, by Luna, unchecked)

Zugleich verwies er auf geplante Handels- und Investitionsgremien; der Artikel berichtet außerdem über umstrittene Vorwürfe im Zusammenhang mit Nvidia-Chef Jensen Huang.
