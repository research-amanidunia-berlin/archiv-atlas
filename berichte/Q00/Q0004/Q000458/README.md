# AI risks are the biggest threat to the financial system, Fed survey finds

Report Q000458 · Source cnbc.com · Date 2026-11-13 · [Open original](https://www.cnbc.com/2026/11/13/ai-risks-financial-system-federal-reserve.html)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

In der Federal-Reserve-Umfrage nannten 87 Prozent der Befragten KI als bedeutsames Risiko für das Finanzsystem, gegenüber 50 Prozent im Frühjahr 2026. Als Gefahren gelten laut Bericht unter anderem überhöhte Aktienbewertungen, Cyberrisiken und komplexe KI-Finanzierungen; trotz insgesamt relativ stabiler Einschätzung verweist die Erhebung auf stark gehebelte, konzentrierte Hedgefondspositionen.
