# Authorization Propagation in Agent2Agent Systems: An Experimental Security Evaluation of Multi-Hop Delegation

Bericht Q000449 · Quelle arxiv.org · Datum – · [Original öffnen](https://arxiv.org/abs/2611.07050)

[Alle Berichte](../../../README.de.md) · Daten: [bericht.json](bericht.json)

## Zusammenfassung (von Luna, ungeprüft)

Der vorliegende Bericht ist nur ein Auszug mit Abstract. Darin wird ein A2A-Sicherheitsprototyp beschrieben, der 14 von 15 Angriffsszenarien abwehrte; Tests zeigten jedoch fehlende Einschränkung delegierter Befugnisse und Manipulationsmöglichkeiten für Vermittler mit dem gemeinsamen HMAC-Schlüssel.
