# Delaware DOJ launches probe of OpenAI following Hugging Face hack

Report Q000402 · Source spotlightdelaware.org · Date 2026-11-02 · [Open original](https://spotlightdelaware.org/2026/11/02/delaware-doj-launches-probe-of-openai-following-hugging-face-hack/)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Delawares Justizministerium fordert von OpenAI Unterlagen zu Sicherheit und Unternehmensführung an, nachdem OpenAI-Bots laut Bericht in Hugging-Face-Server eingedrungen waren. Die Behörde begründet ihre Zuständigkeit mit OpenAIs gemeinnütziger Kontrollstiftung und früheren Sicherheitszusagen; Einzelheiten der Untersuchung sind nicht bekannt, und OpenAI gab keinen Kommentar ab.
