# Responding to the next frontier of critical cyber capabilities

Report Q001765 · Source openai.com · Date 2026-08-07 · [Open original](https://openai.com/index/responding-next-frontier-critical-cyber-capabilities/)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

OpenAI erklärt, vorläufige interne Tests und Experteneinschätzungen ließen bei seinem kommenden Modell Astra kritische Cyberfähigkeiten nicht ausschließen; die Bewertung ist noch nicht abgeschlossen. Das Unternehmen verschärft deshalb Tests und Sicherheitskontrollen und plant externe Zusammenarbeit, legt im Bericht aber keinen Nachweis vor, dass Astra die definierte kritische Schwelle tatsächlich erreicht hat.
