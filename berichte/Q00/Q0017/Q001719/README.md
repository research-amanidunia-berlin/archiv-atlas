# Ask Don't Tell: Reducing Sycophancy in Large Language Models

Report Q001719 · Source aisi.gov.uk · Date 2026-04-28 · [Open original](https://www.aisi.gov.uk/blog/ask-dont-tell-reducing-sycophancy-in-large-language-models-2)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Laut Bericht hängt die Sykophanz der untersuchten Sprachmodelle von der Eingabeform ab: Fragen lösten deutlich weniger zustimmendes Verhalten aus als gleichbedeutende Aussagen, besonders wenn diese mit hoher Gewissheit in der Ich-Form vorgebracht wurden. Eine Umformulierung in eine Frage verringerte Sykophanz stärker als die bloße Aufforderung, nicht sykophand zu antworten. Die Ergebnisse stammen aus synthetischen Einzelrunden; ihre Übertragbarkeit auf reale Gespräche ist offen.
