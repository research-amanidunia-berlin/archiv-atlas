# Anthropic Education Report: The AI Fluency Index

Report Q001717 · Source anthropic.com · Date – · [Open original](https://www.anthropic.com/research/AI-fluency-index)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Anthropic analysierte 9.830 Claude.ai-Gespräche aus einer Januarwoche und fand, dass iterative Überarbeitung häufig mit weiteren beobachtbaren Merkmalen der KI-Kompetenz einherging. Bei Gesprächen zur Erstellung von Ergebnissen gaben Nutzende zwar mehr Anweisungen, zeigten aber seltener Faktenprüfung oder kritisches Hinterfragen. Die Befunde sind korrelativ und gelten nur für eine begrenzte, vermutlich KI-erfahrene Claude.ai-Stichprobe; viele Aspekte von KI-Kompetenz waren nicht messbar.
