# AI Safety in China #26

Report Q001751 · Source aisafetychina.substack.com · Date 2026-04-08 · [Open original](https://aisafetychina.substack.com/p/ai-safety-in-china-26)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Der Bericht beschreibt eine stärkere institutionelle Beschäftigung Chinas mit KI-Sicherheit: OpenClaw-Warnungen, eine neue TC260-Arbeitsgruppe und ein erweiterter CAICT-Benchmark rücken Agenten- und Frontier-Risiken stärker ins Zentrum. Zugleich bleiben Umsetzung, umfassende Tests, ein mögliches KI-Gesetz und die Wirkung des UN-Gremiums offen.
