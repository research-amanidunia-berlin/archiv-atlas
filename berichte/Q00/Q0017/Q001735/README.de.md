# AlphaGeometry: An Olympiad-level AI system for geometry

Bericht Q001735 · Quelle deepmind.google · Datum 2024-01-17 · [Original öffnen](https://deepmind.google/blog/alphageometry-an-olympiad-level-ai-system-for-geometry/)

[Alle Berichte](../../../README.de.md) · Daten: [bericht.json](bericht.json)

## Zusammenfassung (von Luna, ungeprüft)

Laut Google DeepMind löste AlphaGeometry 25 von 30 getesteten Olympiade-Geometrieaufgaben und kombinierte dafür ein Sprachmodell mit einem regelbasierten Beweissystem, trainiert auf 100 Millionen synthetischen Beispielen. Die berichtete Leistung ist auf Geometrie beschränkt; da typischerweise nur zwei von sechs Olympiade-Aufgaben Geometrie betreffen, deckt das System nicht den gesamten Wettbewerb ab.
