# OpenAI Cybersecurity Grant Program

Report Q001753 · Source openai.com · Date 2023-06-01 · [Open original](https://openai.com/index/openai-cybersecurity-grant-program/)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Der Bericht beschreibt ein OpenAI-Förderprogramm für praktische KI-Anwendungen in der defensiven Cybersicherheit und nennt ursprünglich einen Fonds von einer Million US-Dollar; offensive Sicherheitsprojekte sollten nicht gefördert werden. Ein Nachtrag vom Februar 2026 kündigt eine Ausrichtung auf groß angelegte Cyberabwehr mit Trusted Access for Cyber und 10 Millionen US-Dollar an API-Guthaben an, nennt aber keine konkreten Ergebnisse.
