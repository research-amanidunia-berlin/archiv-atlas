# MirrorCode: Evidence that AI can already do some weeks-long coding tasks

Bericht Q001746 · Quelle metr.org · Datum 2026-04-10 · [Original öffnen](https://metr.org/blog/2026-04-10-mirrorcode-preliminary-results/)

[Alle Berichte](../../../README.de.md) · Daten: [bericht.json](bericht.json)

## Zusammenfassung (von Luna, ungeprüft)

Der Auszug stellt MirrorCode als METR- und Epoch-AI-Projekt vor und behauptet im Titel, es gebe Hinweise, dass KI bereits manche wochenlangen Programmieraufgaben bewältigen kann. Methode, Ergebnisse und Einschränkungen fehlen; für Details verweist METR auf einen hier nicht enthaltenen Beitrag von Epoch AI.
