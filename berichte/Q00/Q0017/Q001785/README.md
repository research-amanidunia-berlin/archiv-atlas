# Fine-tuning experiments on CoT controllability

Report Q001785 · Source metr.org · Date 2026-04-01 · [Open original](https://metr.org/blog/2026-04-01-fine-tuning-cot-controllability/)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

METR berichtet, dass geringes Fine-Tuning bei vier Modellen die Befolgung von Vorgaben für Denkspuren verbesserte: Im CoTControl-Test stieg der Durchschnitt laut Bericht von 2,9 auf 8,8 Prozent, blieb aber niedrig und variierte stark nach Modell und Anweisung. Ob dadurch die Überwachbarkeit sinkt oder sich Effekte auf mehrstufige beziehungsweise agentische Systeme übertragen, wurde nicht gezeigt.
