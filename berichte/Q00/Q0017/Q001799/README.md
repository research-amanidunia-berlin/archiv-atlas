## Summary (German, by Luna, unchecked)

Der bereitgestellte Quelltext ist nur ein Auszug, vor allem der Abstract zu SANDBOXESCAPEBENCH, einem Benchmark für mögliche Ausbrüche von Sprachmodellen aus Container-Sandboxes. Die Autoren berichten, dass Modelle eingebrachte Schwachstellen erkennen und ausnutzen können; konkrete Messwerte oder detaillierte Einzelergebnisse enthält der Auszug nicht.
