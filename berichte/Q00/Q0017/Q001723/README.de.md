# An opt-in vulnerability-finding service for open-source software

Bericht Q001723 · Quelle anthropic.com · Datum 2026-10-08 · [Original öffnen](https://www.anthropic.com/research/launching-opt-in-vuln-finding-service-for-open-source)

[Alle Berichte](../../../README.de.md) · Daten: [bericht.json](bericht.json)

## Zusammenfassung (von Luna, ungeprüft)

Anthropic stellt OSS Scanner vor, einen kostenlosen Opt-in-Dienst, der Open-Source-Projekte mit Sprachmodellen auf Schwachstellen prüft und ungeprüfte Berichte schneller bereitstellen soll. In einer frühen Stichprobe erfüllten laut Anthropic 85 von 97 kritischen oder schwerwiegenden Meldungen die Anforderungen des eigenen Offenlegungsprozesses; der Bericht betont zugleich, dass automatische Funde falsch sein, Schweregrade überhöht sein oder Bedrohungsmodelle missverstanden werden können.
