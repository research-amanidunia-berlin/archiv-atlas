# Should AI systems behave like people?

Bericht Q001702 · Quelle aisi.gov.uk · Datum 2024-09-25 · [Original öffnen](https://www.aisi.gov.uk/blog/should-ai-systems-behave-like-people)

[Alle Berichte](../../../README.de.md) · Daten: [bericht.json](bericht.json)

## Zusammenfassung (von Luna, ungeprüft)

Eine gewichtete Befragung von 1.498 Erwachsenen im Vereinigten Königreich ergab laut Bericht breite Zustimmung zu transparenter Kennzeichnung von KI und klare Skepsis gegenüber simulierten Beziehungen sowie behaupteten Gefühlen. Beim Gesprächston waren die Ansichten gemischter, bei moralischer Verantwortung oft unklar; untersucht wurden textbasierte Chatbots, und künftige Einstellungen könnten sich ändern.
