# Measuring AI’s capability to accelerate biological research in the wet lab

Report Q001789 · Source openai.com · Date 2025-12-16 · [Open original](https://openai.com/index/accelerating-biological-research-in-the-wet-lab/)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Laut Bericht steigerte GPT‑5 in einem konkreten Klonierungssystem die Effizienz nach mehreren Versuchsrunden um das 79-Fache; dazu kombinierten sich eine Enzymänderung mit RecA und gp32 sowie eine veränderte Zelltransformation. Die Forschenden sehen darin einen frühen Hinweis auf KI-Unterstützung im Labor, betonen aber die begrenzte Übertragbarkeit, die weiterhin nötige menschliche Versuchsdurchführung und die Biosecurity-Relevanz.
