# Infusion: Shaping model behaviour by editing training data via influence functions

Bericht Q001790 · Quelle aisi.gov.uk · Datum 2026-04-10 · [Original öffnen](https://www.aisi.gov.uk/research/infusion-shaping-model-behaviour-by-editing-training-data-via-influence-functions)

[Alle Berichte](../../../README.de.md) · Daten: [bericht.json](bericht.json)

## Zusammenfassung (von Luna, ungeprüft)

Vorliegt nur ein Auszug mit dem Abstract. Die Arbeit beschreibt Infusion, ein Verfahren für subtile Änderungen an Trainingsdaten, die Modellverhalten beeinflussen sollen; laut den berichteten CIFAR-10-Ergebnissen können Änderungen an 0,2 Prozent der Daten mit einer Vergleichsmethode konkurrieren. Vorläufige Sprachversuche zeigen dem Abstract zufolge, dass der Ansatz bereits gelernte Verhaltensweisen am besten verstärkt und auch scheitern kann.
