# How to evaluate control measures for AI agents?

Report Q002174 · Source aisi.gov.uk · Date 2025-04-11 · [Open original](https://www.aisi.gov.uk/blog/how-to-evaluate-control-measures-for-ai-agents)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Der Beitrag beschreibt AI Control als Schutzansatz, der Handlungen zunehmend autonomer KI-Agenten durch Überwachung, menschliche Freigaben, Zugriffsbeschränkungen und Tests begrenzen soll. Die Autoren skizzieren fünf Fähigkeitsstufen und betonen, dass bestehende Kontrollverfahren für Systeme mit weit übermenschlichen Täuschungsfähigkeiten nicht genügen würden; der vorgestellte Rahmen sei ein früher Entwurf, für den weitere Forschung nötig ist.
