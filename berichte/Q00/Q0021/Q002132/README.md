# Do chatbots inform or misinform voters?

Report Q002132 · Source aisi.gov.uk · Date 2025-09-30 · [Open original](https://www.aisi.gov.uk/blog/do-chatbots-inform-or-misinform-voters)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Laut der im Bericht beschriebenen AISI-Studie nutzten rund 13 Prozent der Wahlberechtigten im Vereinigten Königreich Chatbots für wahlrelevante Informationen. In kurzen randomisierten Versuchen verbesserten sich Einschätzungen zu wahren und falschen politischen Behauptungen durch Chatbot-Recherche etwa so stark wie durch Suchmaschinen; die Ergebnisse sind jedoch auf ein Land, eine Wahl und eine begrenzte Zahl von Modellen beschränkt.
