Report Q002113 · Source digital-strategy.ec.europa.eu · Date – · [Open original](https://digital-strategy.ec.europa.eu/en/policies/ai-literacy-practices/danish-agency-digital-government)

## Summary (German, by Luna, unchecked)

Die dänische Agentur für Digitalverwaltung berichtet von zweistündigen Einsteiger-Workshops zu generativer KI, ergänzt durch Intranet-Informationen und interne Nutzungsregeln. Inhalte werden anhand von Teilnehmenden-Feedback angepasst; laut Bericht waren die Workshops schnell ausgebucht, doch messbare Kompetenzzuwächse werden nicht genannt. Ein fortgeschrittenes Angebot ist geplant.
