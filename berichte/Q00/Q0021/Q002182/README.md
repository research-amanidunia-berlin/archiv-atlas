# Causal Bayesian Networks: A flexible tool to enable fairer machine learning

Report Q002182 · Source deepmind.google · Date 2019-10-03 · [Open original](https://deepmind.google/blog/causal-bayesian-networks-a-flexible-tool-to-enable-fairer-machine-learning/)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Die Autoren stellen kausale Bayes-Netze als Möglichkeit vor, Verzerrungen in ML-Systemen anhand der konkreten Wirkungswege sensibler Merkmale sichtbar zu machen und zu messen. An einem vereinfachten Zulassungsbeispiel zeigen sie, warum Fairnessmaße je nach als fair oder unfair bewerteten Pfaden zu falschen Urteilen führen können; die Bestimmung eines passenden Netzes und komplexe kontrafaktische Analysen bleiben schwierig.
