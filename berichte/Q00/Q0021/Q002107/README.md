# Helen Toner's Testimony Before the U.S.-China Economic and Security Review Commission

Report Q002107 · Source cset.georgetown.edu · Date 2019-06-07 · [Open original](https://cset.georgetown.edu/publication/technology-trade-and-military-civil-fusion-chinas-pursuit-of-artificial-intelligence/)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Der Berichtsauszug skizziert Helen Toners Anhörung zu KI, darunter Forschungsoffenheit, mögliche Folgen von Beschränkungen, Fachkräfte und Einwanderung, China und KI-Standards. Er erwähnt Empfehlungen zur Stärkung der US-Wettbewerbsfähigkeit, führt sie aber nicht aus; konkrete Begründungen und Ergebnisse fehlen ebenfalls.
