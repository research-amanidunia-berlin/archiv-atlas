## Summary (German, by Luna, unchecked)

Der vorliegende Auszug aus dem ABOUT ML Reference Document erklärt dessen Zweck und empfiehlt verschiedenen Gruppen passende Abschnitte zur Dokumentation von ML-Systemen. Bibliothek und Pilotanwendungen werden als geplante Angebote beschrieben; der Auszug belegt weder ihre Umsetzung noch die Wirksamkeit der Empfehlungen.
