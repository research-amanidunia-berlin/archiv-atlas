# “Tech and Tariffs” Campaign: Influence activity targeting US tech policy

Report Q002126 · Source openai.com · Date 2026-06-01 · [Open original](https://openai.com/index/disrupting-malicious-uses-of-ai-tech-and-tariffs/)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

OpenAI zufolge erstellte ein Cluster mutmaßlich aus China stammender Konten mit ChatGPT politische Inhalte gegen US-Technologiepolitik und Zölle, die wahrscheinlich unechte X-Konten verbreiteten. Die Hinweise deuteten auf prochinesische Einflussaktivitäten, belegten aber weder eine konkrete institutionelle Zugehörigkeit noch eine Verbindung zu einer früheren Operation abschließend. OpenAI stufte die Kampagne als auf X begrenzt und mit geringer sichtbarer Resonanz ein.
