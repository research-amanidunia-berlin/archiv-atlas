# Expanding Project Glasswing

Bericht Q002177 · Quelle anthropic.com · Datum 2026-06-02 · [Original öffnen](https://www.anthropic.com/news/expanding-project-glasswing)

[Alle Berichte](../../../README.de.md) · Daten: [bericht.json](bericht.json)

## Zusammenfassung (von Luna, ungeprüft)

Anthropic will Project Glasswing um etwa 150 Organisationen erweitern, die nach Erfüllung von Sicherheitsanforderungen Claude Mythos Preview für defensive Sicherheitsarbeit nutzen sollen. Das Unternehmen berichtet von mehr als 10.000 gefundenen schwerwiegenden Schwachstellen bei bisherigen Partnern und sieht Prüfung und Behebung als zentralen Engpass; ein allgemeiner Zugang zu vergleichbaren Modellen müsse warten, bis Schutzmaßnahmen gegen Missbrauch entwickelt sind.
