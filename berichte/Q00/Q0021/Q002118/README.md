# Details about METR's evaluation of OpenAI GPT-5.1-Codex-Max

Report Q002118 · Source metr.org · Date 2025-11-19 · [Open original](https://metr.org/evaluations/gpt-5-1-codex-max-report/)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

METR stuft GPT-5.1-Codex-Max als moderate, trendgemäße Verbesserung gegenüber GPT-5 ein und hält es für unwahrscheinlich, dass vergleichbare Entwicklungen in den nächsten sechs Monaten die untersuchten Schwellen für stark beschleunigte KI-Forschung oder eigenständige Replikation erreichen. Die Einschätzung beruht auf Agententests und einer unsicheren Trendfortschreibung; Durchbrüche, Rechenskalierung, Messfehler und weitere, nicht untersuchte Risiken bleiben offen.
