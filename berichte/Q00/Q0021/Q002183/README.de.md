# Human-AI Collaboration Trust Literature Review: Key Insights and Bibliography

Bericht Q002183 · Quelle partnershiponai.org · Datum 2019-09-25 · [Original öffnen](https://partnershiponai.org/paper/human-ai-collaboration-trust-literature-review-key-insights-and-bibliography/)

[Alle Berichte](../../../README.de.md) · Daten: [bericht.json](bericht.json)

## Zusammenfassung (von Luna, ungeprüft)

Der Bericht wertet eine erste, multidisziplinäre Sammlung von 78 Forschungsartikeln zu Vertrauen zwischen Menschen und KI aus. Er hebt hervor, dass Vertrauen kontextabhängig ist, Misstrauen und institutionelles Vertrauen zu wenig untersucht werden und weder Erklärungen noch Vertrauen allein die Nutzung von KI zuverlässig erklären.
