# AlphaStar: Grandmaster level in StarCraft II using multi-agent reinforcement learning

Bericht Q002171 · Quelle deepmind.google · Datum 2019-10-30 · [Original öffnen](https://deepmind.google/blog/alphastar-grandmaster-level-in-starcraft-ii-using-multi-agent-reinforcement-learning/)

[Alle Berichte](../../../README.de.md) · Daten: [bericht.json](bericht.json)

## Zusammenfassung (von Luna, ungeprüft)

DeepMind berichtet, AlphaStar habe mit einer Kombination aus menschlichen Spieldaten, Imitationslernen, Selbstspiel und einer League aus Haupt- und Exploiter-Agenten Großmeister-Niveau in allen drei StarCraft-II-Rassen erreicht. Auf Battle.net habe es unter eingeschränkten, menschenähnlichen Bedingungen gespielt und eine Wertung über 99,8 Prozent der aktiven Spieler erzielt. Der Bericht benennt Herausforderungen wie Vergessen und den riesigen Handlungsraum; eine Übertragbarkeit der Ergebnisse auf reale Aufgaben bleibt eine Aussicht, kein belegtes Ergebnis.
