# A new model and dataset for long-range memory

Bericht Q002136 · Quelle deepmind.google · Datum 2020-02-10 · [Original öffnen](https://deepmind.google/blog/a-new-model-and-dataset-for-long-range-memory/)

[Alle Berichte](../../../README.de.md) · Daten: [bericht.json](bericht.json)

## Zusammenfassung (von Luna, ungeprüft)

DeepMind stellt den Compressive Transformer vor, der ältere Informationen für längere Textkontexte verdichtet, sowie PG-19, einen Datensatz aus rund 28.000 älteren Büchern. Der Beitrag berichtet von guten Benchmark-Ergebnissen und Verbesserungen bei langen Buchtexten, betont aber, dass das Modell kein in der realen Welt verankertes Sprachverständnis hat.
