# OpenAI and Microsoft

Bericht Q009007 · Quelle openai.com · Datum 2016-11-15 · [Original öffnen](https://openai.com/index/openai-and-microsoft/)

[Alle Berichte](../../../README.de.md) · Daten: [bericht.json](bericht.json)

## Zusammenfassung (von Luna, ungeprüft)

OpenAI kündigt an, die meisten groß angelegten KI-Experimente auf Microsoft Azure zu verlagern und dafür künftig Tausende bis Zehntausende Rechner einzusetzen. Der Bericht beschreibt geplante Forschung, Veröffentlichungen und technische Erwartungen, enthält aber keine Ergebnisse oder Belege für bereits eingetretene Auswirkungen.
