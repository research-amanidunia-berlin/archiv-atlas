# Microsoft invests in and partners with OpenAI to support us building beneficial AGI

Report Q009046 · Source openai.com · Date 2019-07-22 · [Open original](https://openai.com/index/microsoft-invests-in-and-partners-with-openai/)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

OpenAI kündigt eine Milliarde US-Dollar Investition von Microsoft und eine gemeinsame Entwicklung von Azure-Technologien für zunehmend leistungsfähige KI an; Microsoft solle exklusiver Cloud-Anbieter und bevorzugter Partner für die Vermarktung ausgewählter OpenAI-Technologien sein. Der Bericht formuliert sichere AGI und breit geteilten Nutzen als Ziele, nennt aber weder Zeitplan noch Belege für deren Verwirklichung.
