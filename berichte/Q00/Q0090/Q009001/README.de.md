# OpenAI licenses GPT-3 technology to Microsoft

Bericht Q009001 · Quelle openai.com · Datum 2020-09-22 · [Original öffnen](https://openai.com/index/openai-licenses-gpt-3-technology-to-microsoft/)

[Alle Berichte](../../../README.de.md) · Daten: [bericht.json](bericht.json)

## Zusammenfassung (von Luna, ungeprüft)

OpenAI kündigt an, Microsoft GPT‑3 für eigene Produkte und Dienste zu lizenzieren, und erklärt, dass der Zugang über die OpenAI-API unverändert bestehen bleibe. Der Bericht beschreibt GPT‑3 mit 175 Milliarden Parametern, nennt aber weder Vertragsbedingungen noch konkrete Microsoft-Anwendungen; die Angaben stammen von OpenAI.
