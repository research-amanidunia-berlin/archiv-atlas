# DALL·E API now available in public beta

Bericht Q009014 · Quelle openai.com · Datum 2022-11-03 · [Original öffnen](https://openai.com/index/dall-e-api-now-available-in-public-beta/)

[Alle Berichte](../../../README.de.md) · Daten: [bericht.json](bericht.json)

## Zusammenfassung (von Luna, ungeprüft)

OpenAI kündigte 2022 die öffentliche Betaversion seiner DALL·E-API an, mit der Entwickler Bilder aus Textbeschreibungen erzeugen und bearbeiten lassen könnten. Als Beispiele nennt der Bericht Anwendungen von Microsoft, CALA und Mixtiles sowie eingebaute Moderationsfilter; deren Grenzen werden nicht näher beschrieben.
