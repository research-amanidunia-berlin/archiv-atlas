# OpenAI’s API now available with no waitlist

Bericht Q009035 · Quelle openai.com · Datum 2021-11-18 · [Original öffnen](https://openai.com/index/api-no-waitlist/)

[Alle Berichte](../../../README.de.md) · Daten: [bericht.json](bericht.json)

## Zusammenfassung (von Luna, ungeprüft)

OpenAI hob laut Ankündigung vom November 2021 die Warteliste für die GPT‑3-API in unterstützten Ländern auf und verwies auf neue Schutzfunktionen sowie Entwicklerwerkzeuge. Zahlreiche Inhaltsarten bleiben verboten; Inhalte für Erwachsene seien derzeit ausgeschlossen, weil das System akzeptable und schädliche Nutzung nicht zuverlässig unterscheiden könne.
