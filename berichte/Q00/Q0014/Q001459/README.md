# "Just a Strange Pic": Rethinking 'Safety' in GenAI Image Safety Annotation Tasks from Diverse Annotators’ Perspectives

Report Q001459 · Source deepmind.google · Date 2025-07-21 · [Open original](https://deepmind.google/research/publications/139779/)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Der vorliegende Text ist nur ein Abstract: Eine Auswertung von 5.372 Kommentaren legt laut den Autorinnen und Autoren nahe, dass Annotierende die Sicherheit KI-generierter Bilder mit moralischen, sozialen und kontextabhängigen Erwägungen beurteilen, die gängige Kategorien nicht vollständig abbilden. Auch Richtlinien, Bildqualität und Abweichungen zwischen Prompt und Ausgabe beeinflussten die Urteile; empfohlen werden Bewertungsverfahren, die unterschiedliche Schadensarten und subjektive Einschätzungen berücksichtigen.
