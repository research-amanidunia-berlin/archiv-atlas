# Introducing Mistral OCR 3

Report Q001473 · Source mistral.ai · Date 2025-12-17 · [Open original](https://mistral.ai/news/mistral-ocr-3/)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Mistral zufolge verbessert OCR 3 gegenüber OCR 2 besonders die Erkennung von Handschrift, Formularen, schwierigen Scans und komplexen Tabellen; in internen Benchmarks habe es OCR 2 insgesamt in 74 Prozent der Fälle übertroffen. Die Benchmarkdetails im Bericht reichen nicht aus, um diese Leistungsbehauptungen unabhängig zu überprüfen. OCR 3 ist laut Text per API und Playground verfügbar, während OCR 4 inzwischen das neuere Modell ist.
