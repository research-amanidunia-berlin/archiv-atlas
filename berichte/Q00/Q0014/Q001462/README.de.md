# Cyber Operation: Korean-language malware support

Bericht Q001462 · Quelle openai.com · Datum 2025-10-01 · [Original öffnen](https://openai.com/index/disrupting-malicious-uses-of-ai-korean-language-malware-support/)

[Alle Berichte](../../../README.de.md) · Daten: [bericht.json](bericht.json)

## Zusammenfassung (von Luna, ungeprüft)

OpenAI zufolge nutzte eine Gruppe koreanischsprachiger Konten ChatGPT für Anfragen zu Schadsoftware, Browserdaten, Phishing und Cloud- beziehungsweise GitHub-Diensten; die Konten wurden gesperrt. Eine Zuordnung zu Nordkorea blieb unbestätigt, und OpenAI fand weder Belege, dass die bei Trellix beschriebenen Schadprogramme mit den Modellen erstellt wurden, noch Hinweise auf neuartige Fähigkeiten durch den Modellzugang.
