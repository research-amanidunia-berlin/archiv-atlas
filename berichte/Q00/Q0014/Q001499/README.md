# Education Report: How educators use Claude

Report Q001499 · Source anthropic.com · Date 2025-08-27 · [Open original](https://www.anthropic.com/research/anthropic-education-report-how-educators-use-claude)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Anthropic berichtet, dass Hochschullehrende Claude vor allem für die Entwicklung von Lehrmaterialien nutzen und damit auch interaktive Lernressourcen erstellen. Die Analyse zeigt überwiegend unterstützende Nutzung, aber auch automatisierte Verwaltungsaufgaben und einen umstrittenen Einsatz bei Bewertungen. Sie erfasst nur einen kleinen, gefilterten Ausschnitt der Claude-Nutzung und ist nicht ohne Weiteres auf alle Lehrenden übertragbar.
