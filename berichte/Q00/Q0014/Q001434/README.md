## Summary (German, by Luna, unchecked)

OpenAI beschreibt Meldewege für Beschäftigte, darunter eine anonyme 24/7-Hotline, und erklärt, Vergeltungsmaßnahmen seien untersagt. Seit Oktober 2026 können KI-Sicherheitsbedenken laut Bericht auch direkt an einen Ausschuss des Foundation-Vorstands gemeldet werden; die Geheimhaltung von Geschäftsgeheimnissen gilt mit einer Ausnahme für geschützte Offenlegungen weiter.
