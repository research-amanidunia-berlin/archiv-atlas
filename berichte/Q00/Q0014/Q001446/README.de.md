# Introducing Mistral 3 | Mistral AI

Bericht Q001446 · Quelle mistral.ai · Datum 2025-12-02 · [Original öffnen](https://mistral.ai/news/mistral-3/)

[Alle Berichte](../../../README.de.md) · Daten: [bericht.json](bericht.json)

## Zusammenfassung (von Luna, ungeprüft)

Mistral 3 umfasst offene Ministral-Modelle in drei Größen und das große Mixture-of-Experts-Modell Large 3; Mistral nennt Leistungs-, Mehrsprachigkeits- und Effizienzvorteile sowie verschiedene Bereitstellungswege. Diese Bewertungen und Vergleichswerte stammen vom Anbieter, und eine Reasoning-Version von Large 3 wird noch angekündigt.
