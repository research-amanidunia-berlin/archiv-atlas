## Zusammenfassung (von Luna, ungeprüft)

Der METR-Bericht leitet aus Anthropic zufolge achtmal mehr zusammengeführtem Code modellbasiert einen wahrscheinlich mehr als doppelt so hohen Forschungsbeitrag pro Forschendem ab; als groben Mittelwert nennt Autor Thomas Kwa etwa das 2,5-Fache.
