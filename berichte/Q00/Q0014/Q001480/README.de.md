# Introducing CodeMender: an AI agent for code security

Bericht Q001480 · Quelle deepmind.google · Datum 2025-10-06 · [Original öffnen](https://deepmind.google/blog/introducing-codemender-an-ai-agent-for-code-security/)

[Alle Berichte](../../../README.de.md) · Daten: [bericht.json](bericht.json)

## Zusammenfassung (von Luna, ungeprüft)

CodeMender soll mit KI und Programmanalyse Sicherheitslücken in Software finden und beheben sowie bestehenden Code vorsorglich absichern. DeepMind berichtet von 72 übermittelten Korrekturen in sechs Monaten, betont aber, dass die Ergebnisse vorläufig sind und alle Patches derzeit von Menschen geprüft werden.
