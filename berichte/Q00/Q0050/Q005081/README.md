# Ben Bernanke joins the Long-Term Benefit Trust

Report Q005081 · Source anthropic.com · Date 2026-07-09 · [Open original](https://www.anthropic.com/news/ben-bernanke)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Anthropic meldet, dass der frühere US-Notenbankchef und Wirtschaftsnobelpreisträger Ben Bernanke dem unabhängigen Long-Term Benefit Trust beitritt. Das Gremium berät das Unternehmen zu KI-Risiken und gesellschaftlichen Folgen; Bernanke soll auch seine wirtschaftliche Expertise einbringen. Der Bericht beschreibt die vorgesehene Governance, bewertet deren Wirksamkeit jedoch nicht unabhängig.
