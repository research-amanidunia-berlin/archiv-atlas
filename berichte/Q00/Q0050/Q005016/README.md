# AI at work: how AI is changing everyday job tasks

Report Q005016 · Source epoch.ai · Date 2026-08-06 · [Open original](https://epoch.ai/publications/one-in-five-workers-delegate-work-to-ai)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Laut einer gewichteten Befragung erwerbstätiger US-Erwachsener nutzt ein Fünftel KI für Aufgaben, die zuvor an andere Menschen delegiert wurden; KI wird in allen zehn untersuchten Tätigkeiten eingesetzt, meist unterstützend. Befragte berichten bei größerem KI-Anteil öfter von Zeitersparnis, doch etwa jede sechste unterstützte Aufgabe dauert länger, und die Umfrage belegt weder Ursache noch vollständige Automatisierung von Berufen.
