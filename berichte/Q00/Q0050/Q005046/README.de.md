# A general language assistant as a lab for alignment

Bericht Q005046 · Quelle anthropic.com · Datum 2021-12-01 · [Original öffnen](https://www.anthropic.com/research/a-general-language-assistant-as-a-laboratory-for-alignment)

[Alle Berichte](../../../README.de.md) · Daten: [bericht.json](bericht.json)

## Zusammenfassung (von Luna, ungeprüft)

Der bereitgestellte Text enthält nur das Abstract eines Berichts über Ansätze, große Sprachmodelle an menschlichen Werten auszurichten. Laut Abstract profitieren einfache Eingriffe mit wachsender Modellgröße; geranktes Präferenzmodellieren übertrifft Imitationslernen, während binäre Diskriminierung diesem meist ähnelt. Messwerte und methodische Einzelheiten fehlen im Auszug.
