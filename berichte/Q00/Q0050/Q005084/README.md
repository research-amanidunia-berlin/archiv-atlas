# China's Use of AI in its COVID-19 Response

Report Q005084 · Source cset.georgetown.edu · Date 2020-08-27 · [Open original](https://cset.georgetown.edu/publication/chinas-use-of-ai-in-its-covid-19-response/)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Der vorgelegte Text ist ein Auszug aus einem CSET-Bericht, der ausgewählte, von CAICT zusammengestellte KI-Anwendungen in Chinas COVID-19-Reaktion überblickt. Er nennt fünf Technologiebereiche und berichtet, dass die Projekte vor allem in Großstädten wie Wuhan stattfanden; die Beispiele belegen für sich genommen weder die Wirksamkeit noch die Repräsentativität der Anwendungen.
