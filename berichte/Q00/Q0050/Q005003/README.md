# Scaling Streams with Google

Report Q005003 · Source deepmind.google · Date 2018-11-13 · [Open original](https://deepmind.google/blog/scaling-streams-with-google/)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

DeepMind kündigt an, dass das Streams-Team zu Google wechselt und die Klinik-App zu einem KI-Assistenten für medizinisches Personal weiterentwickeln soll. Das Team soll in London bleiben; laut Beitrag behalten die NHS-Partner die Kontrolle über Patientendaten und deren Nutzung. Die erwarteten Vorteile für Forschung und Versorgung werden als Ziel beziehungsweise Prognose beschrieben, nicht im Text abschließend belegt.
