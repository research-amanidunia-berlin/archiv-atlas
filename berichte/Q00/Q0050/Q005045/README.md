# Expanding AI access and cyber defense for federal, state, local, and tribal governments

Report Q005045 · Source openai.com · Date 2026-09-10 · [Open original](https://openai.com/index/expanding-ai-access-us-government/)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

OpenAI und die US-Bundesverwaltung kündigen vergünstigten KI-Zugang für berechtigte Behörden auf Bundes-, Landes-, Kommunal- und Stammesebene bis Ende 2028 an, ergänzt durch Cyberabwehrwerkzeuge, Schulungen und Einführungshilfen. Die Erfolge in Behörden, die der Bericht anführt, beruhen auf OpenAIs Angaben; unabhängige Belege und vollständige Teilnahmebedingungen werden im Text nicht ausgeführt.
