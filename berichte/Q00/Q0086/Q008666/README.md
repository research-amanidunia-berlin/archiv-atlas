# Testing robustness against unforeseen adversaries

Report Q008666 · Source openai.com · Date 2019-08-22 · [Open original](https://openai.com/index/testing-robustness/)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Der Bericht schlägt mit UAR eine Kennzahl und ein dreiteiliges Verfahren vor, um Bildklassifikatoren gegen unbekannte adversariale Verzerrungen zu bewerten. Die Autoren berichten, dass Schutz gegen bekannte Angriffe nicht zuverlässig übertragbar ist und empfehlen daher Tests mit vielfältigen Angriffen und Verzerrungsstärken; die Aussagen beziehen sich auf die beschriebenen Untersuchungen.
