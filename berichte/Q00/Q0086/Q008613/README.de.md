# Collective alignment: public input on our Model Spec

Bericht Q008613 · Quelle openai.com · Datum 2025-08-27 · [Original öffnen](https://openai.com/index/collective-alignment-aug-2025-updates/)

[Alle Berichte](../../../README.de.md) · Daten: [bericht.json](bericht.json)

## Zusammenfassung (von Luna, ungeprüft)

OpenAI berichtet über eine Befragung von rund 1.000 Personen, deren Präferenzen überwiegend mit den Bewertungen eines Modells zur Auslegung der Model Spec übereinstimmten. Eine Klarstellung zu politischen Inhalten für breite Zielgruppen soll übernommen werden; Änderungen für gezielte politische Ansprache und erotische Inhalte wurden zurückgestellt. Der Bericht betont, dass Stichprobe, Bewertungsverfahren und fehlende abschließende Rückbestätigung die Ergebnisse begrenzen.
