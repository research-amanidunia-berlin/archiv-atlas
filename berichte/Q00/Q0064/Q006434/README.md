# Program to Build a National Technology Transfer System

## Summary (German, by Luna, unchecked)

Der 2017 veröffentlichte chinesische Staatsratsplan soll den Transfer und die praktische Nutzung wissenschaftlicher Ergebnisse fördern, vor allem innerhalb Chinas. Er setzt auf Unternehmensbeteiligung, vernetzte Märkte, Fachkräfte, Finanzierung und regionale sowie internationale Kooperation; ob die Ziele für 2020 und 2025 erreicht wurden, zeigt der Bericht nicht.
