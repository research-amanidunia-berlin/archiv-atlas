# AGI could drive wages below subsistence level

Bericht Q006432 · Quelle epoch.ai · Datum 2025-01-24 · [Original öffnen](https://epoch.ai/gradient-updates/agi-could-drive-wages-below-subsistence-level)

[Alle Berichte](../../../README.de.md) · Daten: [bericht.json](bericht.json)

## Zusammenfassung (von Luna, ungeprüft)

Barnett hält es für möglich, dass AGI menschliche Arbeit so umfassend ersetzt, dass bei knappen Ressourcen und begrenztem technischem Fortschritt die Löhne unter das Existenzminimum sinken. Seine Wahrscheinlichkeiten von etwa einem Drittel innerhalb von 20 und zwei Dritteln innerhalb von 100 Jahren sind persönliche Schätzungen; der Beitrag untersucht Löhne, nicht das gesamte Wohlergehen, und nennt mögliche Gegenkräfte wie Innovation, Regulierung und alternative Einkünfte.
