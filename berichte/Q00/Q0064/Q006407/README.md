# 9 big questions benchmarks can help answer

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Greg Burnham beschreibt neun offene Fragen dazu, ob KI zunehmend offene Arbeit erledigen, wirtschaftlich wichtige Fähigkeiten entwickeln, selbst KI-Forschung betreiben und neue Ideen hervorbringen kann. Benchmarks können laut ihm Fortschritte untersuchen, liefern aber keine abschließenden Antworten; manche sind schwer realitätsnah oder kostengünstig umzusetzen, und die bisherigen Belege bleiben begrenzt.
