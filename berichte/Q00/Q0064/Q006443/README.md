## Summary (German, by Luna, unchecked)

Der vorliegende Text ist ein Auszug; der angekündigte erste Hauptabschnitt fehlt. Die Autoren argumentieren anhand von GATE-Simulationen, dass starke KI-bedingte Wachstumsbeschleunigungen und wesentlich höhere Investitionen plausibler sein könnten als oft angenommen, betonen aber, dass das Modell keine präzisen Vorhersagen liefert. Wegen ausgelassener Faktoren, unsicherer Annahmen und der großen Abweichung der Investitionsschätzung von der Realität empfehlen sie weder Gewissheit über explosives Wachstum noch dessen kategorische Ablehnung.
