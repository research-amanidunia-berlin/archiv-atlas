# An open call for input from GPAI’s Data Governance Working Group

Report Q007161 · Source oecd.ai · Date 2020-11-03 · [Open original](https://oecd.ai/en/wonk/open-call-input-gpai-data-governance-working-group)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Die GPAI-Arbeitsgruppe für Daten-Governance veröffentlichte eine vorläufige Rahmenfassung zur öffentlichen Rückmeldung. Sie ordnet Themen von Daten im KI-Lebenszyklus bis zu technischen, rechtlichen und organisatorischen Governance-Ansätzen und soll nach Konsultation für den Dezember-Gipfel weiterentwickelt werden. Ein ergänzendes Forschungsprojekt untersucht die Rolle von Daten in der KI; fertige Ergebnisse legt der Beitrag nicht vor.
