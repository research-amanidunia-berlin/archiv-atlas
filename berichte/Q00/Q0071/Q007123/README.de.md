## Zusammenfassung (von Luna, ungeprüft)

Der Bericht beschreibt iGPT, einen Transformer, der Bildpixel wie eine Sequenz verarbeitet und ohne Bildlabels trainiert wird. Laut den Autoren erzielte das Modell auf mehreren Klassifikationsdatensätzen starke Ergebnisse, blieb auf ImageNet aber hinter SimCLR und benötigte sehr viel mehr Rechenleistung; zudem könnten Trainingsdaten schädliche Verzerrungen bewirken.
