# Denmark: an independent council and a labelling scheme to promote the ethical use of data

Report Q007128 · Source oecd.ai · Date 2020-06-15 · [Open original](https://oecd.ai/en/wonk/an-independent-council-and-seal-of-approval-among-denmarks-measures-to-promote-the-ethical-use-of-data)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Der Bericht beschreibt Dänemarks Datenethikrat, einen Werkzeugkasten für Unternehmen, eine Offenlegungspflicht für große Firmen und ein geplantes Siegel für Cybersicherheit und verantwortungsvollen Umgang mit KI-Daten. Die Maßnahmen sollten Transparenz und ethische Praxis fördern; der Text nennt Ziele und Erwartungen, aber keine späteren Ergebnisse oder Wirksamkeitsnachweise.
