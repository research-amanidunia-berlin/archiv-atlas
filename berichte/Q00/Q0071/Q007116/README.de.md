# OpenAI and Amazon announce strategic partnership

Bericht Q007116 · Quelle openai.com · Datum 2026-02-27 · [Original öffnen](https://openai.com/index/amazon-partnership/)

[Alle Berichte](../../../README.de.md) · Daten: [bericht.json](bericht.json)

## Zusammenfassung (von Luna, ungeprüft)

OpenAI und Amazon kündigen eine Partnerschaft mit einer geplanten Amazon-Investition von bis zu 50 Milliarden US-Dollar, neuen AWS-Angeboten und einer erweiterten Trainium-Vereinbarung an. Die Produkteinführungen und Trainium4-Lieferungen sind angekündigt beziehungsweise erwartet; ein Teil der Investition ist an Bedingungen geknüpft.
