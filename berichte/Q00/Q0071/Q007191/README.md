# Introducing GPT-5

Report Q007191 · Source openai.com · Date 2025-08-07 · [Open original](https://openai.com/index/introducing-gpt-5/)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

OpenAI stellt GPT‑5 als System vor, das schnelle Antworten und vertieftes Nachdenken je nach Aufgabe kombiniert, und berichtet von Verbesserungen bei Programmierung, Schreiben, Gesundheit, Genauigkeit und Sicherheit. Die Leistungszahlen stammen aus den von OpenAI beschriebenen Benchmarks und Auswertungen; der Bericht nennt Einschränkungen der Vergleichbarkeit und betont, dass weitere Verbesserungen nötig sind.
