# Deepmind’s Alphafold: a solution to the 50-year-old challenge of protein folding

Bericht Q007110 · Quelle oecd.ai · Datum 2020-12-14 · [Original öffnen](https://oecd.ai/en/wonk/deepminds-alphafold-a-solution-to-challenge-of-protein-folding)

[Alle Berichte](../../../README.de.md) · Daten: [bericht.json](bericht.json)

## Zusammenfassung (von Luna, ungeprüft)

DeepMind zufolge wurde AlphaFold bei einer unabhängigen CASP-Bewertung als Lösung für die Herausforderung der Proteinstrukturvorhersage anerkannt; eine frühere Version hatte 2018 die höchste Genauigkeit unter den Teilnehmenden erzielt. Anwendungen für Medizin und Nachhaltigkeit werden als mögliche nächste Schritte beschrieben, stehen laut Beitrag aber noch am Anfang.
