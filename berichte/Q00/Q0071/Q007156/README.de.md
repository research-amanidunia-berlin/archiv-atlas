# An introduction to the Global Partnership on AI’s work on data governance

Bericht Q007156 · Quelle oecd.ai · Datum 2020-08-21 · [Original öffnen](https://oecd.ai/en/wonk/an-introduction-to-the-global-partnership-on-ais-work-on-data-governance)

[Alle Berichte](../../../README.de.md) · Daten: [bericht.json](bericht.json)

## Zusammenfassung (von Luna, ungeprüft)

Der Artikel beschreibt Auftrag und frühe Vorhaben der GPAI-Arbeitsgruppe für Data Governance: Sie wollte einen gemeinsamen Rahmen entwickeln und untersuchen lassen, wie Daten die KI-Entwicklung ermöglichen oder erschweren und welche Folgen ihr Zugang hat. Der Beitrag stellt Pläne aus dem Jahr 2020 vor, enthält aber keine Projektergebnisse; die Aussagen zu Zielen und erwarteter Wirkung stammen von der Verfasserin.
