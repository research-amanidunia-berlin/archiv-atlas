# Memory and new controls for ChatGPT

Report Q007108 · Source openai.com · Date 2024-02-13 · [Open original](https://openai.com/index/memory-and-new-controls-for-chatgpt/)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Der Bericht beschreibt ChatGPTs Gedächtnisfunktion, mit der gespeicherte Angaben und laut späteren Aktualisierungen auch frühere Gespräche für personalisierte Antworten genutzt werden sollen. Nutzer könnten das Gedächtnis verwalten oder ausschalten und temporäre Chats verwenden; der Text nennt zudem Datenschutzmaßnahmen und separate Erinnerungen für GPTs, prüft deren Wirksamkeit jedoch nicht unabhängig.
