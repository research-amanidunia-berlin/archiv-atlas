# OpenAI board of directors announces advisors to nonprofit commission

## Summary (German, by Luna, unchecked)

OpenAI benennt vier Berater für eine Kommission, die Rückmeldungen aus Gemeinschaften und Fachorganisationen sammeln und dem Vorstand binnen 90 Tagen Empfehlungen zu philanthropischen Aktivitäten vorlegen soll. Die Mitteilung schildert Ziele und mögliche Beiträge von KI, berichtet aber noch keine Ergebnisse oder unabhängige Bewertung der erwarteten Wirkung.
