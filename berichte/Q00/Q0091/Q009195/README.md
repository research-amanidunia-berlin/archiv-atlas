## Summary (German, by Luna, unchecked)

OpenAI erweitert den Anzeigenpilot für ChatGPT um einen schrittweise verfügbaren Selbstbedienungsmanager, zusätzliche Partner und CPC-Gebote neben der bisherigen CPM-Abrechnung. Eine neue Conversion-Messung soll Werbewirkung sichtbar machen; OpenAI zufolge erhalten Werbekunden aggregierte Daten, aber keinen Zugriff auf einzelne Gespräche. Der Bericht beschreibt vor allem Unternehmensangaben und enthält keine unabhängigen Belege zur tatsächlichen Wirkung der Funktionen.
