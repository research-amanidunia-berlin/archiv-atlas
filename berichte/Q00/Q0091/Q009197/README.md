# OpenAI o3-mini System Card

Report Q009197 · Source openai.com · Date 2025-01-31 · [Open original](https://openai.com/index/o3-mini-system-card/)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Der bereitgestellte Text ist nur ein Auszug aus OpenAIs o3-mini-Systemkarte: Er nennt die Einstufung vor Risikominderungsmaßnahmen als insgesamt „Medium“, mit „Low“ für Cybersicherheit, und beschreibt die Schwellen für Einsatz und Weiterentwicklung. OpenAI zufolge erreicht das Modell bei Autonomie erstmals „Medium“, bleibt aber bei Prüfungen zu realitätsnaher ML-Forschung für Selbstverbesserung schwach; Einzelheiten zu Tests und Gegenmaßnahmen fehlen im Auszug.
