# OpenAI launches DeployCo to help businesses build around intelligence

Bericht Q009182 · Quelle openai.com · Datum 2026-05-11 · [Original öffnen](https://openai.com/index/openai-launches-the-deployment-company/)

[Alle Berichte](../../../README.de.md) · Daten: [bericht.json](bericht.json)

## Zusammenfassung (von Luna, ungeprüft)

OpenAI kündigt DeployCo an, eine mehrheitlich von OpenAI kontrollierte Einheit, die Unternehmen mit FDEs bei der Analyse, Umgestaltung und Automatisierung wichtiger Arbeitsabläufe unterstützen soll. Eine vereinbarte, noch genehmigungspflichtige Tomoro-Übernahme soll rund 150 Fachkräfte einbringen; der Bericht beschreibt Pläne und erwartete Vorteile, aber keine unabhängigen Ergebnisse des neuen Unternehmens.
