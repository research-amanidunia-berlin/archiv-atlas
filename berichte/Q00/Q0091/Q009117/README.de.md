# OpenAI partners with Scale to provide support for enterprises fine-tuning models

Bericht Q009117 · Quelle openai.com · Datum 2023-08-24 · [Original öffnen](https://openai.com/index/openai-partners-with-scale-to-provide-support-for-enterprises-fine-tuning-models/)

## Zusammenfassung (von Luna, ungeprüft)

OpenAI und Scale wollen Unternehmen das Fine-Tuning von OpenAI-Modellen erleichtern; GPT‑3.5 Turbo sei verfügbar, GPT‑4 dafür im Herbst vorgesehen gewesen. OpenAI macht Angaben zum Kundeneigentum an API-Daten, und als Beispiel wird Brex genannt, doch konkrete Resultate oder technische Einzelheiten liefert der Bericht kaum.
