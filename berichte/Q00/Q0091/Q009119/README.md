# OpenAI and Microsoft extend partnership

Report Q009119 · Source openai.com · Date 2023-01-23 · [Open original](https://openai.com/index/openai-and-microsoft-extend-partnership/)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

OpenAI zufolge investiert Microsoft mehrjährig Milliarden und baut die Zusammenarbeit bei Azure-Infrastruktur, Produktbereitstellung und dem Austausch über Sicherheitserfahrungen aus. Die Mitteilung beschreibt die erwarteten Vorteile aus OpenAIs Sicht, nennt aber weder die genaue Investitionssumme noch unabhängige Belege für die behaupteten Wirkungen.
