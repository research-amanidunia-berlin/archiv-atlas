# AI is a viable alternative to high throughput screening: a 318-target study

Report Q000726 · Source pmc.ncbi.nlm.nih.gov · Date – · [Open original](https://pmc.ncbi.nlm.nih.gov/articles/PMC10987645/pdf/41598_2024_Article_54655.pdf)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

In 318 Projekten untersuchte die Studie, ob AtomNet mithilfe virtuellen Screenings bioaktive Moleküle über viele Zielklassen hinweg finden kann; die ausgewählten Substanzen wurden anschließend im Labor getestet. Die Autoren berichten über Trefferquoten von durchschnittlich 5,5 Prozent in akademischen Projekten und 6,7 Prozent in internen Dosis-Wirkungs-Tests, weisen aber auf begrenzte Nachprüfungen und fehlende direkte Vergleichbarkeit mit HTS hin.
