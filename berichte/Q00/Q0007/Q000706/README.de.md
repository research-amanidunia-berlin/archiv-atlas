# Anthropic launches roadshow for proposed initial public offering

## Zusammenfassung (von Luna, ungeprüft)

Anthropic zufolge hat die Roadshow für einen geplanten Börsengang mit 825 Millionen Aktien begonnen; der erwartete Preis liegt bei 70 bis 78 US-Dollar je Aktie, eine Nasdaq-Notierung unter „ANT“ wurde beantragt. Die Registrierungserklärung ist laut Mitteilung noch nicht wirksam, und die Ankündigung gilt ausdrücklich nicht als Verkaufsangebot.
