# PixelCNN++: Improving the PixelCNN with Discretized Logistic Mixture Likelihood and Other Modifications

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

PixelCNN++ kombiniert eine diskretisierte logistische Mischungsverteilung für Pixelwerte mit Änderungen an Architektur und Regularisierung. Die Autoren berichten für CIFAR-10 einen damaligen Bestwert von 2,92 Bits pro Teilpixel, weisen aber darauf hin, dass die Versuche keine allgemeine Übertragbarkeit jeder Änderung belegen.
