## Summary (German, by Luna, unchecked)

Der Bericht präsentiert ADR, ein Verfahren, das die Vielfalt simulierter Trainingsumgebungen automatisch schrittweise erweitert, und berichtet damit über bessere Übertragung auf eine reale Roboterhand. Die beste Steuerung führte eine festgelegte Würfel-Sequenz in 20 Prozent von zehn Versuchen vollständig aus; Hinweise auf Anpassung während des Einsatzes fanden die Autoren vor allem in Simulationen. Sensorwürfel, besondere Aufkleber, die kleine Zahl realer Versuche und die ungelöste rein visuelle Erkennung eines Standardwürfels begrenzen die Ergebnisse.
