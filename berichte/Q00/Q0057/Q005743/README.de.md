# AI capabilities progress has sped up

Bericht Q005743 · Quelle epoch.ai · Datum 2025-12-23 · [Original öffnen](https://epoch.ai/data-insights/ai-capabilities-progress-has-sped-up)

[Alle Berichte](../../../README.de.md) · Daten: [bericht.json](bericht.json)

## Zusammenfassung (von Luna, ungeprüft)

Epoch AI zufolge beschleunigte sich der gemessene KI-Fähigkeitsfortschritt: Der ECI-Spitzenwert sei zuletzt fast doppelt so schnell gestiegen, und beim METR-Zeithorizont habe es ebenfalls eine Beschleunigung gegeben. Der Bericht stellt einen zeitlichen Zusammenhang mit Reasoning-Modellen und Reinforcement Learning her, weist aber keine Ursache nach; außerdem ist diese Auswertung laut Hinweis überholt.
