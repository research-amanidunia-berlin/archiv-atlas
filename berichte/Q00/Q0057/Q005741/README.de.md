# Diving into Deep Learning with Keyword Cascade Plots

Bericht Q005741 · Quelle cset.georgetown.edu · Datum 2023-02-15 · [Original öffnen](https://cset.georgetown.edu/publication/diving-into-deep-learning-with-keyword-cascade-plots/)

[Alle Berichte](../../../README.de.md) · Daten: [bericht.json](bericht.json)

## Zusammenfassung (von Luna, ungeprüft)

Der Bericht zeigt anhand der Cluster „Remote Sensing Image“ und „Text Classification“, wie Keyword-Cascade-Plots Forschungsbereiche und ihre Zitationsverbindungen zu Deep Learning sichtbar machen können. Die Analyse deutet auf Anwendungen zur Klassifikation hyperspektraler Daten hin; sie beruht jedoch auf zusammengeführten Korpusdaten, ist nicht direkt über die Kartenoberfläche reproduzierbar und untersucht nur zwei ausgewählte Cluster.
