# Will we run out of ML data? Projecting dataset size trends

Report Q005726 · Source epoch.ai · Date 2022-11-10 · [Open original](https://epoch.ai/publications/will-we-run-out-of-ml-data-evidence-from-projecting-dataset)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Epoch AI projiziert, dass bei anhaltenden Trends hochwertige Sprachdaten bereits um 2024, niedrigwertige Sprachdaten etwa zwischen 2032 und 2041 und Bilddaten etwa zwischen 2039 und 2046 knapp werden könnten. Die Forschenden schätzen eine Wahrscheinlichkeit von rund 20 Prozent, dass Datenmangel das Wachstum von ML-Modellen bis 2040 deutlich verlangsamt. Die Projektionen sind wegen starker Annahmen, breiter Unsicherheit und möglicher Fortschritte bei Dateneffizienz und synthetischen Daten mit Vorsicht zu lesen.
