# Total cost of ownership of a one-gigawatt AI data center

Report Q005795 · Source epoch.ai · Date 2026-05-14 · [Open original](https://epoch.ai/data-insights/ai-datacenter-cost-breakdown)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Ein stilisiertes Epoch-AI-Modell schätzt für ein US-Hyperscaler-KI-Rechenzentrum mit 1 GW IT-Leistung jährliche Gesamtkosten von rund 8,5 Milliarden US-Dollar, aus etwa 7,6 Milliarden annualisierten Investitionen und 0,9 Milliarden Betriebskosten. Server bilden den größten Posten; die Schätzung hängt stark von der angenommenen Lebensdauer der IT-Ausrüstung ab und ist keine Prognose für eine konkrete Anlage.
