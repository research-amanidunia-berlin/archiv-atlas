# AI chip component costs: memory at 63%

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Epoch AI schätzt, dass HBM zwischen Q1 2024 und Q4 2025 von rund 52 auf 63 Prozent der Komponentenausgaben für KI-Chips der vier betrachteten Entwickler stieg; die Gesamtausgaben erhöhten sich von etwa 22 auf 52 Milliarden US-Dollar pro Jahr. Die Berechnung beruht auf geschätzten Chipkosten und Produktionsmengen, und ein weiterer HBM-Anstieg 2026 wird lediglich erwartet.
