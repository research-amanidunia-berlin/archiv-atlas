# Updates to the OECD’s definition of an AI system explained

Report Q005747 · Source oecd.ai · Date 2023-11-29 · [Open original](https://oecd.ai/en/wonk/ai-system-definition-update)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Der OECD-Bericht erläutert eine überarbeitete Definition von KI-Systemen, die ausdrücklich oder implizit gesetzte Ziele, die Verarbeitung von Eingaben, generierte Inhalte sowie mögliche Anpassungen nach der Einführung berücksichtigt. Die Änderungen sollen technische Entwicklungen wie generative KI erfassen und die internationale Abstimmung unterstützen; für die praktische Anwendung hielt der Bericht ein ergänzendes technisches Memorandum für nötig.
