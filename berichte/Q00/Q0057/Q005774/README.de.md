# Testimony Before House Homeland Security Subcommittee

Bericht Q005774 · Quelle cset.georgetown.edu · Datum 2019-10-22 · [Original öffnen](https://cset.georgetown.edu/publication/cset-senior-faculty-fellow-ben-buchanan-testifies-before-house-homeland-security-subcommittee/)

[Alle Berichte](../../../README.de.md) · Daten: [bericht.json](bericht.json)

## Zusammenfassung (von Luna, ungeprüft)

Dr. Buchanan zufolge könnte KI die Cybersicherheit stark beeinflussen, während ihr Zusammenspiel mit diesem Bereich bislang zu wenig untersucht werde. Der vorliegende Auszug nennt als Analysefelder die Sicherheit von KI-Systemen, offensive Cyberangriffe und die Cyberabwehr, enthält aber keine weiteren Belege oder Einzelheiten.
