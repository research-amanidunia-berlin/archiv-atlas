# Near-Minimax-Optimal Distributional RL with a Generative Model

Bericht Q005794 · Quelle deepmind.google · Datum 2024-02-12 · [Original öffnen](https://deepmind.google/research/publications/70372/)

[Alle Berichte](../../../README.de.md) · Daten: [bericht.json](bericht.json)

## Zusammenfassung (von Luna, ungeprüft)

Der Auszug berichtet über einen neuen Algorithmus für modellbasiertes distributionelles Reinforcement Learning, der laut Autorinnen und Autoren Rückkehrverteilungen mit einem generativen Modell bis auf logarithmische Faktoren minimax-optimal approximiert. Er nennt außerdem eine neue Bellman-Gleichung und eine experimentelle Vergleichsstudie, deren Methoden und Ergebnisse im Auszug nicht ausgeführt werden.
