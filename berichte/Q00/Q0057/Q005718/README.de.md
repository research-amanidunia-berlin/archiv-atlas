## Zusammenfassung (von Luna, ungeprüft)

Der bereitgestellte Bericht ist nur das Abstract einer IJCAI-2023-Arbeit. Die Autoren berichten, ein auf Online-Kompression beruhendes Modell mit Levin Tree Search erziele in vier kombinatorischen Suchgebieten Ergebnisse, die frühere neuronale Ansätze erreichen oder teilweise übertreffen, und ermögliche laut ihrer Analyse theoretische Garantien. Versuchsdetails und Messwerte fehlen im Auszug.
