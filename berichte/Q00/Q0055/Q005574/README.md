# What do “economic value” benchmarks tell us?

Report Q005574 · Source epoch.ai · Date 2026-02-13 · [Open original](https://epoch.ai/publications/what-do-economic-value-benchmarks-tell-us)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Der Bericht vergleicht drei Benchmarks für digitale Wirtschaftsaufgaben: RLI, APEX-Agents und GDPval. Die Autoren halten Fortschritte für einen möglichen Hinweis auf KI-Nutzen, aber nicht für einen Beleg, dass ganze Berufe automatisiert werden können. Aufgabenwahl, Bewertungsverfahren und Agenten-Umgebungen begrenzen die Aussagekraft; selbst hohe Werte könnten vor allem einzelne Arbeitsschritte beschleunigen und den Anteil menschlicher Planung und Kontrolle erhöhen.
