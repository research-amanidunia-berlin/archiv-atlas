# Responsible and Ethical Military AI

Report Q005523 · Source cset.georgetown.edu · Date 2021-08-24 · [Open original](https://cset.georgetown.edu/publication/responsible-and-ethical-military-ai/)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Der bereitgestellte Text ist eine einführende Zusammenfassung, kein vollständiger Bericht. Er beschreibt gemeinsame ethische Leitlinien für militärische KI unter US-Verbündeten als hilfreich für Zusammenarbeit und warnt, dass Unterschiede bei Verantwortlichkeit und Risikobewertung Koalitionen belasten könnten. Die USA gelten darin als Vorreiter; der Entwicklungsstand der Verbündeten wird unterschiedlich eingeschätzt.
