# The AI data scraping challenge:  How can we proceed responsibly?

Report Q005534 · Source oecd.ai · Date 2024-03-05 · [Open original](https://oecd.ai/en/wonk/data-scraping-responsibly)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Der Bericht beschreibt Scraping als mögliche Grundlage nützlicher KI- und Forschungsanwendungen, zugleich aber als Quelle von Konflikten um Urheberrecht, Privatsphäre, Sicherheit, Vergütung und mögliche Nachahmung durch KI-Ausgaben. Er plädiert für eine kombinierte Antwort aus Recht, Verhaltenskodizes, Verträgen, technischen Schutzmaßnahmen und Bildung, weist aber auf internationale Unterschiede und die Kosten langwieriger Rechtsstreitigkeiten hin.
