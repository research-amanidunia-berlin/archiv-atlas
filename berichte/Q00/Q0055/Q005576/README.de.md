# Introducing ChatGPT for Financial Services

Bericht Q005576 · Quelle openai.com · Datum 2026-09-10 · [Original öffnen](https://openai.com/index/introducing-chatgpt-financial-services/)

[Alle Berichte](../../../README.de.md) · Daten: [bericht.json](bericht.json)

## Zusammenfassung (von Luna, ungeprüft)

OpenAI stellt ChatGPT for Financial Services als Finanzarbeitsplatz mit GPT‑6 Astra, integrierten Finanzdaten, Quellenbelegen und Vorlagen für Unternehmensunterlagen vor. Die Ankündigung nennt Sicherheits- und Verwaltungsfunktionen sowie einen OfficeQA-Pro-Wert von 69,9 Prozent für GPT‑6 Astra, liefert dafür aber keine unabhängige Prüfung; verfügbar sei das Produkt für berechtigte Finanzinstitute.
