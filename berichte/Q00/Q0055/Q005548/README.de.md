# Messier than Oil: Assessing Data Advantage in Military AI

Bericht Q005548 · Quelle cset.georgetown.edu · Datum 2020-07-23 · [Original öffnen](https://cset.georgetown.edu/publication/messier-than-oil-assessing-data-advantage-in-military-ai/)

[Alle Berichte](../../../README.de.md) · Daten: [bericht.json](bericht.json)

## Zusammenfassung (von Luna, ungeprüft)

Der vorliegende Auszug argumentiert, dass ein militärischer KI-Datenvorteil nicht an der bloßen Menge von Rohdaten hängt, sondern daran, ob passende Daten für konkrete Anwendungen aufbereitet sind. Kommerzielle Daten seien nur begrenzt auf militärische Anwendungen übertragbar; ob neue Ansätze künftig weniger reale Daten benötigen, bleibe für militärische Zwecke offen.
