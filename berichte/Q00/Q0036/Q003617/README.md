# Anthropic commits $10 million to Canadian AI research

Report Q003617 · Source anthropic.com · Date 2026-07-14 · [Open original](https://www.anthropic.com/news/canadian-ai-research)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Anthropic kündigt 10 Millionen kanadische Dollar für KI-Forschung an acht kanadischen Einrichtungen sowie API-Guthaben für angeschlossene Start-ups an. Das Unternehmen berichtet zudem über hohe Claude-Nutzung in Kanada und regionale Unterschiede, gestützt auf anonym ausgewertete Nutzungsdaten; unabhängige Überprüfungen oder Ergebnisse der geförderten Forschung nennt der Bericht nicht.
