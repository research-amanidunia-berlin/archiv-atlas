# AI capabilities can be significantly improved without expensive retraining

Report Q003689 · Source epoch.ai · Date 2023-12-12 · [Open original](https://epoch.ai/publications/ai-capabilities-can-be-significantly-improved-without-expensive-retraining)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Der Bericht schätzt, dass nachträgliche Verbesserungen von Sprachmodellen bei den jeweils untersuchten Benchmarks oft einem fünf- bis dreißigfach höheren Vortrainingsbudget entsprechen, bei vergleichsweise geringen einmaligen Anpassungskosten. Einzelne Methoden können jedoch die laufenden Inferenzkosten stark erhöhen. Die Autoren empfehlen, Sicherheitsregeln auf mögliche künftige Zuwächse auszurichten und zu berücksichtigen, dass solche Verfahren auch Akteuren mit weniger Rechenressourcen offenstehen können.
