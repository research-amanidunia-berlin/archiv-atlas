# Open-sourcing MuJoCo

Bericht Q003688 · Quelle deepmind.google · Datum 2022-05-23 · [Original öffnen](https://deepmind.google/blog/open-sourcing-mujoco/)

[Alle Berichte](../../../README.de.md) · Daten: [bericht.json](bericht.json)

## Zusammenfassung (von Luna, ungeprüft)

DeepMind berichtet, MuJoCo vollständig auf GitHub als Open-Source-Simulator veröffentlicht zu haben, und beschreibt es als Grundlage für gemeinsame Weiterentwicklung in der Robotik. Benchmarks werden für zwei Modelle und mehrere Threadzahlen auf einem bestimmten Windows-Rechner erwähnt, doch ihre konkreten Werte fehlen im bereitgestellten Text. Eine Roadmap kündigt unter anderem parallele Simulation, Unterstützung größerer Szenen, einen neuen Compiler, Unity-Integration und Physikableitungen an.
