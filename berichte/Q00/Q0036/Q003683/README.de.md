# A new way to reflect on how you use Claude

Bericht Q003683 · Quelle anthropic.com · Datum 2026-07-09 · [Original öffnen](https://www.anthropic.com/news/reflect-with-claude)

[Alle Berichte](../../../README.de.md) · Daten: [bericht.json](bericht.json)

## Zusammenfassung (von Luna, ungeprüft)

Anthropic beschreibt „Reflect“ als Beta-Dashboard, das Claude-Nutzungsmuster zusammenfasst, zur Selbstreflexion anregen und mithilfe eines 4D-Rahmenwerks praktische Hinweise geben soll. Laut Unternehmen bleiben inkognito Chats und Gesundheitsintegrationen außen vor, während sensible Gespräche auf hoher Ebene erscheinen können; verfügbar sei die Funktion für Free-, Pro- und Max-Konten mit aktiviertem Memory.
