## Summary (German, by Luna, unchecked)

Anthropic beschreibt „Reflect“ als Beta-Dashboard, das Claude-Nutzungsmuster zusammenfasst, zur Selbstreflexion anregen und mithilfe eines 4D-Rahmenwerks praktische Hinweise geben soll.
