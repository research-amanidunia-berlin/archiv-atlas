# Turning contracts into searchable data at OpenAI

Report Q003669 · Source openai.com · Date 2025-09-29 · [Open original](https://openai.com/index/openai-contract-data-agent/)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

OpenAI beschreibt einen internen Agenten, der Vertragsdokumente verarbeitet, relevante Klauseln begründet extrahiert und Finanzfachleuten strukturierte Daten zur Prüfung bereitstellt. Laut Unternehmensbericht halbiert das die Prüfzeit und ermöglicht die Bearbeitung tausender Verträge; Menschen behalten die fachlichen Entscheidungen. Unabhängige Messungen und Angaben zu Fehlerquoten oder Grenzen fehlen.
