# Univé builds an AI-ready workforce

Report Q003660 · Source openai.com · Date 2026-07-31 · [Open original](https://openai.com/index/unive/)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Der Bericht beschreibt Univé zufolge eine breite Nutzung von ChatGPT Enterprise, gestützt durch Führung, Sicherheitsregeln und Freiraum für Mitarbeitende. Univé gibt an, dass Agenten unter anderem Versicherungsfälle in Minuten für die Entscheidung vorbereiten; die Verantwortung für Entscheidungen bleibe bei Fachkräften. Die Zahlen und Wirkungen sind nicht unabhängig belegt, und weitergehende Agentenabläufe werden noch erkundet.
