# A time-invariant version of Laplace’s rule

## Summary (German, by Luna, unchecked)

Der Bericht schlägt eine zeitinvariante Variante der Laplaceschen Regel vor, die Ereignisse als Poisson-Prozess behandelt und damit die Abhängigkeit von der gewählten Zeiteinteilung vermeiden soll. Für null beobachtete Ereignisse wird ein virtueller Erfolg angesetzt; bei einem mit dem ersten Erfolg beginnenden Zeitraum wird dieser erste Erfolg nicht mitgezählt. Die genauen Formeln fehlen im bereitgestellten Text, und der Autor warnt insbesondere vor kurzen Beobachtungszeiträumen und ignoriertem Vorwissen.
