## Summary (German, by Luna, unchecked)

Der vorliegende Text ist nur ein Auszug aus einer Übersetzung chinesischer, als unverbindlich beschriebener BCI-Ethikrichtlinien. Er definiert BCI und unterscheidet nichtinvasive, invasive und interventionelle Verfahren; laut einleitender Zusammenfassung mahnen die Richtlinien besonders bei augmentativen Anwendungen zur Mäßigung, da sie Ungleichheit verstärken könnten.
