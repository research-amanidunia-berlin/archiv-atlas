# Introducing Claude Corps

Report Q003645 · Source anthropic.com · Date 2026-06-11 · [Open original](https://www.anthropic.com/news/claude-corps)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Anthropic kündigt ein mit zunächst 150 Millionen US-Dollar finanziertes, zwölfmonatiges Fellowship an: 1.000 Berufseinsteiger sollen für gemeinnützige Organisationen in den USA im Einsatz von Claude geschult werden; mindestens 400 Organisationen sollen sie aufnehmen. Die erste Gruppe soll im Oktober 2026 starten. Der Bericht schildert Ziele und geplante Abläufe, aber noch keine gemessenen Ergebnisse; eine spätere Ausweitung und offene Bereitstellung von Teilen der Infrastruktur sind Vorhaben.
