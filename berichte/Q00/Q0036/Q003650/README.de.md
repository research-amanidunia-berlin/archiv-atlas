## Zusammenfassung (von Luna, ungeprüft)

DeepSeek kündigt für seine API JSON-Ausgabe, Function Calling, Chat Prefix Completion, ein höheres Tokenlimit und eine neue FIM-Schnittstelle an. Die Beta-Funktionen sind laut Beitrag für alle zugänglich, erfordern eine spezielle Basisadresse und können sich ändern, da sie als instabil gelten.
