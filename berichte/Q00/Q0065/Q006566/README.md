# WAIC Artificial Intelligence Security and Rule of Law Guidelines

Report Q006566 · Source cset.georgetown.edu · Date 2020-01-15 · [Open original](https://cset.georgetown.edu/publication/waic-artificial-intelligence-security-and-rule-of-law-guidelines/)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Die vorgeschlagenen Leitlinien von 2019 behandeln KI-Risiken bei Algorithmen, Daten, Schutzrechten, Beschäftigung und Haftung und skizzieren dafür rechtliche, technische und soziale Maßnahmen. Sie enthalten Risikoeinschätzungen und Vorschläge, aber keine berichtete Prüfung ihrer Umsetzung oder Wirksamkeit.
