# How big could an “AI Manhattan Project” get?

Report Q006597 · Source epoch.ai · Date 2025-07-02 · [Open original](https://epoch.ai/gradient-updates/how-big-could-an-ai-manhattan-project-get)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Der Autor schätzt, dass ein stark finanziertes US-KI-Großprojekt bis Ende 2027 einen Trainingslauf von etwa 2 × 10²⁹ FLOP ermöglichen könnte – rund 500-mal so groß wie das bis dahin rechenintensivste Modell. Dafür wären nach seiner Rechnung etwa 27 Millionen H100-Äquivalente und 7,4 GW Strom nötig; der Beitrag hält diese Energieversorgung mit staatlicher Unterstützung für grundsätzlich machbar. Die Schätzung ist annahmenabhängig, keine Prognose oder Empfehlung und berücksichtigt andere mögliche Engpässe nur begrenzt.
