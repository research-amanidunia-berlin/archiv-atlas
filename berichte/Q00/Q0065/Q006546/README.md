# Build more natural voice experiences with GPT‑Live‑1 in the API

Report Q006546 · Source openai.com · Date 2026-09-10 · [Open original](https://openai.com/index/introducing-gpt-live-1-in-the-api/)

## Summary (German, by Luna, unchecked)

OpenAI kündigt GPT‑Live‑1 für die API an: Das Modell soll gleichzeitig zuhören und sprechen, Unterbrechungen natürlicher handhaben und komplexe Aufgaben an Backend-Modelle delegieren können. OpenAI und zitierte Kunden berichten von besseren Benchmark- und Praxisergebnissen, doch einige Kennzahlen sind nicht vollständig aufgeschlüsselt; der API-Preis wird mit 0,05 US-Dollar pro Minute für die Sprachschicht angegeben.
