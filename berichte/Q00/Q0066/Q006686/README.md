# How persistent is the inference cost burden?

Report Q006686 · Source epoch.ai · Date 2026-02-16 · [Open original](https://epoch.ai/gradient-updates/how-persistent-is-the-inference-cost-burden)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Der Autor stimmt zu, dass RL oft längere und damit teurere Inferenz ermöglicht, hält aber sowohl die langfristige Kostenlast als auch Ords Schätzung von 10.000-mal mehr RL-Rechenleistung für unsicher. Er verweist auf sinkende Kosten für feste Fähigkeiten, schätzt deren Rückgang grob auf das Fünf- bis Zehnfache pro Jahr und nennt zugleich Einschränkungen bei dieser Schätzung und der verfügbaren RL-Datenlage.
