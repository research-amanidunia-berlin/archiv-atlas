# How many digital workers could OpenAI deploy?

Report Q006664 · Source epoch.ai · Date 2025-10-03 · [Open original](https://epoch.ai/gradient-updates/how-many-digital-workers-could-openai-deploy)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Der Autor schätzt spekulativ, dass OpenAI mit vorhandener Hardware im Median etwa 7 Millionen KI-Arbeitsäquivalente für Aufgaben bereitstellen könnte, die heutige Systeme bewältigen; die Unsicherheit ist sehr groß. Die Zahl bedeutet nicht, dass KI heute sieben Millionen Menschen ersetzen kann, und mögliche wirtschaftliche Folgen hängen von weiterem Fähigkeits- und Rechenleistungswachstum ab.
