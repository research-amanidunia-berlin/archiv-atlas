# Re-boosting Self-Collaboration Parallel Prompt GAN for Unsupervised Image Restoration

[Alle Berichte](../../../README.de.md) · Daten: [bericht.json](bericht.json)

## Zusammenfassung (von Luna, ungeprüft)

Die Autoren schlagen RSCP2GAN vor: Ein Prompt-GAN erzeugt synthetische Trainingsbilder, während Self-Collaboration und Re-Boosting den Restorer schrittweise verbessern sollen, ohne laut Bericht die Inferenz zu verteuern. In Tests zu Entrauschen, Regen- und Schneentfernung schneidet das Verfahren nach Angaben der Autoren häufig besser ab als unbeaufsichtigte Vergleichsmethoden; gemischte Beschädigungen bleiben eine offene Aufgabe.
