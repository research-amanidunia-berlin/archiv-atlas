# 🚀 DeepSeek V2.5: The Grand Finale 🎉

Bericht Q003705 · Quelle api-docs.deepseek.com · Datum – · [Original öffnen](https://api-docs.deepseek.com/news/news1210)

[Alle Berichte](../../../README.de.md) · Daten: [bericht.json](bericht.json)

## Zusammenfassung (von Luna, ungeprüft)

DeepSeek kündigt eine zuschaltbare Websuche für chat.deepseek.com und das Modell DeepSeek-V2.5-1210 an. Das Unternehmen beansprucht Verbesserungen in mehreren Benchmarks, nennt dafür aber keine Messwerte oder Testbedingungen; zugleich erklärt es die V2.5-Reihe für beendet und kündigt weitere Foundation-Modelle an.
