# Claude Frontier Academy: $100M to train 10,000 engineers

Report Q003729 · Source anthropic.com · Date 2026-10-02 · [Open original](https://www.anthropic.com/news/claude-frontier-academy)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Anthropic kündigt eine mit 100 Millionen US-Dollar finanzierte Academy an, die bis Ende 2027 10.000 Ingenieurinnen und Ingenieure für den praktischen KI-Einsatz in Unternehmen ausbilden soll. Der Bericht erläutert Auswahl, Präsenztraining und zwölfwöchige Praxisphase, nennt aber noch keine Ergebnisse abgeschlossener Teilnahmen.
