# Stacking our way to more general robots

Report Q003715 · Source deepmind.google · Date 2021-10-11 · [Open original](https://deepmind.google/blog/stacking-our-way-to-more-general-robots/)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

DeepMind beschreibt RGB-Stacking, einen Benchmark, bei dem Roboterarm-Systeme verschieden geformte Objekte anhand von Bildern stapeln sollen. Das dreistufige Training kombiniert Simulation und Daten realer Roboter; laut Bericht erreichte es 82 Prozent Erfolg bei bekannten Testkombinationen und 54 Prozent bei der Verallgemeinerung auf neue Objekte. DeepMind betont, dass echte Verallgemeinerung eine offene Herausforderung bleibt.
