# How can we build human values into AI?

Bericht Q003799 · Quelle deepmind.google · Datum 2023-04-24 · [Original öffnen](https://deepmind.google/blog/how-can-we-build-human-values-into-ai/)

[Alle Berichte](../../../README.de.md) · Daten: [bericht.json](bericht.json)

## Zusammenfassung (von Luna, ungeprüft)

In einem Spiel bevorzugten Teilnehmende, die ihre eigene Position nicht kannten, laut Bericht häufiger eine KI-Regel, die Benachteiligten hilft, statt den Gesamtertrag zu maximieren. Die Forschenden sehen im „Schleier des Nichtwissens“ einen möglichen Ansatz für die faire Auswahl von KI-Prinzipien, betonen aber, dass die Ergebnisse aus einem vereinfachten Szenario stammen und weitere Forschung nötig ist.
