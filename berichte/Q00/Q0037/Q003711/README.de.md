## Zusammenfassung (von Luna, ungeprüft)

Der Bericht stellt Ithaca vor, ein KI-System, das beschädigte altgriechische Inschriften rekonstruiert und bei der Bestimmung von Herkunftsort und Entstehungszeit helfen soll. Laut den berichteten Tests verbessert die Zusammenarbeit mit dem System die Rekonstruktionsleistung von Historikern; die Ergebnisse beziehen sich auf griechische Texte und legen keine allgemeine Übertragbarkeit auf andere Sprachen nahe.
