# The Next Chapter of the Microsoft–OpenAI Partnership

Bericht Q003708 · Quelle openai.com · Datum 2025-10-28 · [Original öffnen](https://openai.com/index/next-chapter-of-microsoft-openai-partnership/)

[Alle Berichte](../../../README.de.md) · Daten: [bericht.json](bericht.json)

## Zusammenfassung (von Luna, ungeprüft)

OpenAI beschreibt neue Vertragsregeln für die Partnerschaft mit Microsoft: Microsoft behält wichtige Modell- und Azure-Rechte, während beide Seiten zusätzliche Möglichkeiten für eigene Entwicklungen erhalten. Laut OpenAI gehören dazu eine unabhängige Prüfung einer AGI-Erklärung, ein zusätzlicher Azure-Kauf über 250 Milliarden US-Dollar und neue Freiheiten bei ausgewählten Produkten; konkrete Kriterien und Sicherheitsdetails bleiben teilweise offen.
