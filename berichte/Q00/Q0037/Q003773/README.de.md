# MuZero: Mastering Go, chess, shogi and Atari without rules

Bericht Q003773 · Quelle deepmind.google · Datum 2020-12-23 · [Original öffnen](https://deepmind.google/blog/muzero-mastering-go-chess-shogi-and-atari-without-rules/)

## Zusammenfassung (von Luna, ungeprüft)

Der Bericht zufolge plant MuZero mit einem gelernten Modell, das nur entscheidungsrelevante Aspekte abbildet, und benötigt dafür keine vorgegebenen Spielregeln. In Tests erzielte es starke Ergebnisse bei Go, Schach, Shogi und Atari; Anwendungen außerhalb dieser Spielumgebungen werden als mögliche Zukunftsperspektive genannt.
