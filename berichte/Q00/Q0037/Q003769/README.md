# Desktop Extensions: One-click MCP installs

Report Q003769 · Source anthropic.com · Date 2025-06-26 · [Open original](https://www.anthropic.com/research/desktop-extensions)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Anthropic beschreibt Desktop Extensions als installierbare `.mcpb`-Pakete, die lokale MCP-Server samt Manifest und möglichen Abhängigkeiten bündeln und die Einrichtung in Claude Desktop vereinfachen sollen. Spezifikation und Werkzeuge sollen quelloffen sein; der Formatstand 0.1 ist laut Bericht noch in Entwicklung, und bestehende `.dxt`-Erweiterungen bleiben nutzbar. Praktische Wirksamkeit und Sicherheit werden nicht unabhängig belegt.
