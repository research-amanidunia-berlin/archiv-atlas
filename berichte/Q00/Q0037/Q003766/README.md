## Summary (German, by Luna, unchecked)

DeepSeek kündigt V3-0324 mit behaupteten Verbesserungen beim Schlussfolgern, bei Frontend-Aufgaben und beim Werkzeugeinsatz an. Die API bleibe unverändert; für einfache Aufgaben empfiehlt DeepSeek V3 ohne „DeepThink“, und die Gewichte sollen unter MIT-Lizenz auf Hugging Face verfügbar sein. Messwerte oder Testbedingungen nennt der Text nicht.
