# Putting the power of AlphaFold into the world’s hands

Report Q003765 · Source deepmind.google · Date 2022-07-22 · [Open original](https://deepmind.google/blog/putting-the-power-of-alphafold-into-the-worlds-hands/)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

DeepMind kündigt eine frei zugängliche Datenbank mit AlphaFold-Vorhersagen für menschliche Proteine und 20 weitere Organismen an und beschreibt mögliche Anwendungen in Medizin und Forschung. Der Beitrag berichtet von frühen Erfolgssignalen, ist jedoch eine Darstellung des Entwicklers; methodische Grenzen werden kaum ausgeführt, und die geplante Erweiterung auf über 100 Millionen Strukturen war zum beschriebenen Zeitpunkt noch ein Vorhaben.
