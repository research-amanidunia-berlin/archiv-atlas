## Zusammenfassung (von Luna, ungeprüft)

DeepSeek stellt V3.1 mit Denk- und Nicht-Denkmodus vor und behauptet Verbesserungen bei Geschwindigkeit, Werkzeugnutzung, Agentenaufgaben und Benchmarks. Die API soll unter anderem 128.000 Token Kontext sowie Anthropic-Format und Beta-Unterstützung für striktes Function Calling bieten; konkrete Benchmarkwerte fehlen im Text. Der Bericht nennt außerdem Modellupdates, offene Gewichte und einen angekündigten Wechsel der API-Preise am 5. September 2025.
