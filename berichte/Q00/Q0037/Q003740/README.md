# Algorithmic progress in language models

Report Q003740 · Source epoch.ai · Date 2024-03-12 · [Open original](https://epoch.ai/publications/algorithmic-progress-in-language-models)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Epoch AI schätzt, dass die für ein bestimmtes Leistungsniveau nötige Rechenleistung bei Sprachmodellen ungefähr alle acht Monate halbiert wurde. Laut der Studie entfiel der größere Teil der Leistungsgewinne auf mehr Rechenleistung und Trainingsdaten; algorithmische Verbesserungen trugen ebenfalls bei, lassen sich aber wegen methodischer Unsicherheiten schwer genau beziffern.
