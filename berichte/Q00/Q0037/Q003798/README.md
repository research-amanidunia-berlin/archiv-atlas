# Examining Patent Data in PARAT

Report Q003798 · Source cset.georgetown.edu · Date 2022-03-30 · [Open original](https://cset.georgetown.edu/publication/examining-patent-data-in-parat/)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Der Bericht zeigt, dass PARAT-Unternehmen je nach KI-Patentzahl anders rangieren als alle Patentierenden im umfassenderen CSET-Datensatz: In PARAT führen IBM, Microsoft und Google, insgesamt dagegen IBM, Baidu, Tencent, Samsung und State Grid. Die Autorin betont, dass die Unterschiede unter anderem aus der begrenzten Unternehmensauswahl, möglichen Verzögerungen der Patentdaten und den Grenzen von Patenten als Aktivitätsmaß entstehen.
