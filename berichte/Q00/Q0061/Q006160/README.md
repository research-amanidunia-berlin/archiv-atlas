# Canada and the UK compare AI governance efforts and  reflect on regulating AI

Report Q006160 · Source oecd.ai · Date 2023-07-25 · [Open original](https://oecd.ai/en/wonk/canada-and-the-uk-compare-ai-governance-efforts-and-reflect-on-regulating-ai)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Eine britisch-kanadische Gesprächsrunde verglich Ansätze zur KI-Governance anhand des Finanzsektors. Die Teilnehmenden betonten, dass Industriestandards Regulierung ergänzen können, ließen aber offen, wie sektorale Regeln und eine übergreifende KI-Governance zusammenwirken sollten. Vorgeschlagen wurden weitere gemeinsame Arbeit an Standards, Rahmenwerken und Forschung; der Bericht präsentiert keine abgeschlossene Lösung.
