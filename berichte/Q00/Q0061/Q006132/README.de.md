## Zusammenfassung (von Luna, ungeprüft)

Der Auszug beschreibt SAFEAs Plan von 2016, zwei bisherige Arbeitserlaubnisse für Ausländer zusammenzuführen, Anträge zu vereinfachen und die Verwaltung stärker zu digitalisieren. Eine Pilotphase sollte 2016/17 beginnen, die landesweite Einführung war für April 2017 vorgesehen; der Text berichtet jedoch nicht über die tatsächliche Umsetzung. Es liegt ausdrücklich nur ein Auszug vor, der auf eine vollständige Übersetzung im PDF verweist.
