# The pace of large-scale model releases is accelerating

Report Q006195 · Source epoch.ai · Date 2024-06-19 · [Open original](https://epoch.ai/data-insights/large-scale-model-releases)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Der bereitgestellte Auszug von Epoch AI behauptet, dass die Zahl der KI-Modelle mit über 10²³ FLOP Trainingsaufwand stark zugenommen hat; als mögliche Gründe nennt er höhere Investitionen und günstigere Hardware. Die Abbildungsdaten weichen teilweise von den Zahlen im Text ab, und der Auszug erklärt weder die Abweichungen noch die Methode ausführlich.
