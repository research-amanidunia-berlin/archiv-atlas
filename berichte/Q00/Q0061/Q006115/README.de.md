# DeepMind, meet Android

Bericht Q006115 · Quelle deepmind.google · Datum 2018-05-08 · [Original öffnen](https://deepmind.google/blog/deepmind-meet-android/)

[Alle Berichte](../../../README.de.md) · Daten: [bericht.json](bericht.json)

## Zusammenfassung (von Luna, ungeprüft)

DeepMind und Android kündigten für Android P Adaptive Battery an, das mithilfe von Nutzungsvorhersagen Hintergrundaktivitäten verringern soll, sowie Adaptive Brightness, das persönliche Helligkeitsvorlieben erlernt. Der Beitrag berichtet von positiven Ergebnissen interner Tests, nennt jedoch keine Messwerte oder genauere Testmethodik.
