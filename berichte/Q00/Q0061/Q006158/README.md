# Predicting eye disease with Moorfields Eye Hospital

Report Q006158 · Source deepmind.google · Date 2018-11-05 · [Open original](https://deepmind.google/blog/predicting-eye-disease-with-moorfields-eye-hospital/)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

DeepMind und Moorfields wollen anhand von bis zu 7.000 anonymisierten OCT-Aufnahmen untersuchen, ob KI eine Verschlechterung der AMD im zunächst gesunden Auge früh vorhersagen kann. Der Bericht beschreibt Planung und zugesagte Datenkontrollen, enthält aber noch keine Ergebnisse zur Zuverlässigkeit oder zum Nutzen des Ansatzes.
