# Epoch’s Capabilities Index stitches together benchmarks across a wide range of difficulties

## Summary (German, by Luna, unchecked)

Epoch zufolge fasst der Capabilities Index Ergebnisse verschiedener Benchmarks auf einer gemeinsamen Skala zusammen, weil einzelne Tests oft nach ein bis drei Jahren an Aussagekraft verlieren. Eine Grafik verknüpft ECI-Werte mit erwarteten Leistungen bei GSM8K, OTIS Mock AIME und FrontierMath; die genaue Berechnung und Gewichtung des Index erläutert der Bericht nicht.
