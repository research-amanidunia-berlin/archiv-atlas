# Today’s largest data center can do more than 20 GPT-4-scale training runs each month

Report Q006118 · Source epoch.ai · Date 2025-12-04 · [Open original](https://epoch.ai/data-insights/gpt-4s-trainable)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Epoch AI schätzt, dass Fairwater Atlanta etwa 23 GPT-4-große Trainingsläufe pro Monat ermöglicht; für Fairwater Wisconsin prognostiziert der Bericht bis Ende 2027 mehr als 225. Die Werte werden aus geschätztem Trainingsaufwand und geschätzter Rechenleistung bei 16-Bit-Präzision berechnet und bezeichnen Kapazitäten, keine belegten tatsächlichen Trainingsläufe.
