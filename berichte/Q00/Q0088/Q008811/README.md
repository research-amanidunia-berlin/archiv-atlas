OpenAI beschreibt ein VGG16-basiertes Netz, das Spam-Dosen laut den Autoren trotz ausschließlich simulierten Trainings auch in realen, mit unbekannten Gegenständen gefüllten Szenen erkennt; demonstriert wird dies mit einem Roboterarm.
