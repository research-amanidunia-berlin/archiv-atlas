# AI and compute

Report Q008815 · Source openai.com · Date 2018-05-16 · [Open original](https://openai.com/index/ai-and-compute/)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Der Bericht schätzt, dass sich der Compute großer KI-Trainingsläufe seit 2012 alle 3,4 Monate verdoppelte; die Schätzungen sind jedoch ungenau, und für historische Daten räumen die Autoren noch größere Unsicherheit ein. Sie halten eine Fortsetzung des Trends für möglich, können seine Dauer und Folgen aber nicht vorhersagen und plädieren dafür, KI-Sicherheit, Missbrauchsschutz und Politik frühzeitig mitzudenken.
