# Frontier Model Forum

Bericht Q008864 · Quelle openai.com · Datum 2023-07-26 · [Original öffnen](https://openai.com/index/frontier-model-forum/)

[Alle Berichte](../../../README.de.md) · Daten: [bericht.json](bericht.json)

## Zusammenfassung (von Luna, ungeprüft)

Anthropic, Google, Microsoft und OpenAI kündigen ein Forum an, das Sicherheitsforschung, gemeinsame Standards, Bewertungen und den Austausch über Risiken bei besonders leistungsfähigen KI-Modellen fördern soll. Der Bericht stellt geplante Arbeitsfelder und Organisationsstrukturen vor, enthält aber keinen Nachweis, dass sie bereits umgesetzt wurden oder Wirkung zeigen.
