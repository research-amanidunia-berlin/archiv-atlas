# How GPT-5 helped mathematician Ernest Ryu solve a 40-year-old open problem

Report Q008867 · Source openai.com · Date 2025-11-24 · [Open original](https://openai.com/index/gpt-5-mathematical-discovery/)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Der Bericht zufolge half GPT‑5 dem Mathematiker Ernest Ryu, Ideen für einen Beweis zu einem offenen Problem über die Stabilität von NAG schneller zu erkunden. Viele Vorschläge des Modells waren falsch; Ryu erkannte einen brauchbaren Ansatz, entwickelte ihn selbst weiter und überprüfte die Argumente sorgfältig. Der öffentlich verfügbare Vorabdruck wird laut Bericht noch begutachtet, und der geschilderte Einzelfall belegt keine allgemeine Zuverlässigkeit von GPT‑5.
