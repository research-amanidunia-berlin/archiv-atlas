## Zusammenfassung (von Luna, ungeprüft)

Vorinostat habe 91 Prozent einer fibrosefördernden Schädigungsreaktion blockiert. Das sind frühe Laborbefunde, kein Beleg für eine wirksame oder sichere Behandlung beim Menschen.
