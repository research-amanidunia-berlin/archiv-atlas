# Anthropic awarded $200M DOD agreement

Bericht Q004489 · Quelle anthropic.com · Datum 2025-07-14 · [Original öffnen](https://www.anthropic.com/news/anthropic-and-the-department-of-defense-to-advance-responsible-ai-in-defense-operations)

[Alle Berichte](../../../README.de.md) · Daten: [bericht.json](bericht.json)

## Zusammenfassung (von Luna, ungeprüft)

Anthropic zufolge hat das US-Verteidigungsministerium eine zweijährige Prototypenvereinbarung mit einem Höchstrahmen von 200 Millionen US-Dollar geschlossen. Geplant sind unter anderem KI-Prototypen auf Basis von Ministeriumsdaten und Maßnahmen gegen mögliche feindliche Nutzung. Die Unternehmensmitteilung nennt weitere staatliche Einsätze, enthält jedoch keine konkreten Ergebnisse oder ausführlichen Vertragsdetails.
