# Defining AI incidents and related terms

Report Q004487 · Source oecd.ai · Date 2024-05-06 · [Open original](https://oecd.ai/en/ai-publications/defining-ai-incidents-and-related-terms)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Der Auszug berichtet, dass die OECD Definitionen für KI-Vorfälle als tatsächliche Schäden und KI-Gefährdungen als mögliche Gefahren vorschlägt. Die Begriffe sollen internationale Anschlussfähigkeit mit Spielraum für einzelne Rechtsordnungen verbinden; Vorgehen und nähere Ergebnisse sind im vorliegenden kurzen Auszug nicht enthalten.
