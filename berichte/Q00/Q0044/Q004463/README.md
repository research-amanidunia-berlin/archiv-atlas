# Trends in Robotics Patents

Report Q004463 · Source cset.georgetown.edu · Date 2021-11-02 · [Open original](https://cset.georgetown.edu/publication/trends-in-robotics-patents/)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Der Text ist ein Auszug aus einem Bericht über erteilte Robotikpatente in 88 Ländern von 2005 bis 2019. Laut Auszug führte China bei den Gesamtpatenten, während Russland trotz eines kleinen Gesamtanteils einen vergleichsweise hohen Anteil an militärischen Robotikpatenten stellte; die USA und China lagen je nach Anwendungsfeld vorn. Patente dienen hier als Indikator, und der Auszug enthält keine ausführliche Methodendarstellung.
