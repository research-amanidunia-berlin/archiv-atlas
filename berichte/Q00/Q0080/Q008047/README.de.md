## Zusammenfassung (von Luna, ungeprüft)

Der bereitgestellte Text ist ein Auszug: OpenAI berichtet darin von zwei gesperrten, wahrscheinlich China zuzuordnenden Kontengruppen, die mutmaßlich Debatten über US-Rechenzentren und Zölle beeinflussen sollten. OpenAI sagt, es gebe keine Hinweise auf nennenswerte Verbreitung außerhalb ihrer Aktivitäten; die Bedeutung liege im Testen von Narrativen zu KI-Infrastruktur und im Ausnutzen bestehender Sorgen.
