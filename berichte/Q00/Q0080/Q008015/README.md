# Buy it in ChatGPT: Instant Checkout and the Agentic Commerce Protocol

Report Q008015 · Source openai.com · Date 2025-09-29 · [Open original](https://openai.com/index/buy-it-in-chatgpt/)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

OpenAI kündigt Instant Checkout in ChatGPT für einzelne Käufe bei US-Etsy-Verkäufern an; Shopify-Händler und weitere Funktionen sollen später folgen. Die Abwicklung läuft über das offene Agentic Commerce Protocol, während Händler Zahlungen und Kundenservice verantworten. Die Angaben zu Sicherheit, Datenschutz und Produktauswahl sind OpenAIs eigene Zusicherungen; der beschriebene Start ist auf die USA und Einzelkäufe begrenzt.
