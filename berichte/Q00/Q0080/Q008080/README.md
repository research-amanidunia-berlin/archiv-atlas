# More on Dota 2

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

OpenAI berichtet, dass sein durch Selbstspiel trainierter Dota-2-Bot innerhalb kurzer Zeit im 1-gegen-1-Modus Profis besiegte, aber durch ungewöhnliche Strategien weiterhin verwundbar war. Für den wesentlich komplexeren 5-gegen-5-Modus wollte das Team mit Verhaltensklonen aus 5,8 Millionen Expertenspielen beginnen; der Bericht belegt keine Übertragung der bisherigen Erfolge auf diesen Modus.
