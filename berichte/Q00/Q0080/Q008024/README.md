# A free version of ChatGPT built for teachers

Report Q008024 · Source openai.com · Date 2025-11-19 · [Open original](https://openai.com/index/chatgpt-for-teachers/)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

OpenAI kündigt ChatGPT for Teachers an und verspricht verifizierten US-K–12-Lehrkräften kostenlose Nutzung bis Juni 2028, mit Unterrichts-, Kollaborations- und Verwaltungsfunktionen. Datenschutz, Sicherheit und Unterstützung bei FERPA-Anforderungen werden als Eigenschaften des Angebots dargestellt, aber im Bericht nicht unabhängig überprüft; außerdem enthält der angefügte Abbildungsabschnitt sachfremde Bildunterschriften.
