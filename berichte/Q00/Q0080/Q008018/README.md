# Built to Benefit Everyone: OpenAI’s Updated Structure

Report Q008018 · Source openai.com · Date 2025-10-28 · [Open original](https://openai.com/index/built-to-benefit-everyone/)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

OpenAI zufolge kontrolliert die gemeinnützige OpenAI Foundation weiterhin das nun als Public Benefit Corporation organisierte Unternehmen und soll durch dessen Erfolg Mittel für gemeinnützige Vorhaben erhalten. Als anfängliches Engagement nennt der Bericht 25 Milliarden US-Dollar für Gesundheit und technische KI-Resilienz; die Darstellung stammt von OpenAI und führt weder die genauen Umsetzungsbedingungen noch unabhängige Bewertungen aus.
