# New embedding models and API updates

Bericht Q008037 · Quelle openai.com · Datum 2024-01-25 · [Original öffnen](https://openai.com/index/new-embedding-models-and-api-updates/)

[Alle Berichte](../../../README.de.md) · Daten: [bericht.json](bericht.json)

## Zusammenfassung (von Luna, ungeprüft)

OpenAI kündigt neue Einbettungsmodelle mit laut Bericht besseren Benchmarkwerten und niedrigeren Preisen für das kleine Modell an, außerdem Aktualisierungen für GPT‑3.5 Turbo, GPT‑4 Turbo und die Moderations-API. Neue Optionen sollen das Kürzen von Einbettungen, die Steuerung von API-Schlüsselrechten und die Auswertung des Verbrauchs je Schlüssel ermöglichen; die Leistungs- und Produktangaben stammen von OpenAI und werden im Bericht nicht unabhängig überprüft.
