# Introducing canvas

Report Q006710 · Source openai.com · Date 2024-10-03 · [Open original](https://openai.com/index/introducing-canvas/)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

OpenAI stellt Canvas als Beta-Oberfläche vor, in der Nutzende gemeinsam mit ChatGPT Schreib- und Programmierprojekte direkt bearbeiten, kommentieren und überarbeiten können. Interne Vergleiche hätten Verbesserungen bei Auslöserkennung, gezielten Änderungen und Kommentaren gezeigt; OpenAI betont jedoch die Abhängigkeit der Baseline von der Prompt-Formulierung und bezeichnet Canvas als noch frühe Beta.
