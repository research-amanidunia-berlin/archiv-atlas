# Zendesk uses OpenAI to build adaptive service agents focused on resolutions

## Summary (German, by Luna, unchecked)

Zendesk beschreibt gemeinsam mit OpenAI entwickelte Serviceagenten, die Gespräche kontextbezogen führen, Geschäftsabläufe berücksichtigen und mehrstufige Aufgaben ausführen sollen. Die Plattform wird noch erprobt; 80 Prozent Automatisierung sind ein Ziel, und umfassendere Kennzahlen standen laut Bericht erst später 2025 aus.
