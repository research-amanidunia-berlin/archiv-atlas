# Creating real-world data trusts: progress so far and the path ahead

Bericht Q006709 · Quelle oecd.ai · Datum 2022-02-14 · [Original öffnen](https://oecd.ai/en/wonk/creating-real-world-data-trusts-progress)

[Alle Berichte](../../../README.de.md) · Daten: [bericht.json](bericht.json)

## Zusammenfassung (von Luna, ungeprüft)

Der Bericht stellt erste GPAI-Untersuchungen zu Data Trusts vor: Sie umfassen Erfahrungen von 45 Forschenden und Praktikern sowie einen Vergleich rechtlicher Entwicklungen in elf Rechtsordnungen. Dem Beitrag zufolge wächst das Feld, doch Umsetzung, Rolle der Treuhänder und politische Schutz- und Rechenschaftsregeln sind noch offen und hängen vom jeweiligen Kontext ab.
