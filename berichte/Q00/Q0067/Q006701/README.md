# OECD Framework for Classifying AI Systems: two page overview

Report Q006701 · Source oecd.ai · Date 2022-02-18 · [Open original](https://oecd.ai/en/wonk/documents/oecd-framework-for-classifying-ai-systems-two-page-overview)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Der vorliegende Auszug beschreibt einen OECD-Rahmen, der KI-Systeme anhand von fünf Dimensionen einordnet und politische Debatten sowie die Entwicklung passender Maßnahmen unterstützen soll. Er nennt auch Register und Bestandslisten als mögliche Anwendung, liefert aber keine konkreten Wirksamkeitsbelege oder ausführlichen Details zu den Dimensionen.
