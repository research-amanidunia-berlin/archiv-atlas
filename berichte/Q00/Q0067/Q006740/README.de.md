# Better prompt caching for GPT-6

Bericht Q006740 · Quelle openai.com · Datum 2026-09-22 · [Original öffnen](https://openai.com/index/better-prompt-caching-for-gpt-6/)

[Alle Berichte](../../../README.de.md) · Daten: [bericht.json](bericht.json)

## Zusammenfassung (von Luna, ungeprüft)

OpenAI zufolge soll verbessertes Prompt-Caching für GPT‑6 gemeinsame Prompt-Präfixe häufiger wiederverwenden und dadurch Antwortzeiten und Kosten senken; für geeignete gecachte Eingaben nennt der Bericht Rabatte von bis zu 90 Prozent. Ein Dashboard, Diagnosewerkzeuge und Empfehlungen zu stabilen Werkzeugdefinitionen, Cache-Grenzen und Vorwärmen sollen die Optimierung erleichtern. Die im Text genannten Einsparungen stammen von Unternehmensvertretern und werden nicht unabhängig belegt.
