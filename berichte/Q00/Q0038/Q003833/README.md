# Restoring ancient text using deep learning: a case study on Greek epigraphy

Report Q003833 · Source deepmind.google · Date 2019-10-15 · [Open original](https://deepmind.google/blog/restoring-ancient-text-using-deep-learning-a-case-study-on-greek-epigraphy/)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Der Bericht beschreibt Pythia, ein neuronales System zur Ergänzung fehlender Zeichen in altgriechischen Inschriften, das mehrere Vorschläge samt Vertrauenswerten erzeugt und Kontext berücksichtigt. Auf dem eigens aufbereiteten PHI-ML-Korpus meldeten die Autoren eine Zeichenfehlerrate von 30,1 Prozent gegenüber 57,3 Prozent bei Oxford-Doktoranden; in 73,5 Prozent der Fälle war die richtige Folge unter den Top 20. Die Ergebnisse beziehen sich auf diesen Korpus und Vergleich; Pythia wird als Hilfsmittel dargestellt.
