## Summary (German, by Luna, unchecked)

DeepSeek kündigt V4-Flash-Vision-Exp als experimentelles multimodales API-Modell an. Laut Anbieter entspricht es bei Textaufgaben V4-Flash und verbessert die Ergebnisse bei multimodalen Agenten-Benchmarks deutlich; konkrete Werte oder unabhängige Prüfungen nennt der Bericht nicht. Bilder werden mit bis zu 384 Tokens zum V4-Flash-Preis abgerechnet, und die kostenlose Files API ermöglicht Wiederverwendung per `file_id`.
