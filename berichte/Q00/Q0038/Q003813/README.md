# Can AI automate Epoch?

Report Q003813 · Source epoch.ai · Date 2026-10-08 · [Open original](https://epoch.ai/publications/can-ai-automate-epoch)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Epoch testete sechs Modelle mit elf realen Aufgaben aus fünf Arbeitsbereichen. Fable 5.1 und GPT-6 Astra waren bei klar umrissenen Tätigkeiten am zuverlässigsten, scheiterten laut Bericht aber weiterhin an unausgesprochenen Qualitätsmaßstäben, gutem Forschungsdesign und der richtigen Deutung fehlerhafter Ergebnisse. Die Ergebnisse sind wegen kleiner Stichprobe, Einzelbewertungen, Epoch-spezifischer Aufgaben und unterschiedlicher Softwareumgebungen nur eingeschränkt verallgemeinerbar.
