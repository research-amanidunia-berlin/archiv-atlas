# Can AI scaling continue through 2030?

Report Q003854 · Source epoch.ai · Date 2024-08-20 · [Open original](https://epoch.ai/publications/can-ai-scaling-continue-through-2030)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Epoch AI schätzt, dass bis 2030 Trainingsläufe von etwa 2 × 10²⁹ FLOP technisch möglich sein könnten, sofern das bisherige Wachstum anhält. Am ehesten begrenzen Stromversorgung und Chipproduktion die Skalierung; die Schätzungen hängen jedoch von unsicheren Infrastruktur-, Effizienz- und Datenannahmen ab, und die nötigen Investitionen könnten Hunderte Milliarden Dollar kosten.
