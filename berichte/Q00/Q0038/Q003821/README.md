# Pandemic Resilience Developing an AI-calibrated ensemble of models to inform decision making

Report Q003821 · Source oecd.ai · Date 2025-05-18 · [Open original](https://oecd.ai/en/wonk/documents/pandemic-resilience-developing-an-ai-calibrated-ensemble-of-models-to-inform-decision-making)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Der Auszug beschreibt die Entwicklung und Erprobung eines KI-gestützt kalibrierten Modell-Ensembles, das für COVID-19 den Einsatz nichtpharmazeutischer Maßnahmen und mögliche Folgen für Gesundheit und Wirtschaft an verschiedenen Orten untersuchen sollte. Er nennt fünf Entwicklungsphasen, enthält aber keine konkreten Ergebnisse oder Empfehlungen, da der bereitgestellte Auszug vor deren Darstellung endet.
