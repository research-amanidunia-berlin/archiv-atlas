## Summary (German, by Luna, unchecked)

Die Autoren berichten, dass SelMo in Simulationen durch neugiergetriebenes Erkunden vielfältige Robotik-Verhaltensweisen hervorbrachte, die ohne konkrete Zielaufgabe gelernt wurden. Beim JACO-Arm beschleunigte die Wiederverwendung selbst entdeckter Verhaltensweisen laut Bericht das Lernen, einen Würfel anzuheben; die Fähigkeiten können während weiterer Exploration jedoch wieder überschrieben werden.
