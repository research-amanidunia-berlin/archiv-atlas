# Doppel’s AI defense system stops attacks before they spread

Report Q003803 · Source openai.com · Date 2025-10-28 · [Open original](https://openai.com/index/doppel/)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Doppel beschreibt ein KI-System, das digitale Bedrohungen mit GPT-5 und einem durch Analystenfeedback trainierten o4-mini erkennt, einstuft und bei hoher Sicherheit eigenständig Maßnahmen auslöst. Das Unternehmen berichtet von 80 Prozent weniger Analystenaufwand, dreifacher Bearbeitungskapazität und Reaktionen binnen Minuten; der Bericht nennt dazu keine Messmethodik oder unabhängige Prüfung.
