# Cohere's Command A+ Model

Bericht Q004904 · Quelle docs.cohere.com · Datum – · [Original öffnen](https://docs.cohere.com/docs/command-a-plus)

[Alle Berichte](../../../README.de.md) · Daten: [bericht.json](bericht.json)

## Zusammenfassung (von Luna, ungeprüft)

Cohere beschreibt Command A+ als mehrsprachiges Text- und Bildmodell für agentische Aufgaben, das auf einer sparsamen Expertenarchitektur beruht und in bestimmten Hardwarekonfigurationen bereitgestellt werden kann. Die behaupteten Leistungsverbesserungen sind im Bericht nicht durch Vergleichsdaten belegt; auch die Nutzung von Eingaben hängt laut Text davon ab, ob das Modell kundenseitig oder Cohere-gehostet betrieben wird.

## Sammelfragen

Je Zelle: Anteil Stufe 4–7 / Stufe 3–7 (4 = enthält zitierbare Belege … 7 = beantwortet direkt; 3 = nützlicher Hintergrund).
