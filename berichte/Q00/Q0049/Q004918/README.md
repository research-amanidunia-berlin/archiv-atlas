## Summary (German, by Luna, unchecked)

Der vorliegende Auszug fasst eine Analyse der US-KI-Belegschaft zusammen: Diese sei geografisch konzentriert und von 2015 bis 2019 gewachsen, wobei sich Arbeitsmarkttrends je nach Beruf unterschieden. Einen allgemeinen Fachkräftemangel behaupten die Autorinnen nicht; mögliche Engpässe sehen sie eher bei Informatik- und Informationsforschenden, während sie bei anderen untersuchten Berufen weniger Hinweise darauf finden.
