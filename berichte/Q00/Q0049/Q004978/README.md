## Summary (German, by Luna, unchecked)

Der bereitgestellte Text ist ein Auszug aus einem CSET-Bericht, der anhand eines Datensatzes mit 469 Laboren Chinas Staatliches Schlüssellabor-System beschreibt. Die Autoren betonen dessen Bedeutung für Forschung, Fachkräftegewinnung und Innovation sowie mögliche Risiken durch geringe Transparenz; für das Ziel von 700 Laboren bis 2020 fanden sie keinen Beleg, dass es erreicht wurde.
