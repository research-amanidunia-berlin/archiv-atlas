# Independent Reviewers release first annual report on DeepMind Health

Bericht Q004977 · Quelle deepmind.google · Datum 2017-07-05 · [Original öffnen](https://deepmind.google/blog/independent-reviewers-release-first-annual-report-on-deepmind-health/)

[Alle Berichte](../../../README.de.md) · Daten: [bericht.json](bericht.json)

## Zusammenfassung (von Luna, ungeprüft)

DeepMind Health berichtet über den ersten Jahresbericht eines unabhängigen Gremiums, das laut den Autoren vollen Zugang zur Arbeit des Unternehmens hatte. Das Unternehmen sagt Änderungen sowie eine stärkere Einbindung von Patienten und NHS-Gruppen zu, nennt aber weder die konkreten Prüfergebnisse noch die einzelnen Maßnahmen.
