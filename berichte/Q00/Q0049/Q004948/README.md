# Working with the NHS to build lifesaving technology

Report Q004948 · Source deepmind.google · Date 2016-11-22 · [Open original](https://deepmind.google/blog/working-with-the-nhs-to-build-lifesaving-technology/)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

DeepMind kündigt 2016 eine fünfjährige Zusammenarbeit mit dem Royal Free an, um mit der App Streams Klinikteams früher über mögliche akute Nierenschädigungen zu informieren und das System später auf weitere Erkrankungen auszuweiten. Der Bericht beschreibt erwartete Vorteile sowie geplante Datenschutzkontrollen, belegt die prognostizierten Wirkungen aber nicht und enthält keine späteren Ergebnisse.
