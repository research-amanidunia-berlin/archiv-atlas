# From co-generated data to generative AI

Report Q004908 · Source oecd.ai · Date 2024-12-04 · [Open original](https://oecd.ai/en/wonk/documents/from-co-generated-data-to-generative-ai)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Der Bericht untersucht anhand von sechs Fällen, welche Rechte bei gemeinsam erzeugten Daten und Ergebnissen gelten können. Er beschreibt ein komplexes Geflecht bestehender Rechte, zugleich aber Lücken bei Technologie, KI-generierten Werken und kollektiven Ansprüchen; gerade für generative KI bleibe die Rechtslage schwer zu bestimmen.
