# 02 – Social media governance project: Summary of work in 2024

Report Q004943 · Source oecd.ai · Date 2024-12-03 · [Open original](https://oecd.ai/en/wonk/documents/02-social-media-governance-project-summary-of-work-in-2024)

## Summary (German, by Luna, unchecked)

Der Auszug stellt die Arbeit des GPAI-Projekts zur Governance sozialer Medien im Jahr 2024 vor und nennt drei Themen: Erkennung KI-generierter Inhalte, Empfehlungssysteme und Klassifikatoren für schädliche Inhalte. Er erläutert die Relevanz des Feldes, enthält aber keine konkreten Methoden oder Ergebnisse der Projektarbeit.
