# Scaling laws of learning from repeated data

Bericht Q004946 · Quelle anthropic.com · Datum 2022-05-21 · [Original öffnen](https://www.anthropic.com/research/scaling-laws-and-interpretability-of-learning-from-repeated-data)

[Alle Berichte](../../../README.de.md) · Daten: [bericht.json](bericht.json)

## Zusammenfassung (von Luna, ungeprüft)

Der vorliegende Auszug berichtet, dass wiederholte Trainingsdaten bei bestimmten Häufigkeiten die Testleistung von Sprachmodellen stark verschlechtern können; als Beispiel wird ein 800-Millionen-Parameter-Modell genannt, das dadurch auf das Niveau eines halb so großen Modells fällt. Als mögliche Erklärung vermuten die Forschenden, dass Memorieren Kapazität beansprucht und Strukturen für Generalisierung beeinträchtigt; der Text enthält nur den Abstract, nicht den vollständigen Bericht.
