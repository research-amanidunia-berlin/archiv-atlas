## Summary (German, by Luna, unchecked)

Der bereitgestellte Auszug beschreibt einen OECD-Leitfaden zur Einschätzung, wie Organisationen KI für den Weg zu Netto-Null nutzen können. Er nennt fünf Bereiche der KI-Bereitschaft und vier Fallstudiensektoren, enthält aber keine konkreten Checklisten oder Fallstudienergebnisse.
