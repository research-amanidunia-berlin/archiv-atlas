# Optimal stopping: spending evaluation compute where it counts

Report Q000921 · Source aisi.gov.uk · Date 2026-08-27 · [Open original](https://www.aisi.gov.uk/blog/optimal-stopping-spending-evaluation-compute-where-it-counts)

## Summary (German, by Luna, unchecked)

AISI beschreibt optstop als Werkzeug, das KI-Evaluationen anhand laufender Unsicherheit vorzeitig beenden kann, wenn Messungen präzise genug oder stabil sind. In den berichteten Tests auf öffentlichen Benchmarks sparte es laut AISI 57 bis 97 Prozent der geplanten Durchläufe, ohne die geschätzten Punktzahlen zu verändern; die Aufgaben müssen dafür randomisiert angeordnet sein.
