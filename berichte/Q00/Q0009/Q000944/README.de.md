# Claude discovers a novel enzyme system

Bericht Q000944 · Quelle anthropic.com · Datum 2026-09-23 · [Original öffnen](https://www.anthropic.com/research/claude-discovers-novel-enzyme-system)

[Alle Berichte](../../../README.de.md) · Daten: [bericht.json](bericht.json)

## Zusammenfassung (von Luna, ungeprüft)

Anthropic berichtet, Claude habe bei der Suche in DNA-Daten ein bislang nicht charakterisiertes System namens ART erkannt: eine reverse Transkriptase mit benachbartem Gen und einem Array von DNA-Wiederholungen. Erste Labortests fanden kurze RNAs, doch Funktion und mögliche CRISPR-ähnliche Programmierbarkeit sind ungeklärt; die Untersuchungen dauern an.
