# Mistral x Mozilla: Private, Multilingual AI Browsing

Report Q000930 · Source mistral.ai · Date – · [Open original](https://mistral.ai/news/mistral-x-mozilla/)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Mistral-Modelle sollen Mozillas Firefox Smart Window antreiben, das in der Beta bei Suchen und beim Wiederfinden von Informationen aus Browser-Tabs helfen soll. Die Unternehmen betonen offene Technologie, regionale Anpassung und Datenschutz; die genannten Schutzmaßnahmen und Ziele werden im Beitrag jedoch nicht unabhängig geprüft.
