# How quantum technologies could open new frontiers for AI

Report Q000913 · Source oecd.ai · Date 2026-07-06 · [Open original](https://oecd.ai/en/wonk/how-quantum-technologies-could-open-new-frontiers-for-ai)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Der Beitrag beschreibt mögliche Ergänzungen von KI durch Quantencomputing, Quantensensoren und Quantenkommunikation. Während quanteninspirierte Tensor-Netzwerk-Kompression bereits auf klassischer Hardware untersucht und eingesetzt wird, seien QML und sichere Quantenkommunikation noch mit erheblichen offenen Fragen verbunden; die skizzierten Anwendungen sind vielfach Zukunftsmöglichkeiten.
