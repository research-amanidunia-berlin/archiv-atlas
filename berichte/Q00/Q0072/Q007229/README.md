# Supporting Europe’s work in ensuring a trustworthy AI ecosystem

Report Q007229 · Source openai.com · Date 2026-06-11 · [Open original](https://openai.com/index/supporting-eu-trustworthy-ai-ecosystem/)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

OpenAI kündigt seine Unterstützung für den EU-Kodex zur Transparenz KI-generierter Inhalte an und beschreibt eigene Maßnahmen wie C2PA-Metadaten, SynthID-Wasserzeichen und ein öffentliches Prüfwerkzeug. Zugleich räumt der Bericht ein, dass Metadaten verloren gehen, Wasserzeichen schwächer werden und Kennzeichnungen übersehen werden können; die Verfahren seien noch ausbaufähig. Die Darstellung der Fortschritte stammt von OpenAI und enthält keine unabhängige Bewertung.
