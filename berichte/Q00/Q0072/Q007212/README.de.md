## Zusammenfassung (von Luna, ungeprüft)

OpenAI stellt GPT‑5 für die API als Modell für Coding und agentische Aufgaben vor und berichtet über hohe Ergebnisse in mehreren Programmier-, Werkzeugnutzungs- und Langkontext-Benchmarks. Neu sind unter anderem einstellbarer Denkaufwand und Antwortlänge, Klartext-Werkzeuge sowie drei Modellgrößen. Die Leistungswerte stammen aus OpenAI-Auswertungen und ausgewählten Rückmeldungen; einzelne Tests haben ausdrücklich genannte Einschränkungen.
