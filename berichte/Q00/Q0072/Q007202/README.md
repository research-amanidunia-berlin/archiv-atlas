# Intercom's three lessons for creating a sustainable AI advantage

Report Q007202 · Source openai.com · Date 2025-07-30 · [Open original](https://openai.com/index/intercom/)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Der Beitrag zufolge baut Intercom seinen KI-Kundendienst auf frühem Experimentieren, systematischen Modelltests und einer modularen Architektur auf. Das Unternehmen berichtet, GPT‑4.1 habe bei Fin Tasks Zuverlässigkeit erhöht und gegenüber GPT‑4o 20 Prozent Kosten eingespart; die genannten Ergebnisse beruhen auf Intercoms eigenen Auswertungen. Die geplante Ausweitung auf weitere Geschäftsbereiche wird beschrieben, aber nicht unabhängig belegt.
