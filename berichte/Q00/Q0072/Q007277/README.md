# Introducing data residency in Asia

Report Q007277 · Source openai.com · Date 2025-05-07 · [Open original](https://openai.com/index/introducing-data-residency-in-asia/)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

OpenAI beschreibt Datenresidenz für ChatGPT Enterprise, ChatGPT Edu und die API in Japan, Indien, Singapur und Südkorea. Neue Enterprise- und Edu-Workspaces sowie berechtigte API-Projekte können Inhalte laut Bericht in der ausgewählten Region im Ruhezustand speichern lassen; OpenAI nennt dazu Verschlüsselung und weitere Datenschutzmaßnahmen. Die Angaben sind Unternehmensbehauptungen, und Einzelheiten zu Berechtigung und unterstützten Daten verweist der Bericht auf separate Hilfeseiten.
