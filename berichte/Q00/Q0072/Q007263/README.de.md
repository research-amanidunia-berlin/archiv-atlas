# OpenAI and Reddit Partnership

Bericht Q007263 · Quelle openai.com · Datum 2024-05-16 · [Original öffnen](https://openai.com/index/openai-and-reddit-partnership/)

[Alle Berichte](../../../README.de.md) · Daten: [bericht.json](bericht.json)

## Zusammenfassung (von Luna, ungeprüft)

OpenAI und Reddit kündigen eine Partnerschaft an: OpenAI soll Reddit-Inhalte über die Data API in ChatGPT und weitere Produkte einbinden; Reddit will mit OpenAIs Modellen KI-Funktionen für Nutzer und Moderation entwickeln. Zudem wird OpenAI Reddit-Werbepartner. Der Bericht beschreibt die Ziele der Unternehmen, liefert aber keine unabhängige Bewertung oder konkreten Ergebnisse.
