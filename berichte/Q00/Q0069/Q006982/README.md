## Summary (German, by Luna, unchecked)

Der Bericht beschreibt einen internationalen Vergleich amtlicher Messungen zur KI-Nutzung in Unternehmen, einschließlich Definitionen und Fragen in IKT-Erhebungen. Der vorliegende Text ist nur eine knappe Inhaltsbeschreibung und enthält keine konkreten Vergleichswerte oder Ergebnisse.
