# Updating the ECI methodology to use a Bayesian model

Bericht Q006953 · Quelle epoch.ai · Datum 2026-11-04 · [Original öffnen](https://epoch.ai/publications/eci-bayesian-methodology)

[Alle Berichte](../../../README.de.md) · Daten: [bericht.json](bericht.json)

## Zusammenfassung (von Luna, ungeprüft)

Der unvollständige Berichtsauszug beschreibt Epoch AIs Wechsel beim ECI zu einem Bayes-Modell, das Unsicherheit über Verteilungen schätzt und Benchmark-spezifisches Rauschen berücksichtigt. Laut den gezeigten Ergebnissen bleiben Frontier-Schätzungen ähnlich, während schwächere Modelle meist niedrigere Werte erhalten; die Modellprüfung ist gemischt und Teile für eine Gesamtbewertung fehlen.
