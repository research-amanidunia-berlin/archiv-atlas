# GPAI’s AI and Pandemic Response Working Group work in 2021

Report Q006910 · Source oecd.ai · Date 2021-06-09 · [Open original](https://oecd.ai/en/wonk/gpai-pandemic-response-in-2021)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Der Bericht beschreibt zwei GPAI-Projekte für 2021: eines soll KI-Initiativen zur Pandemiebekämpfung erfassen, bewerten und mögliche Förderkandidaten auswählen; das andere soll Empfehlungen zur Förderung offener KI-Forschung für die Arzneimittelentwicklung erarbeiten. Er nennt Ziele und geplante Methoden, aber keine abgeschlossenen Ergebnisse.
