# Zico Kolter Joins OpenAI’s Board of Directors

Report Q006928 · Source openai.com · Date 2024-08-08 · [Open original](https://openai.com/index/zico-kolter-joins-openais-board-of-directors/)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

OpenAI beruft den KI-Sicherheitsforscher und Carnegie-Mellon-Professor Zico Kolter in seinen Verwaltungsrat und den Sicherheits- und Sicherheitsausschuss. Die Mitteilung verweist auf seine Forschung zu robusten Modellen und automatisierten Sicherheitsprüfungen, bewertet aber weder die Ernennung unabhängig noch die künftige Ausschussarbeit.
