# Jeff Ding's Testimony Before the U.S.-China Economic and Security Review Commission

Report Q006041 · Source cset.georgetown.edu · Date 2019-06-07 · [Open original](https://cset.georgetown.edu/publication/chinas-current-capabilities-policies-and-industrial-ecosystem-in-ai/)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Der Auszug aus Jeff Dings Aussage bewertet die USA als strukturell führend in mehreren Grundlagen- und Technologiebereichen der KI; China stehe laut seiner Einschätzung nicht kurz vor einem Überholen. Er skizziert Chinas KI-Plan von 2017 und ein Ökosystem aus Technologiekonzernen und Start-ups, enthält aber weder ausführliche Belege noch die angekündigten politischen Empfehlungen.
