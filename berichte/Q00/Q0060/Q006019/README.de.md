# Understanding LLM Embeddings for Regression

Bericht Q006019 · Quelle deepmind.google · Datum 2024-11-22 · [Original öffnen](https://deepmind.google/research/publications/135718/)

[Alle Berichte](../../../README.de.md) · Daten: [bericht.json](bericht.json)

## Zusammenfassung (von Luna, ungeprüft)

Der Abstract berichtet, dass LLM-Embeddings bei hochdimensionaler Regression traditionelle Merkmale übertreffen können, und führt dies teilweise auf die erhaltene Lipschitz-Stetigkeit numerischer Daten zurück. Er merkt zugleich an, dass größere Modelle und stärkeres Sprachverständnis die Leistung nicht immer verbessern; konkrete Versuchsdaten enthält der Auszug nicht.
