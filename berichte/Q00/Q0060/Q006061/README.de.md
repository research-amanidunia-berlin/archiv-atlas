# Build times for gigawatt-scale data centers

Bericht Q006061 · Quelle epoch.ai · Datum 2025-11-10 · [Original öffnen](https://epoch.ai/data-insights/data-centers-buildout-speeds)

[Alle Berichte](../../../README.de.md) · Daten: [bericht.json](bericht.json)

## Zusammenfassung (von Luna, ungeprüft)

Der bereitgestellte Epoch-AI-Berichtsauszug schätzt, dass erfasste US-Rechenzentren nach Baubeginn in ein bis 3,6 Jahren 1 GW erreichen könnten; für xAIs Colossus 2 werden zwölf Monate veranschlagt. Die Schätzungen beruhen auf Satellitenbildern, Genehmigungen und Unternehmensangaben, und die aufgeführten Meilensteine bezeichnen erwartete früheste Zeitpunkte, keine bestätigten Ergebnisse.
