# US adults are no more likely to face cyber incidents than when Claude Fable 5 launched

Report Q006040 · Source epoch.ai · Date 2026-10-07 · [Open original](https://epoch.ai/data-insights/cyber-incidents-flat-since-fable-5)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

In zwei Umfragen von Epoch AI/Ipsos meldeten im Juni und September 2026 jeweils rund 45 Prozent der befragten US-Erwachsenen mindestens einen Cybervorfall im vergangenen Jahr; eine statistisch verlässliche Zunahme wurde nicht festgestellt. Der Bericht betont, dass andere Hinweise auf wachsende KI-Cyberfähigkeiten keinen Anstieg selbstberichteter Vorfälle in der Bevölkerung belegen und dass die Umfragen keinen ursächlichen Zusammenhang nachweisen.
