# Profile Highlight: HuggingFace

Report Q006007 · Source cset.georgetown.edu · Date 2022-12-07 · [Open original](https://cset.georgetown.edu/publication/profile-highlight-huggingface/)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Der Beitrag beschreibt Hugging Faces Aufstieg zu einem bedeutenden Anbieter von Open-Source-KI-Modellen und -Werkzeugen und führt den GitHub-Aktivitätsanstieg 2019 unter anderem auf die Transformers-Veröffentlichung zurück. Der Autor sieht Open Source als wichtigen Wachstumstreiber, doch die dargestellten Daten reichen bis 2021 und belegen weder einen Vergleich mit anderen Unternehmen noch eine alleinige Ursache des Erfolgs.
