# Disclosed CVEs: July reached 5× the pre-Mythos record

Report Q006032 · Source epoch.ai · Date 2026-07-31 · [Open original](https://epoch.ai/data-insights/cve-severity-spike-july-2026)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Epoch AI zufolge wurden im Juli 2026 etwa 2.500 hoch oder kritisch bewertete CVEs veröffentlicht – rund fünfmal so viele wie der monatliche Rekord vor der Mythos-Ankündigung und 60 Prozent mehr als im Juni. Der Bericht verweist zudem auf Unternehmensberichte über erfolgreiche oder unbefugte Cyberzugriffe durch Modelle, betont aber Unterschiede bei der Meldung von CVEs und belegt keine Ursache für den Anstieg.
