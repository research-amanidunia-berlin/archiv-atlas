# Applying machine learning to mammography screening for breast cancer

Bericht Q006091 · Quelle deepmind.google · Datum 2017-11-24 · [Original öffnen](https://deepmind.google/blog/applying-machine-learning-to-mammography-screening-for-breast-cancer/)

[Alle Berichte](../../../README.de.md) · Daten: [bericht.json](bericht.json)

## Zusammenfassung (von Luna, ungeprüft)

DeepMind und Forschungspartner wollen anhand anonymisierter Mammografien von rund 7.500 Frauen untersuchen, ob maschinelles Lernen Brustkrebs zuverlässiger erkennen und Fachleute besser unterstützen kann. Der Bericht beschreibt das Vorhaben als frühe, explorative Forschung und enthält noch keine Ergebnisse, die einen Nutzen belegen.
