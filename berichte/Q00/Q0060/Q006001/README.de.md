# Global GitHub: Mapping the Utilization of Open Source Software by Organizations

Bericht Q006001 · Quelle cset.georgetown.edu · Datum 2022-11-09 · [Original öffnen](https://cset.georgetown.edu/publication/global-github-mapping-the-utilization-of-open-source-software-by-organizations/)

[Alle Berichte](../../../README.de.md) · Daten: [bericht.json](bericht.json)

## Zusammenfassung (von Luna, ungeprüft)

Der Bericht stellt mögliche Vorteile von GitHub für Organisationen dar und wertet die geografische Verteilung verifizierter Organisationen mit öffentlichen Projekten in einem begrenzten CSET-Datensatz aus. Die USA führen bei der Gesamtzahl, während seit 2019 mehr Organisationen außerhalb der USA hinzukamen; die Daten erfassen jedoch nicht alle GitHub-Nutzer oder -Projekte und der Text nennt keine konkreten Prozentwerte.
