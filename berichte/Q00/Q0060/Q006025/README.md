# VfL Wolfsburg turns ChatGPT into a club-wide capability

Report Q006025 · Source openai.com · Date 2026-03-05 · [Open original](https://openai.com/index/vfl-wolfsburg/)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Der Bericht beschreibt, wie VfL Wolfsburg ChatGPT Enterprise mithilfe maßgeschneiderter GPTs in Arbeitsabläufe von Verwaltung, Kommunikation, Marketing und weiteren Bereichen integriert. Er nennt über 50 täglich genutzte GPTs sowie schnellere Abläufe und geringere Agenturkosten, beziffert die jährlichen Einsparungen jedoch widersprüchlich mit über einer Million beziehungsweise einem sechsstelligen Betrag; Belege oder Berechnungsmethoden fehlen.
