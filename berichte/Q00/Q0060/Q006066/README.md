# The size of datasets used to train language models doubles approximately every six months

Report Q006066 · Source epoch.ai · Date 2024-06-19 · [Open original](https://epoch.ai/data-insights/dataset-size-trend)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Epoch AI zufolge verdoppelt sich die Größe von Sprachmodell-Trainingsdatensätzen ungefähr alle sechs Monate; die größten Modelle nutzten demnach Datensätze mit mehreren zehn Billionen Wörtern. Der Auszug ergänzt eine umfangreiche Modelltabelle, erklärt aber weder ihre Auswahl und Messmethodik noch die uneinheitlichen Größenangaben in Datenpunkten, Wörtern und Tokens.
