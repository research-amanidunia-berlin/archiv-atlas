## Zusammenfassung (von Luna, ungeprüft)

OpenAI führt laut Bericht die optionale Funktion „Trusted Contact“ ein: Bei Gesprächen, die auf eine ernsthafte Selbstgefährdung hindeuten könnten, prüft ein geschultes Team den Fall, bevor eine knappe Benachrichtigung an eine zuvor bestätigte Vertrauensperson geht. Die Funktion soll reale Unterstützung ergänzen, nicht professionelle Hilfe ersetzen; OpenAI weist darauf hin, dass Meldungen die Situation nicht immer genau abbilden.
