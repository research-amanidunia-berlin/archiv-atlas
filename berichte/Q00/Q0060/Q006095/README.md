## Summary (German, by Luna, unchecked)

Der Bericht beschreibt das Relation Network, das gelernte Beziehungen zwischen Objekten für visuelle und textbasierte Fragen nutzt, und das Visual Interaction Network, das aus wenigen Videobildern physische Entwicklungen vorhersagt.
