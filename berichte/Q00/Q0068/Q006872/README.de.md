# We didn’t learn much from the IMO

## Zusammenfassung (von Luna, ungeprüft)

Greg Burnham zufolge zeigt das Lösen von fünf IMO-Aufgaben 2025 vor allem zuverlässige Leistungen bei leichten bis mittelschweren Problemen; die ungewöhnliche Schwierigkeitsverteilung erlaubt kaum Rückschlüsse auf neue mathematische Fähigkeiten. Die sehr schwere, ungelöste Aufgabe verlangte laut ihm Abstraktion und Kreativität, während frühere KI-Ergebnisse bereits nahe an die gelösten Aufgaben heranreichten.
