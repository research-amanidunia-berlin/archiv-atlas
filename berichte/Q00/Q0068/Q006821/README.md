# Thinking with images

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Der Bericht stellt OpenAI o3 und o4-mini als Modelle vor, die Bilder während des Schlussfolgerns mit Werkzeugen verändern und genauer untersuchen können, und nennt Beispiele sowie von OpenAI berichtete Benchmark-Erfolge. Er weist auf mögliche Wahrnehmungsfehler, unnötig lange Verarbeitung und schwankende Zuverlässigkeit hin; zudem seien die Modelle inzwischen in ChatGPT nicht mehr verfügbar und in der API abgekündigt.
