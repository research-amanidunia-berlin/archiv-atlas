# Color Health uses the reasoning capabilities of GPT-4o to help doctors transform cancer care

Report Q006832 · Source openai.com · Date – · [Open original](https://openai.com/index/color-health/)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Color Health und OpenAI entwickelten laut Bericht einen ärztlich überwachten GPT‑4o-Copiloten, der fehlende Krebsdiagnostik erkennen und personalisierte Abklärungspläne vorbereiten soll. Color meldet in einer begrenzten Einführung mehr erkannte Befundlücken und eine durchschnittliche Analysezeit von fünf Minuten; eine UCSF-Auswertung war erst geplant, sodass der Bericht keine abgeschlossene Wirksamkeitsprüfung belegt. Die bereitgestellte Fassung endet mitten in einer Bildbeschreibung.
