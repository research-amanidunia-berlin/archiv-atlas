# The least understood driver of AI progress

Report Q006825 · Source epoch.ai · Date 2026-02-25 · [Open original](https://epoch.ai/gradient-updates/the-least-understood-driver-of-ai-progress)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Der Bericht schätzt, dass KI-Software die für vergleichbare Fähigkeiten nötige Trainingsrechenleistung womöglich jedes Jahr um ein Mehrfaches senkt; Ho nennt persönlich etwa den Faktor zehn, betont aber die große Unsicherheit der Schätzung. Ein Teil der gemessenen Fortschritte könnte von besseren Daten und wenigen Innovationen stammen, deren Nutzen mit größerem Trainingscompute wächst. Diese Compute-Abhängigkeit könnte eine selbstverstärkende KI-Forschung bremsen, doch die Belege reichen laut Autor nicht für eine sichere Prognose.
