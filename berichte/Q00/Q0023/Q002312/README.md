# Evaluating Multimodal Interactive Agents

Report Q002312 · Source deepmind.google · Date 2022-05-27 · [Open original](https://deepmind.google/blog/evaluating-multimodal-interactive-agents/)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Die STS bewertet Agentenfortsetzungen in Szenarien, die aus menschlichen Interaktionen stammen und in einer 3D-Simulation offline abgespielt werden; Menschen markieren die Ergebnisse als Erfolg oder Misserfolg. Die Autorinnen und Autoren berichten eine Korrelation von Spearman r=0,81 mit interaktiver Evaluation, während menschliche Bewertungen weiterhin nötig sind und eine Automatisierung nur als mögliche künftige Entwicklung erscheint.
