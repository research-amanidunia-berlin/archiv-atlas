## Summary (German, by Luna, unchecked)

Der vorgelegte Text ist ein Auszug; die vollständige Übersetzung samt Anhängen fehlt. Laut Bericht verlangt die Bekanntmachung für bestimmte Ausfuhren von Gütern mit chinesischen seltenen Erden eine MOFCOM-Genehmigung und soll auch bestimmte im Ausland gefertigte Produkte erfassen; Anträge für militärische und weitere kontrollierte Nutzer werden grundsätzlich nicht genehmigt.
