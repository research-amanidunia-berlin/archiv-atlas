# Building a culture of pioneering responsibly

Report Q002348 · Source deepmind.google · Date 2022-05-24 · [Open original](https://deepmind.google/blog/building-a-culture-of-pioneering-responsibly/)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Lila Ibrahim beschreibt verantwortungsvolle Technologieentwicklung als fortlaufende Aufgabe: KI könne gesellschaftlichen Nutzen bringen, aber auch Ungleichheiten und Vorurteile verstärken. Sie nennt offene interne Beratung, kontinuierliche Verbesserung anhand von Rückmeldungen, externe Expertise und die Beteiligung betroffener Gemeinschaften als Bestandteile des DeepMind-Ansatzes. Der persönliche Beitrag bewertet nicht unabhängig, wie wirksam die beschriebenen Maßnahmen sind.
