# Task scam: AI-assisted fake review jobs

Report Q002334 · Source openai.com · Date 2025-02-01 · [Open original](https://openai.com/index/disrupting-malicious-uses-of-ai-task-scam/)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Laut OpenAI nutzte ein mutmaßlich aus Kambodscha operierendes Netzwerk ChatGPT, um Nachrichten für gefälschte Bewertungsjobs zu übersetzen und Interessierte schrittweise zu Zahlungen zu bewegen. Der Bericht stützt sich auf begrenzte Einblicke: Einige Betroffene wirkten skeptisch, doch Gespräche und Online-Berichte deuteten darauf hin, dass zumindest manche Geld einzahlten; Vorgänge außerhalb von OpenAIs Werkzeugen seien nicht unabhängig überprüfbar.
