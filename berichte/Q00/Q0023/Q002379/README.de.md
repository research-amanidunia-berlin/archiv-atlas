# Code execution with MCP for efficient agents

Bericht Q002379 · Quelle anthropic.com · Datum 2025-11-04 · [Original öffnen](https://www.anthropic.com/research/code-execution-with-mcp)

[Alle Berichte](../../../README.de.md) · Daten: [bericht.json](bericht.json)

## Zusammenfassung (von Luna, ungeprüft)

Anthropic argumentiert, dass Codeausführung MCP-Agenten effizienter machen kann: Sie laden nur benötigte Werkzeugbeschreibungen und verarbeiten Zwischendaten außerhalb des Modellkontexts. Eine im Bericht genannte Einsparung von 98,7 Prozent gilt für das beschriebene Beispiel; zugleich erfordert der Ansatz eine sichere, überwachte Ausführungsumgebung und zusätzlichen Betriebsaufwand.
