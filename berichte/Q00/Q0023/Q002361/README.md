# When it comes to AI incidents, safety and security are not the same

Report Q002361 · Source oecd.ai · Date 2025-08-25 · [Open original](https://oecd.ai/en/wonk/when-it-comes-to-ai-incidents-safety-and-security-are-not-the-same)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Der Beitrag hält den OECD-Rahmen für eine brauchbare gemeinsame Grundlage zur Meldung von KI-Vorfällen, sieht aber fehlende Angaben für den Umgang mit absichtlichen Angriffen und Schwachstellen. Er empfiehlt sicherheitsspezifische Ergänzungen oder gekennzeichnete Parallelprozesse, ohne allgemeine Schadensfälle in ein Cybersecurity-Schema zu zwingen; die Vorschläge werden argumentativ, nicht empirisch geprüft.
