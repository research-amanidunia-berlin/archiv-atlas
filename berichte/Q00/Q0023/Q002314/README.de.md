# Effective harnesses for long-running agents

Bericht Q002314 · Quelle anthropic.com · Datum 2025-11-26 · [Original öffnen](https://www.anthropic.com/research/effective-harnesses-for-long-running-agents)

[Alle Berichte](../../../README.de.md) · Daten: [bericht.json](bericht.json)

## Zusammenfassung (von Luna, ungeprüft)

Anthropic beschreibt einen Ablauf für Coding-Agenten, die über mehrere Sitzungen hinweg an Projekten arbeiten: Ein erster Agent richtet Arbeitsumgebung, Fortschrittsnotizen und eine Funktionsliste ein; spätere Agenten bearbeiten jeweils einzelne Funktionen und dokumentieren geprüfte Änderungen. Laut den berichteten Versuchen halfen schrittweises Arbeiten und Browser-Tests, doch Werkzeuge erkannten nicht alle Fehler, und die Übertragbarkeit auf andere Aufgaben ist noch offen.
