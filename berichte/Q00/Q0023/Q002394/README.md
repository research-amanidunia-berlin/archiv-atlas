# Is generative AI a General Purpose Technology? Implications for productivity and policy

Report Q002394 · Source oecd.ai · Date 2025-06-27 · [Open original](https://oecd.ai/en/ai-publications/is-generative-ai-a-general-purpose-technology-implications-for-productivity-and-policy)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Der bereitgestellte Auszug berichtet, die Studie sehe in generativer KI das Potenzial einer Allzwecktechnologie: Sie könne breit eingesetzt werden, sich weiter verbessern und zusätzliche Innovationen anstoßen. Deutliche Produktivitätsgewinne könnten laut Studie erst langfristig entstehen und hingen auch von geeigneter Politik ab; konkrete Zahlen oder Maßnahmen nennt der Auszug nicht.
