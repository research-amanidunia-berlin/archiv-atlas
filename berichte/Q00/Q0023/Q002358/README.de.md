# OpenAI to acquire Pierre Computer Company, Inc.

Bericht Q002358 · Quelle openai.com · Datum 2026-11-04 · [Original öffnen](https://openai.com/index/openai-to-acquire-pierre/)

[Alle Berichte](../../../README.de.md) · Daten: [bericht.json](bericht.json)

## Zusammenfassung (von Luna, ungeprüft)

OpenAI will Pierre Computer Company übernehmen, das unter anderem die in Codex verwendeten Entwicklerwerkzeuge Trees und Diffs sowie Code Storage entwickelt. Das Unternehmen plant, die Git- und Codeprüfungsfunktionen gemeinsam weiterzuentwickeln; Pierres Open-Source-Projekte sollen offen bleiben. Der Abschluss steht noch aus und ist unter anderem von behördlichen Genehmigungen abhängig.
