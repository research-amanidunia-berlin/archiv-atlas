## Zusammenfassung (von Luna, ungeprüft)

Eine viermonatige Analyse von ChatGPT-Nachrichten zeigt laut OpenAI, dass Beschäftigte KI wiederholt auch für Aufgaben außerhalb ihres üblichen Berufsfelds nutzen; die Häufigkeit variiert deutlich je nach Tätigkeit. Der Bericht sieht darin einen möglichen Hinweis auf breitere Aufgabenprofile, weist aber anhand der Nutzungsdaten nicht nach, dass sich formale Jobverantwortung dauerhaft verändert oder KI diese Entwicklung verursacht hat.
