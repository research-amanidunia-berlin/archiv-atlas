# SchoolAI builds an AI platform that empowers teachers

Report Q003471 · Source openai.com · Date 2025-09-22 · [Open original](https://openai.com/index/schoolai/)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Der Bericht stellt SchoolAI als KI-Plattform vor, die mit Dot Unterrichtsmaterial erstellt und Lernende über Sidekick begleitet, während Lehrkräfte Interaktionen beobachten und früher Unterstützung anbieten sollen. SchoolAI meldet eine Million erreichte Klassenräume und Zeitersparnisse von über zehn Stunden pro Woche; Messmethoden und unabhängige Belege für diese Wirkungen werden im Bericht nicht erläutert.
