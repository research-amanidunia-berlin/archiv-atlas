# Claude is now available in Brazil

Report Q003472 · Source anthropic.com · Date 2024-08-01 · [Open original](https://www.anthropic.com/news/claude-brazil)

## Summary (German, by Luna, unchecked)

Anthropic kündigt Claude für Nutzer und Unternehmen in Brasilien an, verfügbar über Web, mobile Apps und API. Der Bericht nennt Pro- und Team-Tarife samt Preisen und gibt Anthropics Aussagen zu Sicherheit und Datenschutz wieder, ohne diese unabhängig zu belegen.
