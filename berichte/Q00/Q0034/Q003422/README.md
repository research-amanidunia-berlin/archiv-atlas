# Key Concepts in AI Safety: Interpretability in Machine Learning

Report Q003422 · Source cset.georgetown.edu · Date 2021-03-17 · [Open original](https://cset.georgetown.edu/publication/key-concepts-in-ai-safety-interpretability-in-machine-learning/)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Der Auszug stellt Interpretierbarkeit von ML-Systemen als Möglichkeit dar, automatisierte Entscheidungen für Menschen nachvollziehbar zu machen. Er argumentiert, dass dies angesichts wachsender Komplexität, folgenreicher Anwendungen und institutioneller Ansprüche auf Erklärungen wichtig sei; konkrete Methoden oder Ergebnisse enthält der Auszug nicht.
