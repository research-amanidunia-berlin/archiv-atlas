# Claude is now generally available in Xcode

Bericht Q003458 · Quelle anthropic.com · Datum 2025-09-15 · [Original öffnen](https://www.anthropic.com/news/claude-in-xcode)

[Alle Berichte](../../../README.de.md) · Daten: [bericht.json](bericht.json)

## Zusammenfassung (von Luna, ungeprüft)

Laut Anthropic ist Claude Sonnet 4 nun in Xcode 26 verfügbar und unterstützt dort unter anderem Codegespräche, Erklärungen, Dokumentation, SwiftUI-Vorschauen und Änderungen im Editor. Die Nutzung setzt einen geeigneten Claude-Tarif voraus; das plattformübergreifende Abo-Kontingent wird geteilt, wobei nur ein nicht näher bezifferter Teil in Xcode verfügbar ist.
