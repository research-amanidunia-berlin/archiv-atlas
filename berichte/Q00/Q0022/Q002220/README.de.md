# Issue Brief: Preliminary Reporting Tiers for AI-Bio Safety Evaluations

Bericht Q002220 · Quelle frontiermodelforum.org · Datum 2025-03-18 · [Original öffnen](https://www.frontiermodelforum.org/updates/issue-brief-preliminary-reporting-tiers-for-ai-bio-safety-evaluations/)

[Alle Berichte](../../../README.de.md) · Daten: [bericht.json](bericht.json)

## Zusammenfassung (von Luna, ungeprüft)

Das Frontier Model Forum schlägt ein vorläufiges dreistufiges Verfahren zur Berichterstattung über biologische Sicherheitsprüfungen von KI vor: allgemeine Informationen sollen öffentlich, sensible technische Details nur in vertrauenswürdigen Netzwerken und konkrete Schwachstellen oder bestimmte Datensätze privat geteilt werden. Welche Stufe angemessen ist, kann vom Prüfergebnis abhängen; der Bericht betont, dass die Regeln vorläufig und unter Fachleuten teils umstritten sind.

## Sammelfragen

Je Zelle: Anteil Stufe 4–7 / Stufe 3–7 (4 = enthält zitierbare Belege … 7 = beantwortet direkt; 3 = nützlicher Hintergrund). Aufgeführt: Sammelfragen, bei denen mindestens ein Modell den Stufen 3–7 mindestens 10 % gibt. „–“ = Modell hat diesen Bericht nicht bewertet. Volle Verteilungen: [bericht.json](bericht.json).
