# Introducing Claude for Nonprofits

Report Q002242 · Source anthropic.com · Date 2025-12-02 · [Open original](https://www.anthropic.com/news/claude-for-nonprofits)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Anthropic kündigt mit GivingTuesday ein Angebot für gemeinnützige Organisationen an: vergünstigte Claude-Pläne, Schnittstellen zu drei Nonprofit-Diensten und einen kostenlosen KI-Kurs. Der Artikel nennt positive Anwendungsbeispiele und Effizienzangaben aus Kundenberichten, legt dafür aber keine unabhängige Prüfung oder vergleichende Evaluation vor.
