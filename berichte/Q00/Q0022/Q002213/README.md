# Claude Gov models for US national security

Report Q002213 · Source anthropic.com · Date 2025-06-06 · [Open original](https://www.anthropic.com/news/claude-gov-models-for-u-s-national-security-customers)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Anthropic zufolge sind die neuen Claude-Gov-Modelle für eingestufte US-Umgebungen der nationalen Sicherheit entwickelt worden und sollen unter anderem Geheimdienst- und Verteidigungsinformationen, relevante Sprachen sowie Cybersicherheitsdaten besser bearbeiten. Das Unternehmen nennt Kundenfeedback und Sicherheitstests als Grundlage, legt im Bericht aber keine Kennzahlen oder konkreten Belege für die behaupteten Leistungsverbesserungen vor.
