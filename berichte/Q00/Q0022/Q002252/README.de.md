## Zusammenfassung (von Luna, ungeprüft)

Der bereitgestellte Auszug stellt ein PAI-Weißbuch vor, das verantwortungsvolle Veröffentlichung von KI-Forschung fördern soll. Es skizziert Empfehlungen für Forschende, Forschungsleitungen und Publikationsorte, enthält aber weder das vollständige Weißbuch noch die sechs Empfehlungen im Detail.
