# German Rectors' Conference (HRK) | Shaping Europe’s digital future

Report Q002293 · Source digital-strategy.ec.europa.eu · Date – · [Open original](https://digital-strategy.ec.europa.eu/en/policies/ai-literacy-practices/german-rectors-conference-hrk)

## Summary (German, by Luna, unchecked)

Die HRK veröffentlichte 2025 eine szenariobasierte Orientierung zur KI-Kompetenz an Hochschulen, die kritische Diskussion und institutionelle Anpassung unterstützen soll, statt konkrete Software zu schulen. Laut Bericht gibt es erste positive Rückmeldungen, aber noch keine abschließende Wirkungsbilanz; Reichweite, Hochschulvielfalt und die schnelle Entwicklung von KI bleiben Herausforderungen.
