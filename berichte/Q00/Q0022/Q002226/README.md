# SweetSpecter: China-linked cyber activity

Report Q002226 · Source openai.com · Date 2024-10-01 · [Open original](https://openai.com/index/disrupting-malicious-uses-of-ai-sweetspecter/)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

OpenAI schreibt der mutmaßlich China-basierten Gruppe SweetSpecter Phishing-Versuche gegen Mitarbeitende sowie die Nutzung von ChatGPT-Konten für Schwachstellenrecherche, Skripting und Social Engineering zu. Laut Unternehmen wurden die E-Mails blockiert, die Konten unterbrochen und durch den KI-Einsatz keine neuartigen Fähigkeiten erlangt; die Zuschreibung stützt sich auf eine Einschätzung aus glaubwürdiger Quelle.
