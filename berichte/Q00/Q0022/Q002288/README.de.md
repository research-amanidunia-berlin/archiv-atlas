# Equipping agents with Agent Skills

Bericht Q002288 · Quelle anthropic.com · Datum 2025-10-16 · [Original öffnen](https://www.anthropic.com/research/equipping-agents-for-the-real-world-with-agent-skills)

[Alle Berichte](../../../README.de.md) · Daten: [bericht.json](bericht.json)

## Zusammenfassung (von Luna, ungeprüft)

Anthropic beschreibt Agent Skills als modulare Verzeichnisse, mit denen Agenten bedarfsgerecht Anweisungen, zusätzliche Dateien und ausführbaren Code laden können. Der Bericht gibt Entwicklungs- und Sicherheitsempfehlungen, enthält aber keine unabhängigen Leistungsdaten; angekündigte künftige Funktionen sind als Vorhaben formuliert.
