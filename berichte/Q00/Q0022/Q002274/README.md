# Silver lining playbook: Likely China-origin activity targeting US persons

Report Q002274 · Source openai.com · Date 2026-02-01 · [Open original](https://openai.com/index/disrupting-malicious-uses-of-ai-silver-lining-playbook/)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

OpenAI zufolge erstellten gesperrte ChatGPT-Konten mutmaßlich aus China gezielte Beratungsanfragen an US-Beamte und Fachleute, die mit einer erfundenen Firma, persönlichen Komplimenten, hohen Anreizen und raschem Wechsel zu Videoanrufen arbeiteten. Der Bericht deutet das als mögliche Anwerbung, kann aber weder bestätigen, dass die E-Mails versandt wurden, noch dass Empfänger reagierten.
