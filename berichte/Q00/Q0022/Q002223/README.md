# AI Extinction Statement Press Release

Report Q002223 · Source safe.ai · Date 2023-05-30 · [Open original](https://safe.ai/work/press-release-ai-risk)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Die CAIS-Pressemitteilung stellt einen Aufruf vor, das mögliche Aussterberisiko durch fortgeschrittene KI als globale Priorität zu behandeln, und verweist auf zahlreiche bestätigte Unterschriften aus KI und anderen Fachgebieten. Sie fordert vorbeugende Maßnahmen und internationale Zusammenarbeit, bietet aber keine eigene technische Risikoanalyse oder ausführlichen Belege zur Höhe des Risikos.
