# Web3, AI, and other technologies provide new opportunities to improve healthcare

Report Q005306 · Source oecd.ai · Date 2023-09-20 · [Open original](https://oecd.ai/en/wonk/web3-ai-healthcare)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Der Bericht beschreibt mögliche gemeinsame Anwendungen von KI und Blockchain im Gesundheitswesen, etwa für sichere Datenweitergabe, personalisierte Medizin, Überwachung von Netzwerken und Rückverfolgung von Arzneimitteln. Er betont Datenschutz, Fairness, Transparenz und Regulierung; die Vorteile bleiben jedoch Potenzialbehauptungen ohne im Text dargestellte empirische Belege.
