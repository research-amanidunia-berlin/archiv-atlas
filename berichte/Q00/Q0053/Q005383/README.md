# Coordinated vulnerability disclosure for Claude-discovered vulnerabilities

Report Q005383 · Source anthropic.com · Date 2026-03-06 · [Open original](https://www.anthropic.com/coordinated-vulnerability-disclosure)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Anthropic beschreibt Ziele für die koordinierte Offenlegung von Sicherheitslücken, die es mit KI-Werkzeugen entdeckt: meist öffentliche Details nach 90 Tagen, bei aktiv ausgenutzten kritischen Lücken ein Sieben-Tage-Ziel und üblicherweise 45 Tage Wartezeit nach einem Patch bis zur Veröffentlichung technischer Einzelheiten. Die Fristen können je nach Reaktion, Risiken und Behebungsaufwand angepasst werden; der Bericht beschreibt Grundsätze, aber keine konkreten Umsetzungsfälle.
