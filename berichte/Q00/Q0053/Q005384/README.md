# Navigating the challenges and opportunities of synthetic voices

Report Q005384 · Source openai.com · Date 2024-03-29 · [Open original](https://openai.com/index/navigating-the-challenges-and-opportunities-of-synthetic-voices/)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

OpenAI stellt Voice Engine als Modell vor, das anhand einer 15‑Sekunden-Aufnahme ähnliche synthetische Stimmen erzeugen kann, und berichtet über begrenzte Tests für Bildung, Übersetzung, Gesundheit und unterstützte Kommunikation. Wegen des Missbrauchsrisikos werde die Technik laut OpenAI vorerst nicht breit veröffentlicht; die geschilderten Anwendungen und Schutzmaßnahmen beruhen auf OpenAIs Darstellung und kleinen Partnertests.
