# Poly-Autoregressive Prediction for Interaction Modeling

Bericht Q005343 · Quelle deepmind.google · Datum 2025-02-12 · [Original öffnen](https://deepmind.google/research/publications/122892/)

[Alle Berichte](../../../README.de.md) · Daten: [bericht.json](bericht.json)

## Zusammenfassung (von Luna, ungeprüft)

Der vorliegende Auszug stellt PAR vor, ein Verfahren, das die Zustände mehrerer interagierender Akteure nutzt, um das künftige Verhalten eines Akteurs vorherzusagen. Laut Abstract übertrifft es mit einem kleinen Transformer autoregressive Vergleichsmodelle bei drei Aufgaben; Messwerte und nähere Angaben zur Versuchsanordnung fehlen im Auszug.

## Sammelfragen

Je Zelle: Anteil Stufe 4–7 / Stufe 3–7 (4 = enthält zitierbare Belege … 7 = beantwortet direkt; 3 = nützlicher Hintergrund). Aufgeführt: Sammelfragen, bei denen mindestens ein Modell den Stufen 3–7 mindestens 10 % gibt. „–“ = Modell hat diesen Bericht nicht bewertet. Volle Verteilungen: [bericht.json](bericht.json).
