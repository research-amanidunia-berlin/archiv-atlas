# Anthropic is donating $20 million to Public First Action

Report Q005303 · Source anthropic.com · Date 2026-02-12 · [Open original](https://www.anthropic.com/news/donate-public-first-action)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Anthropic kündigt an, 20 Millionen US-Dollar an Public First Action zu spenden, eine parteiübergreifende Organisation, die Bildung und politische Maßnahmen zu KI fördern soll. Das Unternehmen wirbt für mehr Transparenz bei den leistungsfähigsten KI-Modellen, einen bundesweiten Regulierungsrahmen und gezielte Regeln gegen Risiken wie KI-gestützte Cyberangriffe; die Ankündigung stellt Anthropic eigene Positionen dar und bewertet die Organisation nicht unabhängig.
