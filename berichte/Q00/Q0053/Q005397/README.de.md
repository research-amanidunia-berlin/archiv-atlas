## Zusammenfassung (von Luna, ungeprüft)

Der vorliegende Text ist nur ein Auszug und enthält das Abstract, keine ausführlichen Versuchsdaten. Darin wird PIVOT beschrieben: Ein VLM wählt wiederholt aus visuell dargestellten Vorschlägen für Roboteraktionen oder räumliche Antworten aus, die schrittweise verfeinert werden; laut Autorinnen und Autoren gelang damit unter anderem Zero-Shot-Robotersteuerung ohne Robotik-Trainingsdaten, die Leistung sei jedoch noch weit von perfekt entfernt.
