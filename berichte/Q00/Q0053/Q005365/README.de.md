# Canada's Immigration System Increasingly Draws Talent from the United States

Bericht Q005365 · Quelle cset.georgetown.edu · Datum 2020-07-14 · [Original öffnen](https://cset.georgetown.edu/publication/canadas-immigration-system-increasingly-draws-talent-from-the-united-states/)

[Alle Berichte](../../../README.de.md) · Daten: [bericht.json](bericht.json)

## Zusammenfassung (von Luna, ungeprüft)

Laut der Auswertung stiegen die Einladungen über Kanadas Express-Entry-Programm an US-Bewohner von 2017 bis 2019 um 75 Prozent; der Anstieg gehe vollständig auf Nicht-US-Bürger zurück, deren Zahl der Autor als Mindestwert schätzt. Das deute auf eine mögliche Verlagerung qualifizierter Talente nach Kanada hin, belege aber weder tatsächliche Umzüge noch deren Ursachen.
