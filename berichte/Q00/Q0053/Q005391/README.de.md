## Zusammenfassung (von Luna, ungeprüft)

Der vorliegende Auszug beschreibt LMPC, das PaLM 2 mithilfe früherer Mensch-Roboter-Interaktionen und Model Predictive Control effizienter an menschliches Feedback anpassen soll. Das Abstract berichtet über bessere Erfolgsraten und weniger Korrekturen, enthält aber keine ausreichenden Experimentdetails zur unabhängigen Bewertung.
