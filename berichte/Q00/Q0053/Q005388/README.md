# Decoupling in Strategic Technologies

Report Q005388 · Source cset.georgetown.edu · Date 2022-07-26 · [Open original](https://cset.georgetown.edu/publication/decoupling-in-strategic-technologies/)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Der bereitgestellte Text ist nur ein Einleitungsauszug. Er behauptet, Exportkontrollen könnten Rivalen bei strategischen Technologien vorübergehend bremsen, aber selten dauerhaft aufhalten; ihre Wirkung hänge unter anderem davon ab, wie geografisch konzentriert und austauschbar die Lieferkette ist. Der Bericht untersucht dazu Satellitentechnologie und überträgt die Lehren auf KI, deren Wettbewerb sich laut Einleitung nur begrenzt durch Entkopplung beeinflussen lasse.
