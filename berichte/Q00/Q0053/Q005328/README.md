# Estimating the Number of Chinese STEM Students in the United States

Report Q005328 · Source cset.georgetown.edu · Date 2020-10-13 · [Open original](https://cset.georgetown.edu/publication/estimating-the-number-of-chinese-stem-students-in-the-united-states/)

## Summary (German, by Luna, unchecked)

Der vorliegende Text ist nur die Executive Summary einer Studie, die Daten mehrerer US-amerikanischer Stellen kombiniert, um chinesische MINT-Studierende an US-Universitäten zu schätzen. Für 2018/19 nennt sie rund 46.000 Bachelor-, 40.000 Master- und 36.000 Promotionsstudierende und kommt auf chinesische Anteile von 2 Prozent bei MINT-Bachelorstudierenden und 16 Prozent bei MINT-Graduierten; die Autoren betonen, dass die Schätzung wegen uneinheitlicher Datenquellen nötig ist.
