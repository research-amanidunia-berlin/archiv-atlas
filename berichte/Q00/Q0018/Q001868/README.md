# How do frontier AI agents perform in multi-step cyber-attack scenarios?

Report Q001868 · Source aisi.gov.uk · Date 2026-03-16 · [Open original](https://www.aisi.gov.uk/blog/how-do-frontier-ai-agents-perform-in-multi-step-cyber-attack-scenarios)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

AISI berichtet, dass neuere Modelle und höhere Tokenbudgets in einer simulierten Unternehmensangriffskette deutlich mehr Fortschritt ermöglichten, während die Modelle in einem industriellen Szenario nur wenige Schritte bewältigten. Die Tests hatten keine aktiven Verteidiger, und die Ergebnisse schwankten zwischen einzelnen Durchläufen erheblich.
