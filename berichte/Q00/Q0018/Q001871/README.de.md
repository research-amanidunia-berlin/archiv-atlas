## Zusammenfassung (von Luna, ungeprüft)

Eric Wallace zufolge fand ein angekündigtes OpenAI-Cybermodell im Linux-Kernel in einer Woche ungefähr 1.000 LPE-Schwachstellen; ein zitierter OpenAI-Beitrag nennt 948 validierte Funde mit erzeugten Patches sowie mindestens zehn neue Ausnutzungsklassen. Die Kostenangabe von einer Million Dollar beruhe auf öffentlichen API-Preisen; für Firefox werden zudem über 40 behobene Sicherheitslücken genannt, während der Bericht keine unabhängige Prüfung und keine bezifferten Chrome-Ergebnisse bietet.
