# Measuring AI Agents’ Progress on Multi-Step Cyber Attack Scenarios

Report Q001891 · Source aisi.gov.uk · Date 2026-03-16 · [Open original](https://www.aisi.gov.uk/research/measuring-ai-agents-progress-on-multi-step-cyber-attack-scenarios)

## Summary (German, by Luna, unchecked)

Der bereitgestellte Auszug berichtet von Tests mit sieben KI-Modellen in zwei mehrstufigen Cyberangriffsszenarien. Laut Abstract verbesserten sich die Leistungen mit höherem Rechenbudget und von Modellgeneration zu Modellgeneration, blieben beim Szenario für industrielle Steuerungssysteme jedoch gering; der Text enthält keine ausführlicheren Angaben zu den Grenzen der Untersuchung.
