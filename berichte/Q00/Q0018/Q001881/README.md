# How are AI agents used? Evidence from 177,000 MCP tools

Report Q001881 · Source aisi.gov.uk · Date 2026-03-26 · [Open original](https://www.aisi.gov.uk/research/how-are-ai-agents-used-evidence-from-177-000-mcp-tools)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Der vorliegende Text ist nur der Abstract eines Berichts: Die Forschenden berichten über 177.436 Werkzeuge aus öffentlichen MCP-Repositorien und einen Anstieg des Nutzungsanteils von Aktionswerkzeugen von 27 auf 65 Prozent zwischen November 2024 und Februar 2026. Softwareentwicklung stellte laut Abstract den größten Bereich; die Überwachung der Werkzeugebene könne auch Risiken folgenreicher Aktionen wie Finanztransaktionen sichtbar machen. Details zur Methode und zur Repräsentativität fehlen im Auszug.
