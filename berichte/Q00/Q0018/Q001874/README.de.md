# A multi-turn framework for evaluating AI misuse in fraud and cybercrime scenarios

Bericht Q001874 · Quelle aisi.gov.uk · Datum 2026-02-26 · [Original öffnen](https://www.aisi.gov.uk/research/a-multi-turn-framework-for-evaluating-ai-misuse-in-fraud-and-cybercrime-scenarios)

[Alle Berichte](../../../README.de.md) · Daten: [bericht.json](bericht.json)

## Zusammenfassung (von Luna, ungeprüft)

Der vorliegende Text ist nur ein Abstract-Auszug. Darin berichten die Forschenden, dass aktuelle Sprachmodelle bei drei untersuchten Betrugs- und Cybercrime-Szenarien wenig praktische Hilfe leisteten, während sicherheitsbereinigte offene Modelle stärker unterstützten und aufgeteilte, harmlos wirkende Anfragen mehr Hilfe hervorbrachten. Das entwickelte Bewertungsverfahren soll Veränderungen künftiger Risiken beobachtbar machen.

## Sammelfragen

Je Zelle: Anteil Stufe 4–7 / Stufe 3–7 (4 = enthält zitierbare Belege … 7 = beantwortet direkt; 3 = nützlicher Hintergrund).
