# Applying machine learning to radiotherapy planning for head & neck cancer

Bericht Q001887 · Quelle deepmind.google · Datum 2016-08-30 · [Original öffnen](https://deepmind.google/blog/applying-machine-learning-to-radiotherapy-planning-for-head-neck-cancer/)

[Alle Berichte](../../../README.de.md) · Daten: [bericht.json](bericht.json)

## Zusammenfassung (von Luna, ungeprüft)

DeepMind und UCLH wollen anhand anonymisierter Scans von bis zu 700 früheren Patienten untersuchen, ob maschinelles Lernen die aufwendige Segmentierung für die Strahlentherapie bei Kopf-Hals-Krebs verkürzen kann. Die erhoffte Reduktion von bis zu vier auf etwa eine Stunde ist ein Forschungsziel, kein berichtetes Ergebnis; Behandlungsentscheidungen sollen bei den klinischen Fachkräften bleiben.
