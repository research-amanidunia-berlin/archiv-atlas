# Enabling Continual Learning in Neural Networks

Report Q001820 · Source deepmind.google · Date 2017-03-13 · [Open original](https://deepmind.google/blog/enabling-continual-learning-in-neural-networks/)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Der Bericht beschreibt EWC, ein von synaptischer Gedächtniskonsolidierung inspiriertes Verfahren, das wichtige Verbindungen eines neuronalen Netzes beim Lernen neuer Aufgaben vor Veränderungen schützt. In einem Atari-Experiment lernte ein Agent laut Beitrag mit EWC mehrere Spiele besser nacheinander, während er sie ohne EWC schnell vergaß; die Ergebnisse gelten als Schritt, nicht als Beleg für Echtzeitlernen oder als abschließender Nachweis der neurowissenschaftlichen Theorie.
