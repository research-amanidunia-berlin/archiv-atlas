# Singapore’s model framework balances innovation and trust in AI

Report Q009572 · Source oecd.ai · Date 2020-06-24 · [Open original](https://oecd.ai/en/wonk/singapores-model-framework-to-balance-innovation-and-trust-in-ai)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Der Bericht beschreibt Singapurs freiwilligen, prinzipienbasierten Ansatz zur KI-Governance, der Innovation fördern und öffentliches Vertrauen stärken soll. Er nennt einen Modellrahmen, ein Beratungsgremium und ein Forschungsprogramm sowie geplante Schulungen und Zertifizierungen; die Darstellung belegt die Wirkung dieser Maßnahmen nicht unabhängig.
