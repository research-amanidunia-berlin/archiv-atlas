# Wir bereiten unseren nächsten Sicherheitssprint vor, um OpenAI besser zu schützen

Report Q009541 · Source openai.com · Date – · [Open original](https://openai.com/index/preparing-our-next-security-sprint-to-harden-openai/)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

OpenAI kündigt einen Sicherheitssprint mit dem Partner Cathedral an und will zugleich die Prämien für kritische Bug-Bounty-Meldungen auf mehr als das Vierfache erhöhen. Das Unternehmen verweist auf einen früheren Sprint mit 25 Prozent des Produktentwicklungsteams und auf eine Milliarde US-Dollar für sechs Monate subventionierten Daybreak-Zugang; Ergebnisse des angekündigten Sprints nennt der Bericht noch nicht.
