## Zusammenfassung (von Luna, ungeprüft)

Der Bericht zeigt, wie CloudKit-Abonnements Datenänderungen in Swift-Apps in Push-Mitteilungen umsetzen können, ohne dass ein eigener Server betrieben wird. Er nennt Einschränkungen, etwa SwiftDatas veränderliche interne Feldnamen, und skizziert Gruppen- und öffentliche Datenbanken als Wege zu Mitteilungen an ausgewählte oder alle Nutzenden.
