# AlphaGo, in context

Report Q009585 · Source karpathy.medium.com · Date 2017-05-31 · [Open original](https://karpathy.medium.com/alphago-in-context-c47718cb95a5)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Karpathy sieht AlphaGo als starke, sorgfältig umgesetzte Kombination etablierter KI-Verfahren, aber nicht als grundlegenden algorithmischen Durchbruch oder allgemein übertragbare Intelligenz. Der Erfolg beruhe auch auf den besonderen Bedingungen von Go, die etwa in der Robotik meist fehlen; AlphaGo symbolisiere für ihn vor allem Alphabets Stärke im KI-Bereich.
