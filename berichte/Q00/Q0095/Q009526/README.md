# Operation „A2Z“: Mehrsprachige Einflussaktivitäten

Report Q009526 · Source openai.com · Date – · [Open original](https://openai.com/index/disrupting-malicious-uses-of-ai-a2z/)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

OpenAI berichtet von einer mehrsprachigen Einflussoperation namens „A2Z“, deren Betreiber KI für gefälschte Profile und politische Kommentare auf X und Facebook eingesetzt hätten. Die Reichweite sei überwiegend gering gewesen, doch manche Beiträge hätten reale Antworten ausgelöst; OpenAI sagt, es habe die Nutzung seiner Modelle Anfang Juni 2024 unterbunden, worauf die identifizierten Konten zunächst verstummt seien. Der ergänzende Abbildungsanhang im bereitgestellten Text ist teilweise abgeschnitten.
