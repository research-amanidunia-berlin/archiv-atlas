# How the OECD’s AI system classification work added to a year of progress in AI governance

Report Q009569 · Source oecd.ai · Date 2021-01-06 · [Open original](https://oecd.ai/en/wonk/oecd-ai-system-classification-year-of-progress-ai-governance)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Der Beitrag beschreibt die OECD-Klassifizierung von KI-Systemen als Grundlage für eine risikobasierte Abstufung von Governance und Regulierung, von freiwilligen Leitlinien bis zu verbindlichen Gesetzen. Als mögliche Hochrisikobereiche nennt er unter anderem Gesichtserkennung, algorithmische Entscheidungen in Justiz und Polizei, Personalverfahren und Finanzbewertungen, während er auch vor Überregulierung warnt.
