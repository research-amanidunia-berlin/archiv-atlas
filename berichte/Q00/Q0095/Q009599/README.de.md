## Zusammenfassung (von Luna, ungeprüft)

Der vollständige Bericht zeigt anhand von MCPSwiftWrapper, wie Swift-Apps MCP-Server wie GitHub mit OpenAI- oder Anthropic-Modellen verbinden und Werkzeugaufrufe abwickeln können. Die Vorteile werden vom Autor behauptet, aber nicht durch Tests belegt; außerdem müsse für macOS die App-Sandbox deaktiviert werden.
