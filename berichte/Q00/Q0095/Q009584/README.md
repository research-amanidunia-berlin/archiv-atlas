# Software 2.0

Report Q009584 · Source karpathy.medium.com · Date 2017-11-11 · [Open original](https://karpathy.medium.com/software-2-0-a64152b37c35)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Karpathy beschreibt neuronale Netze als „Software 2.0“: Statt alle Regeln von Hand zu programmieren, werden gewünschte Ergebnisse durch Daten vorgegeben und Modelle darauf trainiert. Er sieht Vorteile und eine Ausbreitung in vielen Bereichen, warnt aber auch vor schwer erklärbaren Modellen, Verzerrungen und unerwarteten Fehlern.
