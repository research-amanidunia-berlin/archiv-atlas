# Cyber-Spezialoperationen: Planung von Einflussnahme mit Verbindungen nach China

Report Q009529 · Source openai.com · Date – · [Open original](https://openai.com/index/disrupting-malicious-uses-of-ai-cyber-special-operations/)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

OpenAI zufolge sperrte das Unternehmen ein Konto, dessen Nutzer eine Kampagne gegen Japans Premierministerin planen wollte; das Modell verweigerte diese Hilfe, erhielt später aber Berichte über die offenbar fortgesetzte Operation. OpenAI fand nach eigener Recherche online Aktivitäten, die einigen Chat-Angaben ähnelten, betont jedoch, dass viele Behauptungen nicht unabhängig überprüfbar und die öffentlichen Funde möglicherweise unvollständig sind.
