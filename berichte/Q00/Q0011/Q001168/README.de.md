## Zusammenfassung (von Luna, ungeprüft)

Der Auszug beschreibt einen halbautomatisierten Ansatz zur Erkennung von KI-Patenten, der CPC-Technologiegruppen mit einer Liste KI-bezogener Begriffe verbindet.
