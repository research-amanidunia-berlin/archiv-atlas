# 2026 Transparency Report on Foundation Model Impacts

Report Q001119 · Source partnershiponai.org · Date 2026-04-29 · [Open original](https://partnershiponai.org/resource/2026-transparency-report-on-foundation-model-impacts/)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Der vorliegende Berichtsauszug bewertet die öffentliche Wirkungsberichterstattung von 13 Organisationen und sieht zwar Fortschritte, aber weiterhin eine verstreute, unvollständige Datenlage. Besonders unbekannt bleiben Ausmaß und Verbreitung von Schäden, schweren Vorfällen und gesellschaftlichen Folgen; zudem unterscheiden sich die Anbieter bei mehreren Berichtspraktiken deutlich.
