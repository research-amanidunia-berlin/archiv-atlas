# Forecasting Frontier Language Model Agent Capabilities

Bericht Q001175 · Quelle apolloresearch.ai · Datum – · [Original öffnen](https://apolloresearch.ai/science/forecasting-frontier-language-model-agent-capabilities)

[Alle Berichte](../../../README.de.md) · Daten: [bericht.json](bericht.json)

## Zusammenfassung (von Luna, ungeprüft)

Der Bericht vergleicht sechs Prognoseverfahren und schätzt für Januar 2026 unter anderem 54 bis 87 Prozent auf SWE-Bench Verified sowie 55 bis 66 Prozent auf Cybench, abhängig von der Optimierung der Agenten. Die Autorinnen und Autoren betonen die Unsicherheit durch wenige Frontier-Modelle, begrenzte Agentenoptimierung, kaum berücksichtigte Inferenz-Rechenzeit und die enge Auswahl an Benchmarks.
