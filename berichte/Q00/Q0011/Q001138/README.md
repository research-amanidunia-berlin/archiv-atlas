# Apply AI Strategy

Report Q001138 · Source digital-strategy.ec.europa.eu · Date – · [Open original](http://digital-strategy.ec.europa.eu/en/policies/apply-ai)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Die EU-Strategie „Apply AI“ soll KI in wichtigen Branchen und im öffentlichen Sektor verbreiten, Europas technologische Eigenständigkeit stärken und die Koordination durch neue Zentren, Förderangebote und ein Bündnis verbessern. Der Bericht führt ergänzende Vorhaben in Wissenschaft, Daten und Energie auf, belegt aber keine Umsetzungsergebnisse oder bereits eingetretenen Wirkungen.
