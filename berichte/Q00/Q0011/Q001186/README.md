# Partnering with Hacktron to find vulnerabilities in OpenAI’s systems

Report Q001186 · Source openai.com · Date 2026-11-06 · [Open original](https://openai.com/index/partnering-with-hacktron/)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

OpenAI und Hacktron wollen gemeinsam besonders wichtige Bereiche von OpenAIs Systemen auf Schwachstellen prüfen, vor allem an Verbindungen zu Diensten Dritter; Hacktron erhält dafür erweiterten Zugang zu OpenAIs Frontier-Modellen. Der Bericht nennt Hacktrons frühere Sicherheitsforschung als Begründung, enthält aber keine konkreten Ergebnisse oder Angaben zu Zeitplan und Testverfahren.
