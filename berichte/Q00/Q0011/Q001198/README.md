# Putting sign language AI into users’ hands

Report Q001198 · Source deepmind.google · Date 2026-08-12 · [Open original](https://deepmind.google/blog/putting-sign-language-ai-into-users-hands/)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Google DeepMind stellt SL2T vor, ein Modell, das ASL zunächst auf Pixel 11 in Gboard und Live Transcribe in englischen Text umwandeln soll. Google nennt starke Benchmark-Ergebnisse und beschreibt Datenschutzmaßnahmen sowie die Mitwirkung gehörloser Fachleute; zugleich räumt der Bericht Übersetzungsfehler ein und begrenzt den Start auf ASL zu Englisch.
