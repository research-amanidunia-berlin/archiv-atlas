# The limited benefit of recycling foundation models

Report Q005271 · Source epoch.ai · Date 2023-07-07 · [Open original](https://epoch.ai/publications/the-limited-benefit-of-recycling-foundation-models)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Der Bericht schätzt, dass die Wiederverwendung älterer Foundation Models Rechenaufwand sparen kann, der Vorteil aber in den modellierten Szenarien meist begrenzt ist. Besonders das Weitertrainieren alter Gewichte könnte durch übernommene Architekturen neue algorithmische Fortschritte behindern; die Aussagen beruhen auf vereinfachten Annahmen, und Formeln sowie Abbildungen sind im bereitgestellten Text nur unvollständig enthalten.
