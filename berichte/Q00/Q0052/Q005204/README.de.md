# Donating MCP to the Agentic AI Foundation

Bericht Q005204 · Quelle anthropic.com · Datum 2025-12-09 · [Original öffnen](https://www.anthropic.com/news/donating-the-model-context-protocol-and-establishing-of-the-agentic-ai-foundation)

[Alle Berichte](../../../README.de.md) · Daten: [bericht.json](bericht.json)

## Zusammenfassung (von Luna, ungeprüft)

Anthropic überträgt MCP an die neue Agentic AI Foundation der Linux Foundation und erklärt, die bisherige gemeinschaftliche Governance des Protokolls bleibe bestehen. Das Unternehmen berichtet von breiter Verbreitung und zahlreichen Weiterentwicklungen, legt im Text aber keine unabhängige Prüfung der genannten Zahlen oder Bewertung möglicher Nachteile vor.
