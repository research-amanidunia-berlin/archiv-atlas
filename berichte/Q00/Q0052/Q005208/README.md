# Classifying AI Systems

Report Q005208 · Source cset.georgetown.edu · Date 2021-11-10 · [Open original](https://cset.georgetown.edu/publication/classifying-ai-systems/)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Der vorliegende Quelltext enthält nur die Executive Summary eines Berichts zur Klassifikation von KI-Systemen. In einem Umfrageexperiment mit mehr als 360 Personen schnitten manche von vier untersuchten Rahmen deutlich besser ab; eine Übersicht der Einstufungsdimensionen half, und konkrete Autonomiestufen waren leichter einzuordnen. Die Zusammenfassung betont zugleich, dass verlässliche Einstufungen ausreichende Systeminformationen voraussetzen, die besonders zu technischen Merkmalen oft fehlen.
