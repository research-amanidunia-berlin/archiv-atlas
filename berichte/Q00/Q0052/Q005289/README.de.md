# Microsoft, NVIDIA, and Anthropic partnerships

Bericht Q005289 · Quelle anthropic.com · Datum 2025-11-18 · [Original öffnen](https://www.anthropic.com/news/microsoft-nvidia-anthropic-announce-strategic-partnerships)

[Alle Berichte](../../../README.de.md) · Daten: [bericht.json](bericht.json)

## Zusammenfassung (von Luna, ungeprüft)

Anthropic kündigt den Ausbau von Claude auf Azure sowie eine Technologiepartnerschaft mit NVIDIA an; Microsoft will Claude über Foundry und seine Copilot-Produkte zugänglich machen. Die Unternehmen nennen umfangreiche Rechenkapazitäts- und Investitionszusagen, während Amazon laut Bericht primärer Cloud- und Trainingspartner bleibt. Der Text schildert die Ankündigungen aus Unternehmenssicht und belegt die erwarteten Vorteile nicht unabhängig.
