## Summary (German, by Luna, unchecked)

Anthropic kündigt den Ausbau von Claude auf Azure sowie eine Technologiepartnerschaft mit NVIDIA an; Microsoft will Claude über Foundry und seine Copilot-Produkte zugänglich machen.
