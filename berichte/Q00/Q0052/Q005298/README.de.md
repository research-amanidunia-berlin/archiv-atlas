# The longest training run

Bericht Q005298 · Quelle epoch.ai · Datum 2022-08-17 · [Original öffnen](https://epoch.ai/publications/the-longest-training-run)

[Alle Berichte](../../../README.de.md) · Daten: [bericht.json](bericht.json)

## Zusammenfassung (von Luna, ungeprüft)

Der Bericht entwickelt ein Modell für die optimale Dauer großer Trainingsläufe: Späterer Start kann bessere Hardware, größere Budgets und effizientere Verfahren erschließen, lässt aber weniger Trainingszeit. Je nach Annahmen reichen die Schätzwerte von wenigen Monaten bis zu 3,6 Jahren; Unsicherheit, technische Probleme und gemietete Hardware können für kürzere Läufe sprechen. Die Werte sind bedingte Schätzungen, besonders der angenommene Fortschritt bei algorithmischer Effizienz ist unsicher.
