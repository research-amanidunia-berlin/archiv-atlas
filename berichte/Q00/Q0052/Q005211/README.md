# Mariano-Florentino Cuéllar appointed to Long-Term Benefit Trust

Report Q005211 · Source anthropic.com · Date 2026-01-21 · [Open original](https://www.anthropic.com/news/mariano-florentino-long-term-benefit-trust)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Anthropic meldet die Berufung von Tino Cuéllar in den Long-Term Benefit Trust und hebt seine Erfahrung in Recht, internationaler Politik und KI-Governance hervor. Zugleich scheiden die Gründungsmitglieder Kanika Bahl und Zachary Robinson aus; der Bericht schildert die Vorgänge und Würdigungen aus Sicht der Beteiligten, ohne unabhängige Wirkungsbewertung.
