# OpenAI Board Forms Safety and Security Committee

Report Q002430 · Source openai.com · Date 2024-05-28 · [Open original](https://openai.com/index/openai-board-forms-safety-and-security-committee/)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

OpenAI kündigt einen Ausschuss an, der binnen 90 Tagen Sicherheitsprozesse prüfen und dem Verwaltungsrat Empfehlungen vorlegen soll; anschließend will das Unternehmen im Rahmen der Sicherheitsbelange über angenommene Empfehlungen berichten. Der Bericht nennt die Mitglieder und externe Berater, enthält aber noch keine Prüfergebnisse und keine unabhängige Bewertung der Schutzmaßnahmen.
