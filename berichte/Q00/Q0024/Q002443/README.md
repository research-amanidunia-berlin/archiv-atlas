# How will AI enable the crimes of the future?

Report Q002443 · Source aisi.gov.uk · Date 2025-07-03 · [Open original](https://www.aisi.gov.uk/blog/how-will-ai-enable-the-crimes-of-the-future)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Das AISI beschreibt, wie multimodale Inhalte, bessere Planung und KI-Agenten kriminelle Täuschung und Angriffe unterstützen könnten; eine breitere Verbreitung könnte den Zugang dazu erleichtern. Das Institut untersucht die Risiken durch Modellbewertungen, Nutzungsdatenanalysen und Red-Team-Übungen, um fundierte Maßnahmen vorzubereiten. Der Bericht legt den Ansatz dar, berichtet jedoch keine konkreten Ergebnisse zu einzelnen Modellen oder zur Wirksamkeit bestimmter Maßnahmen.
