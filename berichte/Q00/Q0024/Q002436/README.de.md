# How we’re working with frontier AI developers to improve model security

Bericht Q002436 · Quelle aisi.gov.uk · Datum 2025-09-13 · [Original öffnen](https://www.aisi.gov.uk/blog/how-were-working-with-frontier-ai-developers-to-improve-model-security)

[Alle Berichte](../../../README.de.md) · Daten: [bericht.json](bericht.json)

## Zusammenfassung (von Luna, ungeprüft)

Das AISI beschreibt seine Zusammenarbeit mit Anthropic, OpenAI und dem US-amerikanischen CAISI, um Schwachstellen in KI-Modellen zu finden und Schutzmaßnahmen zu stärken. Es sagt, der vertiefte Modellzugang habe die Untersuchungen unterstützt, nennt aber keine konkreten Befunde oder messbaren Ergebnisse.
