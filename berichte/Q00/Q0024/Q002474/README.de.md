## Zusammenfassung (von Luna, ungeprüft)

Der bereitgestellte Text ist ein Auszug aus William Hannas’ Senatsaussage, kein vollständiger Bericht. Hannas behauptet, Chinas Beschaffung ausländischer Technologie sei ein staatlich gestütztes, seit den 1950er-Jahren zentral gelenktes System mit einer großen institutionellen und personellen Basis; der Auszug bietet dazu keine ausführliche unabhängige Prüfung.
