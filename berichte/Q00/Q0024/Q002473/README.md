# Managing risks from increasingly capable open-weight AI systems

Report Q002473 · Source aisi.gov.uk · Date 2025-08-29 · [Open original](https://www.aisi.gov.uk/blog/managing-risks-from-increasingly-capable-open-weight-ai-systems)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Der AISI-Bericht beschreibt offene Modellgewichte als wichtig für Forschung und Transparenz, aber auch als Risiko, weil Schutzmaßnahmen entfernt und Modelle schädlich verändert werden können. Er empfiehlt eine Kombination aus Datenfilterung, vollständigen Audits und organisatorischen Maßnahmen; keine davon bietet laut Bericht eine vollständige Sicherheitsgarantie, und die Bewertungen sind vorläufig.
