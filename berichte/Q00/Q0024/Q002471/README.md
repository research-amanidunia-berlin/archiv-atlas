# Sovereign AI for assistive and public technologies: How policymakers can reinforce critical digital capacities

Report Q002471 · Source oecd.ai · Date 2025-09-05 · [Open original](https://oecd.ai/en/wonk/sovereign-ai-for-assistive-and-public-technologies-critical-digital-capacities)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Der Beitrag fordert, die europäische KI-Souveränität auch auf barrierefreie öffentliche und assistive Systeme auszurichten. Er empfiehlt unter anderem inklusive Datensätze, offlinefähige und energiesparsame Modelle, zugängliche Robotik sowie gemeinsame Standards und Tests; die Empfehlungen werden nicht durch eine eigene Wirksamkeitsstudie geprüft.
