# Fast reinforcement learning through the composition of behaviours

Bericht Q002409 · Quelle deepmind.google · Datum 2020-10-12 · [Original öffnen](https://deepmind.google/blog/fast-reinforcement-learning-through-the-composition-of-behaviours/)

[Alle Berichte](../../../README.de.md) · Daten: [bericht.json](bericht.json)

## Zusammenfassung (von Luna, ungeprüft)

Der Bericht stellt GPE und GPI vor: Ein Agent bewertet bekannte Strategien anhand neuer Ziele und setzt sie zu einer neuen Verhaltensweise zusammen. In einem einfachen Rasterexperiment soll das die Anpassung gegenüber einzelnem Neulernen beschleunigen; die Methode bleibt jedoch auf das vorhandene Strategierepertoire und die gezeigten, begrenzten Versuchsumgebungen angewiesen.
