# Chinese Catalogue of Technologies Prohibited or Restricted from Export [2023]

Report Q002459 · Source cset.georgetown.edu · Date 2025-02-11 · [Open original](https://cset.georgetown.edu/publication/china-export-control-catalog-2023/)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Der bereitgestellte Bericht ist nur ein Auszug aus der Übersetzung eines 2023 überarbeiteten chinesischen Katalogs zu verbotenen und beschränkten Technologieausfuhren. Er nennt mögliche Begründungen wie Sicherheit, öffentliches Interesse, Gesundheit, Umweltschutz und rechtliche Verpflichtungen, enthält aber weder die konkreten Technologielisten noch das Verfahren für beschränkte Ausfuhren.
