# Disrupting malicious uses of AI by state-affiliated threat actors

Report Q002455 · Source openai.com · Date 2024-02-14 · [Open original](https://openai.com/index/disrupting-malicious-uses-of-ai-by-state-affiliated-threat-actors/)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

OpenAI zufolge wurden in Zusammenarbeit mit Microsoft fünf staatlich zugeordnete Akteure gestört, deren Konten gesperrt wurden; sie hätten KI-Dienste hauptsächlich für Recherchen, Übersetzungen und einfache Programmierhilfe genutzt, teils auch für mutmaßliche Phishing-Zwecke. OpenAI beschreibt Überwachung, Kontosperren, branchenweiten Informationsaustausch und fortlaufende Schutzmaßnahmen, räumt aber ein, dass nicht jeder Missbrauch verhindert werden kann; unabhängige Bestätigungen enthält der Bericht nicht.
