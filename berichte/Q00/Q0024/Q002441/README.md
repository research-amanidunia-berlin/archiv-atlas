## Summary (German, by Luna, unchecked)

Der bereitgestellte Auszug beschreibt PAIs Leitfaden für eine stärkere Beteiligung von Menschen, die von KI betroffen sind, und nennt Vertrauen, Inklusion sowie die Berücksichtigung marginalisierter Gruppen als Ziele. Er betont, dass es kein allgemeingültiges Beteiligungsmodell gibt; konkrete Methoden und Wirksamkeitsbelege fehlen in der unvollständigen Passage.
