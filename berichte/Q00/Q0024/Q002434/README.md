# OpenAI’s approach to AI and national security

Report Q002434 · Source openai.com · Date 2024-10-24 · [Open original](https://openai.com/global-affairs/openais-approach-to-ai-and-national-security/)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

OpenAI befürwortet eine an demokratischen Werten orientierte KI-Entwicklung für Sicherheitsaufgaben und verweist auf bestehende Kooperationen sowie interne Prüfregeln für mögliche Partnerschaften. Weitere Einsatzfelder wie Forschung, Logistik und die Verringerung ziviler Schäden werden als Möglichkeiten genannt; eine unabhängige Bewertung der Wirksamkeit der Schutzmaßnahmen enthält der Bericht nicht.
