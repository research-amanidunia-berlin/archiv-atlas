## Zusammenfassung (von Luna, ungeprüft)

Astrophysiker CK Chan setzt Codex ein, um neue Verfahren für Simulationen schwarzer Löcher zu entwickeln und wissenschaftlichen Code zu prüfen. Die von ihm berichtete mögliche Beschleunigung um den Faktor 1000 ist im Artikel nicht unabhängig belegt; Chan überprüft die Vorschläge weiterhin selbst. Das Forschungsteam hofft auf eine erste bewegte Aufnahme 2027, die noch nicht vorliegt.
