## Summary (German, by Luna, unchecked)

Mistral stellt einen KI-Workflow vor, der Besprechungstranskripte mit zwei Mistral-Large-2-Agenten in PRDs und anschließend in Tickets für Werkzeuge wie Linear oder Jira umwandeln soll.
