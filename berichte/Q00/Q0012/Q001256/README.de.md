# Introducing Le Chat Enterprise

Bericht Q001256 · Quelle mistral.ai · Datum 2025-05-07 · [Original öffnen](https://mistral.ai/news/le-chat-enterprise/)

[Alle Berichte](../../../README.de.md) · Daten: [bericht.json](bericht.json)

## Zusammenfassung (von Luna, ungeprüft)

Mistral stellt Le Chat Enterprise als anpassbare KI-Plattform für Unternehmen vor, mit Suche über angebundene Wissensquellen, Dokumentfunktionen, eigenen Agenten und verschiedenen Betriebsoptionen. Das Produkt war im Google Cloud Marketplace verfügbar; weitere Anbindungen und Marktplätze waren angekündigt. Angaben zu Preisen und unabhängigen Nachweisen für die beworbenen Datenschutz- und Produktivitätsvorteile fehlen.
