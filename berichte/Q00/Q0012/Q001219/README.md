# We need to use AI to fight climate change

Report Q001219 · Source oecd.ai · Date 2023-05-30 · [Open original](https://oecd.ai/en/wonk/fight-climate-change)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Der Beitrag sieht KI als mögliches Werkzeug für Klimamodelle, Energieeinsparungen und Frühwarnsysteme, fordert aber zugleich Regeln, mehr gezielte Forschung und den Ausbau von Fachwissen. Er betont, dass KI ihre Umweltwirkungen selbst verringern müsse und Klimaschutz gemeinsame Arbeit von Politik, Wirtschaft und Zivilgesellschaft erfordere; eine eigene Wirkungsanalyse legt der Text nicht vor.
