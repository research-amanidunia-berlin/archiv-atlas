## Zusammenfassung (von Luna, ungeprüft)

Frank Andrade empfiehlt, ChatGPT-Prompts je nach Bedarf aus sechs Elementen aufzubauen: einer klaren Aufgabe, relevantem Kontext, Beispielen, einer passenden Persona, einem gewünschten Ausgabeformat und einem festgelegten Ton. Der Beitrag bietet praktische Hinweise und Beispiele, aber keine systematische Untersuchung oder Messwerte zur Wirksamkeit dieser Empfehlungen.

## Sammelfragen

Je Zelle: Anteil Stufe 4–7 / Stufe 3–7 (4 = enthält zitierbare Belege … 7 = beantwortet direkt; 3 = nützlicher Hintergrund).
