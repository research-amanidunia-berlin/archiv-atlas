Der Artikel zeigt zwei Wege, ReplayKit-Broadcasts aus SwiftUI zu starten: eine einfache Systemauswahl oder eine kontrollierbare Oberfläche mit `RPBroadcastActivityViewController` und `RPBroadcastController`.
