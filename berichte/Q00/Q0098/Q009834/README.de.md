# Swift: Dynamic Safari Content Blocker

Bericht Q009834 · Quelle medium.com · Datum 2026-04-04 · [Original öffnen](https://medium.com/@itsuki.enjoy/swift-dynamic-safari-content-blocker-d5f7760a60ac)

[Alle Berichte](../../../README.de.md) · Daten: [bericht.json](bericht.json)

## Zusammenfassung (von Luna, ungeprüft)

Der Bericht zeigt, wie Safari-Blockierregeln als JSON angelegt und für dynamische Änderungen in einer App Group gespeichert werden können. Bei Regeländerungen soll Safari über `reloadContentBlocker` neu laden; eine leere Regelliste verursacht laut Autor einen Kompilierungsfehler und muss durch eine gültige, nie zutreffende Regel ersetzt werden.
