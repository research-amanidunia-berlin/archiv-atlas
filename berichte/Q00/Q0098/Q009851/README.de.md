# SwiftUI: Request Parental Permission with PermissionKit

Bericht Q009851 · Quelle medium.com · Datum 2026-03-16 · [Original öffnen](https://medium.com/gitconnected/swiftui-request-parental-permission-with-permissionkit-6480a30c528c)

## Zusammenfassung (von Luna, ungeprüft)

Der vollständige Bericht beschreibt einen SwiftUI-Ablauf, der mit PermissionKit die Zustimmung zur Kommunikation mit einem Minderjährigen einholt, Antworten asynchron verarbeitet und bestehende Freigaben prüft. Laut Autor bietet PermissionKit nur „approve“ oder „decline“; Tests erfordern unter anderem zwei Geräte, ein eingerichtetes Kinderkonto und aktivierte iCloud-Kontaktsynchronisierung.

## Sammelfragen

Je Zelle: Anteil Stufe 4–7 / Stufe 3–7 (4 = enthält zitierbare Belege … 7 = beantwortet direkt; 3 = nützlicher Hintergrund). Aufgeführt: Sammelfragen, bei denen mindestens ein Modell den Stufen 3–7 mindestens 10 % gibt. „–“ = Modell hat diesen Bericht nicht bewertet. Volle Verteilungen: [bericht.json](bericht.json).
