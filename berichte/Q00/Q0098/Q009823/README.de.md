## Zusammenfassung (von Luna, ungeprüft)

Itsuki beschreibt eine WebKit-App für iOS und macOS, die Beta-Dokumentation auf Apples Entwicklerwebsite mithilfe von Vue.js-Daten und Beta-Markierungen herausfiltern soll. Der Autor berichtet von möglichen Abstürzen beim direkten Abbrechen der Webseitenverarbeitung und erläutert daher ein eigenes Abbruchkennzeichen. Der Beitrag stellt den Code und ein macOS-Bundle bereit, enthält aber keine unabhängigen Angaben zu Vollständigkeit oder Zuverlässigkeit.
