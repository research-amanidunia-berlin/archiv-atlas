## Zusammenfassung (von Luna, ungeprüft)

Das vollständige Swift-3-Tutorial zeigt ein programmatisch erstelltes dreispaltiges Bilderraster mit `UICollectionView` und eine einfache Vollbildanimation beim Antippen. Das Beispiel nutzt 50-mal dasselbe Bild; dynamisches Laden, etwa aus einer REST-API, wird nur als mögliche Erweiterung genannt.
