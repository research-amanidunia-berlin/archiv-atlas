## Zusammenfassung (von Luna, ungeprüft)

Das Tutorial zeigt anhand einer Flickr-Foto-App, wie JSON mit `URLSession` abgerufen und über Core Data samt `NSFetchedResultsController` in einer Tabelle angezeigt wird. Der Autor berichtet, dass Löschen vor dem erneuten Speichern Duplikate verhindert und Änderungen den Feed schon beim ersten Start aktualisieren; das Beispiel setzt die Flickr-Datenstruktur voraus und ist für Swift 3, iOS 10 und Xcode 8.1 geschrieben.
