Der Artikel beschreibt die Anbindung von Amazon IVS an eine SwiftUI-App: Einrichtung eines Low-Latency-Kanals, Broadcast über das SDK mit Kamera und Berechtigungen sowie Wiedergabe per `VideoPlayer`.
