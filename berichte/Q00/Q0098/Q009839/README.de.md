# MacOS: Create (A Little?) Cooler dmg

Bericht Q009839 · Quelle medium.com · Datum 2026-03-29 · [Original öffnen](https://medium.com/@itsuki.enjoy/macos-create-a-little-cooler-dmg-38b91619e6ce)

[Alle Berichte](../../../README.de.md) · Daten: [bericht.json](bericht.json)

## Zusammenfassung (von Luna, ungeprüft)

Der Autor berichtet, dass `create-dmg` bei seinen Versuchen zwar einfache DMGs erzeugte, von den gewünschten Anpassungen aber nur Fenstergröße und Symlink funktionierten. Er vermutet ein Problem beim Speichern von Finder-Metadaten und stellt als Alternative ein Python-Skript mit `dmgbuild` vor, weist jedoch ebenfalls auf Grenzen bei Beschriftungsfarbe, Textgröße und skalierendem Hintergrund hin.

## Sammelfragen

Je Zelle: Anteil Stufe 4–7 / Stufe 3–7 (4 = enthält zitierbare Belege … 7 = beantwortet direkt; 3 = nützlicher Hintergrund). Aufgeführt: Sammelfragen, bei denen mindestens ein Modell den Stufen 3–7 mindestens 10 % gibt. „–“ = Modell hat diesen Bericht nicht bewertet. Volle Verteilungen: [bericht.json](bericht.json).

Keine Sammelfrage erreicht bei einem Modell 10 % in Stufe 3–7.
