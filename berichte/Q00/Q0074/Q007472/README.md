# An OpenAI model has disproved a central conjecture in discrete geometry

Report Q007472 · Source openai.com · Date 2026-05-20 · [Open original](https://openai.com/index/model-disproves-discrete-geometry-conjecture/)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

OpenAI berichtet, ein internes KI-Modell habe die Erdős-Vermutung zum Einheitsabstandsproblem widerlegt: Für unendlich viele Punktzahlen konstruiere der Beweis deutlich mehr Einheitsabstandspaare als die bisher als nahezu optimal geltende Quadratgitter-Methode. Der Ansatz verbinde Geometrie mit algebraischer Zahlentheorie und sei extern geprüft worden; die konkrete Verbesserung δ = 0,014 werde einer angekündigten Verfeinerung zugeschrieben, und der Bericht betont weiterhin die Rolle menschlicher Mathematiker.
