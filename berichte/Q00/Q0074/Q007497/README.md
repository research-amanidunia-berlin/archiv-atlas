# Research acceleration: The view inside OpenAI

Report Q007497 · Source openai.com · Date 2026-09-06 · [Open original](https://openai.com/index/research-acceleration-view-inside-openai/)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

OpenAI zufolge nutzen Forschende Coding-Agenten immer stärker, und interne Kennzahlen weisen auf mehr Experimente sowie steigende Erfolgsquoten bei delegierten Aufgaben hin. Die Messungen seien jedoch vorläufig und kein direkter Beleg für entsprechend schnelleren Forschungsfortschritt; bei komplexen Aufgaben bleibt menschliche Steuerung nötig. OpenAI beschreibt verschärfte Sicherheitsmaßnahmen und betont, dass Entwicklung bei unvertretbaren Risiken gebremst oder gestoppt werden soll.
