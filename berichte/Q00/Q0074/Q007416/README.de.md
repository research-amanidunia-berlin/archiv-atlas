# Operation “ScopeCreep”: Russian-speaking malware development

Bericht Q007416 · Quelle openai.com · Datum 2025-06-01 · [Original öffnen](https://openai.com/index/disrupting-malicious-uses-of-ai-scopecreep/)

[Alle Berichte](../../../README.de.md) · Daten: [bericht.json](bericht.json)

## Zusammenfassung (von Luna, ungeprüft)

OpenAI zufolge nutzte ein mutmaßlich russischsprachiger Akteur ChatGPT zur schrittweisen Entwicklung von Windows-Schadsoftware, die über ein gefälschtes Gaming-Werkzeug verbreitet werden sollte. OpenAI berichtet, die Aktivität erkannt, das Repository mit dem Hosting-Anbieter entfernen lassen und die beteiligten Konten gesperrt zu haben; Belege für eine breite Verbreitung habe es nicht gesehen.
