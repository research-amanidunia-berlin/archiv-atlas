# The Newsroom AI Catalyst: a global program with WAN-IFRA

Bericht Q007411 · Quelle openai.com · Datum 2024-05-29 · [Original öffnen](https://openai.com/index/newsroom-ai-catalyst-global-program-with-wan-ifra/)

[Alle Berichte](../../../README.de.md) · Daten: [bericht.json](bericht.json)

## Zusammenfassung (von Luna, ungeprüft)

WAN-IFRA und OpenAI kündigen ein dreimonatiges KI-Förderprogramm für 128 Nachrichtenredaktionen in vier Weltregionen an; OpenAI finanziert es und bietet technische Unterstützung. Der geplante Ablauf umfasst Lernmodule, Workshops, einen kleinen Hackathon und eine Präsentation. Der Bericht beschreibt mögliche Anwendungen und Risiken, nennt aber noch keine erzielten Ergebnisse; Einzelheiten zur Teilnahme sollten später veröffentlicht werden.
