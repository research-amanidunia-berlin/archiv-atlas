# OpenAI Residency

Report Q008442 · Source openai.com · Date 2021-11-30 · [Open original](https://openai.com/index/openai-residency/)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

OpenAI kündigte eine sechsmonatige, voll bezahlte Residency an, die Menschen aus Technikberufen oder wissenschaftlichen Fachgebieten außerhalb der KI durch praktische Mitarbeit an Vollzeitrollen heranführen sollte. Der Beitrag nennt zwei Tracks, frühere Einstellungen aus Mentorenprogrammen und positive Erfahrungsberichte; diese Angaben stammen von OpenAI und ausgewählten Alumni, nicht aus einer unabhängigen Evaluation. Die Ankündigung bezieht sich auf den geplanten Start 2022 und belegt nicht den heutigen Programmstand.
