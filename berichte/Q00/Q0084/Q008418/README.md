# Neural MMO: A massively multiagent game environment

Report Q008418 · Source openai.com · Date 2019-03-04 · [Open original](https://openai.com/index/neural-mmo/)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Der Bericht beschreibt Neural MMO, eine OpenAI-Spielumgebung, in der viele lernende Agenten dauerhaft Nahrung suchen, erkunden und kämpfen. Erste Experimente legen laut den Autoren nahe, dass größere Agentenpopulationen die Leistung und Erkundung steigern und mehrere Populationen die Bildung räumlicher Nischen fördern. Die Ergebnisse sind vorläufig; der Bericht räumt ungelöste Einschränkungen ein.
