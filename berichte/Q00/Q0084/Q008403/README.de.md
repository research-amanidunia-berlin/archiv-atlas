# Gotta Learn Fast: A new benchmark for generalization in RL

Bericht Q008403 · Quelle openai.com · Datum 2018-04-10 · [Original öffnen](https://openai.com/index/gotta-learn-fast/)

[Alle Berichte](../../../README.de.md) · Daten: [bericht.json](bericht.json)

## Zusammenfassung (von Luna, ungeprüft)

Der Auszug kündigt einen auf Sonic the Hedgehog basierenden RL-Benchmark an, mit dem Transfer- und Few-Shot-Learning bewertet werden sollen. Er erwähnt Baseline-Algorithmen, enthält aber keine Einzelheiten zu Vorgehen oder Ergebnissen; es liegt nur ein kurzer Auszug vor.
