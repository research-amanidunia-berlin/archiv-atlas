# OpenAI announces leadership transition

Bericht Q008430 · Quelle openai.com · Datum 2023-11-17 · [Original öffnen](https://openai.com/index/openai-announces-leadership-transition/)

[Alle Berichte](../../../README.de.md) · Daten: [bericht.json](bericht.json)

## Zusammenfassung (von Luna, ungeprüft)

OpenAI zufolge scheidet Sam Altman als CEO und Verwaltungsratsmitglied aus, nachdem der Verwaltungsrat laut eigener Darstellung das Vertrauen in seine Kommunikation verloren hat. Mira Murati übernimmt vorläufig die Leitung, während eine dauerhafte Nachfolge gesucht wird; Greg Brockman gibt den Verwaltungsratsvorsitz ab, bleibt aber im Unternehmen.
