# Organizational update from OpenAI

Report Q008412 · Source openai.com · Date 2020-12-29 · [Open original](https://openai.com/index/organizational-update/)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

OpenAI kündigt den Weggang von Forschungs-Vizepräsident Dario Amodei und eine neue Forschungsrolle für Mira Murati an, die Forschung, Produkt und Partnerschaften stärker verbinden soll. Das Unternehmen betont KI-Sicherheit, vorsichtige Produktanwendung und fortgesetzte Forschung; konkrete Ergebnisse oder unabhängige Belege zur Sicherheit enthält die Mitteilung nicht.
