## Zusammenfassung (von Luna, ungeprüft)

Der Bericht erklärt TypeSafes „Score“ für Bewertungen auf geordneten Skalen: Das Modell gibt Wahrscheinlichkeiten je Stufe, einen gewichteten Mittelwert und einen Konfidenzwert zurück. Die Dokumentation empfiehlt konkrete, eindimensionale Stufen und passende Beispiele, betont aber, dass hohe Konfidenz keine Korrektheit garantiert und die Beschreibungen mit eigenen Daten geprüft werden sollten.

## Sammelfragen

Je Zelle: Anteil Stufe 4–7 / Stufe 3–7 (4 = enthält zitierbare Belege … 7 = beantwortet direkt; 3 = nützlicher Hintergrund).
