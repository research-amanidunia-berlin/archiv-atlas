# Expanded legal protections and API improvements

Bericht Q004708 · Quelle anthropic.com · Datum 2023-12-19 · [Original öffnen](https://www.anthropic.com/news/expanded-legal-protections-api-improvements)

[Alle Berichte](../../../README.de.md) · Daten: [bericht.json](bericht.json)

## Zusammenfassung (von Luna, ungeprüft)

Anthropic kündigt erweiterte vertragliche Zusagen bei bestimmten Urheberrechtsansprüchen sowie eine Beta der strukturierten Messages API an. Die API soll Prompt-Formatierungsfehler früher erkennbar machen; weitere Funktionen und eine breitere Verfügbarkeit werden angekündigt, aber nicht konkret terminiert.
