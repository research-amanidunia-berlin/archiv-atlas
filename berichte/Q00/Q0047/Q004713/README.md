# Our position on open-weights models

Report Q004713 · Source anthropic.com · Date 2026-07-27 · [Open original](https://www.anthropic.com/news/position-open-weights-models)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Amodei zufolge lehnt Anthropic ein pauschales Verbot offener KI-Gewichte ab, sieht aber Risiken durch staatliche Aufrüstung und möglichen Missbrauch für Cyber- oder Bioangriffe. Er fordert stattdessen Beschränkungen für leistungsfähige Chips, gezielte Maßnahmen gegen industrielle Destillation und verpflichtende Sicherheitstests für hinreichend leistungsfähige offene wie geschlossene Modelle.
