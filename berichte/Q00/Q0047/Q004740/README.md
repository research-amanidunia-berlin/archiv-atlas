# Images altered to trick machine vision can influence humans too

Report Q004740 · Source deepmind.google · Date 2024-01-02 · [Open original](https://deepmind.google/blog/images-altered-to-trick-machine-vision-can-influence-humans-too/)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Laut den Autoren können kaum sichtbare Bildveränderungen, die KI-Modelle gezielt fehlleiten, auch menschliche Urteile subtil in Richtung einer Zielkategorie verschieben. In kontrollierten Versuchen wählten Teilnehmende passende Bilder häufiger als zufällig, erkannten aber weiterhin das ursprüngliche Motiv; wie stark der Effekt außerhalb solcher Versuche ist, bleibt im Bericht offen.
