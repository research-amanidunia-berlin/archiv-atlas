## Zusammenfassung (von Luna, ungeprüft)

Die Seite beschreibt Bespoke-Nimble-9B-v3 als LoRA-Adapter für Qwen/Qwen3.5-9B, der für Auswahl- und Ja-Nein-Fragen Wahrscheinlichkeiten ausgibt; genannt wird ein Decision-Index-Wert von 56,88 für Version 0.2.1. Laut Seite ist die Nutzung des Adapters kommerziell ausgeschlossen, das Basismodell separat unter Apache 2.0 lizenziert und das Modell bei keinem Inference Provider verfügbar.
