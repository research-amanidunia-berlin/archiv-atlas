# Replit expands access to software creation with GPT-5.6 Luna

Report Q004725 · Source openai.com · Date 2026-08-19 · [Open original](https://openai.com/index/replit/)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Replit führt laut Bericht einen kostenlosen Modus ein, der GPT‑5.6 Luna nutzt und Nutzern beim Ausarbeiten und Bauen von Software helfen soll. Die Unternehmen schreiben das Angebot geringeren Modellkosten zu und sehen darin einen Weg, Entwicklung für mehr Menschen zu öffnen; unabhängige Leistungsdaten und genaue Nutzungsbedingungen nennt der Bericht nicht.
