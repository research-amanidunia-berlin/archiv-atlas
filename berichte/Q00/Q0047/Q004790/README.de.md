## Zusammenfassung (von Luna, ungeprüft)

Der Bericht erklärt, dass „State“ der zu bewertende Inhalt einer System-One-Anfrage ist und als Zeichenkette, JSON-Objekt oder Array übermittelt werden kann; für die meisten Fälle empfiehlt er ein Objekt mit klar benannten, zusammengehörigen Informationen. Fragen legen getrennt vom State fest, welche Urteile dazu abgegeben werden, und können laut Text unabhängig voneinander auf denselben State angewendet werden. Bilder sind möglich, Audio und Video werden derzeit nicht nativ unterstützt.
