# Comparing Corporate and University Publication Activity in AI/ML

Report Q004792 · Source cset.georgetown.edu · Date 2021-01-27 · [Open original](https://cset.georgetown.edu/publication/comparing-corporate-and-university-publication-activity-in-ai-ml/)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Der vorliegende Auszug berichtet, dass Universitäten laut den Verfassenden deutlich mehr ML-Arbeiten veröffentlichen, Unternehmenspublikationen aber mehr Zitate erhalten; Spitzenarbeiten entstünden oft in Kooperationen, und Universitätsarbeiten stellten seit 2010 stabil die Mehrheit der 100 meistzitierten Beiträge. Der Text empfiehlt, neben Unternehmen auch Universitäten und die Unterschiede zwischen Firmen zu berücksichtigen, enthält aber keine ausführliche Methodik oder prüfbare Zahlen.
