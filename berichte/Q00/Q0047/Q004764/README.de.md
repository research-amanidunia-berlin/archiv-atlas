## Zusammenfassung (von Luna, ungeprüft)

„Choice“ dient laut Bericht dazu, Inhalte einer festgelegten Optionsmenge zuzuordnen; die Antwort umfasst die wahrscheinlichste Option, eine Wahrscheinlichkeitsverteilung und einen daraus abgeleiteten Konfidenzwert. Die Dokumentation empfiehlt gemeinsame Anfragen für mehrere Fragen, klar beschriebene Optionen und bei geringer Konfidenz eine Rückfrage statt einer vorschnellen Aktion. Die Beispiele erläutern den Einsatz, liefern aber keinen allgemeinen Leistungsnachweis.
