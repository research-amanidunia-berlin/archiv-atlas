## Summary (German, by Luna, unchecked)

Claude Tag bringt Claude als gemeinsam nutzbaren, aufgabenorientierten Mitarbeiter in ausgewählte Slack-Kanäle; die Beta richtet sich an Kunden von Claude Enterprise und Team. Anthropic hebt Kontextaufbau, asynchrone Arbeit und durch Administratoren steuerbare Zugriffe hervor, nennt interne Nutzungserfolge jedoch ohne nähere Belege im Bericht.
