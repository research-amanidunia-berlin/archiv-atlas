## Zusammenfassung (von Luna, ungeprüft)

Die Arbeit beschreibt ein unüberwachtes Verfahren zur zeitlichen Segmentierung von Aktionen in Anleitungsvideos, das optionale Hinweise aus Transkripten und typischen Aufgabenabläufen nutzt. Laut Bericht verbessern beide Hinweisquellen die Ergebnisse; konkrete Messwerte fehlen, und die Befunde beziehen sich auf den untersuchten CrossTask-Datensatz.

## Sammelfragen

Je Zelle: Anteil Stufe 4–7 / Stufe 3–7 (4 = enthält zitierbare Belege … 7 = beantwortet direkt; 3 = nützlicher Hintergrund).
