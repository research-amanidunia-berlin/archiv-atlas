# Claude in Amazon Bedrock: FedRAMP High and DoD IL4/5

Bericht Q002826 · Quelle anthropic.com · Datum 2025-06-11 · [Original öffnen](https://www.anthropic.com/news/claude-in-amazon-bedrock-fedramp-high)

[Alle Berichte](../../../README.de.md) · Daten: [bericht.json](bericht.json)

## Zusammenfassung (von Luna, ungeprüft)

Anthropic meldet die Freigabe von Claude 3.5 Sonnet v1 und Claude 3 Haiku über Amazon Bedrock in AWS GovCloud (US) für FedRAMP-High- und DoD-IL4/5-Anwendungen. Das Unternehmen nennt unter anderem Dokumentenanalyse und KI-Agenten als Einsatzmöglichkeiten; weitere Modelle werden nur als mögliche künftige Ergänzungen erwähnt.
