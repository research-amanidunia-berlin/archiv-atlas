# Measures for the Security Management of Facial Recognition Technology Applications

Report Q002870 · Source cset.georgetown.edu · Date 2025-04-01 · [Open original](https://cset.georgetown.edu/publication/china-facial-recognition-security-measures/)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Der Auszug beschreibt chinesische Regeln zur Verarbeitung von Gesichtsinformationen: Der sichtbare Regeltext nennt Datenschutz und rechtmäßiges, ethisches Handeln als Ziele und nimmt Forschung, Entwicklung und Algorithmustraining vom Geltungsbereich aus. Die Einleitung behauptet zusätzlich Vorgaben zur lokalen Speicherung und zu alternativen Anmeldeverfahren; die Übersetzung selbst bricht nach Artikel 3 ab, sodass die weiteren Regelungen hier nicht vorliegen.
