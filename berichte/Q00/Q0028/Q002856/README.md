# FMF Joins USAISI Consortium as a Founding Member

Report Q002856 · Source frontiermodelforum.org · Date 2024-02-08 · [Open original](https://www.frontiermodelforum.org/updates/fmf-joins-aisic/)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Das Frontier Model Forum kündigt an, als Gründungsmitglied dem AISIC beizutreten, das laut Bericht Methoden und Standards zur Bewertung der Sicherheit von KI-Systemen entwickeln soll. Das Forum sieht Zusammenarbeit zwischen Regierung, Zivilgesellschaft und Wirtschaft als zentral an und erwartet, durch Forschung, Austausch und Kooperation zur sicheren Entwicklung fortgeschrittener KI beizutragen. Konkrete Ergebnisse oder einen Zeitplan nennt der Bericht nicht.
