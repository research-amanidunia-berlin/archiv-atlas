# Claude Opus 4.1

Bericht Q002821 · Quelle anthropic.com · Datum 2025-08-05 · [Original öffnen](https://www.anthropic.com/news/claude-opus-4-1)

[Alle Berichte](../../../README.de.md) · Daten: [bericht.json](bericht.json)

## Zusammenfassung (von Luna, ungeprüft)

Anthropic stellt Opus 4.1 als leistungsfähigeres Upgrade zu Opus 4 vor und berichtet unter anderem 74,5 Prozent bei SWE-bench Verified sowie Verbesserungen bei Recherche und agentischer Suche. Das Modell ist über Claude, Claude Code und mehrere Cloud- und API-Angebote erhältlich; die Benchmarkwerte beruhen teils auf unterschiedlichen Denk- und Testbedingungen, und Kundenberichte werden im Beitrag nicht näher methodisch erläutert.
