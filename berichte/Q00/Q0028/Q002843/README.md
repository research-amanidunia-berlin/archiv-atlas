## Summary (German, by Luna, unchecked)

OpenAI veröffentlicht promptbasierte, quelloffene Richtlinien, die Entwicklern laut Unternehmen helfen sollen, Jugendliche in KI-Anwendungen vor sechs Gruppen von Risiken zu schützen. Das Paket ist als anpassbarer Ausgangspunkt gedacht, keine vollständige Lösung oder Garantie; der Bericht nennt keine unabhängigen Wirksamkeitstests.
