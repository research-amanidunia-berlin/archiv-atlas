# Advancing the field of systemic AI safety: grants open

Report Q002815 · Source aisi.gov.uk · Date 2024-10-15 · [Open original](https://www.aisi.gov.uk/blog/advancing-the-field-of-systemic-ai-safety-grants-open)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Das damalige AI Safety Institute eröffnete ein Förderprogramm zur Erforschung gesellschaftlicher KI-Risiken jenseits einzelner Modelle, etwa in wichtigen Sektoren, bei KI-Agenten und für kritische Infrastruktur. Die erste Phase sollte Risiken erkunden, eine Forschungsgemeinschaft aufbauen und mögliche Gegenmaßnahmen finden; der Bericht nennt jedoch keine Förderergebnisse, Summen oder Auswahlkriterien.
