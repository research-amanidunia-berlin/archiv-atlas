# Federal agencies can purchase Claude via GSA

Report Q002812 · Source anthropic.com · Date 2025-08-05 · [Open original](https://www.anthropic.com/news/federal-government-departments-and-agencies-can-now-purchase-claude-through-the-gsa-schedule)

## Summary (German, by Luna, unchecked)

Anthropic zufolge können US-Bundesbehörden Claude nun über den GSA-Beschaffungskatalog mit vorverhandelten Preisen und Bedingungen erwerben. Das Unternehmen verweist auf seine Sicherheits- und Governance-Maßnahmen sowie weitere Regierungskooperationen, nennt aber keine konkreten Einsatzresultate oder unabhängigen Nachweise; interessierte Behörden sollen sein Public-Sector-Team kontaktieren.
