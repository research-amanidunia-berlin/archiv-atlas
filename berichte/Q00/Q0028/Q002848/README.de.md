# ML Engineers Needed for New AI R&D Evals Project

Bericht Q002848 · Quelle metr.org · Datum 2024-05-16 · [Original öffnen](https://metr.org/blog/2024-05-16-ml-engineers-needed/)

## Zusammenfassung (von Luna, ungeprüft)

METR sucht ML-Fachleute, um Tests für KI-Forschungs- und Entwicklungsfähigkeiten zu entwickeln. Die Organisation sieht darin eine Möglichkeit, frühzeitig zu erkennen, ob solche Fähigkeiten Schutzmaßnahmen erfordern; konkrete Testverfahren oder Ergebnisse nennt der Bericht nicht.
