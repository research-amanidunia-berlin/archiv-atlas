# Enabling Claude Code to work more autonomously

Report Q002852 · Source anthropic.com · Date 2025-09-29 · [Open original](https://www.anthropic.com/news/enabling-claude-code-to-work-more-autonomously)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Anthropic stellt für Claude Code eine VS-Code-Erweiterung, eine überarbeitete Terminaloberfläche, das Claude Agent SDK und Checkpoints vor, die laut Unternehmen längere Entwicklungsaufgaben erleichtern sollen. Checkpoints sichern Claude vorgenommene Codeänderungen und erlauben ein Zurücksetzen, decken aber Nutzeränderungen und Bash-Befehle nicht ab; Anthropic empfiehlt daher Versionskontrolle.
