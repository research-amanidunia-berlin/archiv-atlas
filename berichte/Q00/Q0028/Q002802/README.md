# A virtual rodent predicts the structure of neural activity across behaviors

Report Q002802 · Source pmc.ncbi.nlm.nih.gov · Date – · [Open original](https://pmc.ncbi.nlm.nih.gov/articles/PMC12080270/pdf/nihms-2074996.pdf)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Die Studie berichtet, dass ein virtuelles Rattenmodell natürliche Bewegungen nachahmte und seine Netzaktivität neuronale Aktivität im Striatum und motorischen Kortex besser vorhersagte als die untersuchten Bewegungsmerkmale. Das stützt nach Einschätzung der Forschenden die Hypothese einer inversen Dynamik, beweist sie aber nicht; zudem bildet das Modell Muskelsteuerung nicht ab und zielt vor allem auf kurzfristige Bewegungssteuerung.
