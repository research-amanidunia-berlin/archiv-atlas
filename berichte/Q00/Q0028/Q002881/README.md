# Developments in Artificial Intelligence markets: New indicators based on model characteristics, prices and providers

Report Q002881 · Source oecd.ai · Date 2025-06-17 · [Open original](https://oecd.ai/en/ai-publications/developments-in-artificial-intelligence-markets-new-indicators-based-on-model-characteristics-prices-and-providers)

## Summary (German, by Luna, unchecked)

Der bereitgestellte Auszug eines OECD-Berichts nennt sinkende qualitätsbereinigte KI-Preise und mehr Anbieter sowie Modellangebote als Hinweise auf einen dynamischen Markt. Zugleich verweist er auf Engpässe bei Daten, Rechenleistung und Fachkenntnissen; Zahlen und nähere Belege zu den Trends oder ihrem Nutzen für Anwender enthält der Ausschnitt nicht.
