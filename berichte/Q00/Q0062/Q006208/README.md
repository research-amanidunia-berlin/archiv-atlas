# Open-Source Intelligence for S&T Analysis

Report Q006208 · Source cset.georgetown.edu · Date 2020-09-22 · [Open original](https://cset.georgetown.edu/publication/open-source-intelligence-for-st-analysis/)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Der Auszug behauptet, die USA hätten offene Analyse weltweiter Wissenschafts- und Technologieentwicklungen vernachlässigt, während Datenmengen und globale Konkurrenz zunähmen. Er empfiehlt ein unabhängiges National S&T Analysis Center für Analyse und Entscheidungshilfe; der vollständige Bericht ist im bereitgestellten Text nicht enthalten.
