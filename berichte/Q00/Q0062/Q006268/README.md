# Open-weight AI models are 6-7 months behind on cyber

Report Q006268 · Source epoch.ai · Date 2026-10-16 · [Open original](https://epoch.ai/data-insights/open-closed-cyber-eci-gap)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Epoch AI schätzt anhand des Cyber ECI, dass offene KI-Modelle in Cybersecurity-Fähigkeiten etwa sechs bis sieben Monate hinter geschlossenen Modellen liegen. GLM-5.3 führt laut Bericht die aufgeführten offenen Modelle mit 160,1 Punkten an, während Claude Opus 5.5 und GPT-6 Astra bei rund 171 liegen; die Schätzungen beruhen teils auf wenigen Benchmark-Ergebnissen.
