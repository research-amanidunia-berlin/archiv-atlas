# Bolstering U.S. Research Security

Report Q006203 · Source cset.georgetown.edu · Date 2020-09-22 · [Open original](https://cset.georgetown.edu/publication/bolstering-u-s-research-security/)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Der Bericht hält die Bundesbehörden wegen ihrer begrenzten Zuständigkeit, des Misstrauens vieler Forschender und möglicher Informationssperren für unzureichend, um die US-Forschung allein zu schützen. Er empfiehlt eine unabhängige öffentlich-private Einrichtung für Bedrohungseinschätzungen und Schutzpraktiken sowie als ersten Schritt eine Befragung der Forschungsgemeinschaft; die Empfehlung wird im Text nicht als erprobt dargestellt.
