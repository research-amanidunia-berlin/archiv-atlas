# Introducing the Agents API

Bericht Q006209 · Quelle openai.com · Datum 2026-09-10 · [Original öffnen](https://openai.com/index/introducing-the-agents-api/)

[Alle Berichte](../../../README.de.md) · Daten: [bericht.json](bericht.json)

## Zusammenfassung (von Luna, ungeprüft)

OpenAI stellt die Agents API als öffentliche Beta vor, mit der Entwickler den verwalteten Codex-Agentenrahmen samt Kontextverwaltung, Werkzeugen, Sandboxes und parallelen Teilagenten für eigene Anwendungen nutzen können. Ein einzelner Ciridae-Kundenbericht nennt bessere Evaluationsergebnisse und geringere Latenz; der Artikel liefert dazu jedoch keine unabhängige Prüfung oder näheren Testbedingungen.
