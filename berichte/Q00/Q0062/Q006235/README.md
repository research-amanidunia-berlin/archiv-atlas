# Microsoft’s recent $68 billion in physical assets additions were driven by AI-related purchases

Report Q006235 · Source epoch.ai · Date 2026-03-05 · [Open original](https://epoch.ai/data-insights/microsoft-ppe-breakdown)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Der vorliegende Textauszug von Epoch AI zufolge wuchsen Microsofts Brutto-Sachanlagen im zweiten Halbjahr 2025 um rund 67 Milliarden US-Dollar; vor allem Server und Netzwerkausrüstung (57 Prozent) sowie Gebäude (39 Prozent) trugen dazu bei. Epoch deutet den Zuwachs als Folge KI-bezogener Käufe und neuer Rechenzentren, doch der Auszug belegt nicht die konkrete KI-Nutzung jeder Anlage und weist auf die Grenzen der Bruttoanlagenkennzahl hin.
