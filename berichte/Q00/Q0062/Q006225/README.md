# Trade data consistent with $3B of chips smuggled to China via Malaysia

Report Q006225 · Source epoch.ai · Date 2026-09-17 · [Open original](https://epoch.ai/data-insights/malaysia-china-chip-smuggling)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Epoch AI berichtet, dass Chinas und Malaysias Zollangaben für Serverlieferungen von April 2024 bis Juni 2025 stark beim Wert, aber kaum bei der Stückzahl voneinander abweichen. Das sei mit über Malaysia geschleusten und dort möglicherweise unterbewerteten KI-Servern vereinbar; die Daten beweisen Schmuggel jedoch nicht. Die mögliche Rechenleistung wird grob auf 150.000 H100-Äquivalente geschätzt, mit erheblichen Unsicherheiten.
