# The NVIDIA A100 has been the most popular hardware for training notable machine learning models

Bericht Q006242 · Quelle epoch.ai · Datum 2024-10-23 · [Original öffnen](https://epoch.ai/data-insights/models-by-hardware)

[Alle Berichte](../../../README.de.md) · Daten: [bericht.json](bericht.json)

## Zusammenfassung (von Luna, ungeprüft)

Epoch AI zufolge wurde die A100 im eigenen Datensatz am häufigsten für bedeutende ML-Modelle genutzt: 85 Modelle gegenüber 68 auf V100 und 44 auf TPU v3. Der Bericht vermutet auf Basis einer Verkaufsschätzung, dass die H100 künftig aufholen könnte; die Zählung erfasst jedoch nur die im Datensatz berücksichtigten Modelle.
