## Zusammenfassung (von Luna, ungeprüft)

Der vorliegende Auszug aus einer Studie von 2012 skizziert den Vorschlag für ein internationales Technologietransferzentrum in Shenzhen. Laut Bericht soll es regionale und innerchinesische Transfers ebenso wie den Import ausländischer Technik unterstützen; konkrete Methoden oder Ergebnisse der Studie sind im Auszug nicht enthalten.
