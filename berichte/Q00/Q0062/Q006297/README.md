# Coding-agent use at OpenAI is doubling roughly every month

Report Q006297 · Source epoch.ai · Date 2026-10-05 · [Open original](https://epoch.ai/data-insights/openai-coding-agent-spending)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Laut einer Auswertung von OpenAI-Daten stieg der tägliche Coding-Agent-Inferenzverbrauch zu Listenpreisen bis Mitte August 2026 auf rund 601 Dollar beim Median und 7.047 Dollar beim 90. Perzentil; modellierte jüngere Trends ergeben Verdopplungszeiten von etwa 34 beziehungsweise 27 Tagen. Die Preiswerte sind keine tatsächlichen internen Ausgaben, und die Hochrechnung von rund zwei Millionen Dollar im Jahr für besonders intensive Nutzung ist ein Größenvergleich, kein Nachweis von Kosten oder Produktivitätswirkung.
