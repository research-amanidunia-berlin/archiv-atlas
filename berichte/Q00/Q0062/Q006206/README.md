# An Alliance-Centered Approach to AI

Report Q006206 · Source cset.georgetown.edu · Date 2020-09-22 · [Open original](https://cset.georgetown.edu/publication/an-alliance-centered-approach-to-ai/)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Der bereitgestellte Text ist ein Auszug, der die US-Bündnisse als Vorteil für eine demokratische KI-Politik beschreibt und eine gemeinsame Strategie gegen digitale Autokratie sowie für Forschung, Standards und KI-Kapazitäten in Entwicklungsländern empfiehlt. Die angeführten Daten stammen aus einer CSET-Befragung; der Auszug enthält keine ausführliche Methodik oder den vollständigen Bericht.
