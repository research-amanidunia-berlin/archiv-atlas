## Summary (German, by Luna, unchecked)

OpenAI stellt LifeVal als Maßstab für KI-Unterstützung bei Alltagsaufgaben vor, entwickelt anhand von Zeitverwendungsdaten und einer Befragung von 3.995 Personen. Für fünf Beispiele nennt das Unternehmen Modellwerte von 90,4 bis 100 Prozent, erläutert aber weder die Bewertungsmethode noch Vergleichsmaßstäbe oder Unsicherheiten ausreichend, um die Zahlen anhand des Textes einzuordnen.
