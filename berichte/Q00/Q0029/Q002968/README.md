# Rewarding defenders with bigger bug bounties

Report Q002968 · Source openai.com · Date 2026-11-02 · [Open original](https://openai.com/index/rewarding-defenders-with-bigger-bug-bounties/)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

OpenAI kündigt deutlich höhere Bug-Bounty-Prämien sowie Qualitäts-, Treue- und Kampagnenboni an; für außergewöhnliche kritische Funde in Kernprodukten nennt das Unternehmen mit Boni bis zu 172.000 US-Dollar. Die Beispielrechnungen seien unverbindlich, und der Bericht belegt nicht, wie sich die Änderungen später auf tatsächliche Auszahlungen oder die Sicherheit auswirken.
