# Making frontier cybersecurity capabilities available to defenders

Report Q002919 · Source anthropic.com · Date 2026-02-20 · [Open original](https://www.anthropic.com/news/claude-code-security)

## Summary (German, by Luna, unchecked)

Anthropic kündigt Claude Code Security als Vorschauwerkzeug an, das Code auf Sicherheitslücken untersucht und geprüfte Patch-Vorschläge für menschliche Freigabe bereitstellt. Das Unternehmen berichtet, sein Team habe mit Claude Opus 4.6 über 500 bislang unentdeckte Schwachstellen in Open-Source-Code gefunden; deren Prüfung und Offenlegung laufen noch.
