## Zusammenfassung (von Luna, ungeprüft)

OpenAI berichtet, Pando skaliere Git für parallele Entwicklung, indem es Branches unabhängig aktualisiert und Packfiles über Caches wiederverwendet. Das Unternehmen nennt deutlich schnellere Pushes und hohe Zuverlässigkeit, räumt aber ein, dass mehrere Branches beim Lesen keinen gemeinsamen zeitgleichen Stand garantieren; die Vergleichssimulation sei kein Produktionsbenchmark.
