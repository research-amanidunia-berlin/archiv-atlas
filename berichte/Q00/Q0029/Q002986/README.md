Der Bericht legt nahe, dass Hippocampus und medialer präfrontaler Kortex Bausteine samt räumlichen Beziehungen repräsentieren und dass schnelle neuronale Wiederaktivierungen beim Zusammensetzen neuer Formen mögliche Lösungen schrittweise eingrenzen könnten.
