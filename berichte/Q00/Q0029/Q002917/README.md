# AI skills and capabilities in Canada

Report Q002917 · Source oecd.ai · Date 2025-02-28 · [Open original](https://oecd.ai/en/ai-publications/ai-skills-and-capabilities-in-canada)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Die vorliegende Kurzbeschreibung eines Berichts zur KI-Kompetenznachfrage in Kanada nennt mehr als zwölf Millionen Online-Stellenanzeigen aus den Jahren 2018 bis 2023 als Datenbasis. Demnach erreichte die Nachfrage 2021 einen Höhepunkt, während spezialisierte KI-Kenntnisse weiter an Bedeutung gewannen; besonders betroffen seien Data Science, Cloud Engineering und KI-Forschung. Der Bericht empfiehlt laut Beschreibung flexible Bildungswege und eine breitere KI-Nutzung.
