# A sectoral taxonomy of AI intensity

## Summary (German, by Luna, unchecked)

Der bereitgestellte Auszug beschreibt eine Taxonomie, die KI-Bezüge von Wirtschaftssektoren anhand von Humankapital, Innovation, Exposition und Nutzung vergleicht. Laut Text schneiden IT-Dienstleistungen in allen Dimensionen hoch ab, während die Pharmaindustrie hohes KI-Humankapital, aber geringe KI-Innovation aufweist; Messverfahren und Datengrundlage werden im Auszug nicht erläutert.
