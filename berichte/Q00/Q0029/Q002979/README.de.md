# An impossibility theorem in game dynamics

Bericht Q002979 · Quelle pmc.ncbi.nlm.nih.gov · Datum – · [Original öffnen](https://pmc.ncbi.nlm.nih.gov/articles/PMC10576106/pdf/pnas.202305349.pdf)

## Zusammenfassung (von Luna, ungeprüft)

Die Autoren beweisen mithilfe der Conley-Indextheorie, dass es ein degeneriertes Spiel gibt, für das keine deterministische Dynamik in diskreter oder kontinuierlicher Zeit im definierten Sinn zu Nash-Gleichgewichten konvergiert. Sie berichten auch ein entsprechendes Hindernis für angenäherte Gleichgewichte, während ihre Ergebnisse stochastische Dynamiken nicht erfassen und für Spiele ohne Degeneration nur eine rechnerisch teure Konstruktion angeben.
