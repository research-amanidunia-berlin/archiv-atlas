# Introducing Sonnet 4.6

Bericht Q002925 · Quelle anthropic.com · Datum 2026-02-17 · [Original öffnen](https://www.anthropic.com/news/claude-sonnet-4-6)

[Alle Berichte](../../../README.de.md) · Daten: [bericht.json](bericht.json)

## Zusammenfassung (von Luna, ungeprüft)

Anthropic zufolge verbessert Sonnet 4.6 Programmierung, Computernutzung, langes Schlussfolgern und weitere Wissensaufgaben; frühe Tests und Kundenrückmeldungen fallen überwiegend positiv aus. Die berichteten Ergebnisse beruhen auf Unternehmensauswertungen und frühen Rückmeldungen, während Anthropic zugleich Einschränkungen von Benchmarks und einen Rückstand gegenüber den besten menschlichen Computernutzern einräumt.
