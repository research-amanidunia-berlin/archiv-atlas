# Introducing the Grid Protectors Program

Report Q002952 · Source openai.com · Date 2026-11-02 · [Open original](https://openai.com/index/grid-protectors-program/)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

OpenAI will mit dem Grid Protectors Program künftige Rechenzentren so betreiben, dass sie bei Netzengpässen ihren Stromverbrauch senken und damit laut Unternehmen die Versorgung vor Ort unterstützen können. Für den geplanten Campus in Georgia nennt OpenAI eine Vereinbarung mit bis zu 1.000 Megawatt flexibler Nachfrage; die im Bericht genannten Kundeneinsparungen sind Prognosen, und konkrete Zusagen für weitere Standorte stehen noch aus.
