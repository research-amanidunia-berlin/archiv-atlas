# Guidelines for capability elicitation

Report Q002912 · Source metr.org · Date 2024-03-15 · [Open original](https://metr.org/blog/2024-03-15-guidelines-for-capability-elicitation/)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

METR empfiehlt, Modelle vor einer Bewertung grundlegend für Werkzeugnutzung und eigenständiges Arbeiten vorzubereiten und verbleibende Fehler danach zu behandeln, ob sie leicht behebbar, schwer lösbar oder aufgabenspezifische Zielkonflikte sind. Die Leitlinien verlangen zudem Kontrollen auf Überanpassung und Bewertungsfehler sowie eine nachvollziehbare Dokumentation; laut METR waren sie noch nicht vollständig erprobt und experimentell bestätigt.
