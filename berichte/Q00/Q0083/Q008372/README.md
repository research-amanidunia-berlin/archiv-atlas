## Summary (German, by Luna, unchecked)

OpenAI kündigt eine Alterseinschätzung für ChatGPT an: Erkannte Minderjährige und Personen mit unklarer Altersangabe sollen vorsichtshalber eine altersgerechte Version erhalten. Geplante Elternkontrollen umfassen Konto-Verknüpfung, Funktionseinschränkungen, Sperrzeiten und Warnungen bei erkannten akuten Notlagen. Der Beitrag beschreibt Vorhaben, nennt aber keine Daten zur Genauigkeit oder Wirksamkeit.
