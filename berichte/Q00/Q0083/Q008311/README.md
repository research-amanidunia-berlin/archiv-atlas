## Summary (German, by Luna, unchecked)

OpenAI beschreibt ein in Simulation trainiertes Robotersystem, das laut Beitrag eine Aufgabe nach einer einzigen VR-Demonstration auf neue Ausgangslagen übertragen kann. Beim Blockstapeln halfen variierte Simulationsbilder und verrauschte Trainingsdaten; konkrete Erfolgsraten oder ein systematischer Leistungsvergleich werden nicht genannt.
