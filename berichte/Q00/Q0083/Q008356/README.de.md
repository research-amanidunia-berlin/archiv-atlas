# Extensions and limitations of the neural GPU

## Zusammenfassung (von Luna, ungeprüft)

Der vorliegende Text ist ein Auszug aus dem Abstract. Die Autor:innen berichten, dass Lernpläne und größere, speichereffizient implementierte Neural-GPU-Modelle arithmetische Aufgaben auf beliebig langen Dezimalzahlen ermöglichen; längere Ausdrücke gelangen nur binär und nicht vollkommen genau. Ungewöhnliche, stark symmetrische Eingaben können trotz sonst guter Leistung zu Fehlern führen.
