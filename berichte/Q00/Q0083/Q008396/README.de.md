# AWS and OpenAI announce multi-year strategic partnership

Bericht Q008396 · Quelle openai.com · Datum 2025-11-03 · [Original öffnen](https://openai.com/index/aws-and-openai-partnership/)

[Alle Berichte](../../../README.de.md) · Daten: [bericht.json](bericht.json)

## Zusammenfassung (von Luna, ungeprüft)

AWS und OpenAI kündigen eine auf 38 Milliarden US-Dollar bezifferte, mehrjährige Vereinbarung an: OpenAI soll sofort AWS-Rechenleistung nutzen, darunter Hunderttausende NVIDIA-GPUs. Die Kapazität soll bis Ende 2026 bereitgestellt und später ausgebaut werden; der Bericht gibt Unternehmensangaben wieder und belegt weder den Abschluss des Ausbaus noch konkrete Leistungsresultate.
