# Direct Approach interactive model

Bericht Q004196 · Quelle epoch.ai · Datum 2023-05-31 · [Original öffnen](https://epoch.ai/publications/direct-approach-interactive-model)

[Alle Berichte](../../../README.de.md) · Daten: [bericht.json](bericht.json)

## Zusammenfassung (von Luna, ungeprüft)

Epoch AIs interaktives Modell schätzt, wann verfügbare effektive Rechenleistung den angenommenen Bedarf für transformative KI übersteigt; unter Standardannahmen liegt der Median bei 2029, mit 57 Prozent Wahrscheinlichkeit bis 2030 und 85 Prozent bis 2050. Die Autoren betonen, dass dies eine unsichere Extrapolation historischer Trends und keine allumfassende Prognose ist.
