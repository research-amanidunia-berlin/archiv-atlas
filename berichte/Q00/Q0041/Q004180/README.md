## Summary (German, by Luna, unchecked)

Der vorliegende Text ist ein Auszug, kein vollständiger Bericht. Er beschreibt ein Projekt, das Datengerechtigkeit über Datenschutz und technische Schadensbegrenzung hinaus mit Machtverhältnissen, Ungleichheit, Diskriminierung, Repräsentation und der Verteilung von Vorteilen aus Datennutzung verknüpfen will.
