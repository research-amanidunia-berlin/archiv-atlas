## Summary (German, by Luna, unchecked)

Der Bericht beschreibt WaveNet als Modell, das Sprache und Musik direkt aus rohen Audiosamples erzeugt. Die Autoren berichten bessere Hörtestwerte als für die verglichenen Google-TTS-Systeme und behaupten, WaveNet halbiere den Abstand zur menschlichen Sprachqualität; die eingebetteten Audiobeispiele sind im Text nicht hörbar. Die letzte nachgeholte Bildbeschreibung bricht ab.
