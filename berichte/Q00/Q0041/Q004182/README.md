# WaveNet launches in the Google Assistant

Report Q004182 · Source deepmind.google · Date 2017-10-04 · [Open original](https://deepmind.google/blog/wavenet-launches-in-the-google-assistant/)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

DeepMind berichtet, dass die beschleunigte WaveNet-Version nun Assistant-Stimmen für US-Englisch und Japanisch erzeugt. Laut Beitrag ist sie 1.000-mal schneller als das ursprüngliche Modell und erreicht in Hörtests für vier Stimmen höhere MOS-Werte als die verglichenen Systeme; Angaben zum Testaufbau fehlen, und die Audio-Beispiele sind im Text nicht hörbar.
