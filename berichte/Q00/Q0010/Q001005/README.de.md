# Addendum to GPT-5 System Card: Sensitive Conversations

Bericht Q001005 · Quelle deploymentsafety.openai.com · Datum 2025-10-27 · [Original öffnen](https://deploymentsafety.openai.com/gpt-5-sensitive-conversations)

[Alle Berichte](../../../README.de.md) · Daten: [bericht.json](bericht.json)

## Zusammenfassung (von Luna, ungeprüft)

OpenAI berichtet, dass das GPT-5-Update vom 3. Oktober in den meisten veröffentlichten Sicherheitsbenchmarks besser abschnitt als die Version vom 15. August, besonders bei Tests zu emotionaler Abhängigkeit, psychischer Gesundheit und Jailbreaks. Bei SimpleQA nahmen Genauigkeit und Halluzinationsrate jedoch eine ungünstige Richtung; die bewusst schwierigen Tests sind laut Bericht nicht repräsentativ für den durchschnittlichen Chatverkehr.
