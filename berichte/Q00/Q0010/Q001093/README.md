# The Mistral AI Non-Production License

Report Q001093 · Source mistral.ai · Date 2024-05-29 · [Open original](https://mistral.ai/news/mistral-ai-non-production-license-mnpl/)

## Summary (German, by Luna, unchecked)

Mistral führt die MNPL ein, die laut Unternehmen nicht kommerzielle Nutzung und Forschung ermöglichen und Geschäfte auf Grundlage seiner Technologie fairer gestalten soll. Codestral erscheint unter dieser Lizenz; zugleich will Mistral weiterhin Modelle und Code unter Apache 2.0 veröffentlichen. Konkrete Lizenzbedingungen nennt der Bericht nicht.
