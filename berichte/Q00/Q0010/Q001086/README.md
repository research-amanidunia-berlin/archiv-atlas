# AI talent, skills and literacy

Report Q001086 · Source digital-strategy.ec.europa.eu · Date – · [Open original](http://digital-strategy.ec.europa.eu/en/policies/ai-talent-skills-and-literacy)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Der vorliegende Berichtsauszug beschreibt die Pflicht von KI-Anbietern und -Betreibern, die KI-Kompetenz beteiligter Personen zu fördern, ohne ein bestimmtes individuelles Kompetenzniveau vorzuschreiben. EU-Stellen sollen dabei unterstützen; eine Sammlung von mehr als 40 Praxisbeispielen dient laut Bericht dem Austausch, belegt aber für sich allein keine Einhaltung der Vorschrift. Weitere angekündigte Initiativen werden im Auszug nicht ausgeführt.
