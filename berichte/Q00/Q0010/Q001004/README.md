# How IBM's Responsible Technology Team Created Multiple Avenues for Employee Feedback

Report Q001004 · Source partnershiponai.org · Date 2026-06-18 · [Open original](https://partnershiponai.org/resource/how-ibms-responsible-ai-team-created-multiple-avenues-for-employee-feedback/)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Der vorliegende Auszug berichtet, dass IBM 2025 neben der Teilnahme an einer Lern- und Austauschgruppe Beschäftigte dazu befragte, wie KI in ihrer Arbeit eingesetzt werden sollte. Als Erkenntnisse nennt er offene Führung, Möglichkeiten zum Experimentieren, vielfältige Perspektiven, breiteren KI-Zugang und Reaktionen auf Feedback als mögliche Wege zu besserer Nutzung und mehr Vertrauen. Details und die vollständige Fallstudie fehlen.
