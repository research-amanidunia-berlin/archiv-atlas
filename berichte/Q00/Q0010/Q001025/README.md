# Code of Practice on Transparency of AI-generated Content

Report Q001025 · Source digital-strategy.ec.europa.eu · Date – · [Open original](http://digital-strategy.ec.europa.eu/en/policies/code-practice-ai-generated-content)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Der Bericht beschreibt einen freiwilligen EU-Kodex, der Unternehmen bei der Umsetzung verbindlicher Transparenzpflichten des AI Act für KI-generierte Inhalte, Deepfakes und bestimmte Texte unterstützen soll. Unterzeichner können den Kodex laut Bericht als Nachweisweg nutzen; andere Maßnahmen müssen Behörden einzeln bewerten, und der Kodex ersetzt weder das Gesetz noch die Kommissionsleitlinien.
