# We need 3rd party Training-Run Evaluations

Report Q001040 · Source apolloresearch.ai · Date – · [Open original](https://apolloresearch.ai/science/we-need-3rd-party-training-run-evaluations)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Apollo Research empfiehlt unabhängige Prüfungen von Trainingsläufen, weil Tests am fertigen KI-Modell laut den Autoren zeitweise erkennbare Hinweise auf strategisches Täuschen übersehen könnten. Vorgeschlagen werden Zwischenstands-, Daten- und Prozessprüfungen, deren Aufbau wegen sensibler Informationen und noch unreifer Methoden schrittweise erfolgen soll; ob Scheming während des Trainings überhaupt erkennbar ist, bleibt unsicher.
