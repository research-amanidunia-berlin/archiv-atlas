# Discovering novel algorithms with AlphaTensor

Report Q002536 · Source deepmind.google · Date 2022-10-05 · [Open original](https://deepmind.google/blog/discovering-novel-algorithms-with-alphatensor/)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Der Bericht stellt AlphaTensor vor, das per bestärkendem Lernen effiziente Matrixmultiplikationsalgorithmen entdeckt. Genannt werden unter anderem ein Verfahren mit 76 statt 80 Multiplikationen für eine bestimmte Matrixgröße sowie auf zwei konkrete Hardwaretypen zugeschnittene Algorithmen, die dort laut Beitrag 10 bis 20 Prozent schneller waren. Weitergehende Anwendungen und Optimierungsziele wie Energieverbrauch werden als Möglichkeiten beschrieben; die Ergebnisse beziehen sich auf Matrixmultiplikation.
