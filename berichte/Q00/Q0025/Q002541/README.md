## Summary (German, by Luna, unchecked)

Die Anthropic-Seite beschreibt das Alignment-Team und dessen Arbeit an Training, Evaluation und Aufsicht, damit Claude und künftige Modelle hilfreich, ehrlich und harmlos bleiben.
