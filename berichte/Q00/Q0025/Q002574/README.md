## Summary (German, by Luna, unchecked)

Der bereitgestellte Text enthält nur den Abstract einer Arbeit, deren Autoren Schwächen gängiger Bewertungen von Machine Unlearning behaupten: Tests könnten Wissen neu vermitteln, je nach Aufgabe stark abweichende Resultate liefern oder auf Scheinkorrelationen beruhen. Sie schlagen minimale Informationszufuhr und die Beachtung nachgelagerter Aufgaben vor; Einzelheiten zu den Experimenten fehlen im Auszug.
