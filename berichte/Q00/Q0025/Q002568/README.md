# Big Tech in Taiwan

## Summary (German, by Luna, unchecked)

Der bereitgestellte Text ist nur die „Executive Summary“ des Berichts samt Abbildungsplatzhalter. Sie besagt, dass 17 US-Technologieunternehmen wirtschaftlich mit Taiwan verflochten sind, die meisten aber engere Beziehungen zu China haben; Google, Apple, Microsoft und Amazon weisen laut Bericht besonders starke Taiwan-Verbindungen auf. Die Analyse kartiert mögliche Anreize und Risiken für eine Krise, lässt jedoch die Halbleiterabhängigkeit und konkrete Folgen von Chip-Lieferausfällen ausdrücklich außerhalb ihres Umfangs.
