# Operation “Peer Review”: AI-assisted surveillance planning

Report Q002571 · Source openai.com · Date 2025-02-01 · [Open original](https://openai.com/index/disrupting-malicious-uses-of-ai-peer-review/)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

OpenAI zufolge nutzte eine wahrscheinlich aus China stammende Kontengruppe ChatGPT unter anderem für Recherche, Dokumentenanalyse und die Entwicklung von Code und Werbematerial für ein beschriebenes Werkzeug zur Überwachung sozialer Medien. Die behaupteten Einsätze und Weitergaben an Behörden seien nicht unabhängig belegt; OpenAI fand weder Hinweise auf eine Veröffentlichung der Kommentare noch darauf, dass das Werkzeug mit OpenAI-Modellen betrieben wurde.
