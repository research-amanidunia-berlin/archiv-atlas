# Best practices for data enrichment

Bericht Q002523 · Quelle deepmind.google · Datum 2022-11-16 · [Original öffnen](https://deepmind.google/blog/best-practices-for-data-enrichment/)

[Alle Berichte](../../../README.de.md) · Daten: [bericht.json](bericht.json)

## Zusammenfassung (von Luna, ungeprüft)

DeepMind und die Partnership on AI entwickelten fünf Empfehlungen für fairere Bedingungen bei bezahlten Aufgaben zur Aufbereitung und Bewertung von KI-Daten. DeepMind berichtet von klareren Abläufen und besseren Erfahrungen für Beschäftigte, nennt dafür aber keine Messwerte; zusätzlich sollen Risiken weiterhin für jedes Projekt einzeln geprüft werden.
