# Guidelines and Code of Practice on transparent AI systems

Report Q002549 · Source digital-strategy.ec.europa.eu · Date – · [Open original](http://digital-strategy.ec.europa.eu/en/faqs/guidelines-and-code-practice-transparent-ai-systems)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Der EU-Bericht erläutert, wie Artikel 50 des AI Act Transparenz über KI-Interaktionen und bestimmte KI-generierte oder manipulierte Inhalte schaffen soll, und beschreibt dafür mögliche Kennzeichnungsverfahren sowie einen freiwilligen Verhaltenskodex. Die genannten Fristen und Wirkungen sind Kommissionsdarstellungen beziehungsweise damalige Planungen; der Text bestätigt nicht, ob der Kodex später fertiggestellt oder angenommen wurde.
