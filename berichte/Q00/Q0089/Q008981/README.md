# Fine-tuning now available for GPT-4o

Report Q008981 · Source openai.com · Date 2024-08-20 · [Open original](https://openai.com/index/gpt-4o-fine-tuning/)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

OpenAI kündigte die Feinabstimmung von GPT‑4o und GPT‑4o mini mit eigenen Trainingsdaten an und nannte Partnerergebnisse auf SWE-bench und BIRD-SQL als Beispiele für mögliche Leistungssteigerungen. Diese Zahlen werden als OpenAI-Angaben berichtet, ohne unabhängige Prüfung im Text. Ein Update vom Mai 2026 besagt, dass die Plattform für neue Nutzer geschlossen wird und bestehende Modelle bis zur Abkündigung ihrer Basismodelle verfügbar bleiben sollen.
