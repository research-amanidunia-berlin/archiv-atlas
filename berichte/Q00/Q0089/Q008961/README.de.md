# How OpenAI is approaching 2024 worldwide elections

Bericht Q008961 · Quelle openai.com · Datum 2024-01-15 · [Original öffnen](https://openai.com/index/how-openai-is-approaching-2024-worldwide-elections/)

[Alle Berichte](../../../README.de.md) · Daten: [bericht.json](bericht.json)

## Zusammenfassung (von Luna, ungeprüft)

OpenAI berichtet über Regeln gegen Wahlmanipulation, Verweise von ChatGPT auf offizielle oder journalistische Informationsquellen und Maßnahmen zur Kennzeichnung beziehungsweise Ablehnung bestimmter KI-Bilder. Das Unternehmen nennt Nutzungszahlen und sagt, keine viral verbreiteten US-Wahlbeeinflussungsoperationen mit seinen Modellen beobachtet zu haben; unabhängige Wirksamkeitsnachweise liefert der Bericht nicht.
