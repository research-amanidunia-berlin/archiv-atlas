# Scaling the OpenAI Academy: A new hub for AI literacy and community learning

Report Q008956 · Source openai.com · Date 2025-03-25 · [Open original](https://openai.com/global-affairs/scaling-the-openai-academy/)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

OpenAI kündigt an, die Academy mit einem kostenlosen Online-Hub, Lernmaterialien und Veranstaltungen für ein breiteres Publikum auszubauen. Geplante Kooperationen, darunter ein Goodwill-Workshop zur Nutzung von ChatGPT bei der Unterstützung Arbeitssuchender, sollen praktische KI-Kompetenzen fördern. Der Bericht beschreibt Vorhaben und erwartete Vorteile, nennt aber keine gemessenen Wirkungen oder konkreten Reichweitenzahlen.
