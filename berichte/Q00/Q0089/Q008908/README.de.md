# Introducing the ChatGPT app for iOS

## Zusammenfassung (von Luna, ungeprüft)

OpenAI kündigt eine kostenlose ChatGPT-App für iOS mit geräteübergreifender Gesprächssynchronisierung und Spracheingabe über Whisper an; Plus-Mitglieder sollten zusätzliche GPT‑4-Funktionen und schnellere Antworten erhalten. Der zunächst in den USA geplante Rollout sollte auf weitere Länder ausgeweitet werden, eine Android-Version sei laut Bericht bald vorgesehen; unabhängige Nachweise oder feste Termine nennt der Text nicht.
