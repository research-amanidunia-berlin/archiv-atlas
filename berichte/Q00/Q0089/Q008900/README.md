# OpenAI nonprofit jam

Report Q008900 · Source openai.com · Date 2025-07-17 · [Open original](https://openai.com/global-affairs/openai-nonprofit-jam/)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

OpenAI kündigte einen Nonprofit Jam an, bei dem mehr als 1.000 Führungskräfte gemeinnütziger Organisationen an zehn US-Standorten den praktischen Einsatz von ChatGPT erkunden und eigene Werkzeuge entwickeln sollten. Der Bericht nennt geplante Lernangebote und zwölf Monate kostenlosen Plus-Zugang, belegt aber keine konkreten Wirkungen; der später verlinkte Abschlussbericht ist hier nicht enthalten.
