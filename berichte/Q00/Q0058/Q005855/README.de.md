# Proactive Agents for Multi-Turn Text-to-Image Generation Under Uncertainty

[Alle Berichte](../../../README.de.md) · Daten: [bericht.json](bericht.json)

## Zusammenfassung (von Luna, ungeprüft)

Der vorliegende Bericht ist ein Abstract-Auszug zu proaktiven Text-zu-Bild-Agenten, die bei Unsicherheit nachfragen und ihre Interpretation als bearbeitbaren Graphen zeigen sollen. Laut Abstract fanden mindestens 90 Prozent der Versuchspersonen den Ansatz hilfreich; auf drei genannten Datensätzen hätten die Agenten mindestens doppelt so hohe VQAScores wie eine Einzeldurchlauf-Erzeugung erzielt. Details zu Stichprobe und Versuchsaufbau fehlen im Auszug.
