# The US hosts the majority of GPU cluster performance, followed by China

Report Q005835 · Source epoch.ai · Date 2025-06-05 · [Open original](https://epoch.ai/data-insights/ai-supercomputers-performance-share-by-country)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Der bereitgestellte Quelltext ist eine Notizensammlung zu sechs Abschnitten, kein vollständiger Bericht über KI-Rechencluster und Trainingsläufe. Er beschreibt die starke geschätzte Stellung der USA, nennt zahlreiche GPU- und TPU-Systeme und betont, dass die Daten nur einen Teil der globalen Leistung abdecken. Viele Werte beruhen auf Schätzungen oder Ankündigungen; bei geplanten und anonymisierten Systemen bleiben Baufortschritt, Hardware und Größenordnung teils offen.
