## Summary (German, by Luna, unchecked)

Die CSET-Auswertung erfasst 1.212 Bioinformatik-Cluster: Die meisten sind der Medizin zugeordnet, und die USA führen bei der Zahl der Arbeiten knapp vor China. Nur wenige Cluster haben einen hohen KI-Anteil; der Bericht hebt außerdem einen auf Neurodegeneration fokussierten Cluster und 16 Cluster mit hohem Anteil an Industrieförderung hervor.
