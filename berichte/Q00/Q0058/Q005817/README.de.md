# Concentrations of AI-Related Topics in Research: Natural Language Processing

Bericht Q005817 · Quelle cset.georgetown.edu · Datum 2021-09-08 · [Original öffnen](https://cset.georgetown.edu/publication/concentrations-of-ai-related-topics-in-research-natural-language-processing/)

[Alle Berichte](../../../README.de.md) · Daten: [bericht.json](bericht.json)

## Zusammenfassung (von Luna, ungeprüft)

Der Bericht zeigt anhand von 397 Forschungsclustern aus einer Momentaufnahme von 2021, dass NLP-Forschung überwiegend der Informatik zugeordnet ist, aber auch in Sozialwissenschaften, Mathematik und anderen Bereichen vorkommt. Er illustriert unterschiedliche NLP-Anteile und Wachstum anhand von vier Clustern; die Cluster-IDs sind nach einer späteren Aktualisierung nicht mehr direkt übertragbar, und beim Mathematik-Beispiel weicht eine ID intern ab.
