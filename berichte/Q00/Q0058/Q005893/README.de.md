# A People-First AI Fund: $50M to support nonprofits

Bericht Q005893 · Quelle openai.com · Datum 2025-09-08 · [Original öffnen](https://openai.com/index/people-first-ai-fund/)

## Zusammenfassung (von Luna, ungeprüft)

OpenAI kündigt einen 50-Millionen-Dollar-Fonds für US-amerikanische gemeinnützige Organisationen an, mit Schwerpunkten auf KI-Bildung, gemeinschaftlicher Innovation und fairen wirtschaftlichen Chancen. Laut Bericht mussten Anträge bis zum 8. Oktober 2025 eingereicht werden; Ergebnisse der Förderrunde werden nicht genannt.
