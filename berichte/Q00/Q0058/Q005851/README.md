## Summary (German, by Luna, unchecked)

Der bereitgestellte Bericht ist nur ein Abstract-Auszug: Morris beschreibt, wie HCI die Entwicklung von KI in Richtung AGI so mitgestalten könnte, dass sie für Menschen nützlich und bedienbar ist und mögliche Schäden besser begrenzt werden. Sie nennt dafür mehrere Forschungsfelder, liefert im Auszug aber keine konkreten Studien oder Ergebnisse.
