## Summary (German, by Luna, unchecked)

Der Notiz-Auszug fasst eine Epoch-AI-Analyse zusammen, laut der die Rechenleistung führender KI-Supercomputer seit 2019 jährlich um das 2,5-Fache gestiegen sei. Er katalogisiert zudem bestehende, geplante und für Modelltrainings genutzte Systeme, weist aber darauf hin, dass viele Zahlen auf Schätzungen, Ankündigungen oder indirekten Ableitungen beruhen und teils unklar bleiben.
