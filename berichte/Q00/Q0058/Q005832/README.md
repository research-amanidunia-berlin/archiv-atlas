# Advancing coding in low‑resource programming languages

Report Q005832 · Source openai.com · Date 2026-10-19 · [Open original](https://openai.com/index/low-resource-programming-languages/)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

OpenAI berichtet von besseren Ergebnissen seiner Modelle bei Aufgaben in wenig verbreiteten Programmiersprachen: GPT‑6 Astra habe in einer Mehrsprachen-Evaluation durchschnittlich 87,4 Prozent der Tests bestanden, und GPT‑6.1 Sol habe bei COBOL-Migrationen bis zu 97,9 Prozent Genauigkeit erreicht. Die Angaben beruhen auf zwei konkreten Testverfahren; laut Bericht benötigen produktive Migrationen weiterhin fachkundige Prüfung und Tests mit den Geschäftsregeln und Abhängigkeiten des jeweiligen Systems.
