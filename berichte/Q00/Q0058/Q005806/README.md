# Reducing the carbon emissions of AI

Report Q005806 · Source oecd.ai · Date 2022-04-12 · [Open original](https://oecd.ai/en/wonk/reducing-ai-carbon-emissions)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Ein Forschungsteam von Google und Berkeley beschreibt vier Ansatzpunkte, um die betrieblichen Emissionen von ML zu senken: effizientere Modelle und Hardware, bessere Rechenzentren und Standorte mit sauberer Energie. Für konkrete Beispiele nennt es erhebliche Einsparungen, darunter 747-mal geringere Emissionen über vier Jahre, weist aber nicht nach, dass solche Werte für alle Anwendungen gelten. Die Autoren kritisieren zudem frühere Schätzungen als teils stark überhöht; diese Kritik wird im Beitrag nicht unabhängig überprüft.
