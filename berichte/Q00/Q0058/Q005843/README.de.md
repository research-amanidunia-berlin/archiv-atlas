# AI-Supported COVID-19 Research

Bericht Q005843 · Quelle cset.georgetown.edu · Datum 2021-10-20 · [Original öffnen](https://cset.georgetown.edu/publication/ai-supported-covid-19-research/)

[Alle Berichte](../../../README.de.md) · Daten: [bericht.json](bericht.json)

## Zusammenfassung (von Luna, ungeprüft)

Der Bericht beschreibt 307 COVID-19-Forschungscluster und meldet, dass die meisten nur einen kleinen Anteil KI-bezogener Arbeiten enthielten. Zwei größere Cluster betrafen KI-gestützte Bildanalyse sowie Anwendungen des Internets der Dinge; die Analyse zeigt Literaturmuster, belegt aber keine kausale Wirkung von KI.
