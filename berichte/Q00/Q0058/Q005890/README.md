# Dialogues Between Technologists and the Art Worlds

Report Q005890 · Source deepmind.google · Date 2025-07-16 · [Open original](https://deepmind.google/research/publications/181976/)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Die Autoren sprechen sich dafür aus, generative KI im Austausch mit dem gesamten lokalen Kunstökosystem zu entwickeln, statt nur einzelne Nutzende zu betrachten. Beispiele aus Schreiben, Comedy, Musik und bildender Kunst zeigen laut Bericht sowohl kreative Möglichkeiten als auch Risiken kultureller Fehlausrichtung; umfassende quantitative Wirksamkeitsnachweise werden nicht vorgelegt.
