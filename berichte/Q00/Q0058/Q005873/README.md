# Exploring Supercomputing with the Map of Science

Report Q005873 · Source cset.georgetown.edu · Date 2021-12-15 · [Open original](https://cset.georgetown.edu/publication/exploring-supercomputing-with-the-map-of-science/)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Der Bericht vergleicht die Publikationsaktivität von Ländern in drei ausgewählten Forschungsclustern zu Supercomputern. Russland führt bei der Analyse von Systemverhalten knapp vor den USA, China dominiert die Forschung zum Sunway TaihuLight, und Japan liegt bei Vektorprozessoren und Extremwettervorhersagen vorn. Die Zahlen messen Veröffentlichungen in MAG-basierten Clustern, nicht unmittelbar die nationale Rechenleistung.
