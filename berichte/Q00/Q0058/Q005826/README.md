# Concentrations of AI-Related Topics in Research: Robotics

Report Q005826 · Source cset.georgetown.edu · Date 2021-09-22 · [Open original](https://cset.georgetown.edu/publication/concentrations-of-ai-related-topics-in-research-robotics/)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Der Bericht wertet 477 Forschungscluster aus, die einen festgelegten Mindestanteil an Robotik- und KI-Arbeiten aufwiesen. Die meisten liegen in der Informatik; Beispiele reichen von humanoiden Robotern und Fahrzeugtechnik bis zu Assistenzrobotik für Menschen mit Behinderungen. Die Ergebnisse beziehen sich auf den Datenstand von Juli 2021, und die Cluster-IDs wurden bei einer späteren Kartenaktualisierung geändert.
