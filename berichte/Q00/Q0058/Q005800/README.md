# Global AI power capacity is now comparable to peak power usage of New York State

Report Q005800 · Source epoch.ai · Date 2026-01-16 · [Open original](https://epoch.ai/data-insights/ai-datacenter-power)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Epoch AI schätzt die Kapazität von KI-Rechenzentren Ende 2025 auf rund 30 GW und vergleicht sie mit dem Spitzenstromverbrauch des Bundesstaats New York. Die Schätzung leitet sich aus verkauften Chips und einem pauschalen Faktor für Rechenzentrumsinfrastruktur ab; der Tabellenwert von 31,24 GW für das vierte Quartal 2025 ist extrapoliert.
