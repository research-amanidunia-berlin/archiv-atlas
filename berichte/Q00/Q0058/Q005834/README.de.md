# Map of Science Updates and User Interface Launch: What’s New?

Bericht Q005834 · Quelle cset.georgetown.edu · Datum 2021-10-06 · [Original öffnen](https://cset.georgetown.edu/publication/map-of-science-updates-and-user-interface-launch-whats-new/)

[Alle Berichte](../../../README.de.md) · Daten: [bericht.json](bericht.json)

## Zusammenfassung (von Luna, ungeprüft)

CSET stellt eine öffentliche Oberfläche seiner „Map of Science“ vor und berichtet über ergänzte Publikationsdaten, darunter Papers with Code, arXiv und zusätzliche CNKI-Dokumente. Die Karte bietet Filter und Detailansichten zu Forschungsklustern; am Beispiel eines Clusters zu Malware-Erkennung und schädlichem JavaScript werden deren Funktionen erläutert. Eine systematische Bewertung der Oberfläche oder unabhängige Prüfung der Daten enthält der Beitrag nicht.
