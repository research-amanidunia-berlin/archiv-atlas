# Learning Agile Soccer Skills for a Bipedal Robot with Deep Reinforcement Learning

Bericht Q005823 · Quelle deepmind.google · Datum 2024-04-10 · [Original öffnen](https://deepmind.google/research/publications/31284/)

[Alle Berichte](../../../README.de.md) · Daten: [bericht.json](bericht.json)

## Zusammenfassung (von Luna, ungeprüft)

Der Auszug beschreibt Deep-RL-Training in einer Simulation für einen kleinen humanoiden Fußballroboter, der laut Abstract dynamische Bewegungen, vorausschauendes Spielverhalten und die Abwehr von Schüssen lernte. Beim Transfer auf reale Roboter übertraf er eine programmierte Vergleichssteuerung in vier berichteten Geschwindigkeitskennzahlen; Details zu Versuchsaufbau und Messunsicherheit fehlen im Auszug.
