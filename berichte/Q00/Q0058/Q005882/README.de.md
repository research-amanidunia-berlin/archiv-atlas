# Tools for trustworthy AI: A framework to compare implementation tools for trustworthy AI systems

Bericht Q005882 · Quelle oecd.ai · Datum 2021-06-28 · [Original öffnen](https://oecd.ai/en/ai-publications/implementation-tools-for-trustworthy-ai)

[Alle Berichte](../../../README.de.md) · Daten: [bericht.json](bericht.json)

## Zusammenfassung (von Luna, ungeprüft)

Der bereitgestellte Bericht liegt nur als Abstract-Auszug vor. Er beschreibt einen OECD-Rahmen zum Vergleich von Werkzeugen für vertrauenswürdige KI, der Wissen bündeln und eine geplante öffentliche Datenbank auf OECD.AI stützen soll; konkrete Werkzeuge oder Ergebnisse nennt der Auszug nicht.
