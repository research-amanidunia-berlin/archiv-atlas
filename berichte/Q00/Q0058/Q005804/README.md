# Teach LLMs to Phish: Stealing Private Information from Language Models

Report Q005804 · Source deepmind.google · Date 2024-05-07 · [Open original](https://deepmind.google/research/publications/43000/)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Der Abstract-Auszug beschreibt „neural phishing“, einen von den Autorinnen und Autoren vorgeschlagenen Angriff, der sensible Daten aus Sprachmodellen extrahieren soll. Sie berichten von Erfolgsraten über 10 Prozent bis hin zu 50 Prozent, doch der Auszug erklärt weder die Messbedingungen noch die getesteten Datensätze.
