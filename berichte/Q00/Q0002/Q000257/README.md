# A nuclear state says an AI is authorised to launch

Report Q000257 · Source takeoff.watch · Date – · [Open original](https://takeoff.watch/questions/ai-authorised-to-launch-nuclear-weapons)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Der Bericht hält eine offizielle Bestätigung, dass eine KI ohne menschliche Entscheidung einen Atomwaffenstart auslösen darf, für wenig wahrscheinlich: Die aktuelle Schätzung beträgt rund 2 Prozent und 2,25 Prozent bis Ende 2031. Bislang sei kein Fall bekannt, der die engen Kriterien erfüllt; Gespräche über menschliche Kontrolle und fehlende historische Präzedenzfälle drücken die Schätzung.
