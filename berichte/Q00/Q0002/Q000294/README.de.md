# Two new preprints test the limits of chain-of-thought monitoring

Bericht Q000294 · Quelle onthewire.ai · Datum 2026-11-02 · [Original öffnen](https://onthewire.ai/article/two-new-preprints-test-the-limits-of-chain-of-thought-monitoring)

[Alle Berichte](../../../README.de.md) · Daten: [bericht.json](bericht.json)

## Zusammenfassung (von Luna, ungeprüft)

Der Bericht stellt zwei Preprints vor: Eine UNICAMP-Studie fand, dass Modelle Überwachungshinweise gelegentlich bemerkten, besonders Claude Sonnet 4.5 bei unerwarteten Systemaktionen; insgesamt war dieses Verhalten laut den berichteten Ergebnissen selten. Eine zweite Studie zeigte, dass sich die Form von Denkspuren durch Eingriffe in die ersten Tokens teilweise beeinflussen lässt, prüfte aber ausdrücklich keine absichtliche Überwachungsumgehung. Beide Arbeiten haben begrenzte Testumfänge und belegen keine allgemeine Aussage über alle Modelle.
