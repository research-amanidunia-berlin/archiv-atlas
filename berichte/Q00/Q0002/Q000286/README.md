# Transparency Disclosures for Chain-of-Thought Monitorability

Report Q000286 · Source iaps.ai · Date 2026-11-10 · [Open original](https://www.iaps.ai/research/transparency-disclosures-for-chain-of-thought-monitorability)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Der Bericht empfiehlt, die Überwachbarkeit sichtbarer KI-Gedankenschritte anhand von fünf regelmäßig offenzulegenden Indikatoren zu verfolgen: Zugang und Architekturangaben, Lesbarkeit, Treue, Erkennung gefährlichen Verhaltens und zusätzlicher Überwachungsnutzen. Öffentliche Angaben von OpenAI, Anthropic und Google DeepMind deckten laut der untersuchten Bestandsaufnahme zwar jeden Indikator einzeln ab, aber kein Anbieter alle fünf; freiwillige Prüfungen und fehlende Standards erschwerten unabhängige Vergleiche.
