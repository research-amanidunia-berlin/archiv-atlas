# Why Electricity Law Would Make It Very Hard to Unplug a Rogue AI

Report Q000204 · Source heatmap.news · Date 2026-10-29 · [Open original](https://heatmap.news/daily/why-electricity-law-would-make-it-very-hard-to-unplug-a-rogue-ai)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Ein von Robinson Meyer vorgestellter Bericht der Brown University argumentiert, dass US-Behörden ein Rechenzentrum mit einem außer Kontrolle geratenen KI-Agenten nach geltendem Recht kaum schnell abschalten könnten. Unklare Zuständigkeiten, nötige Gerichtsverfahren, Notstromversorgung und mögliche Schäden für andere Kunden erschwerten das Eingreifen. Der Bericht empfiehlt gemeinsame Notfallplanung von KI-Unternehmen und Stromnetzakteuren; konkrete Gesetzesvorschläge macht er nicht.
