# Signatory Task Forces of the Code of Practice on Transparency of AI-generated Content

Bericht Q000258 · Quelle digital-strategy.ec.europa.eu · Datum – · [Original öffnen](https://digital-strategy.ec.europa.eu/en/policies/task-forces-code-transparency-ai-generated-content)

[Alle Berichte](../../../README.de.md) · Daten: [bericht.json](bericht.json)

## Zusammenfassung (von Luna, ungeprüft)

Der bereitgestellte Bericht ist ein Auszug über zwei Arbeitsgruppen, die laut Text mehr als 90 Unterzeichner am 30. September 2026 zur Unterstützung eines EU-Verhaltenskodex für Transparenz KI-generierter Inhalte eingerichtet haben. Sie sollen Austausch, technische Arbeit und den Dialog mit Fachleuten und Interessengruppen fördern; konkrete Projekte oder Ergebnisse nennt der Auszug nicht.
