# Japan asks Anthropic, OpenAI for more access to advanced models

Bericht Q000278 · Quelle asia.nikkei.com · Datum 2026-10-30 · [Original öffnen](https://asia.nikkei.com/business/technology/artificial-intelligence/japan-asks-anthropic-openai-for-more-access-to-advanced-models)

[Alle Berichte](../../../README.de.md) · Daten: [bericht.json](bericht.json)

## Zusammenfassung (von Luna, ungeprüft)

Der vorliegende Nikkei-Auszug berichtet, Japans Regierung habe Anthropic und OpenAI um erweiterten Zugang zu ihren fortgeschrittenen Modellen zur Erkennung von Cybersicherheitslücken gebeten. Deren Einsatz bei Betreibern wesentlicher Infrastruktur solle gefördert werden; weitere Details oder Reaktionen der Unternehmen enthält der Auszug nicht.
