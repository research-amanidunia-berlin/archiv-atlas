# Databricks brings GPT-5.5 to enterprise agent workflows

Bericht Q005479 · Quelle openai.com · Datum 2026-05-15 · [Original öffnen](https://openai.com/index/databricks/)

[Alle Berichte](../../../README.de.md) · Daten: [bericht.json](bericht.json)

## Zusammenfassung (von Luna, ungeprüft)

Databricks zufolge erreichte GPT‑5.5 auf dem eigenen Benchmark OfficeQA Pro 50 Prozent Genauigkeit und verringerte in einer agentischen Testumgebung die Fehler gegenüber GPT‑5.4 um 46 Prozent. Das Unternehmen hebt Fortschritte beim Auslesen schwieriger Dokumente und bei mehrstufigen Agentenabläufen hervor und bietet das Modell über AI Unity Gateway an. Die Angaben beruhen auf dem unternehmenseigenen Benchmark; der Bericht führt keine detaillierte Methodik oder unabhängige Prüfung an.
