# From Cold War Sanctions to Weaponized Interdependence

Report Q005463 · Source cset.georgetown.edu · Date 2021-09-15 · [Open original](https://cset.georgetown.edu/publication/from-cold-war-sanctions-to-weaponized-interdependence/)

## Summary (German, by Luna, unchecked)

Der Auszug aus einer kommentierten Bibliografie beschreibt, wie wirtschaftliche Verflechtung, Technologie und Exportkontrollen geopolitischen Wettbewerb beeinflussen können. Er stellt mögliche Sicherheitsgewinne von Kontrollen ihren wirtschaftlichen und diplomatischen Kosten gegenüber und betont koordinierte Maßnahmen sowie die regelmäßige Anpassung der Regeln. Die vollständige Bibliografie liegt nicht vor.
