# Lowe’s leverages AI to power home improvement retail

Report Q005440 · Source openai.com · Date 2025-05-05 · [Open original](https://openai.com/index/lowes-chandhu-nair/)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Lowe’s beschreibt KI als Unterstützung für Heimwerkerprojekte und den Filialbetrieb: Die Anwendungen Mylow und Mylow Companion beraten Kundschaft beziehungsweise Mitarbeitende, während weitere Modelle Preise, Prognosen und Lieferketten unterstützen. Das Unternehmen berichtet von mehr als 50 eingesetzten Modellen sowie Schulungs- und Governance-Maßnahmen, nennt aber keine konkreten Ergebnisse seiner ROI-Messungen; die Darstellung stammt aus einem OpenAI-Gespräch mit Lowe’s.
