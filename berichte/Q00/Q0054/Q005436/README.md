# Recommendations on Export Controls for Artificial Intelligence

Report Q005436 · Source cset.georgetown.edu · Date 2020-02-01 · [Open original](https://cset.georgetown.edu/publication/recommendations-on-export-controls-for-artificial-intelligence/)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Der vorliegende Auszug empfiehlt laut Autor, vor allem Anlagen zur Herstellung moderner KI-Chips zu kontrollieren. Neue Beschränkungen für allgemeine KI-Software und nichtmilitärische Datensätze könnten wenig bewirken und US-Interessen schaden; Kontrollen für KI-Chips selbst seien ohne frühzeitige Anlagenkontrollen ebenfalls wenig aussichtsreich.
