# The Huawei Moment

Report Q005477 · Source cset.georgetown.edu · Date 2021-07-22 · [Open original](https://cset.georgetown.edu/publication/the-huawei-moment/)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Der Auszug argumentiert, dass die langfristige staatliche Förderung Chinas Huawei stärkte, während US-Unternehmen unter anderem wegen kurzfristiger Marktanreize ihre Führungsposition in der Telekommunikation verloren. Die Autorin plädiert deshalb für strategische öffentliche Unterstützung sicherheitsrelevanter Technologien; vorliegt jedoch nur die Executive Summary mit einem Abbildungseintrag, nicht der vollständige Bericht.
