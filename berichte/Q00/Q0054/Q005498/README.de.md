# Exposing Limitations of Language Model Agents in Sequential-Task Compositions on the Web

Bericht Q005498 · Quelle deepmind.google · Datum 2024-12-31 · [Original öffnen](https://deepmind.google/research/publications/46840/)

[Alle Berichte](../../../README.de.md) · Daten: [bericht.json](bericht.json)

## Zusammenfassung (von Luna, ungeprüft)

Der bereitgestellte Bericht ist nur ein Abstract-Auszug. Laut diesem sinkt der Erfolg bestehender Sprachmodell-Agenten bei kombinierten Webaufgaben deutlich; HTML-T5++ erzielt bessere Benchmarkwerte, verliert aber ebenfalls Leistung, wenn sich die Reihenfolge der Aufgaben ändert. Die Verfassenden betonen daher den Bedarf an robusterer Verallgemeinerung.
