# Machine Unlearning Doesn’t Do What You Think: Lessons for Generative AI Policy, Research, and Practice

Report Q005478 · Source deepmind.google · Date 2024-12-10 · [Open original](https://deepmind.google/research/publications/101479/)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Der vorliegende Text ist nur ein Auszug: Der Abstract argumentiert, dass maschinelles Unlearning weder das gezielte Entfernen von Trainingsinformationen noch die Unterdrückung bestimmter Ausgaben einfach oder allgemein zuverlässig löst. Er schlägt einen Rahmen vor, um die Grenzen solcher Verfahren klarer zu erfassen und die Verständigung zwischen ML, Recht und Politik zu verbessern; konkrete Methoden und Ergebnisse fehlen im Auszug.
