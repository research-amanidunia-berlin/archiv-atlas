# Long-form factuality in large language models

Report Q005417 · Source deepmind.google · Date 2024-03-27 · [Open original](https://deepmind.google/research/publications/85420/)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Der bereitgestellte Text ist ein Abstract: Er beschreibt LongFact als Fragenkatalog und SAFE als suchgestütztes Verfahren zur Prüfung einzelner Aussagen in langen Modellantworten. Laut den Forschenden erzielte SAFE in Vergleichen gute Übereinstimmung mit menschlichen Bewertungen und geringere Kosten; größere Modelle waren im Allgemeinen faktisch zuverlässiger. Der Auszug enthält keine detaillierten Versuchsangaben oder ausführliche Grenzendiskussion.
