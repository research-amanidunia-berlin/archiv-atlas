# Open-sourcing DeepMind Lab

Report Q003106 · Source deepmind.google · Date 2016-12-03 · [Open original](https://deepmind.google/blog/open-sourcing-deepmind-lab/)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

DeepMind kündigt DeepMind Lab als quelloffene 3D-Umgebung an, in der KI-Agenten aus visuellen Eingaben und Rückmeldungen Aufgaben wie Navigation, Gedächtnis und Erkundung lernen sollen. Die Autoren berichten von interner Nutzung und sehen großes Forschungspotenzial, legen aber keine konkreten Messwerte vor; die vermutete Bedeutung reichhaltiger 3D-Welten für allgemeine Intelligenz bleibt eine These.
