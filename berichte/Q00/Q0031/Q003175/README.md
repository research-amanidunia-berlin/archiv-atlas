# Introducing Anthropic's Transparency Hub

Report Q003175 · Source anthropic.com · Date 2025-02-27 · [Open original](https://www.anthropic.com/news/introducing-anthropic-transparency-hub)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Anthropic stellt einen Transparency Hub vor, der Informationen zu Sicherheitsprüfungen, Governance, Missbrauchsbekämpfung und weiteren Transparenzthemen bündeln soll. Der angekündigte erste regelmäßige Bericht umfasst unter anderem Kontosperren, Einsprüche, NCMEC-Meldungen und behördliche Anfragen, nennt im Artikel aber keine Zahlen.
