# Anthropic achieves ISO 42001 certification

Bericht Q003182 · Quelle anthropic.com · Datum 2025-01-13 · [Original öffnen](https://www.anthropic.com/news/anthropic-achieves-iso-42001-certification-for-responsible-ai)

[Alle Berichte](../../../README.de.md) · Daten: [bericht.json](bericht.json)

## Zusammenfassung (von Luna, ungeprüft)

Anthropic berichtet, eine akkreditierte ISO/IEC-42001-Zertifizierung für sein KI-Managementsystem erhalten zu haben; sie bestätige laut Unternehmen Verfahren für Risikomanagement, Tests, Transparenz und Aufsicht. Der Bericht nennt weder den genauen Prüfungsumfang noch konkrete Ergebnisse und stützt sich überwiegend auf Angaben von Anthropic.
