## Zusammenfassung (von Luna, ungeprüft)

Der vorliegende Berichtsauszug beschreibt einen Hoax auf X: Eine angebliche ChatGPT-Fehlermeldung über einen russischen Troll sei laut OpenAI manuell erstellt worden, während frühere konfrontative Beiträge desselben Kontos Modelle genutzt hätten. OpenAI sperrte sein Konto; der Hoax selbst verbreitete sich laut Bericht deutlich weniger als die Reaktionen darauf. Der Auszug endet mit einer abgeschnittenen Bildunterschrift.
