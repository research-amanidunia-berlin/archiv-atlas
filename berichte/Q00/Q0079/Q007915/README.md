# OpenAI co-founds Agentic AI Foundation, donates AGENTS.md

Report Q007915 · Source openai.com · Date 2025-12-09 · [Open original](https://openai.com/index/agentic-ai-foundation/)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Der Bericht kündigt die Agentic AI Foundation unter der Linux Foundation an, die offene Standards für KI-Agenten gemeinschaftlich betreuen soll. OpenAI will AGENTS.md beisteuern; Anthropic und Block sollen MCP beziehungsweise goose einbringen. Die Angaben zu Verbreitung und Wirkung beruhen auf OpenAIs Darstellung und werden im Bericht nicht unabhängig überprüft.
