# OpenAI’s comment to the NTIA on open model weights

Bericht Q007961 · Quelle openai.com · Datum 2024-03-27 · [Original öffnen](https://openai.com/global-affairs/openai-s-comment-to-the-ntia-on-open-model-weights/)

[Alle Berichte](../../../README.de.md) · Daten: [bericht.json](bericht.json)

## Zusammenfassung (von Luna, ungeprüft)

OpenAI spricht sich dafür aus, sowohl offene Gewichte als auch APIs und Produkte zu nutzen, und empfiehlt für besonders leistungsfähige Modelle risikobasierte Prüfungen und Gegenmaßnahmen. Das Unternehmen betont, dass die Bewertungsmethoden noch in Entwicklung und mögliche katastrophale Risiken unsicher sind; staatliche Regeln sollten daher flexibel bleiben.
