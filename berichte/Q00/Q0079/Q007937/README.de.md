# Bringing ChatGPT to GenAI.mil

Bericht Q007937 · Quelle openai.com · Datum 2026-02-09 · [Original öffnen](https://openai.com/index/bringing-chatgpt-to-genaimil/)

[Alle Berichte](../../../README.de.md) · Daten: [bericht.json](bericht.json)

## Zusammenfassung (von Luna, ungeprüft)

OpenAI kündigt eine angepasste ChatGPT-Version für nicht klassifizierte Aufgaben auf der staatlichen Plattform GenAI.mil an, etwa für Dokumente, Beschaffung, Recherche und Verwaltung. Das Unternehmen sagt, die Nutzung werde durch Schutzmaßnahmen abgesichert und Daten blieben von öffentlichen und kommerziellen Modellen getrennt; der Bericht liefert dafür keine unabhängige Prüfung oder Leistungsdaten.
