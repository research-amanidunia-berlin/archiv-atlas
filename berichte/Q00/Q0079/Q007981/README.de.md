# Using AI to help physicians diagnose rare genetic diseases affecting children

Bericht Q007981 · Quelle openai.com · Datum 2026-06-18 · [Original öffnen](https://openai.com/index/diagnose-rare-childhood-diseases/)

[Alle Berichte](../../../README.de.md) · Daten: [bericht.json](bericht.json)

## Zusammenfassung (von Luna, ungeprüft)

In einer rückblickenden Studie lieferte ein KI-Modell für 376 zuvor ungelöste Fälle Hinweise, die nach fachlicher Prüfung und Bestätigung zu 18 Diagnosen führten (4,8 Prozent). Das Modell stellte selbst keine Diagnosen; Nutzen, Aufwand und Auswirkungen auf die Versorgung wurden nicht gemessen, und die Forschenden sehen weitere prospektive Untersuchungen als nötig an.
