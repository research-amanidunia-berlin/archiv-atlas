# Interpreting Deep Neural Networks using Cognitive Psychology

Bericht Q003393 · Quelle deepmind.google · Datum 2017-06-27 · [Original öffnen](https://deepmind.google/blog/interpreting-deep-neural-networks-using-cognitive-psychology/)

[Alle Berichte](../../../README.de.md) · Daten: [bericht.json](bericht.json)

## Zusammenfassung (von Luna, ungeprüft)

Die Autoren berichten, dass Matching Networks und ein Inception-Modell bei einem psychologischen Form-Bias-Experiment eher nach Objektform als nach Farbe zuordneten. Sie führen außerdem Unterschiede zwischen Trainingsläufen und gleich gute One-shot-Leistung trotz unterschiedlich starker Formverzerrung an; der Bericht enthält dazu keine vollständigen numerischen Ergebnisse.
