# Going beyond average for reinforcement learning

Bericht Q003367 · Quelle deepmind.google · Datum 2017-07-24 · [Original öffnen](https://deepmind.google/blog/going-beyond-average-for-reinforcement-learning/)

[Alle Berichte](../../../README.de.md) · Daten: [bericht.json](bericht.json)

## Zusammenfassung (von Luna, ungeprüft)

Der Bericht beschreibt ein Reinforcement-Learning-Verfahren, das die Verteilung möglicher Erträge statt nur ihres Durchschnitts modelliert. Laut den Autoren lernte ein entsprechend angepasstes Atari-DQN schneller und erzielte bessere Ergebnisse; die Beispiele zeigen zugleich Grenzen der Vorhersagbarkeit durch unvollständige Beobachtung und eigenes Agentenverhalten.
