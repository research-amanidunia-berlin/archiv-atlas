## Summary (German, by Luna, unchecked)

Der Bericht stellt Population Based Training (PBT) vor: Mehrere neuronale Netze werden parallel trainiert, wobei schwächere Modelle Einstellungen erfolgreicherer übernehmen und zugleich neue Hyperparameter erkunden können.
