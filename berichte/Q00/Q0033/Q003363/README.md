# Apple’s Xcode now supports the Claude Agent SDK

Report Q003363 · Source anthropic.com · Date 2026-02-03 · [Open original](https://www.anthropic.com/news/apple-xcode-claude-agent-sdk)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Anthropic zufolge bringt Xcode 26.3 das Claude Agent SDK in die Entwicklungsumgebung und soll damit längere, selbstständig ausgeführte Programmieraufgaben samt Preview-Prüfung, Projektanalyse und MCP-Zugriff ermöglichen. Die Release-Candidate-Version sei für Mitglieder des Apple Developer Program verfügbar; unabhängige Belege für die behaupteten Vorteile oder nähere Angaben zu Grenzen enthält die Ankündigung nicht.
