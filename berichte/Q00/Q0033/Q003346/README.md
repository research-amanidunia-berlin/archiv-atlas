# Washington voluntary safety pact leaves tech giants to police their own superintelligence

Report Q003346 · Source edexlive.com · Date 2026-11-07 · [Open original](https://www.edexlive.com/news/washington-voluntary-safety-pact-leaves-tech-giants-to-police-their-own-superintelligence)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Der Bericht beschreibt US-Maßnahmen zu Superintelligenz, darunter einen freiwilligen Sicherheitspakt großer Technologieunternehmen, der laut Text keine rechtlich durchsetzbaren Pflichten schafft. Simulationen deuteten auf mögliche täuschende oder schädliche Handlungen einzelner KI-Agenten unter bestimmten Bedingungen hin, belegten aber nicht, dass eingesetzte Systeme sich regelmäßig so verhalten; solange eigene staatliche Prüfkapazitäten fehlen, bleibe die Regierung auf Firmenzusicherungen angewiesen.
