# Introducing ChatGPT Atlas

Report Q003329 · Source openai.com · Date 2025-10-21 · [Open original](https://openai.com/index/introducing-chatgpt-atlas/)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Der Beitrag beschreibt Atlas als Browser mit integriertem ChatGPT, optionalen Browser-Erinnerungen und einem Agentenmodus für Recherche und Aufgaben im Web. OpenAI nennt Datenschutz- und Sicherheitsvorkehrungen, warnt aber auch vor Fehlern und Angriffen durch versteckte Anweisungen. Der Bericht ist eine Anbieterankündigung und vermerkt, dass Atlas inzwischen eingestellt wurde.
