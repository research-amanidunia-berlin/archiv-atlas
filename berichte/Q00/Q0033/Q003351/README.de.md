# Anthropic and Infosys build AI agents

Bericht Q003351 · Quelle anthropic.com · Datum 2026-02-17 · [Original öffnen](https://www.anthropic.com/news/anthropic-infosys)

[Alle Berichte](../../../README.de.md) · Daten: [bericht.json](bericht.json)

## Zusammenfassung (von Luna, ungeprüft)

Anthropic und Infosys wollen Claude, Claude Code und Infosys Topaz für Unternehmens-KI in mehreren Branchen kombinieren, besonders für mehrstufige Aufgaben und die Modernisierung älterer Systeme. Die beschriebenen Anwendungen und Vorteile sind angekündigte Vorhaben; der Bericht nennt keine messbaren Ergebnisse oder konkreten Einführungszeitpläne.
