# Open-sourcing Psychlab

Report Q003300 · Source deepmind.google · Date 2018-01-26 · [Open original](https://deepmind.google/blog/open-sourcing-psychlab/)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

DeepMind stellt Psychlab als offene Plattform vor, mit der künstliche Agenten und Menschen dieselben kontrollierten, psychologischen Aufgaben bearbeiten können. In einem Suchtest zeigte ein moderner Agent laut Bericht ein anderes Reaktionszeitmuster als Menschen; die Autoren sehen darin einen Hinweis auf Unterschiede bei der Aufmerksamkeit, nicht jedoch einen umfassenden Nachweis über alle Fähigkeiten künstlicher Agenten.
