## Zusammenfassung (von Luna, ungeprüft)

Der Autor zeigt anhand von Swift-Code, wie SwiftSwarm Agentenrollen definiert und einen laufenden Chat vom Engineer- an einen Designer-Agenten übergibt. Laut Bericht nutzt die Bibliothek die Chat Completions API und ist zwischen Aufrufen zustandslos; Gesprächsverlauf und Chat-Oberfläche sind nicht Teil der gezeigten Beispiele.
