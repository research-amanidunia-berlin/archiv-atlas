## Zusammenfassung (von Luna, ungeprüft)

Der Autor stellt ein nicht offizielles Swift-Paket vor, das Amazon Bedrock mit Apples Foundation Models Framework verbinden soll und unter anderem Streaming, Tool-Aufrufe, Caching, Anhänge und Zitate unterstützt. Bedrocks Einschränkungen bei strukturierten Ausgaben bleiben bestehen; weitere Funktionen wie automatische Bildkomprimierung werden lediglich als mögliche Ergänzungen genannt.
