## Zusammenfassung (von Luna, ungeprüft)

Der Beitrag führt anhand von SwiftAnthropic vor, wie iOS-Apps Claudes Messages-API für vollständige oder gestreamte Antworten nutzen können, und empfiehlt im dargestellten API-Angebot Messages gegenüber Text Completions. Die Beispiele erläutern Anfrageparameter, Antwortfelder und das Zusammensetzen gestreamter Textteile; der Autor nennt als damalige Zugangshürde einen API-Schlüssel über eine Warteliste.
