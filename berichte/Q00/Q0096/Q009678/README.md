## Summary (German, by Luna, unchecked)

Itsuki nutzt KI nicht zum Schreiben von Code, sondern lässt damit eigene technische Entscheidungen und Entwürfe prüfen, Varianten vergleichen und mögliche Gegenargumente finden. Sie berichtet von einem Beispiel, in dem Claude Code beim UI-Refactoring wichtige Abläufe entfernte, und betont, dass die Freude am Programmieren für sie wichtiger ist als der Einsatz von KI.
