# SwiftUI: Is My Toolbar Button Overflowing?

## Zusammenfassung (von Luna, ungeprüft)

Der Autor schildert, dass lange Beschriftungen in vertikalen SwiftUI-Toolbars mit „Glass“ oder „GlassProminent“ überlaufen können und gängige Wege zur Erkennung der Toolbar-Kante für ihn nicht zuverlässig waren. Sein Beispiel misst den verfügbaren Platz mit `GeometryReader`, schätzt die Inhaltsgröße separat und kann bei Überlauf eine Ersatzansicht einsetzen; die Textkürzung ist ausdrücklich nur eine Demonstration.
