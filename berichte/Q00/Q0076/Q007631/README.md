## Summary (German, by Luna, unchecked)

OpenAI behauptet, ein internes KI-System habe bewiesen, dass eine glatte dreidimensionale Flüssigkeitsströmung unter bestimmten Bedingungen in endlicher Zeit eine Singularität entwickeln kann, und verweist auf eine Lean-Formalisierung. Laut Bericht arbeiteten rund 10.000 Agenten an der Lösung; der Text enthält den Beweis jedoch nicht und dokumentiert keine unabhängige Bestätigung.
