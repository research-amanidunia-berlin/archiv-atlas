# Launching Health in ChatGPT

Report Q007628 · Source openai.com · Date 2026-07-23 · [Open original](https://openai.com/index/health-in-chatgpt/)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

OpenAI führt „Health in ChatGPT“ für eingeloggte Erwachsene in den USA auf Web und iOS ein. Mit Zustimmung können verbundene Apple-Health- und ausgewählte Krankenaktendaten in Antworten einfließen; laut OpenAI werden diese Daten nicht für Modelltraining oder gezielte Werbung genutzt. Der Bericht weist darauf hin, dass ChatGPT Fehler machen kann, keine medizinische Versorgung ersetzt und verbundene Angaben unvollständig oder veraltet sein können.
