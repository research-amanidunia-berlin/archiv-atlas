# Developers can now submit apps to ChatGPT

Bericht Q007611 · Quelle openai.com · Datum 2025-12-17 · [Original öffnen](https://openai.com/index/developers-can-now-submit-apps-to-chatgpt/)

[Alle Berichte](../../../README.de.md) · Daten: [bericht.json](bericht.json)

## Zusammenfassung (von Luna, ungeprüft)

OpenAI kündigt Einreichungen für ChatGPT-Apps und ein Verzeichnis zu ihrer Entdeckung an. Der Bericht beschreibt Entwicklungs-, Prüf-, Datenschutz- und Monetarisierungsregeln sowie geplante Funktionen, liefert jedoch keine unabhängige Bewertung ihrer Umsetzung oder Wirkung.
