# Donating another $20 million to Public First Action

Report Q005195 · Source anthropic.com · Date 2026-07-21 · [Open original](https://www.anthropic.com/news/donation-public-first-action)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Anthropic kündigt eine zusätzliche Spende von 20 Millionen Dollar an Public First Action an und verbindet sie mit Forderungen nach strengeren staatlichen Sicherheitsregeln, Prüfungen und Exportkontrollen für fortgeschrittene KI. Als Begründung nennt das Unternehmen mögliche Gefahren leistungsfähiger Modelle und zugleich deren medizinisches, wissenschaftliches und wirtschaftliches Potenzial; die Darstellung ist Anthropics eigene politische Position und wird im Text nicht unabhängig überprüft.
