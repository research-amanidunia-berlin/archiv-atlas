# System Re-engineering

Report Q005173 · Source cset.georgetown.edu · Date 2020-09-22 · [Open original](https://cset.georgetown.edu/publication/system-re-engineering/)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Der Auszug fordert, die US-amerikanische FuE-Politik an ein vielfältigeres und global vernetztes Forschungssystem anzupassen. Er empfiehlt unter anderem eine koordinierende Rolle des OSTP, globale FuE-Beobachtung, eine Infrastruktur- und Lückenanalyse sowie neue Kooperationen mit Verbündeten; detaillierte Methodik und Ergebnisse enthält der Auszug nicht.
