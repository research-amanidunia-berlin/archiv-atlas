# An Impossibility Theorem in Game Dynamics

## Summary (German, by Luna, unchecked)

Der bereitgestellte Bericht ist nur der Abstract eines Artikels. Die Autorinnen und Autoren berichten, dass es Spiele gibt, bei denen keine deterministische Spieldynamik von jedem Startzustand aus zu einem Nash-Gleichgewicht konvergiert; der Beweis betrifft degenerierte Spiele, während die entsprechende Aussage für nichtdegenerierte Spiele nur vermutet wird. Auch für bestimmte Näherungen von Nash-Gleichgewichten beschreiben sie eine Unmöglichkeit und folgern, dass Gleichgewichte langfristiges Verhalten nicht vollständig vorhersagen.
