# METR Finds Anthropic's AI-Assisted R&D Moving Twice as Fast

Report Q005118 · Source alphasignal.ai · Date 2026-11-05 · [Open original](https://alphasignal.ai/news/metr-finds-anthropic-s-ai-assisted-r-d-moving-twice-as-fast)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

METR schätzt, dass Anthropic seine Modelle auf klar definierten Aufgaben seit Oktober 2025 ungefähr doppelt so schnell verbessert; als wichtigen Treiber nennt die Untersuchung KI-Unterstützung in der Forschung. Die Schätzung bleibt unsicher, unter anderem wegen redigierter Belege, begrenzter Messbarkeit und eines Benchmarks, der komplexe Produktionsarbeit nur teilweise abbildet.
