## Zusammenfassung (von Luna, ungeprüft)

Der Auszug beschreibt Michelangelo, eine Evaluation für das Schlussfolgern über lange Kontexte, die mit LSQ das Erkennen verborgener Strukturen statt bloßen Faktenabrufs prüfen soll. Die Verfassenden berichten von drei Tests für Code und natürliche Sprache sowie aussagekräftigen Ergebnissen, sehen aber weiteren Verbesserungsbedarf; konkrete Daten und Versuchsdetails fehlen im Auszug.
