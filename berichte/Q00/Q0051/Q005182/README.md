# Shaping the Terrain of AI Competition

Report Q005182 · Source cset.georgetown.edu · Date 2020-06-02 · [Open original](https://cset.georgetown.edu/publication/shaping-the-terrain-of-ai-competition/)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Der Text ist ein Auszug aus der Executive Summary von Tim Hwangs Bericht, nicht der vollständige Bericht. Hwang empfiehlt, KI-Forschung strategisch so zu fördern, dass Demokratien weniger Trainingsdaten benötigen, demokratische Werte wie Datenschutz und Fairness besser berücksichtigen und ML für Überwachung und soziale Kontrolle weniger nützlich machen können; der Auszug enthält keine konkreten Wirksamkeitsnachweise.
