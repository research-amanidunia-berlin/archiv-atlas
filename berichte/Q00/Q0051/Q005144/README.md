# Banned in D.C.

Report Q005144 · Source cset.georgetown.edu · Date 2022-10-26 · [Open original](https://cset.georgetown.edu/publication/banned-in-d-c/)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Der Bericht argumentiert, dass US-Bundesregeln gegen bestimmte ausländische ICTS bisher nicht verlässlich auf staatliche und kommunale Beschaffung durchschlagen. Laut einer GovSpend-Auswertung kauften mindestens 1.681 lokale Stellen zwischen 2015 und 2021 Technik, die auf Bundesebene verboten war. Die vorliegende Quelle ist nur die Executive Summary; der Autor fordert eine koordinierte Umsetzung unter Führung des Bundes.
