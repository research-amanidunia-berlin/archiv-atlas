# Tino Cuéllar joins as Chief Global Affairs Officer

Report Q005107 · Source anthropic.com · Date 2026-08-04 · [Open original](https://www.anthropic.com/news/tino-cuellar)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Anthropic kündigt Tino Cuéllar als ersten Chief Global Affairs Officer an. Er soll weltweit die politische Arbeit und Regierungsbeziehungen des Unternehmens führen; zuvor hatte er unter anderem Spitzenämter in Wissenschaft und öffentlichen Institutionen sowie ein Richteramt in Kalifornien inne. Für den Wechsel ist er aus dem Long-Term Benefit Trust von Anthropic ausgeschieden; konkrete Arbeitspläne nennt der Beitrag nicht.
