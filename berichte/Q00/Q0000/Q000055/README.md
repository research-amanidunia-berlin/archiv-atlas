# Moonshot Limits Kimi Model’s Hacking Capabilities

Report Q000055 · Source stratnewsglobal.com · Date 2026-10-24 · [Open original](https://stratnewsglobal.com/technology/moonshot-kimi-model-hacking-capabilities-ai-cyberattacks/)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Moonshot AI sagt, es habe die offensiven Cyberfähigkeiten von Kimi K3.1 Pro durch das Entfernen cybersicherheitsbezogener Trainingsdaten verringert und dabei die allgemeinen Programmierfähigkeiten erhalten. Ein interner Benchmark fiel laut Unternehmen von 90,5 auf 81 Prozent; der Bericht weist darauf hin, dass die Ergebnisse nicht unabhängig geprüft wurden. Zugleich beschreibt er Sicherheitsnutzen und Aufsichtsprobleme offener Modellgewichte sowie mögliche Exportkontrollen in China.
