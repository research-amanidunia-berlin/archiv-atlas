# Developing Safety Standards Is Not Inherently Anticompetitive

Report Q000096 · Source itif.org · Date 2026-10-02 · [Open original](https://itif.org/publications/2026/10/02/developing-safety-standards-is-not-inherently-anticompetitive/)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

Der Beitrag argumentiert, freiwillige KI-Sicherheitsstandards seien nicht schon deshalb wettbewerbswidrig, weil Wettbewerber sie gemeinsam entwickeln oder damit das Entwicklungstempo beeinflussen. Die Autoren sehen den entscheidenden Maßstab darin, ob die Zusammenarbeit den Wettbewerb tatsächlich beschränkt; die gegen vier KI-Unternehmen erhobenen Vorwürfe seien damit nicht bewiesen. Sie plädieren dafür, legitime Sicherheitskooperation zuzulassen, legen aber keine konkreten Standards fest.
