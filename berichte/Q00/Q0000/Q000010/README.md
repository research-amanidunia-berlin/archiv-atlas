# On-Device AI Against Scams: Google DeepMind & MDDI

Report Q000010 · Source deepmind.google · Date 2026-10-14 · [Open original](https://deepmind.google/blog/on-device-ai-scam-detection-mddi/)

## Summary (German, by Luna, unchecked)

Google DeepMind und GovTech Singapore beschreiben ein zweistufiges, lokal auf Smartphones laufendes System, das verdächtige Gespräche erkennen und vor möglichen Betrugsversuchen warnen soll. Laut Bericht wurden anonymisierte Daten zum Training genutzt und eine Android-Beta von Anti-Scam Pango gestartet; Messwerte zu Erkennungsleistung, Fehlalarmen oder vermiedenen Schäden nennt der Text nicht.
