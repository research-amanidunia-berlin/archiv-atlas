# Work at the Frontier: AI’s effect on freelance work

Report Q000006 · Source openai.com · Date 2026-11-10 · [Open original](https://openai.com/index/ai-effect-on-freelance-work)

[All reports](../../../README.md) · Data: [bericht.json](bericht.json)

## Summary (German, by Luna, unchecked)

OpenAI und Upwork berichten, dass sich Freelance-Nachfrage und Projektzuschnitte mit wachsender KI-Nutzung verändern könnten: KI-bezogene Ausschreibungen verbinden häufiger unterschiedliche Aufgaben und weisen höhere Festpreisbudgets sowie mehr erfasste Arbeitsstunden auf, während Stundenlöhne ähnlich bleiben. Die Muster unter den 63 verglichenen Kategorien sind jedoch uneinheitlich; der Plattformvergleich belegt weder eine einfache Verdrängung noch eine Ursache-Wirkung-Beziehung.
